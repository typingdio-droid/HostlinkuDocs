Hostlinku menyediakan gateway API yang kompatibel dengan OpenAI, Anthropic, dan Responses API. Gunakan satu API key untuk mengakses katalog model dari berbagai provider.

## Yang bisa Anda lakukan

- Memanggil model lewat `/v1/chat/completions`, `/v1/messages`, dan `/v1/responses`.
- Mengatur Service Mode: Performance atau Low-Cost.
- Memantau penggunaan, biaya, dan log request dari Console.
