[Codex CLI](https://developers.openai.com/codex/cli) memakai protokol OpenAI Responses. Arahkan provider kustom ke [`POST /v1/responses`](/responses); kecocokan tool dan reasoning bergantung pada model dan jalur Responses yang digunakan.

<Steps>

### Instal Codex CLI

```bash
npm install -g @openai/codex
# atau: brew install codex
```

### Tambahkan provider Hostlinku

Edit `~/.codex/config.toml` (buat bila belum ada). Provider **harus** didefinisikan di file
pengguna ini - `.codex/config.toml` di dalam proyek tidak boleh menimpa `model_providers` demi
keamanan.

```toml
model = "gpt-5-3-codex"
model_provider = "hostlinku"
model_reasoning_effort = "medium"

[model_providers.hostlinku]
name = "Hostlinku"
base_url = "https://api.hostlinku.com/v1"
env_key = "HOSTLINKU_API_KEY"
wire_api = "responses"
```

### Set API key dan jalankan

```bash
export HOSTLINKU_API_KEY=sk-your-api-key   # simpan di ~/.zshrc / ~/.bashrc
codex
```

Codex membaca key dari variabel yang disebut di `env_key`; key tidak pernah ditulis ke
`config.toml`.

<Callout type="tip" title="Ingin kelola lewat GUI dengan satu klik?">
  Gunakan aplikasi desktop [CC Switch](/integrations/cc-switch) untuk menambahkan dan berpindah
  provider/model Codex tanpa mengedit `config.toml` secara manual.
</Callout>

### Verifikasi

Kirim satu instruksi sederhana (mis. *"jelaskan struktur repo ini"*). Request akan tampil di
console → **Log Permintaan** dengan model `gpt-5-3-codex`. Bila ingin memastikan endpoint sebelum
membuka Codex:

```bash
curl https://api.hostlinku.com/v1/responses \
  -H "Authorization: Bearer $HOSTLINKU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "gpt-5-3-codex", "input": "Halo" }'
```

</Steps>

## Beberapa model lewat profil

`cepat` dan `kuat` adalah nama contoh yang bebas kamu pilih, bukan profil bawaan Codex atau Hostlinku. Nama profil boleh berisi huruf, angka, tanda hubung, dan garis bawah.

Codex membaca `~/.codex/config.toml`. Saat kamu menjalankan `--profile <nama>`, Codex juga membaca `~/.codex/<nama>.config.toml`. Buat file terpisah untuk setiap profil, dengan pengaturan di tingkat utama; jangan gunakan bagian `[profiles.*]`. Lihat [panduan profil resmi Codex](https://developers.openai.com/codex/config-advanced/#profiles).

File `~/.codex/cepat.config.toml`:

```toml
model = "gpt-5-6-luna"
model_provider = "hostlinku"
model_reasoning_effort = "low"
```

File `~/.codex/kuat.config.toml`:

```toml
model = "gpt-6-astra"
model_provider = "hostlinku"
```

Provider `hostlinku` tetap didefinisikan di `~/.codex/config.toml`. Pilih profil saat menjalankan Codex:

```bash
codex --profile kuat
codex --profile cepat "tulis unit test untuk utils/date.ts"
```

<Callout type="warning" title="Kompatibilitas model dan tool">
  Gunakan model OpenAI/GPT yang mendukung tool versi Codex kamu. Pada Service Mode Performance dan Low-Cost, Codex tidak mendukung model Claude maupun model domestik seperti DeepSeek, Qwen, GLM, Kimi, MiniMax, dan MiMo. Bridge Chat Completions mendukung teks dan function calling; custom tools shell/patch serta reasoning terenkripsi memerlukan dukungan native. Jika muncul `The requested tool type is not supported by this model`, ganti ke model OpenAI/GPT atau gunakan Claude Code/Chat untuk model lain. Untuk Dedicated, dukungan tool mengikuti model dan deployment; uji sebelum produksi. Lihat [Responses API](/responses).
</Callout>

<Callout type="note" title="Stateless">
  Kirim riwayat penuh dalam `input` dan gunakan `store: false`. Hostlinku menolak `previous_response_id` atau `conversation` non-null dan `background: true`. Item reasoning terenkripsi hanya dapat dipakai bila jalur upstream mendukungnya; lihat [Responses API](/responses).
</Callout>

<Callout type="tip" title="Hanya ingin mengganti endpoint OpenAI bawaan?">
  Alternatif tanpa provider baru: set `openai_base_url = "https://api.hostlinku.com/v1"` di
  `config.toml` dan `OPENAI_API_KEY=sk-…` (API key Hostlinku). Provider kustom tetap disarankan
  karena namanya jelas di UI dan key-nya terpisah dari key OpenAI asli.
</Callout>

## Troubleshooting

- **`401`** - variabel di `env_key` belum ter-export di shell tempat `codex` dijalankan.
- **Tool shell/patch tidak berjalan** — periksa dukungan tool pada model dan jalur Responses; jawaban teks saja tidak membuktikan tool telah dijalankan.
- **`400 previous_response_id`** — hilangkan `previous_response_id`/`conversation`, kirim ulang riwayat penuh dalam `input`, dan gunakan `store: false`.
- **Model tidak muncul / `404`** - slug salah; `/v1/models` menampilkan daftar yang valid untuk
  key kamu.
- **Versi klien lama** — perbarui Codex dan gunakan `wire_api = "responses"` sesuai [referensi konfigurasi resmi](https://developers.openai.com/codex/config-reference/).
