[GitHub Copilot](https://docs.github.com/en/copilot) mendukung **BYOK (Bring Your Own Key)** di
beberapa permukaan. Di tempat yang menerima *base URL* sendiri, kamu bisa mengarahkannya ke
Hostlinku dan memakai model dari katalog dengan saldo Hostlinku.

| Permukaan Copilot | Bisa diarahkan ke Hostlinku? | Panduan |
|---|---|---|
| **Copilot CLI** (`copilot`) | Ya - environment variable `COPILOT_PROVIDER_*` | [di bawah](#copilot-cli) |
| **GitHub Copilot app** (desktop) | Ya - *Settings → Model providers* (public preview) | [di bawah](#github-copilot-app) |
| **Copilot Chat di VS Code** | Ya - provider *Custom Endpoint* | [VS Code](/integrations/vscode) |
| Copilot di JetBrains, Visual Studio, Xcode; autocomplete inline | Tidak - tidak ada pengaturan base URL | [Batasan](#batasan) |

## Copilot CLI

Saat variabel BYOK di-set, Copilot CLI mengirim semua request model ke provider kamu. **Login
GitHub tidak wajib** untuk mode ini.

<Steps>

### Set environment variable

```bash
export HOSTLINKU_API_KEY=sk-your-api-key   # API key Hostlinku
export COPILOT_PROVIDER_BASE_URL=https://api.hostlinku.com/v1
export COPILOT_PROVIDER_API_KEY="$HOSTLINKU_API_KEY"
export COPILOT_MODEL=claude-sonnet-4-6
```

`COPILOT_PROVIDER_TYPE` default-nya `openai` (Chat Completions), jadi tidak perlu di-set. Copilot
menambahkan `/chat/completions` sendiri - base URL cukup sampai `/v1`.

### (Disarankan) Beri tahu batas token model

Copilot CLI tidak mengenal slug Hostlinku, jadi isi batasnya dari [katalog](/models) agar
konteks dipangkas dengan benar:

```bash
export COPILOT_PROVIDER_MAX_PROMPT_TOKENS=1000000
export COPILOT_PROVIDER_MAX_OUTPUT_TOKENS=64000
```

Periksa apakah key sudah terisi di shell yang sama sebelum menjalankan `copilot`, tanpa mencetak nilainya:

```bash
test -n "$COPILOT_PROVIDER_API_KEY" && echo "API key tersedia" || echo "API key belum diatur"
```

### Jalankan

```bash
copilot
# atau ganti model per sesi
copilot --model gpt-5-5
```

Request pertama tampil di console → **Log Permintaan**.

</Steps>

### Varian: format Anthropic

Untuk model Claude lewat Messages API (prompt caching penuh), pakai provider `anthropic` dengan base
URL **tanpa** `/v1`:

```bash
export COPILOT_PROVIDER_TYPE=anthropic
export COPILOT_PROVIDER_BASE_URL=https://api.hostlinku.com
export COPILOT_PROVIDER_API_KEY="$HOSTLINKU_API_KEY"
export COPILOT_MODEL=claude-sonnet-4-6
```

<Callout type="note" title="Model wajib mendukung tool calling dan streaming">
  Copilot CLI membutuhkan *tool calling* dan *streaming*, serta menyarankan konteks minimal 128K token. Periksa ketiganya di [katalog](/models) sebelum memilih model.
</Callout>

- **Gunakan format API yang sesuai dengan tool dan model.** Chat Completions adalah default provider `openai`; batas Responses dijelaskan di [referensi Responses](/responses).
- **Tanpa login GitHub**, fitur yang bergantung pada server GitHub (`/delegate`, GitHub MCP server,
  code search) tidak tersedia. Login dengan `copilot login` bila butuh fitur itu - request model
  tetap ke Hostlinku.
- **`COPILOT_OFFLINE=true`** mematikan semua koneksi ke GitHub (termasuk telemetri). Prompt tetap
  dikirim ke `api.hostlinku.com`.

## GitHub Copilot app

Aplikasi desktop GitHub Copilot mendukung provider model sendiri (public preview). Kamu tetap
perlu login GitHub, tetapi **tidak butuh paket Copilot** bila hanya memakai provider sendiri.

<Steps>

### Tambah provider

Buka app settings → **Model providers** → **Add provider** → pilih **OpenAI-compatible**.

### Isi detail provider

| Field | Nilai |
|---|---|
| **Display name** | `Hostlinku` |
| **Base URL** | `https://api.hostlinku.com/v1` |
| **API key** | `sk-…` (API key Hostlinku) |

Klik **Add provider**. Key disimpan di credential store sistem operasi.

### Pilih model per sesi

Model Hostlinku muncul di model picker di samping model GitHub. Pilih salah satu saat memulai
sesi agent.

</Steps>

Untuk model Claude, kamu juga bisa memilih provider **Anthropic** dan mengisi base URL
`https://api.hostlinku.com` (tanpa `/v1`) - tersedia bila form provider menampilkan kolom base URL.

## Batasan

- **Copilot di JetBrains, Visual Studio, dan Xcode** tidak punya pengaturan base URL atau provider
  kustom per pengguna. Di JetBrains, pakai [JetBrains AI Assistant](/integrations/jetbrains)
  atau [Junie CLI](/integrations/junie) untuk model Hostlinku.
- **Autocomplete inline (ghost text)** di semua editor selalu memakai infrastruktur Copilot. BYOK
  hanya berlaku untuk chat dan agent.
- **Copilot Business/Enterprise:** admin organisasi harus mengizinkan BYOK (dan Copilot CLI untuk
  Copilot app) di pengaturan kebijakan Copilot.

## Troubleshooting

| Gejala | Solusi |
|---|---|
| `401` | `COPILOT_PROVIDER_API_KEY` kosong atau salah di shell yang menjalankan `copilot`. Gunakan pemeriksaan di atas untuk memastikan key terisi; salin ulang dari console jika masih ditolak. |
| `404` di semua request | Provider `openai` tanpa `/v1`, atau provider `anthropic` dengan `/v1`. |
| `404 model_not_found` | `COPILOT_MODEL` harus slug persis dari `GET /v1/models`. |
| Error model tidak mendukung tool calling | Ganti ke model ber-*tool calling* dari [katalog](/models). |
| Masih memakai model GitHub | Variabel di-export di shell lain - jalankan `copilot` dari shell yang sama atau tambahkan ke `~/.zshrc`. |
