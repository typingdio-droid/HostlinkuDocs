[Cursor](https://cursor.com) mengizinkan API key sendiri dengan *Override OpenAI Base URL*.
Dengan mengarahkannya ke Hostlinku, chat, Cmd-K (inline edit), dan Agent memakai model dari
katalog Hostlinku dan dibebankan ke saldo kamu, bukan kuota Cursor.

<Steps>

### Buka pengaturan model

`Cursor Settings` (⌘/Ctrl + Shift + J) → tab **Models**.

### Isi API key dan base URL

Di bagian **API Keys**:

1. Aktifkan **OpenAI API Key** dan tempel API key Hostlinku (`sk-…`).
2. Aktifkan **Override OpenAI Base URL** dan isi:

```text
https://api.hostlinku.com/v1
```

![Cursor Settings → Models: kolom Override OpenAI Base URL berisi https://api.hostlinku.com/v1](/images/integrations/cursor-openai-base-url.jpg "Kolom Override OpenAI Base URL diisi https://api.hostlinku.com/v1, lalu klik Save.")

Jangan tambahkan `/chat/completions` di belakangnya — Cursor menambahkan path-nya sendiri. Klik
**Save**, lalu **Verify** di samping kolom API key; Cursor mengirim satu request uji ke gateway.

### Tambahkan model Hostlinku

Masih di tab **Models** → **Add Custom Model**, masukkan slug persis dari
[katalog](/models), satu per satu:

```text
claude-sonnet-4-6
gpt-5-5
deepseek-v4-flash
```

Nonaktifkan model bawaan yang tidak ingin kamu pakai agar daftar pemilih model tetap ringkas.

### Pilih model di chat

Di panel Chat/Agent, pilih model yang baru ditambahkan dari dropdown model. Request pertama akan
muncul di console → **Log Permintaan**.

</Steps>

## Yang perlu diketahui

<Callout type="warning" title="Override bersifat global">
  Selama **Override OpenAI Base URL** aktif, semua model keluarga OpenAI di Cursor — termasuk yang
  dikelola Cursor — ikut dialihkan ke Hostlinku. Pakai slug Hostlinku untuk semuanya, atau matikan
  toggle override saat ingin kembali ke model bawaan Cursor.
</Callout>

- **Request dikirim dari server Cursor**, bukan dari komputer kamu. Karena itu base URL harus
  publik — `https://api.hostlinku.com` memenuhi syarat ini (alamat `localhost` ditolak Cursor).
- **Cursor Tab (autocomplete) tidak terpengaruh.** Fitur Tab memakai infrastruktur khusus Cursor dan
  tidak bisa dialihkan ke provider mana pun. Hostlinku melayani chat, Cmd-K, dan Agent.
- **Agent mode** memerlukan model dengan *tool calling* dan *streaming* — semua model yang
  direkomendasikan di [Ikhtisar](/integrations) memenuhinya. Bila Agent menolak dengan
  *BAD_MODEL_NAME*, periksa kembali slug dan pastikan toggle **OpenAI API Key** aktif.
- **Koneksi menggantung / error protokol** — di pengaturan yang sama, ubah *HTTP Compatibility
  Mode* ke **HTTP/1.1**.

<Callout type="tip" title="Model Claude lewat jalur OpenAI">
  Kamu tidak perlu mengisi kolom *Anthropic API Key*. Slug `claude-sonnet-4-6` dipanggil lewat jalur
  OpenAI Chat Completions yang sama; gateway yang menerjemahkan ke protokol Anthropic.
</Callout>

## Troubleshooting

| Gejala | Solusi |
|---|---|
| *Verify* gagal `401` | API key salah/dicabut, atau ada spasi ikut tersalin. |
| *Model not found* | Slug salah ketik — salin dari `GET /v1/models`. |
| Jawaban terpotong | Model punya batas output lebih kecil dari yang diminta Cursor; coba model lain atau Service Mode berbeda. |
| Agent berhenti di tengah dengan `429` | Agent mengirim banyak request paralel. Lihat [Pemakaian & Limit](/usage-and-limits). |
