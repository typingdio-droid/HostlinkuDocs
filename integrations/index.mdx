## Batas kompatibilitas

- **Format URL berbeda per tool.** SDK Anthropic umumnya memakai `https://api.hostlinku.com`; tool OpenAI memakai `https://api.hostlinku.com/v1`. VS Code dan Junie dapat meminta URL endpoint penuh. Ikuti panduan tool di tabel.
- **Codex CLI memerlukan dukungan tool native Responses**, termasuk shell dan `apply_patch`. Bridge teks/function calling saja belum cukup; lihat [Codex CLI](/integrations/codex-cli).
- **Fitur mengikuti model dan protokol.** Periksa dukungan vision, reasoning, JSON schema, dan tool calling di halaman model serta [referensi API](/api-reference).
- **FIM/autocomplete inline dan embeddings belum dilayani.** Integrasi ini memakai chat, agent, atau edit melalui Chat Completions, Responses, dan Messages.

## API key dan bantuan

Buat API key terpisah per tool dengan limit kredit agar mudah dicabut. Simpan key dalam environment variable atau secret store tool; jangan commit atau cetak nilainya. Pengaturan key dijelaskan di [Autentikasi](/authentication).

Untuk kegagalan request, lihat [daftar kode error](/faqs/errors). Detail konfigurasi dan batas khusus setiap tool ada pada panduan di tabel.
