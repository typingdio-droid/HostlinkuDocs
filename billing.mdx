Hostlinku memakai kredit prabayar. **1 <CreditIcon /> = $1**. Saldo organisasi dipakai bersama oleh API key yang terkait dan merupakan kredit layanan. Pengembalian mengikuti [Refund Policy](/legals/refund-policy).

## Isi saldo

1. Buka [Console](https://console.hostlinku.com) → **Billing** → top-up.
2. Pilih nominal atau preset, lalu metode pembayaran.
3. Pilih bank untuk VA atau coin/jaringan untuk crypto.
4. Periksa total, bonus, kurs, dan biaya, lalu bayar sesuai petunjuk. Kredit masuk otomatis setelah pembayaran terverifikasi.

| Metode | Provider | Halaman |
|---|---|---|
| QRIS | iPaymu Direct | Hostlinku Pay, QR Rupiah |
| Virtual Account | iPaymu Direct | Hostlinku Pay, nomor VA bank |
| Crypto | Heleket | Halaman pembayaran Heleket |

Minimum, maksimum, dan metode tersedia mengikuti ringkasan pembayaran. Invoice pembayaran crypto default **20 menit**; provider dapat memperpanjangnya. Masa berlaku tautan berbeda dari batas waktu membayar: ikuti deadline yang tampil, dan buka kembali transaksi dari Billing jika tautan tidak berlaku.

Tautan Pay dapat dibuka tanpa login untuk satu transaksi. Simpan tautannya secara pribadi. Tautan NOWPayments/BlockBee masih dapat muncul pada transaksi lama.

## Biaya penggunaan

Harga bergantung pada model dan **Service Mode key**. Periksa [katalog model](/models), **Models** di Console, atau `GET /v1/models` dengan key yang akan dipakai.

| Dimensi | Unit harga |
|---|---|
| Input, output, cache read/write | Per 1M token |
| Web search, bila tersedia | Per 1K panggilan |

Token cache termasuk input dan tidak dihitung lagi sebagai input biasa. Billing memakai usage upstream; jika usage tidak tersedia, biaya dapat memakai estimasi.

- **Non-streaming chat**: biaya tampil pada `hostlinku.cost`.
- **Streaming SSE**: periksa biaya final di **Logs / Analytics / Billing** setelah stream selesai.

## Saldo tersedia dan limit key

`available = balance − reserved`. Sebagian saldo ditahan sementara untuk request berjalan, lalu diselesaikan setelah request selesai.

Top-up menambah saldo organisasi, bukan **Monthly Spending Limit** key. Jika menerima `402 PAYMENT_REQUIRED`, periksa pesan: isi saldo jika kurang, atau tunggu reset/ubah limit key jika tercapai. Detail di [Autentikasi](/authentication).

## Transaksi dan invoice

Buka **Billing** untuk riwayat transaksi dan invoice top-up yang sudah dibayar. Cetak atau simpan PDF melalui browser. Invoice dari tautan Pay memerlukan link valid dan transaksi paid.

**Billing Profile** disimpan di browser dan memengaruhi cetakan Console. Profil belum tersinkron ke perangkat lain atau invoice server; invoice Pay dapat menampilkan detail berbeda.

Pantau saldo di Console. Pengaturan auto-recharge dan email saldo rendah belum tersedia pada alur Billing aktif.
