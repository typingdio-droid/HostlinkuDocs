Stream mode sends responses token-by-token via SSE (`text/event-stream`). Tokens can be displayed as soon as the model begins responding, without waiting for the entire response to complete; the timing of the first token depends on the model and provider. Enable it with `"stream": true`.

<a id="ringkas-curl"></a>

<a id="quick-start-curl"></a>

## Summary: curl

```bash
curl -N https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Hitung 1 sampai 5." }],
    "stream": true
  }'
```

The `-N` flag is important: without it, curl holds output until the buffer is full or the stream is complete.

Chunk format:

```text
data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":"1"}}]}

data: [DONE]
```

<a id="python---sdk-openai"></a>

## Python - OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key="sk-your-api-key",
)

stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
```

## Python - requests

Use `stream=True` in requests and call `iter_lines()`. Stop when you receive `data: [DONE]`.

```python
import json
import requests

response = requests.post(
    "https://api.hostlinku.com/v1/chat/completions",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json",
    },
    json={
        "model": "gpt-5-5",
        "messages": [{"role": "user", "content": "Halo!"}],
        "stream": True,
    },
    stream=True,
)

for line in response.iter_lines():
    if not line:
        continue
    text = line.decode("utf-8")
    if not text.startswith("data: "):
        continue
    payload = text[6:]
    if payload == "[DONE]":
        break
    chunk = json.loads(payload)
    if "error" in chunk:
        raise RuntimeError(chunk["error"])
    delta = chunk["choices"][0].get("delta", {}).get("content")
    if delta:
        print(delta, end="", flush=True)
```

<a id="nodejs---sdk-openai"></a>

## Node.js - OpenAI SDK

```js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.hostlinku.com/v1",
  apiKey: process.env.HOSTLINKU_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "gpt-5-5",
  messages: [{ role: "user", content: "Halo!" }],
  stream: true,
});

for await (const chunk of stream) {
  const delta = chunk.choices[0]?.delta?.content;
  if (delta) process.stdout.write(delta);
}
```

## Hostlinku Notes

- The `x-request-id` header is still sent in streaming responses.
- If a stream fails midway, the gateway sends the event `data: {"error": {...}}` and **does not** send a fake `[DONE]`.
- Costs are calculated based on actual usage after the stream ends; if usage data is unavailable, billing uses reservation estimates.
- Do not buffer responses in a reverse proxy or CDN. Forward `text/event-stream` as-is.

<Callout type="tip" title="When is the best time to stream?">
  For chat or agent applications that require a fast-feeling response, use `stream: true`. For batch/job tasks that do not display progress, non-streaming is simpler.
</Callout>
