## Account and API key

<a id="bagaimana-mulai"></a>

<a id="how-do-i-start"></a>

### How do I get started?

[Sign up](https://api.hostlinku.com/api/auth2/register) or [sign in](https://api.hostlinku.com/api/auth2/login), then open [Console](https://console.hostlinku.com). Top up your balance in **Billing** and create a key in **API Keys**. Follow the [Quick Start](/en/getting-started).

<a id="apa-pengaturan-key-yang-tersedia"></a>

### What key settings are available?

Select a name, Service Mode **Performance / Low-Cost / Dedicated**, expiration **30/60/90 days or never**, and an optional monthly limit. The default is Performance and 30 days. No scope. The key management API supports additional periods; see [Authentication](/en/authentication).

<a id="bagaimana-secret-disimpan"></a>

<a id="how-is-the-secret-stored"></a>

### How are secrets stored?

The secret appears once; the server stores the SHA-256 hash. Store it in the server environment. Keys can be edited, enabled/disabled, and deleted. Replace the key if the secret is lost or leaked.

<a id="apakah-passkey-dan-2fa-tersedia"></a>

### Are passkeys and 2FA available?

Yes. **Settings → Security** provides WebAuthn passkeys, TOTP authenticators, and recovery codes via Keycloak.

## Balance and payments

<a id="apa-arti-kredit"></a>

<a id="what-do-credits-mean"></a>

### What does “credit” mean?

**1 credit = $1** as a prepaid service unit. The organization’s balance is used by associated keys; it is not fiat currency that can be freely spent. Refunds are subject to the [Refund Policy](/en/legals/refund-policy).

<a id="bagaimana-top-up"></a>

### How do I top up?

Go to **Billing**, select the amount and payment method. New QRIS/VA payments use **iPaymu Direct**; crypto payments use **Heleket hosted**. The amount, bonus, exchange rate, fees, and deadline are displayed before payment. Credits are automatically applied after verification. View [Billing & Balance](/en/billing).

<a id="di-mana-biaya-dan-invoice"></a>

<a id="where-are-costs-and-invoices"></a>

### Where are the costs and invoices?

**Logs** display request costs, **Analytics** show usage summaries, and **Billing** lists transactions and invoices. Non-streaming chat includes `hostlinku.cost`; for SSE, check the final cost upon completion. Missing usage can be estimated.

Invoices can be printed or saved as PDFs via the browser. Billing Profiles are stored locally in the Console browser, so Console printouts may differ from invoices generated by Pay or other devices.

<a id="apakah-ada-auto-recharge-atau-email-saldo-rendah"></a>

<a id="is-auto-recharge-or-low-balance-email-available"></a>

### Is there an auto-recharge feature or low-balance email?

Not yet available on active Billing. Monitor your balance and top up before production use. Adding funds does not increase the key limit.

## Error and privacy

<a id="apa-tindakan-untuk-429-atau-402"></a>

<a id="what-should-i-do-for-429-or-402"></a>

### What is the action for a 429 or 402 error?

For 429, wait according to `Retry-After` and use backoff; see [Usage & Limits](/en/usage-and-limits). For 402, check available balance and key credit limits; see [Billing & Balance](/en/billing).

<a id="apakah-semua-request-gagal-bebas-biaya"></a>

<a id="are-all-failed-requests-free"></a>

### Are all failed requests free of charge?

Failure without billable usage releases the reservation. For interrupted streams or partial usage, check the final charges in Logs.

<a id="apakah-prompt-dan-respons-disimpan"></a>

<a id="are-prompts-and-responses-stored"></a>

### Are the prompts and responses saved?

Body logging is **disabled by default**; cost metadata, tokens, status, and latency are still logged. When enabled by an admin, the body is size-limited, credential fields are filtered, and the default retention period is 14 days. Secrets in the prompt text are not automatically filtered. See the [Privacy Policy](/en/legals/privacy-policy).
