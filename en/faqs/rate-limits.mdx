The service quota is **600 requests, 6,500,000 input tokens, and 200,000 output tokens per minute**, shared within the same organization. All API keys and organization members are affected when the quota is reached.

Details on quotas and how to handle 429 errors can be found in [Usage & Limits](/en/usage-and-limits).

<a id="backoff-yang-disarankan"></a>

## Recommended backoff

1. Check `Retry-After`; if present, wait for that duration.
2. If none exist, start at 1 second and double the value for each attempt (1, 2, 4, 8 seconds) with jitter.
3. Limit the number of attempts, for example, to 5 times.
4. For high load, queue requests on the application side rather than sending bursts.
