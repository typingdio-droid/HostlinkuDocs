## What is Hostlinku Playground?

Playground is the [Console](https://console.hostlinku.com/playground) interface for trying available models and choosing a Service Mode. It uses your login session and the same organization balance as the API; you do not need to enter an API key.

## How does the integration work?

Point your SDK or application to Hostlinku, use an API key, and choose a model slug. OpenAI Chat Completions and Responses use `https://api.hostlinku.com/v1`; Anthropic Messages uses `https://api.hostlinku.com`. Features depend on the model and protocol. See [Integrations](/en/integrations/index).

## How does billing work?

Top up your organization balance and pay for usage at the model and Service Mode rates. Input, output, and cache have separate rates. Payments use iPaymu Direct for QRIS/VA and Heleket for crypto. See [Billing & Balance](/en/billing).

## Are my prompts stored?

Request and response bodies are not stored by default. Token, cost, status, and latency metadata is recorded. If an admin enables body logging, default body retention is 14 days; secrets written in prompt text are not automatically redacted. See [Privacy](/en/legals/privacy-policy).

## What happens if a model has an outage?

The gateway can try another route according to its available routing configuration. If the request still fails, your application receives an error such as `503`; use backoff and check [Status](https://status.hostlinku.com). Automatic switching to another model in the same family is not guaranteed.

## Is there a free trial for Hostlinku?

Registration is free and does not require a credit card. Trial credits are not available; top up before making paid Playground or API requests.

## Can the official OpenAI SDK be used?

Yes. Set `base_url`/`baseURL` to `https://api.hostlinku.com/v1` and use your Hostlinku API key starting with `sk-…` as the `api_key`. A complete example is available at [Chat Completions](/en/chat-completions#contoh-python-sdk-resmi-openai).

## What endpoints are available?

Gateway endpoints accept an API key:

- `POST /v1/chat/completions`: [Chat Completions](/en/chat-completions).
- `POST /v1/messages`: [Anthropic Messages](/en/anthropic-messages).
- `POST /v1/messages/count_tokens`: Anthropic-format token counting.
- `POST /v1/responses`: stateless [Responses API](/en/responses).
- `GET /v1/models`: [catalog for the key’s Service Mode](/en/models).

The site catalog uses `GET /api/public/models-v2`. Console account endpoints under `/api/*` use a login session. Embeddings are not available on the public gateway.

## What models can I use?

See the [model catalog](/en/models) or **Models** in Console. `GET /v1/models` returns models and rates available for the Service Mode of the API key you use.

## Why was my request rejected with a 401 error?

Check the API key and authentication header. Gateway endpoints accept `Authorization: Bearer sk-...` or `x-api-key`; the key must be correct, active, and unexpired. See [Authentication](/en/authentication).

## Why am I getting a 402 error even though I have a balance?

Check the error message. A 402 error has two possible causes: insufficient **organization balance** (`available` is less than the estimated cost of the request), or the **API key credit limit** has been reached. If the message mentions "API key credit limit," wait for the reset window (daily/weekly/monthly) or change the limit in the console. For more details, see [Billing & Balance](/en/billing).

## How much does a single request cost?

Rates depend on the model, Service Mode, and token/cache dimensions used. Non-streaming chat responses include `hostlinku.cost`; streaming costs are available after completion in Logs/Billing and can use estimates when upstream usage is unavailable. See [Billing & Balance](/en/billing).

## Is there a rate limit?

Each Service Mode has a quota of **600 requests, 6,500,000 input tokens, and 200,000 output tokens per minute**, shared within the same organization. All organization API keys and members are affected when the quota is reached. See [Usage & Limits](/en/usage-and-limits) for quota details and handling 429.

## How do I send an image or multimodal message?

Populate `messages[].content` with an array of content in the OpenAI format (e.g., one object of type `image_url` followed by one object of type `text`) and select a model with `vision`/`image-input` capabilities from the catalog. The level of support depends on the model provider.

## How can I stop the use of a leaked API key?

Disable the key in Console → **API Keys** to reject subsequent requests. Create a replacement, update your application, and delete the old key when no longer needed. Usage history is retained.

## Do request logs store the content of my conversations?

See [the prompt storage answer](#are-my-prompts-stored).

## How should I read latency, TTFT, and TPS?

Latency runs from gateway receipt of the request to response completion. TTFT is time to the first observed streaming token. TPS is the output token rate during generation after the first token, from qualifying stream samples. See [API Reference](/en/api-reference#metrics-and-example-figures).

## Are animations and model charts direct measurements?

Landing speed animations use fixed example figures. The 60 bars on model detail pages are generated from average/P95 latency and failure-count aggregates; bar positions do not represent the last 60 requests in sequence. Aggregate figures and Console usage charts come from request data. Check the period and sample population before comparing performance.

## Does the green footer badge show live status?

The landing footer badge currently uses a fixed status value. Check the [Status page](https://status.hostlinku.com) for monitoring results and incidents.

## What does “reachable” mean?

The endpoint returns an HTTP response below 500, including `401`, `403`, or `404`. This indicates server reachability; successful login or inference requires a check of the relevant function.

## Why can historical cost breakdowns differ?

The charged total is stored in transaction logs. Some input/output/cache breakdowns in analytics are recalculated at current rates and may differ from the historical total. This does not charge old requests again. See [Billing & Balance](/en/billing).

## How long are probe records kept?

Raw health probe records have a default retention of 30 days and are cleaned up periodically. This is separate from 14-day request body retention and usage/transaction metadata. See [Usage & Limits](/en/usage-and-limits).

## How do I contact support?

See [Support](/en/support): email **halo@hostlinku.com**; please include the `x-request-id` from the problematic response.
