Use the API key for the gateway endpoint. The Console account endpoint at `/api/*` uses a login session. Support for parameters, vision, reasoning, cache, and tool calls follows the model and protocol path.

| Endpoint | Usage | Guidelines |
|---|---|---|
| `GET /v1/models` | Catalog for Service Mode key | [Models](/en/models) |
| `POST /v1/chat/completions` | Chat and SSE streaming | [Chat Completions](/en/chat-completions) |
| `POST /v1/messages` | Anthropic message format | [Anthropic Messages](/en/anthropic-messages) |
| `POST /v1/messages/count_tokens` | Calculate Anthropic-format tokens at no cost | [Count tokens](/en/anthropic-messages) |
| `POST /v1/responses` | Stateless responses | [API Responses](/en/responses) |

<a id="base-url-dan-autentikasi"></a>

## Base URL and authentication

The OpenAI SDK uses `https://api.hostlinku.com/v1`; the Anthropic SDK uses `https://api.hostlinku.com`. The gateway accepts `Authorization: Bearer sk-your-api-key` or `x-api-key`. See [Authentication](/en/authentication).

<a id="kompatibilitas-model-dan-tool"></a>

## Model and tool compatibility

The slug appearing in the key catalog can be used for supported endpoints. Format compatibility does not guarantee all features for every client. Check the limits [Responses](/en/responses) and [supported integrations](/integrations).

## Rate Limiting

The following quotas apply per **organization × Service Mode**. All API keys and members of the same organization share the quota; adding keys or members does not increase the quota.

| Limit type | Default quota | Description |
|---|---:|---|
| RPM (requests/minute) | 600 | Calculated per organization and Service Mode, not per model. |
| Input TPM (tokens/minute) | 6,500,000 | Calculated based on the recorded input tokens for the organization and Service Mode. |
| Output TPM (tokens/minute) | 200,000 | Calculated based on the recorded output tokens for the organization and Service Mode. |

- Request quotas are calculated when requests are received. Input and output tokens are recorded after the response is complete; ongoing requests are not terminated.
- Login, Console, and checkout each have their own IP-based limits; see [Usage & Limits](/en/usage-and-limits).
- If the quota is exceeded, the gateway returns `429 RATE_LIMITED`. Use `Retry-After` or `retry-after-ms` if available, reduce concurrency, and perform exponential backoff with jitter.
- Need more capacity? Contact [Support](/en/support).

## Error Codes

Error formats follow the endpoint; failures before the handler may use the general Hostlinku envelope. A list of codes and how to handle failures is available at [Error](/en/errors). Specific formats are described in [Anthropic Messages](/en/anthropic-messages#format-error) and [Responses](/en/responses#format-error).

## Query Available Models

`GET /v1/models` returns the model and price for the Service Mode key. The site catalog uses `GET /api/public/models-v2`. See [Models](/en/models) for a list, capabilities, and how to read pricing.

## Cost and streaming

Non-streaming chat responses contain `hostlinku.cost` and `hostlinku.latencyMs`. Once streaming is complete, check the costs in Logs / Analytics / Billing; do not expect charges for every chunk. Record the `x-request-id` if available. [Billing & Balance](/en/billing).

## Meaning of metrics and numerical examples

| Metrics | Meaning |
|---|---|
| `hostlinku.latencyMs` | The time from when the request is received by the gateway until the response is complete. |
| TTFT | The time until the first token is observed in the stream; may be empty for non-streaming. |
| TPS | Tokens output per second after the first token, from a sample stream that meets the criteria. |

- **Landing animation** uses fixed example numbers; the numbers in the animation are not derived from inferred requests during playback.
- **The 60-bar chart in the model details** is based on aggregates of average/P95 latency and the number of failures. Each bar is a synthetic visualization, not a single request or sequential probe. The Console usage chart uses aggregated request data.
- **Landing page footer badge** uses a fixed status; check [Status](https://status.hostlinku.com) for monitoring results and incidents.
- **Reachable** means an HTTP response below 500, including 401/403/404. This check indicates endpoint reachability; login success and inferences are verified through their respective functions.

Compare metrics from the same period, Service Mode, and sample. Animation results, capacity specifications, traffic aggregates, and benchmarks come from different sources.
