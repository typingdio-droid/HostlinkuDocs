## Compatibility limits

- **URL formats vary by tool.** The Anthropic SDK generally uses `https://api.hostlinku.com`; OpenAI tools use `https://api.hostlinku.com/v1`. VS Code and Junie may require the full endpoint URL. Follow the tool-specific guidelines in the table.
- **Codex CLI requires native tool support for Responses**, including the shell and `apply_patch`. Text bridges or function calls alone are not sufficient; see [Codex CLI](/en/integrations/codex-cli).
- **Features follow the model and protocol.** Check for support of vision, reasoning, JSON schema, and tool calling on the model page and in the [API reference](/en/api-reference).
- **FIM/inline autocomplete and embeddings are not yet supported.** This integration uses chat, agents, or editing via Chat Completions, Responses, and Messages.

## API key and help

Create a separate API key for each tool with a credit limit so it can be easily revoked. Store the key in an environment variable or the tool’s secret store; do not commit or print its value. Key configuration is described in [Authentication](/en/authentication).

For request failures, see the [list of error codes](/en/faqs/errors). Configuration details and tool-specific limits are provided in the guides in the table.
