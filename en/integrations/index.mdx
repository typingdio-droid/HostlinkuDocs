## Compatibility limits

- **URL formats vary by tool.** Anthropic SDKs generally use `https://api.hostlinku.com`; OpenAI tools use `https://api.hostlinku.com/v1`. VS Code and Junie may require a full endpoint URL. Follow the guide linked in the table.
- **Codex CLI requires native Responses tools**, including shell and `apply_patch`. A text/function-calling bridge alone is insufficient; see [Codex CLI](/en/integrations/codex-cli).
- **Features depend on the model and protocol.** Check vision, reasoning, JSON schema, and tool calling on the model page and in the [API reference](/en/api-reference).
- **FIM/inline autocomplete and embeddings are not served.** These integrations use chat, agent, or editing through Chat Completions, Responses, and Messages.

## API keys and help

Create a separate API key with a credit limit for each tool so it can be revoked individually. Keep the key in an environment variable or the tool’s secret store; do not commit or print its value. See [Authentication](/en/authentication) for key settings.

For failed requests, see the [error code reference](/en/faqs/errors). Each guide in the table covers its tool’s configuration and specific limits.
