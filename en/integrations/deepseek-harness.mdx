[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) is an open-source
coding agent from DeepSeek. Inside a workspace folder you choose, `dsh` can read files, edit code,
run shell commands, and complete multi-step tasks - via its Web UI, headless mode, SDK, or ACP.

`dsh` speaks the **Anthropic Messages** protocol. Hostlinku serves it natively at
[`POST /v1/messages`](/en/anthropic-messages), so you can point `dsh` to Hostlinku with just two
environment variables - no proxy or extra plugins required.

<Callout type="note" title="Tested version">
  This guide was verified end-to-end with `@deepseek-ai/dsh` **0.2.1-rc.5** (agent reading a file
  via tool calls and returning the answer in headless mode). DeepSeek Harness is currently in
  *development preview*; configuration file paths or parameter behavior may change in future
  releases.
</Callout>

## Before you begin

- **A current Node.js LTS release** (`node --version`). The `dsh` package pulls in hundreds of
  dependencies, so the initial install can take 1-3 minutes.
- **A Hostlinku API key** (`sk-…`) from [console.hostlinku.com](https://console.hostlinku.com) → **API Keys**.
- **Available balance** or credit limit on that key.
- **A safe test folder.** The directory where you start `dsh` becomes its default workspace. Do not
  run it directly from your home directory or a folder containing sensitive data.

<Steps>

### Install DeepSeek Harness

```bash
npm install -g @deepseek-ai/dsh
dsh --version
```

Or run it without installing globally: `npx @deepseek-ai/dsh web`.

### Point to Hostlinku

`dsh` reads the endpoint from `DEEPSEEK_BASE_URL` and the API key from `DEEPSEEK_API_KEY`.

**macOS / Linux / WSL** (save in `~/.zshrc` or `~/.bashrc`):

```bash
export DEEPSEEK_BASE_URL=https://api.hostlinku.com
export DEEPSEEK_API_KEY=sk-your-api-key
```

**Windows PowerShell:**

```powershell
$env:DEEPSEEK_BASE_URL = "https://api.hostlinku.com"
$env:DEEPSEEK_API_KEY  = "sk-your-api-key"
```

`dsh` appends `/v1/messages` automatically. A base URL of `https://api.hostlinku.com/v1` is also
accepted (the trailing `/v1` is reused, not duplicated).

### Select a model and output limit

The built-in default model in `dsh` (`deepseek-flash`) is not a Hostlinku catalog slug, and `dsh`
sends `max_tokens: 256000` by default - which exceeds the output limit of most models. Configure
both in your home patch file: `~/.dsh/cordis.patch.yml` (or `$DSH_HOME/cordis.patch.yml` if you set
`DSH_HOME`).

```yaml
- id: agent-default-model
  config:
    provider: deepseek-official
    model: deepseek-v4-flash
- id: llm-deepseek
  config:
    apiKeyEnv: DEEPSEEK_API_KEY
    maxTokens: 32000
```

<Callout type="important" title="Patches replace the entire config block">
  Cordis patches do not merge individual fields - the `config` block in your patch **replaces** the
  default block. Always include `provider: deepseek-official` and `apiKeyEnv`, or `dsh` will fail to
  start with `$.provider missing required value`.
</Callout>

### Run

Test quickly in headless mode (runs a single task, prints the final answer, and exits):

```bash
mkdir dsh-test && cd dsh-test
echo "the secret word is PINEAPPLE" > hello.txt
dsh --profile headless "Read hello.txt and reply with only the secret word."
```

Expected output: `PINEAPPLE`. This confirms the agent called the file-read tool through Hostlinku
and returned the answer. For the full browser UI:

```bash
dsh web
```

### Verify

Open the console → **Request Logs**. Requests from `dsh` appear with your selected model, token
counts, cost, and the API key used.

</Steps>

## Recommended models

The `model` field accepts any slug from the [catalog](/en/models) that supports tool calling. You
can check the active list for your key via `GET /v1/models`.

| Use case | Slug | Notes |
|---|---|---|
| Fast, low-cost daily default | `deepseek-v4-flash` | 1M context, reasoning, tool calling. |
| Image inputs (screenshots, diagrams) | `deepseek-v4-1-flash` | Supports vision. |
| Heavy tasks / large refactors | `deepseek-v4-pro` | 1M context, deeper reasoning. |
| Open-weight alternatives | `kimi-k2-7-code`, `glm-5-3` | Tool calling and reasoning. |

<Callout type="tip" title="Match maxTokens to your model">
  `maxTokens` is the per-request output limit, not the context window. `32000` is safe for almost
  every model. Maximum output values per model (e.g., `131072` for `deepseek-v4-flash`) are listed
  on each model's catalog page.
</Callout>

## Security

- During a task, user prompts, code snippets, file contents, and tool outputs are sent to Hostlinku
  for inference. Do not run `dsh` on projects containing trade secrets or personal data without
  authorization.
- Use a **dedicated API key** for `dsh` with a credit limit so it can be revoked cleanly if leaked.
  See [Authentication](/en/authentication).
- Never write your raw API key into `cordis.patch.yml`. `apiKeyEnv` only stores the environment
  variable **name**; the key value itself is read from your shell environment.

## Troubleshooting

| Symptom | Cause & solution |
|---|---|
| `INVALID_REQUEST: max_tokens (256000) exceeds the output limit of model …` | `maxTokens` is not set. Add `maxTokens: 32000` under the `llm-deepseek` block. |
| `startup failed … $.provider missing required value` | The `agent-default-model` block in your patch is missing `provider`. Include the full block shown above. |
| `MISSING_CREDENTIAL` | `DEEPSEEK_API_KEY` is not exported in the shell where `dsh` is running. |
| `401` / *invalid API key* | Key is invalid, revoked, or expired. Create a new key in the console. |
| `404 model not found` | Misspelled slug or still set to `deepseek-flash`. Copy an exact slug from `GET /v1/models`. |
| Image attachment fails | `dsh` attempts to upload via `/v1/files` first, then automatically falls back to inline base64 images. Ensure your selected model supports vision (e.g., `deepseek-v4-1-flash`). |
