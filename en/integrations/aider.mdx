[Aider](https://aider.chat/docs/llms/openai-compat.html) uses LiteLLM internally;
OpenAI-compatible endpoints only require `OPENAI_API_BASE`, and model names must begin with `openai/`.

<Steps>

<a id="instal-aider"></a>

### Install Aider

```bash
python -m pip install -U aider-chat
# atau: pipx install aider-chat
```

<a id="arahkan-ke-hostlinku"></a>

<a id="go-to-hostlinku"></a>

### Redirect to Hostlinku

```bash
export OPENAI_API_BASE=https://api.hostlinku.com/v1
export OPENAI_API_KEY=sk-your-api-key   # API key Hostlinku

aider --model openai/claude-sonnet-4-6
```

The `openai/` prefix is required—it tells Aider to use an OpenAI-compatible path with
`OPENAI_API_BASE`. The part after the prefix is my Hostlink slug.

<a id="disarankan-simpan-di-berkas-konfigurasi"></a>

### (Recommended) Save to a configuration file

`.aider.conf.yml` in the home directory or root of the repo:

```yaml
openai-api-base: https://api.hostlinku.com/v1
model: openai/claude-sonnet-4-6
weak-model: openai/claude-haiku-4-5      # commit message & ringkasan
editor-model: openai/deepseek-v4-flash   # mode architect (opsional)
```

Store the API key in `.env` (in `.gitignore`) so it isn’t committed:

```bash
OPENAI_API_KEY=sk-your-api-key
```

<a id="beri-tahu-aider-ukuran-konteks--harga"></a>

<a id="let-aider-know-the-context-and-price"></a>

### Let Aider know the context and pricing

Aider does not recognize the Hostlinku slug, so it issues a *"model is unknown"* warning and attempts to infer
the context. Create `.aider.model.metadata.json` (home / root repo):

```json
{
  "openai/claude-sonnet-4-6": {
    "max_input_tokens": 1000000,
    "max_output_tokens": 64000,
    "input_cost_per_token": 0.0000024,
    "output_cost_per_token": 0.0000120,
    "litellm_provider": "openai",
    "mode": "chat"
  },
  "openai/claude-haiku-4-5": {
    "max_input_tokens": 200000,
    "max_output_tokens": 16000,
    "input_cost_per_token": 0.0000008,
    "output_cost_per_token": 0.0000040,
    "litellm_provider": "openai",
    "mode": "chat"
  }
}
```

The `max_input_tokens` and `max_output_tokens` values above are examples of Aider’s local limits. Adjust them according to the model limits in the [catalog](/en/models); smaller values restrict usage within the tool.

The price figures above are only examples (Performance mode)—copied from `pricing` in the [catalog](/en/models),
which are stated per **1M tokens**, then **divided by 1,000,000** because Aider uses pricing per 1 token
(e.g., `pricing.input: 2.4` → `input_cost_per_token: 0.0000024`).
Aider’s cost estimates will then closely match the actual billing in the console.

</Steps>

<a id="mode-architect-dengan-dua-model"></a>

## Architect mode with two models

```bash
aider --architect \
  --model openai/claude-opus-4-6 \
  --editor-model openai/claude-sonnet-4-6
```

The *architect* model designs changes, while the *editor* model writes diffs. Both are charged to the same balance
and recorded separately in the **Request Log**.

<Callout type="tip" title="Additional settings per model">
  To pass extra parameters (e.g., `reasoning_effort`, `temperature`) to a specific model,
  use `.aider.model.settings.yml` with the `extra_params` key. See the Aider *Advanced
  model settings* documentation.
</Callout>

## Troubleshooting

- **`AuthenticationError`** - `OPENAI_API_KEY` is not exported or `.env` is unreadable (Aider
  reads `.env` from the working directory/git root).
- **`NotFoundError` model** - missing the `openai/` prefix or incorrect slug.
- **Warning: *unknown context window***—`.aider.model.metadata.json` does not yet exist; see step 4.
- **Answer truncated** - increase `max_output_tokens` in the metadata or select a model with a
  higher output limit.
