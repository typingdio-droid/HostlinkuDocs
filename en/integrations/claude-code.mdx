[Claude Code](https://code.claude.com/docs) uses the Anthropic Messages protocol. Hostlinku
provides a compatible endpoint at [`POST /v1/messages`](/en/anthropic-messages) (including
`/v1/messages/count_tokens`), so Claude Code can be directed to Hostlinku simply via an
environment variable—no additional proxy is needed.

<Steps>

<a id="instal-claude-code"></a>

### Install Claude Code

Select the installation method based on your operating system:

**macOS / Linux / WSL:**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell:**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**npm (requires Node.js 18+):**

```bash
npm install -g @anthropic-ai/claude-code
```

If you’ve previously logged in with an Anthropic/Claude account, run `claude` and then type
`/logout` so that your saved OAuth credentials do not override the gateway configuration.

<a id="arahkan-ke-hostlinku"></a>

<a id="go-to-hostlinku"></a>

### Redirect to Hostlinku

The fastest way—export in the shell (`~/.zshrc` / `~/.bashrc`):

```bash
export ANTHROPIC_BASE_URL=https://api.hostlinku.com
export ANTHROPIC_AUTH_TOKEN=sk-your-api-key

# Pin model untuk alias yang dipakai Claude Code
export ANTHROPIC_DEFAULT_SONNET_MODEL=claude-sonnet-4-6
export ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-4-6
export ANTHROPIC_DEFAULT_HAIKU_MODEL=claude-haiku-4-5

claude
```

Persistence method—the `env` block in `~/.claude/settings.json` (applies to all projects) or
`.claude/settings.local.json` in the project root (only for that project; this file is usually gitignored):

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.hostlinku.com",
    "ANTHROPIC_AUTH_TOKEN": "sk-your-api-key",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-6",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-6",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5"
  }
}
```

Values in `settings.json` **take precedence over** shell exports.

<Callout type="tip" title="Want to manage this via the GUI without editing JSON?">
  Use the [CC Switch](/en/integrations/cc-switch) desktop app to automatically retrieve a list of models
  from `/v1/models` and switch between Claude Code profiles/models with a single click.
</Callout>

<a id="verifikasi"></a>

### Verification

In a Claude Code session, type `/status`: the *API* section should display the base URL
`https://api.hostlinku.com` and the *auth token* authentication method. Send a simple prompt, then
check that the request appears in the console → **Request Log** with the API key you’re using.

<a id="opsional-ganti-model-dari-dalam-sesi"></a>

<a id="optional-change-the-model-within-the-session"></a>

### (Optional) Switch models within a session

`/model` displays the aliases `sonnet` / `opus` / `haiku` that you pinned above. To use
a different slug just once:

```bash
claude --model deepseek-v4-flash
# atau pin default lewat env: export ANTHROPIC_MODEL=gpt-5-5
```

</Steps>

<a id="autentikasi-auth_token-atau-api_key"></a>

## Authentication: `AUTH_TOKEN` or `API_KEY`?

| Variables | Headers sent | Supported by Hostlinku |
|---|---|---|
| `ANTHROPIC_AUTH_TOKEN` | `Authorization: Bearer sk-…` | Yes (recommended) |
| `ANTHROPIC_API_KEY` | `x-api-key: sk-…` | Yes |

Both are accepted by the gateway; choose one—do not enter both with different values.

<a id="ekstensi-vs-code--jetbrains"></a>

## VS Code & JetBrains Extensions

The Claude Code extension checks for login on its own, so the same variables must also be filled in the
extension settings - VS Code: `claudeCode.environmentVariables` in `settings.json`:

```json
{
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.hostlinku.com" },
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "sk-your-api-key" },
    { "name": "ANTHROPIC_DEFAULT_SONNET_MODEL", "value": "claude-sonnet-4-6" },
    { "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL", "value": "claude-haiku-4-5" }
  ]
}
```

In JetBrains, set the same variables in *Settings → Tools → Claude Code → Environment variables*
(or ensure the IDE is running from a shell that has already exported those variables).

<a id="pakai-model-non-claude"></a>

## Use a non-Claude model

Claude Code in Service Mode Performance supports the Claude model as well as domestic models such as DeepSeek, Qwen, GLM, Kimi, MiniMax, and MiMo. In Low-Cost mode, Claude Code only supports the Claude model because the Low-Cost catalog does not include domestic models. GPT models are not supported in Claude Code in either mode; use the Codex CLI, Chat, or Responses API for GPT models. Since the gateway translates the protocol, aliases such as `sonnet` and `haiku` can be populated with Claude slugs or domestic model slugs from the [catalog](/en/models):

```bash
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
```

Features that depend on model capabilities (tool use, *extended thinking*, vision) follow
the target model’s capabilities—check the `capabilities` field in the catalog.

<Callout type="note" title="Claude Code does not recognize non-Claude model names">
  When using slugs like `deepseek-v4-pro` or `deepseek-v4-flash`, Claude Code displays a warning `unrecognized_model` and assumes a 200k-token context. Adjust the context on the client side if the target model has a larger window.
</Callout>

<Callout type="tip" title="Save balance for sub-agents">
  Claude Code uses the alias *haiku* for light tasks (summaries, session titles, quick sub-agents).
  Using `claude-haiku-4-5` or `deepseek-v4-flash` (Performance) significantly reduces the cost of long sessions
  without affecting the quality of the main model.
</Callout>

<Callout type="note" title="Broad context & cache">
  Hostlinku passes `cache_control` (prompt caching) and reports `cache_read_input_tokens` /
  `cache_creation_input_tokens` in `usage`—Claude Code utilizes this automatically. Billing follows
  the pricing for the relevant cache model (see [Billing](/en/billing)).
</Callout>

## Troubleshooting

- **`401 authentication_error` even though the key is correct** - old OAuth credentials are still being used. Run
  `/logout`, close the session, and ensure `ANTHROPIC_BASE_URL` is accessible (`/status`).
- **Model not found (`404`)** - the alias has not been pinned, so Claude Code sends the
  default model name. Replace `ANTHROPIC_DEFAULT_*_MODEL` with a slug from the catalog.
- **`400 max_tokens melebihi batas`** - lower `max_tokens` via `CLAUDE_CODE_MAX_OUTPUT_TOKENS`
  (e.g., `32000`) if the target model has a lower output limit.
- **Rate limit (`429`)** - Claude Code can run multiple sub-agents in parallel. See the limits at
  [Usage & Limits](/en/usage-and-limits).
