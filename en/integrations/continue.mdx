[Continue](https://docs.continue.dev) is configured via `config.yaml`. Each model
has a `provider`, `apiBase`, `apiKey`, and a list of `roles` (chat, edit, apply, …). For
Hostlinku uses the `openai` provider with the `apiBase` gateway.

<Steps>

<a id="buka-konfigurasi"></a>

<a id="open-the-configuration"></a>

### Open configuration

In the Continue panel, click the gear icon → **Open config file**, or edit directly
`~/.continue/config.yaml` (global) / `.continue/config.yaml` (per project).

<a id="tambahkan-model-hostlinku"></a>

<a id="add-a-hostlinku-model"></a>

### Add the Hostlinku model

```yaml
name: Hostlinku
version: 0.0.1
schema: v1

models:
  - name: Claude Sonnet 4.6 (Hostlinku)
    provider: openai
    model: claude-sonnet-4-6
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply]
    defaultCompletionOptions:
      contextLength: 1000000
      maxTokens: 32000

  - name: GPT-5.5 (Hostlinku)
    provider: openai
    model: gpt-5-5
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply]

  - name: DeepSeek V4 Flash (Hostlinku)
    provider: openai
    model: deepseek-v4-flash
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply, summarize]
```

<a id="simpan-api-key-sebagai-secret"></a>

<a id="save-the-api-key-as-a-secret"></a>

### Store the API key as a secret

Create a file named `~/.continue/.env` (do not commit it) containing:

```bash
HOSTLINKU_API_KEY=sk-your-api-key
```

Or replace `${{ secrets.HOSTLINKU_API_KEY }}` with the actual key value if your configuration file
is indeed private.

<a id="muat-ulang-dan-uji"></a>

### Reload and test

Click **Reload config** in the Continue panel (or save the file—Continue monitors changes). Select the
*Claude Sonnet 4.6 (Hostlinku)* model from the dropdown, send a message, then check the console → **Request
Log**.

</Steps>

<a id="peran-roles-yang-didukung"></a>

## Supported roles

| Role | Support via Hostlinku | Notes |
|---|---|---|
| `chat` | Yes | All catalog models. |
| `edit`, `apply` | Yes | Use the model with the calling tool; `claude-sonnet-4-6` works very well for *apply*. |
| `summarize` | Yes | Low-cost models such as `deepseek-v4-flash` / `claude-haiku-4-5`. |
| `autocomplete` | No | Requires the FIM model via `/v1/completions`. Leave this role to other providers (e.g., local models). |
| `embed`, `rerank` | No | Hostlinku does not yet provide embeddings/rerank endpoints. |

If `edit`/`apply` are not assigned a specific model, continue using the active `chat` model.

<Callout type="tip" title="YAML anchor to reduce repetition">
  Define `apiBase` and `apiKey` once as an anchor (`&hostlinku`) and then use
  `<<: *hostlinku` in each model. See the `config.yaml` reference in Continue.
</Callout>

## Troubleshooting

- **Model does not appear in the dropdown** - incorrect YAML indentation or `roles` does not include `chat`.
  See *Output → Continue* in VS Code.
- **`401`** - `~/.continue/.env` has not been read; reload the config or restart the IDE.
- **`404 model_not_found`** - `model:` must be the exact slug from `GET /v1/models`.
- **Streaming is stuttering**—make sure no corporate proxy is buffering `text/event-stream`.
