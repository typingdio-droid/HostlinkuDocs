## Overview

DeepSeek-V4.1-Flash is a multimodal mixture-of-experts model built on an asymmetric Causal Encoder–Decoder architecture, with native visual understanding. It supports a 1M-token context window, up to 384K output tokens, thinking and non-thinking modes, tool calls, and structured JSON output.
