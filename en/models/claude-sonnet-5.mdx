## Overview

Claude Sonnet 5 is designed to be the most agent-capable Sonnet model to date. It can plan, use tools such as browsers and terminals, and operate autonomously at a level that until recently only larger, more expensive models could achieve.

| Property | Value |
|---|---|
| Provider | Anthropic |
| Slug | `claude-sonnet-5` |
| Context | 1,000,000 tokens |
| Max output | 64,000 tokens |
| Input | text, image |
| Output | text |
| Release | 2026-06-30 |
| Tags | production |

## Supported endpoints

| Endpoint | Format | Support |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | available |
| `POST /v1/messages` | Anthropic Messages | native |
| `POST /v1/responses` | OpenAI Responses | adapted (bridge) |

Endpoint and model availability follow the catalog and the API key's Service Mode. If a model is unavailable for that mode, the request may be rejected with `400 MODEL_NOT_IN_SERVICE_MODE`.

## Example request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-5",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
