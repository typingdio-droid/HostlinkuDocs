## Overview

GLM-5.3-Flash is Zhipu AI's lighter multimodal sibling to GLM-5.3 for everyday analysis and agentic work. Available on the Hostlinku Dedicated channel with a higher throughput lane. Tuned for short-context chat applications rather than coding agents.

| Property | Value |
|---|---|
| Provider | Zhipu |
| Slug | `glm-5-3-flash-hyper-chat` |
| Context | 1,000,000 tokens |
| Max output | 64,000 tokens |
| Input | text, image |
| Output | text |
| Release | 2026-08-17 |
| Tags | flagship, reasoning, dedicated, flash |

## Supported endpoints

| Endpoint | Format | Support |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | available |
| `POST /v1/messages` | Anthropic Messages | adapted (bridge) |
| `POST /v1/responses` | OpenAI Responses | adapted (bridge) |

Endpoint and model availability follow the catalog and the API key's Service Mode. If a model is unavailable for that mode, the request may be rejected with `400 MODEL_NOT_IN_SERVICE_MODE`.

## Example request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5-3-flash-hyper-chat",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
