## Overview

Claude Fable 5 is Anthropic's flagship Mythos-class model optimized for long-horizon reasoning, agentic coding, and autonomous workflows. It supports text and image inputs with text output, featuring a 1M-token context window and 128K maximum output.

| Property | Value |
|---|---|
| Provider | Anthropic |
| Slug | `claude-fable-5` |
| Context | 1,000,000 tokens |
| Max output | 128,000 tokens |
| Input | text, image |
| Output | text |
| Release | 2026-06-09 |
| Tags | creative |

## Supported endpoints

| Endpoint | Format | Support |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | available |
| `POST /v1/messages` | Anthropic Messages | native |
| `POST /v1/responses` | OpenAI Responses | adapted (bridge) |

Endpoint and model availability follow the catalog and the API key's Service Mode. If a model is unavailable for that mode, the request may be rejected with `400 MODEL_NOT_IN_SERVICE_MODE`.

## Example request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-fable-5",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
