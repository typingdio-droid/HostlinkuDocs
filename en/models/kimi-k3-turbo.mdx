## Overview

Kimi K3 is Kimi's flagship model, designed for long-range programming and end-to-end knowledge work; it features a 1-million-token context window and delivers leading-edge comprehensive intelligence. Available on the Hostlinku Dedicated channel with a higher throughput lane.

| Property | Value |
|---|---|
| Provider | Moonshot |
| Slug | `kimi-k3-turbo` |
| Context | 1,000,000 tokens |
| Max output | 64,000 tokens |
| Input | text, image |
| Output | text |
| Release | 2026-07-16 |
| Tags | flagship, dedicated |

## Supported endpoints

| Endpoint | Format | Support |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | available |
| `POST /v1/messages` | Anthropic Messages | adapted (bridge) |
| `POST /v1/responses` | OpenAI Responses | adapted (bridge) |

Endpoint and model availability follow the catalog and the API key's Service Mode. If a model is unavailable for that mode, the request may be rejected with `400 MODEL_NOT_IN_SERVICE_MODE`.

## Example request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3-turbo",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
