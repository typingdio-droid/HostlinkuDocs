## Supported endpoints

| Endpoint | Format | Support |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | available |
| `POST /v1/messages` | Anthropic Messages | adapted (bridge) |
| `POST /v1/responses` | OpenAI Responses | native |

Endpoint and model availability follow the catalog and the API key's Service Mode. If a model is unavailable for that mode, the request may be rejected with `400 MODEL_NOT_IN_SERVICE_MODE`.

## Example request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5-3-codex",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
