## Overview

DeepSeek-V4.1-Flash is a multimodal mixture-of-experts model built on an asymmetric Causal Encoder–Decoder architecture, with native visual understanding. It supports a 1M-token context window, up to 384K output tokens, thinking and non-thinking modes, tool calls, and structured JSON output. Available on the Hostlinku Dedicated channel with a higher throughput lane.

| Property | Value |
|---|---|
| Provider | DeepSeek |
| Slug | `deepseek-v4-1-flash-turbo` |
| Context | 1,000,000 tokens |
| Max output | 384,000 tokens |
| Input | text, image |
| Output | text |
| Release | 2026-09-13 |
| Tags | fast, budget, dedicated |
