## Overview

GLM-5 is Zhipu's text foundation model for agentic engineering, supporting 200K context, 128K max output, thinking modes, function calling, structured output, context caching, and MCP.

| Property | Value |
|---|---|
| Provider | Zhipu |
| Slug | `glm-5` |
| Context | 200,000 tokens |
| Max output | Not published |
| Input | text |
| Output | text |
| Release | 2026-06-14 |

## Supported endpoints

| Endpoint | Format | Support |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | available |
| `POST /v1/messages` | Anthropic Messages | adapted (bridge) |
| `POST /v1/responses` | OpenAI Responses | adapted (bridge) |

Endpoint and model availability follow the catalog and the API key's Service Mode. If a model is unavailable for that mode, the request may be rejected with `400 MODEL_NOT_IN_SERVICE_MODE`.

## Example request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
