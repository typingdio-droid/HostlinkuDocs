Hostlinku provides a single centralized model catalog. Each model has a unique **slug** that is used in the `model` parameter in [Chat Completions](/en/chat-completions), along with context size, capabilities, and price per token.

## `GET /v1/models`

Returns all models that are marked as `available`, not yet deprecated, and available for the **Service Mode API key** being used (Performance or Low-Cost), along with the price <CreditIcon /> per 1M tokens in that mode.

```http
GET https://api.hostlinku.com/v1/models
Authorization: Bearer sk-your-api-key
```

Example:

```bash
curl https://api.hostlinku.com/v1/models \
  -H "Authorization: Bearer sk-your-api-key"
```

Response (example truncated; the exact value for your account is retrieved from this endpoint):

```json
{
  "object": "list",
  "service_mode": "performance",
  "data": [
    {
      "id": "claude-haiku-4-5",
      "object": "model",
      "created": 1791380432,
      "owned_by": "hostlinku",
      "context_window": 200000,
      "capabilities": ["text", "tool-calling", "function-calling", "structured-outputs", "json-mode", "streaming", "code-generation", "long-context", "multilingual"],
      "service_mode": "performance",
      "pricing": {
        "input": 0.8,
        "output": 4,
        "cache_read": 0.08,
        "cache_write": 1,
        "unit": "1M_tokens",
        "currency": "🪙"
      }
    }
  ]
}
```

| Field | Meaning |
|---|---|
| `service_mode` (level list & item) | Service Mode API key used: `performance` or `low_cost`. The list of models varies by mode. |
| `id` | Model slug; the value used in the `model` field in `/v1/chat/completions`, `/v1/messages`, and `/v1/responses`. |
| `created` | The time the model was added to the catalog (Unix epoch, seconds). |
| `owned_by` | Always `"hostlinku"` - indicates that the model is managed by the Hostlinku catalog. |
| `context_window` | Maximum context size in tokens (input + output). |
| `capabilities` | List of capabilities, e.g., `vision`, `tool-calling`, `json-mode`, `reasoning`, `long-context`. |
| `pricing` | The pricing object for that Service Mode; `null` if the model does not yet have a price for that mode. `pricing.unit` is always `"1M_tokens"`, and `pricing.currency` contains the credit symbol (1 <CreditIcon /> = $1). |
| `pricing.input` / `pricing.output` | Price per **1M tokens** (not per token or per 1K) for prompt tokens / response tokens. |
| `pricing.cache_read` / `pricing.cache_write` | Price per 1M tokens for a 5-minute cache read / cache write (see [Prompt Caching](/en/prompt-caching)); `null` if the model does not support it. |

<Callout type="note" title="The price in the response is the customer's price">
The `pricing` value is the price you pay for that Service Mode API key; the platform margin is already included in it. The actual cost of each request always appears in the `hostlinku.cost` block in the response and in the console log.
</Callout>

## Public catalog (no authentication required)

For marketing or exploratory use without an API key, a public catalog is available:

```http
GET https://api.hostlinku.com/api/public/models
```

The public catalog displays only Hostlinku models along with their slugs, names, contexts, capabilities, and public prices. Supported queries: `q` (search by name/description), `capability`, `family`, `sort` (`popular`, `newest`, `price-asc`, `price-desc`, `context-desc`, `name-asc`), `page`, and `pageSize` (max 100). The `data` response contains `items`, `total`, `page`, `pageSize`, and `totalPages`.

## How to Choose a Model

1. **Determine your needs**: general chat, reasoning, vision/multimodal, tool invocation,
or structured JSON output. Check the `capabilities` field.
2. **Pay attention to the context size**: make sure `context_window` is large enough to accommodate your prompt and output.
3. **Compare prices**: `pricing.input` for prompt tokens and `pricing.output` for tokens
Answer: Reasoning models generally have higher output costs.
4. **Start with a small model**: for development, use a lightweight model (e.g., `gpt-6-luna`,
`deepseek-v4-1-flash`, `qwen3-6-plus`) are much cheaper; only upgrade the model if the quality is insufficient.
5. **View the console**: the **Model** menu at [console.hostlinku.com](https://console.hostlinku.com)
displays a catalog with the same prices and features, plus a detail page for each model.

<Callout type="tip" title="Alias slug">
Use the exact slug returned by `GET /v1/models`. Slugs are not case-sensitive on the front end, but always copy them exactly as they appear in the catalog to avoid typos. A slug that does not exist in the catalog returns a `404 MODEL_NOT_FOUND` error; a model that has been deprecated or is currently unavailable returns a `503 MODEL_UNAVAILABLE` error along with a suggested replacement slug, if available.
</Callout>

## Routing and Failover

Hostlinku automatically manages the internal routes that serve each model. If an error occurs on the route currently being used (5xx/timeout), the request is automatically retried via another route before giving up. You continue to use the same model slug and don’t need to change anything; these internal details are not displayed in the response.
