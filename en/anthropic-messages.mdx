In addition to the OpenAI format, Hostlinku also provides endpoints compatible with
[Anthropic Messages API](https://docs.anthropic.com/en/api/messages). The official Anthropic SDK,
**Claude Code**, Cursor, Cline, and other tools that support the Anthropic protocol can be used simply
by changing the base URL—one API key and one Hostlinku balance work for both formats.

```http
POST https://api.hostlinku.com/v1/messages
x-api-key: sk-your-api-key
anthropic-version: 2023-06-01
Content-Type: application/json
```

Authentication accepts the `x-api-key` header (Anthropic style) **or** `Authorization: Bearer sk-…`.
Successful responses include the `request-id` / `x-request-id` header (Hostlinku request ID, `msg_…` format); non-streaming successful responses also include `x-model`. Errors occurring before the handler may not include these IDs.

<Callout type="note" title="Any model, not just Claude">
  `model` uses the same Hostlinku public slug as the [model catalog](/en/models) —
  e.g., `claude-sonnet-4-6`, `gpt-5-5`, `deepseek-v4-flash`. Non-Claude models can still be called
  via the Anthropic format; the gateway handles the translation.
</Callout>

<a id="konfigurasi-cepat"></a>

## Quick Setup

Step-by-step guides for each tool (Claude Code, Cline, and others) are available at
[IDE & Agent Integrations](/integrations).

**Claude Code**

```bash
export ANTHROPIC_BASE_URL=https://api.hostlinku.com
export ANTHROPIC_API_KEY=sk-your-api-key
export ANTHROPIC_MODEL=claude-sonnet-4-6
claude
```

**Python (Anthropic’s official SDK)**

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-your-api-key",
    base_url="https://api.hostlinku.com",
)

message = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Jelaskan apa itu API gateway dalam dua kalimat."}],
)
print(message.content[0].text)
print(message.usage.input_tokens, message.usage.output_tokens)
```

**Node.js**

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({ apiKey: "sk-your-api-key", baseURL: "https://api.hostlinku.com" });
const msg = await client.messages.create({
  model: "claude-haiku-4-5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Halo!" }],
});
```

<a id="parameter-body"></a>

## Body parameters

| Parameter | Type | Notes |
|---|---|---|
| `model` | `string` | **Required.** Hostlinku model slug. |
| `messages` | `array` | **Required.** `{ role: "user" \| "assistant", content }`; `content` is a string or block array (`text`, `image`, `tool_use`, `tool_result`, …). |
| `max_tokens` | `integer` | **Required** (as per Anthropic specifications). A `400` error is returned if the model’s output limit is exceeded. |
| `system` | `string` | `array` | System prompt; the block array supports `cache_control`. |
| `stream` | `boolean` | `true` for SSE (see below). |
| `temperature` | `number` | `0`–`1`. |
| `top_p`, `top_k` | `number`, `integer` | Alternative examples. |
| `stop_sequences` | `string[]` | Maximum 16. |
| `tools`, `tool_choice` | `array`, `any` | Use the Anthropic format (including `input_schema`). |
| `thinking` | `object` | Extended thinking, e.g., `{ "type": "enabled", "budget_tokens": 1024 }`. |
| `metadata` | `object` | E.g., `{ "user_id": "…" }`. |
| `mcp_servers`, `context_management`, `output_format` | - | Passed through as-is (depending on model support). |

Fields not on the list are discarded. Invalid bodies are rejected with a `400 invalid_request_error` response, with
details per field in `error.details.issues`.

<a id="respons-non-streaming"></a>

## Non-streaming response

```json
{
  "id": "msg_…",
  "type": "message",
  "role": "assistant",
  "model": "claude-haiku-4-5",
  "content": [{ "type": "text", "text": "API gateway adalah …" }],
  "stop_reason": "end_turn",
  "stop_sequence": null,
  "usage": {
    "input_tokens": 30,
    "output_tokens": 55,
    "cache_creation_input_tokens": 0,
    "cache_read_input_tokens": 0,
    "cache_creation": { "ephemeral_5m_input_tokens": 0, "ephemeral_1h_input_tokens": 0 }
  },
  "hostlinku": { "cost": 0.00021, "currency": "🪙", "serviceMode": "performance", "latencyMs": 940 }
}
```

`id` and `model` are always Hostlinku’s public identifiers. The `hostlinku` block is an extension (the Anthropic SDK
ignores it) containing the cost <CreditIcon />, Service Mode API key, and latency.

<Callout type="note" title="Anthropic usage conventions">
  According to Anthropic’s specifications, `input_tokens` **does not** include cache tokens; cache tokens are reported
  separately in `cache_read_input_tokens` / `cache_creation_input_tokens`. Hostlinku billing calculates
  all three at their respective rates—identical to the `/v1/chat/completions` endpoint
  (see [Billing](/en/billing)).
</Callout>

## Streaming (`stream: true`)

The gateway streams SSE events using Anthropic framing (`event:` + `data:`):

```text
event: message_start
data: {"type":"message_start","message":{"id":"msg_…","type":"message","role":"assistant","model":"claude-haiku-4-5","content":[],"usage":{"input_tokens":22,"output_tokens":1,…}}}

event: content_block_start
data: {"type":"content_block_start","index":0,"content_block":{"type":"text","text":""}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"Apel"}}

event: content_block_stop
data: {"type":"content_block_stop","index":0}

event: message_delta
data: {"type":"message_delta","delta":{"stop_reason":"end_turn","stop_sequence":null},"usage":{"input_tokens":22,"output_tokens":7,…}}

event: message_stop
data: {"type":"message_stop"}
```

Note:

- Final usage is recorded in `message_delta`; costs are calculated based on actual usage after `message_stop`.
- If a stream fails midway, the gateway sends `event: error` with
  `{"type":"error","error":{"type":…,"message":…}}` and **does not** send a fake `message_stop`.
- Errors occurring before the first byte (out of balance, model not found, rate limit) are returned as
  standard JSON responses with the correct HTTP status—the Anthropic SDK maps these to exceptions
  (`AuthenticationError`, `NotFoundError`, `RateLimitError`, …).

<a id="hitung-token"></a>

## Count tokens

```http
POST https://api.hostlinku.com/v1/messages/count_tokens
```

Body: `model`, `messages`, optional `system`, `tools`, `tool_choice`, `thinking`. Response
`{ "input_tokens": 15 }`. No charge.

<a id="format-error"></a>

## Error format

```json
{ "type": "error", "error": { "type": "authentication_error", "message": "The API key is invalid or has been revoked." } }
```

| HTTP | `error.type` | Common causes |
|---|---|---|
| 400 | `invalid_request_error` | Invalid body; `max_tokens` exceeds the model limit; the model is not available in Service Mode key. |
| 401 | `authentication_error` | API key is incorrect/revoked/expired. |
| 402 | `billing_error` | Insufficient balance or API key credit limit reached. |
| 403 | `permission_error` | Account suspended / access denied. |
| 404 | `not_found_error` | The model slug is not in the catalog. |
| 429 | `rate_limit_error` | The request limit has been reached. |
| 503 | `overloaded_error` | Model/upstream is unavailable. Check the catalog for alternative models; retry with a delay if there is a temporary outage. |

The table lists errors handled by the protocol. Restrictions on requests or parsing the body before the handler can use the standard Hostlinku format; see [Error](/en/errors).

Error messages are sanitized to obscure internal identifiers; some reasons for upstream rejections may still appear. [Error](/en/errors).
