## Support channels

| Channel | Usage |
|---|---|
| [halo@hostlinku.com](mailto:halo@hostlinku.com) | Technical questions, accounts, and billing |
| [Console](https://console.hostlinku.com) | Balance, API key, request logs, and audit |
| [Status](https://status.hostlinku.com) | Ongoing disruptions and incidents |

Emails are answered as soon as possible on business days by a small team (best-effort). Incident updates are posted on the Status page.

<a id="informasi-untuk-laporan"></a>

<a id="information-to-include"></a>

## Information for reports

1. `x-request-id` if present in Console responses or logs.
2. Event time with time zone, endpoint, and model slug.
3. HTTP status codes and error bodies; codes/types vary according to the [API format](/en/errors).
4. A minimal, reproducible request example, with the API key and sensitive data removed.

```text
Waktu: 2026-11-06 14:32 UTC+7
Request ID: <x-request-id>
Endpoint: /v1/chat/completions
Model: gpt-5-5
HTTP: 503
Error: UPSTREAM_TIMEOUT ("The request timed out. Please retry.")
Catatan: Terjadi 3 kali dalam 10 menit terakhir.
```

<a id="masalah-keamanan"></a>

## Security issues

Submit security findings privately to [halo@hostlinku.com](mailto:halo@hostlinku.com) with the subject `[SECURITY]`. Avoid publishing details before they are addressed. The support team does not ask for API keys, passwords, or OTP codes; do not include secrets in your report.
