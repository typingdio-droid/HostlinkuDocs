## Support channels

| Channel | Purpose |
|---|---|
| [halo@hostlinku.com](mailto:halo@hostlinku.com) | Technical, account, and billing questions |
| [Console](https://console.hostlinku.com) | Balance, API keys, request logs, and audit |
| [Status](https://status.hostlinku.com) | Ongoing outages and incidents |

A small team answers email as soon as possible on business days (best effort). Incident updates appear on the Status page.

## Information to include

1. `x-request-id` if available in the response or Console log.
2. Time with time zone, endpoint, and model slug.
3. HTTP status and error body; codes/types differ by [API format](/en/errors).
4. A minimal reproducible request, with API keys and sensitive data removed.

```text
Time: 2026-11-06 14:32 UTC+7
Request ID: <x-request-id>
Endpoint: /v1/chat/completions
Model: gpt-5-5
HTTP: 503
Error: UPSTREAM_TIMEOUT ("The request timed out. Please retry.")
Notes: Occurred 3 times in the last 10 minutes.
```

## Security issues

Send security findings privately to [halo@hostlinku.com](mailto:halo@hostlinku.com) with the subject `[SECURITY]`. Avoid publishing details before they are addressed. Support does not ask for API keys, passwords, or OTP codes; do not include secrets in reports.
