Set up curl and your credit balance, then follow the steps below.

<Steps>

<a id="masuk-dan-isi-saldo"></a>

<a id="sign-in-and-top-up"></a>

### Log in and top up your balance

Go to [Sign Up](https://api.hostlinku.com/api/auth2/register) or [Sign In](https://api.hostlinku.com/api/auth2/login). Login is powered by Keycloak. In the [Console](https://console.hostlinku.com), go to **Billing** and top up your credit balance before sending a request. See [Billing](/en/billing) for payment methods.

<a id="buat-api-key"></a>

### Create an API key

Go to **API Keys → Create API Key**, enter a name, then select **Performance** (default), **Low-Cost**, or **Dedicated**. Service Mode determines the model and pricing. Copy the `sk-…` secret—which appears only once—and save it in your server environment. Settings for expiration, credit limits, and passkeys/2FA are explained in [Authentication](/en/authentication).

<a id="kirim-request-pertama"></a>

<a id="send-your-first-request"></a>

### Send the first request

Use the available models for the Service Mode key. The following example uses `gpt-5-5`; for Dedicated keys or other options, retrieve the slug from [`GET /v1/models`](/en/models).

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{"role": "user", "content": "Halo! Perkenalkan dirimu singkat saja."}]
  }'
```

Non-streaming responses are in JSON format. The following example is truncated; the token, cost, and latency are for illustrative purposes only:

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Halo! Saya adalah …"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60},
  "hostlinku": {
    "cost": 0.000123,
    "currency": "🪙",
    "serviceMode": "performance",
    "latencyMs": 812
  }
}
```

<a id="periksa-hasil"></a>

<a id="check-the-result"></a>

### Check the results

Go to **Logs** for tokens, costs, and request latency; **Billing** displays the organization’s balance. If a request fails, check the [error codes](/en/errors). The API key is used at `/v1/*`; Console account endpoints require a login session.

</Steps>
