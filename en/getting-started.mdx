This page walks you from zero to a successful chat completion request through Hostlinku.

## Prerequisites

- **Hostlinku account**: [sign up through the backend](https://api.hostlinku.com/api/auth2/register), which redirects to Keycloak.
- **Credit balance**: the gateway charges per token. Top up in the console before production requests. Test requests usually cost less than a cent, but your balance must not be empty. See [Billing & Balance](/en/billing).
- **Test tools**: curl is enough. For advanced examples, the official OpenAI SDK (`pip install openai`) or Node (`npm install openai`) works without code changes.

## Steps

<Steps>

### Sign up or sign in

Open [Sign up](https://api.hostlinku.com/api/auth2/register) or [Sign in](https://api.hostlinku.com/api/auth2/login). The backend starts the Keycloak flow at `auth2.hostlinku.com`, handles the callback, and opens the Console. Passkey and SSO options depend on your account, device, and available providers.

### Create an API key

Go to [console.hostlinku.com](https://console.hostlinku.com) → **API Keys** → **Create API key**. In the creation dialog you can set:

- **Name**: for identification, e.g. `production-your-app`.
- **Service Mode**: choose **Performance** (default), **Low-Cost**, or **Dedicated**. The key mode determines models and prices.
- **Expiry**: 30 days (default), 60 days, 90 days, or never.
- **Monthly Spending Limit**: optional monthly key cap. The Console form has no scope selector or daily/weekly reset choice; see [Authentication](/en/authentication) for the API contract.

<Callout type="warning" title="The secret is shown only once">
  After the API key is created, the `sk-…` secret is **shown only once** in the console. Copy and store it safely: the server stores only a SHA-256 hash and cannot display it again. If you lose the secret, revoke the key and create a new one.
</Callout>

### Send your first request

All gateway endpoints live at `https://api.hostlinku.com`, authenticated with `Authorization: Bearer sk-…`. Non-streaming example:

```bash
curl https://api.hostlinku.com/v1/chat/completions   -H "Content-Type: application/json"   -H "Authorization: Bearer sk-your-api-key"   -d '{
    "model": "gpt-5-5",
    "messages": [
      { "role": "user", "content": "Hello! Introduce yourself briefly." }
    ]
  }'
```

If everything is correct, you receive an OpenAI-style JSON response plus a `hostlinku` block with the request cost and latency:

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "Hello! I am …" },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60 },
  "hostlinku": {
    "cost": 0.000123,
    "latencyMs": 812
  }
}
```

The model slug above is just an example. See the valid slugs for your account in the console (**Models**) or via the [`GET /v1/models` endpoint](/en/models).

### Recommendation: use streaming

For chat applications, send `"stream": true` to show output as it is generated without waiting for the full answer. Time to first token depends on the model and provider conditions; streaming does not guarantee a particular latency.

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key=os.environ["HOSTLINKU_API_KEY"],
)

stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Hello!"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

With curl, add `-N` so output is not buffered:

```bash
curl -N https://api.hostlinku.com/v1/chat/completions   -H "Content-Type: application/json"   -H "Authorization: Bearer sk-your-api-key"   -d '{ "model": "gpt-5-5", "stream": true, "messages": [{ "role": "user", "content": "Hello!" }] }'
```

### Check balance and history

In the console, open **Billing** to see your organization balance and **Request Log** for request history with tokens, cost, and latency. An equivalent endpoint is available at [`GET /api/wallet/account`](/en/billing) for console sessions, while the public API (`sk-…` keys) uses `/v1/*`.

## Passkey login and 2FA

Hostlinku accounts use Keycloak. Passkeys (WebAuthn), TOTP authenticators, and recovery codes are available through **Settings → Security**. Register the appropriate option before using it at login. Keycloak handles registration and authentication challenges; SSO availability follows enabled providers.

For streaming costs, check **Logs / Analytics / Billing** after the stream completes. Do not expect `hostlinku.cost` in every SSE chunk; billing may estimate costs when upstream omits usage.
