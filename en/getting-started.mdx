Prepare curl and a credit balance, then follow these steps.

<Steps>

### Sign in and top up

Open [Sign up](https://api.hostlinku.com/api/auth2/register) or [Sign in](https://api.hostlinku.com/api/auth2/login). Keycloak handles login. In the [Console](https://console.hostlinku.com), open **Billing** and top up before sending a request. See [Billing](/en/billing) for payment methods.

### Create an API key

Open **API Keys → Create API key**, enter a name, and choose **Performance** (default), **Low-Cost**, or **Dedicated**. The Service Mode determines models and prices. Copy the `sk-…` secret shown only once and store it in your server environment. See [Authentication](/en/authentication) for expiry, spending limits, and passkey/2FA settings.

### Send your first request

Use a model available in the key's Service Mode. This example uses `gpt-5-5`; for a Dedicated key or another model, get a slug from [`GET /v1/models`](/en/models).

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{"role": "user", "content": "Hello! Introduce yourself briefly."}]
  }'
```

A non-streaming response is JSON. This example is abbreviated; token counts, cost, and latency are illustrative:

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Hello! I am …"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60},
  "hostlinku": {
    "cost": 0.000123,
    "currency": "🪙",
    "serviceMode": "performance",
    "latencyMs": 812
  }
}
```

### Check the result

Open **Logs** for request tokens, cost, and latency; **Billing** shows the organization balance. If a request fails, check the [error codes](/en/errors). API keys are used on `/v1/*`; Console account endpoints use a login session.

</Steps>
