Hostlinku's main endpoint. The request and response formats are compatible with the [OpenAI Chat Completions API](https://platform.openai.com/docs/api-reference/chat), so you can use the official OpenAI SDK simply by changing `base_url` to `https://api.hostlinku.com/v1`.

```http
POST https://api.hostlinku.com/v1/chat/completions
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

Successful responses include `x-request-id`; successful non-streaming responses also include `x-model` (the public model slug).

Choose a model available in the API key Service Mode. Vision, JSON schema, reasoning, and tool calling depend on the model and protocol path. See [compatibility limits](/en/responses).

## Body Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `model` | `string` | none | **Required.** Model slug, e.g., `gpt-5-5`. See [Model](/en/models). |
| `messages` | `array` | none | **Required.** At least 1 message. Each item: `{ role, content, name? }`, where `role` is one of `system`, `developer`, `user`, `assistant`, or `tool`. |
| `temperature` | `number` | provider default | Range `0`–`2`. The higher the value, the more random it is. |
| `top_p` | `number` | provider default | Range `0`–`1`. An alternative to _nucleus sampling_ based on `temperature`. |
| `n` | `integer` | `1` | Number of answer choices, `1`–`8`. |
| `stream` | `boolean` | `false` | `true` for SSE streaming responses (see below). |
| `stop` | `string` \| `string[]` | none | One or more text sequences that halt generation. |
| `max_tokens` | `integer` | model default | Output token limit (positive). |
| `max_completion_tokens` | `integer` | none | Modern alternative to `max_tokens` (used by some providers). |
| `presence_penalty` | `number` | `0` | Range `-2`–`2`. |
| `frequency_penalty` | `number` | `0` | Range `-2`–`2`. |
| `user` | `string` | none | End-user identifier for abuse tracking. |
| `tools` | `array` | none | Definition of tool/function calls (OpenAI format). |
| `tool_choice` | `any` | none | Tool selection control (`"auto"`, `"none"`, `{...}`). |
| `response_format` | `any` | none | E.g., `{ "type": "json_object" }` for JSON output (depending on model support). |
| `seed` | `integer` | none | Seed determinism (best-effort, provider-dependent). |

<Callout type="note" title="Parameter validation">
  The table lists the main parameters. The schema also accepts `top_k`, `web_search_options`, `reasoning_effort`, `parallel_tool_calls`, `logprobs`, `top_logprobs`, `logit_bias`, `stream_options`, `metadata`, `thinking`, `verbosity`, `service_tier`, `store`, `prompt_cache_key`, `safety_identifier`, and `truncation`. Unknown top-level fields are removed. Additional `messages[]` fields, including `tool_calls`, `tool_call_id`, `function_call`, and `reasoning_content`, are preserved. Parameter and multimodal support depend on the model/protocol. Invalid bodies return `422 VALIDATION_FAILED` with field details.
</Callout>

## Example: Non-streaming request (curl)

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [
      { "role": "system", "content": "You are a concise assistant." },
      { "role": "user", "content": "Explain what an API gateway is in two sentences." }
    ],
    "temperature": 0.7,
    "max_tokens": 256
  }'
```

Response (abridged):

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "created": 1770000000,
  "model": "gpt-5-5",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "An API gateway is …" },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 30, "completion_tokens": 55, "total_tokens": 85 },
  "hostlinku": {
    "cost": 0.00021,
    "latencyMs": 940
  }
}
```

`model` contains the public Hostlinku slug. The `hostlinku` block in successful non-streaming responses includes cost, Service Mode, and latency. It is not guaranteed in each SSE chunk:

| Field | Meaning |
|---|---|
| `cost` | Cost in 🪙 credits; 1 credit = \$1. |
| `latencyMs` | Total request latency from when the gateway receives the request until it is completed, in milliseconds. |

## Streaming (`stream: true`)

With `stream: true`, the gateway responds with `Content-Type: text/event-stream` (SSE), streams chunks in an OpenAI-compatible format (each chunk uses a public Hostlinku `id` and the same model slug), and then closes the stream with `data: [DONE]`:

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Count from 1 to 5." }],
    "stream": true
  }'
```

```text
data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"role":"assistant","content":""}}]}

data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":"1"}}]}

data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":", 2"}}]}

data: [DONE]
```

Important note:

- Handle error events and unexpected disconnections as stream failures. A `[DONE]` marker alone does not prove success; inspect errors and Request Logs using `x-request-id`.
- Final billing uses upstream usage/cost; missing or zero values can fall back to the reserved estimate.
- The `x-request-id` header is also sent in streaming responses to correlate with logs in
console.

## Example: Python (Official OpenAI SDK)

There are no code changes other than `base_url`. The OpenAI SDK is ready to use:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key="sk-your-api-key",
)

# Non-streaming
response = client.chat.completions.create(
    model="gpt-5-5",
    messages=[
        {"role": "system", "content": "You are a concise assistant."},
        {"role": "user", "content": "Hello from the OpenAI SDK!"},
    ],
)
print(response.choices[0].message.content)

# Streaming
stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Write one short paragraph."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)
```

<Callout type="tip" title="Change the base_url in other libraries">
The same pattern applies to `openai-node` (`new OpenAI({ baseURL: 'https://api.hostlinku.com/v1' })`), LangChain (`baseURL`/`openai_api_base`), and other tools that support OpenAI-compatible endpoints.
</Callout>

## Common errors on this endpoint

| Case | HTTP | `error.code` |
|---|---|---|
| Body failed validation (invalid field/invalid type/empty `messages`) | 422 | `VALIDATION_FAILED` |
| Invalid or expired API key | 401 | `UNAUTHORIZED` |
| Insufficient API key balance or limit | 402 | `PAYMENT_REQUIRED` |
| Model slug not found in the catalog | 404 | `MODEL_NOT_FOUND` |
| `max_tokens` exceeds the model's output limit | 400 | `BAD_REQUEST` |
| Deprecated / currently unavailable model | 503 | `MODEL_UNAVAILABLE` |
| Shared organization quota exceeded | 429 | `RATE_LIMITED` |
| Upstream unavailable / temporary outage (retryable) | 503 | `UPSTREAM_ERROR` |

The complete format of the error envelope is available at [Error](/en/errors).
