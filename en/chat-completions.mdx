Hostlinku’s main endpoint. The request and response formats are compatible with
[OpenAI Chat Completions API](https://platform.openai.com/docs/api-reference/chat), so the
official OpenAI SDK can be used simply by replacing `base_url` with `https://api.hostlinku.com/v1`.

```http
POST https://api.hostlinku.com/v1/chat/completions
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

A successful response includes `x-request-id`; a non-streaming successful response also includes `x-model` (the model’s public slug).

Select the available model for the Service Mode API key. Support for vision, JSON schema, reasoning, and tool calling follows the model and its protocol path. See [compatibility limits](/en/responses).

<a id="parameter-body"></a>

## Body parameters

| Parameter | Type | Default | Notes |
|---|---|---|---|
| `model` | `string` | none | **Required.** Model slug, e.g., `gpt-5-5`. See [Models](/en/models). |
| `messages` | `array` | none | **Required.** At least 1 message. Each item: `{ role, content, name? }` where `role` is one of `system`, `developer`, `user`, `assistant`, or `tool`. |
| `temperature` | `number` | provider-specific | Range `0`–`2`. The higher the value, the more random it is. |
| `top_p` | `number` | provider-specific | Range `0`–`1`. Alternative _nucleus sampling_ of `temperature`. |
| `n` | `integer` | `1` | Number of answer options: `1`–`8`. |
| `stream` | `boolean` | `false` | `true` for SSE streaming responses (see below). |
| `stop` | `string` \| `string[]` | none | One or more text sequences that halt generation. |
| `max_tokens` | `integer` | model properties | Output token limit (positive). |
| `max_completion_tokens` | `integer` | none | Modern alternative: `max_tokens` (used by some providers). |
| `presence_penalty` | `number` | `0` | Range `-2`–`2`. |
| `frequency_penalty` | `number` | `0` | Range `-2`–`2`. |
| `user` | `string` | none | End-user identifier for tracking misuse. |
| `tools` | `array` | none | Definitions of tool/function calls (OpenAI format). |
| `tool_choice` | `any` | none | Tool selection controls (`"auto"`, `"none"`, `{...}`). |
| `response_format` | `any` | none | E.g., `{ "type": "json_object" }` for JSON output (depending on model support). |
| `seed` | `integer` | none | Seed determinism (best-effort, provider-dependent). |

<Callout type="note" title="Parameter validation">
  The list above contains the main parameters. The schema also accepts `top_k`, `web_search_options`, `reasoning_effort`, `parallel_tool_calls`, `logprobs`, `top_logprobs`, `logit_bias`, `stream_options`, `metadata`, `thinking`, `verbosity`, `service_tier`, `store`, `prompt_cache_key`, `safety_identifier`, and `truncation`. Unknown top-level fields are discarded. Additional fields in `messages[]`, including `tool_calls`, `tool_call_id`, `function_call`, and `reasoning_content`, are preserved. Support for multimodal parameters and content remains model/protocol-dependent. Invalid bodies are rejected with a `422 VALIDATION_FAILED` response, along with details on the fields.
</Callout>

<a id="contoh-request-non-streaming-curl"></a>

## Example: non-streaming request (curl)

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [
      { "role": "system", "content": "Kamu adalah asisten yang ringkas." },
      { "role": "user", "content": "Jelaskan apa itu API gateway dalam dua kalimat." }
    ],
    "temperature": 0.7,
    "max_tokens": 256
  }'
```

Response (truncated):

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "created": 1770000000,
  "model": "gpt-5-5",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "API gateway adalah …" },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 30, "completion_tokens": 55, "total_tokens": 85 },
  "hostlinku": {
    "cost": 0.00021,
    "latencyMs": 940
  }
}
```

`model` contains the Hostlinku public slug. The `hostlinku` block in non-streaming success responses contains cost, Service Mode, and latency. This block is not a guaranteed part of every SSE chunk:

| Field | Meaning |
|---|---|
| `cost` | Cost in credits 🪙; 1 credit = $1. |
| `latencyMs` | Total request latency from gateway reception to completion, in milliseconds. |

## Streaming (`stream: true`)

With `stream: true`, the gateway responds with `Content-Type: text/event-stream` (SSE),
streaming chunks in an OpenAI-compatible format (each chunk uses the same public Hostlinku `id`
and model slug), then closes the stream with `data: [DONE]`:

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Hitung 1 sampai 5." }],
    "stream": true
  }'
```

```text
data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"role":"assistant","content":""}}]}

data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":"1"}}]}

data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":", 2"}}]}

data: [DONE]
```

Important note:

- If a stream fails, handle the error event and treat the connection termination as a failure. The `[DONE]` marker alone does not prove a successful request; check for errors and review the Request Log using the `x-request-id`.
- The final cost uses usage/upstream cost; if empty or zero, the gateway may use a reservation estimate.
- The `x-request-id` header is also sent in streaming responses to link to logs in
  the console.

## Example: Python (OpenAI’s official SDK)

No code changes are required other than `base_url`. The OpenAI SDK can be used as-is:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key="sk-your-api-key",
)

# Non-streaming
response = client.chat.completions.create(
    model="gpt-5-5",
    messages=[
        {"role": "system", "content": "Kamu adalah asisten yang ringkas."},
        {"role": "user", "content": "Halo dari SDK OpenAI!"},
    ],
)
print(response.choices[0].message.content)

# Streaming
stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
```

<Callout type="tip" title="Replace `base_url` in other libraries">
  The same pattern applies to `openai-node` (`new OpenAI({ baseURL: 'https://api.hostlinku.com/v1' })`),
  LangChain (`baseURL`/`openai_api_base`), and other tools that support
  OpenAI-compatible endpoints.
</Callout>

## Common errors at this endpoint

| Cases | HTTP | `error.code` |
|---|---|---|
| Body failed validation (invalid field/wrong type/empty `messages`) | 422 | `VALIDATION_FAILED` |
| The API key is invalid or has expired | 401 | `UNAUTHORIZED` |
| API key balance or limit is insufficient | 402 | `PAYMENT_REQUIRED` |
| The model slug is not in the catalog | 404 | `MODEL_NOT_FOUND` |
| `max_tokens` exceeds the model’s output limit | 400 | `BAD_REQUEST` |
| Deprecated / currently unavailable model | 503 | `MODEL_UNAVAILABLE` |
| The organization-wide quota has been exceeded | 429 | `RATE_LIMITED` |
| Upstream is unavailable / temporary outage (retryable) | 503 | `UPSTREAM_ERROR` |

The complete error envelope format is available at [Error](/en/errors).
