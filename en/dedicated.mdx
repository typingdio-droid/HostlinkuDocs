**Dedicated** is one of Hostlinku’s Service Modes for the set of models available in that mode. Select **Dedicated** when creating an API key in the [Console](https://console.hostlinku.com). The mode is tied to the key; requests do not use additional parameters to change the mode.

<Callout type="note" title="One API key = one Service Mode">
To use Performance and Low-Cost simultaneously, create separate API keys. Callable models and pricing follow the Service Mode key; check `GET /v1/models` using that key.
</Callout>

A comparison of the three modes and how to choose a key is available at [Service Mode](/en/service-modes).

## Endpoint and authentication

The base URL remains `https://api.hostlinku.com`. The following API formats are available; some models use a bridge to adapt the format. Support for all vendor features or built-in application tools must be verified separately.

| Format | Endpoint | Authentication header |
|---|---|---|
| OpenAI Chat | `POST /v1/chat/completions` | `Authorization: Bearer <API_KEY>` |
| OpenAI Responses | `POST /v1/responses` | `Authorization: Bearer <API_KEY>` |
| Anthropic Messages | `POST /v1/messages` | `x-api-key: <API_KEY>` |

<a id="pricing"></a>

## Price

Billed based on usage via the Service Mode API key. **1 <CreditIcon /> = $1**. Check the [Dedicated pricing](https://hostlinku.com/models?mode=dedicated) or `GET /v1/models` using a Dedicated key.

## Prompt caching

In models that support auto-caching, repeating prefixes can result in cache hits without `cache_control`. Hits and cache duration follow the upstream. Cache usage is reported via `cached_tokens` in Chat Completions or `cache_read_input_tokens` in Messages when available. See [Prompt Caching](/en/prompt-caching).

<a id="batasan"></a>

## Limitations

- The model must be available for the Service Mode key; there is no automatic fallback to another mode.
- Features and output limits follow the model and protocol. The application’s built-in tools may not be supported by the bridge.
