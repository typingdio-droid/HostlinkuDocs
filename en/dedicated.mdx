**Dedicated** is a Hostlinku Service Mode for the set of models available in that mode. Select **Dedicated** when creating an API key in the [Console](https://console.hostlinku.com). The mode belongs to the key; requests do not use an extra parameter to change it.

<Callout type="note" title="One API key = one Service Mode">
Create separate API keys to use Performance or Low-Cost alongside Dedicated. Available models and prices follow the key’s Service Mode; check `GET /v1/models` with that key.
</Callout>

## Endpoints and authentication

The base URL remains `https://api.hostlinku.com`. The following API formats are available; some models use bridges to adapt the format. Check support for vendor features and application built-in tools separately.

| Format | Endpoint | Authentication header |
|---|---|---|
| OpenAI Chat | `POST /v1/chat/completions` | `Authorization: Bearer <API_KEY>` |
| OpenAI Responses | `POST /v1/responses` | `Authorization: Bearer <API_KEY>` |
| Anthropic Messages | `POST /v1/messages` | `x-api-key: <API_KEY>` |

## Pricing

Billed by usage at the API key’s Service Mode rates. **1 <CreditIcon /> = \$1**. Check [Dedicated rates](https://hostlinku.com/en/models?mode=dedicated) or `GET /v1/models` with a Dedicated key.

## Prompt caching

Models supporting automatic caching may reuse repeated prefixes without `cache_control`. Cache hits and lifetimes depend on upstream. Cache usage is reported through `cached_tokens` in Chat Completions or `cache_read_input_tokens` in Messages when available. See [Prompt Caching](/en/prompt-caching).

## Limitations

- The model must be available in the key’s Service Mode; there is no automatic fallback to another mode.
- Features and output limits depend on the model and protocol. Bridges may not support application built-in tools.
