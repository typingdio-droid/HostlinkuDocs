Hostlinku provides OpenAI Chat Completions, Anthropic Messages, and Responses API through one gateway. Each API key belongs to **Performance**, **Low-Cost**, or **Dedicated** Service Mode; its models and rates follow that mode.

## Your first request

Register in [Console](https://console.hostlinku.com), top up your organization balance, and create an API key. Use a model from your key’s catalog; replace the example slug when needed. [Full quickstart](/en/getting-started).

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-5","messages":[{"role":"user","content":"Hello"}]}'
```
