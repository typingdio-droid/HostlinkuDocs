Hostlinku provides OpenAI Chat Completions, Anthropic Messages, and Responses API through a single gateway. API keys are tied to the **Performance**, **Low-Cost**, or **Dedicated** Service Modes; models and pricing follow those modes.

<a id="request-pertama"></a>

<a id="your-first-request"></a>

## First request

Sign up at [Console](https://console.hostlinku.com), top up your organization’s balance, and then create an API key. The following example uses a model from the key catalog; replace the slug if necessary. [Complete guide](/en/getting-started).

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-5","messages":[{"role":"user","content":"Hello"}]}'
```
