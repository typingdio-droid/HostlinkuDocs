**Hostlinku** is an AI gateway with OpenAI Chat Completions, Anthropic Messages, and Responses API formats. Parameter and capability support depends on the model and endpoint. An API key accesses the catalog for the **Service Mode** chosen when creating it: **Performance**, **Low-Cost**, or **Dedicated**. Models and prices may change; use the [model catalog](/en/models) and `GET /v1/models` with your key as the reference.

With Hostlinku you don't need to manage separate accounts, API keys, and request formats for every provider:

- **One API key** for the models in your selected Service Mode (`sk-…`).
- **OpenAI-compatible**: use the official OpenAI SDKs (`openai-python`, `openai-node`) by changing only `base_url`.
- **SSE streaming**: token-by-token responses in `text/event-stream` format, just like OpenAI.
- **Centralized model catalog**: slugs, per-token pricing, context windows, and capabilities in one place.
- **Usage controls**: per-key credit limits, request history, and full logs in the console.
- **Prepaid billing**: top up organization credits with QRIS / Virtual Account (iPaymu Direct) or crypto (Heleket hosted payments). **1 credit = $1** as the service-credit unit.

## Architecture at a glance

```text
Your application
    │  Authorization: Bearer sk-…
    ▼
api.hostlinku.com  ──►  Hostlinku Gateway  ──►  Routing & failover
(v1/chat/completions)        │                        │
                             │                        ├─► OpenAI
                             ├─ Reserve balance      ├─► Anthropic
                             ├─ Telemetry & logs     ├─► Google
                             └─ Commit actual cost   └─► …and more
```

Every request follows the same path: API key authentication, credit-limit checks, balance reservation (estimate), forwarding to the model service (with automatic retries on failure), then settling cost from upstream usage or an estimate when usage is unavailable, and recording telemetry.

The Hostlinku Console (`console.hostlinku.com`) uses the same backend: API keys, balance, request history, and audit logs all come from real gateway data.
