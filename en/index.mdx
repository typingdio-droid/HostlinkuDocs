**Hostlinku** is a unified AI gateway: one API that is fully compatible with OpenAI. Your requests are routed to hundreds of models from multiple providers (OpenAI, Anthropic, Google, DeepSeek, Qwen, and others) through a single API key.

With Hostlinku you don't need to manage separate accounts, API keys, and request formats for every provider:

- **One API key** for every model (`sk-…`).
- **OpenAI-compatible**: use the official OpenAI SDKs (`openai-python`, `openai-node`) by changing only `base_url`.
- **SSE streaming**: token-by-token responses in `text/event-stream` format, just like OpenAI.
- **Centralized model catalog**: slugs, per-token pricing, context windows, and capabilities in one place.
- **Usage controls**: per-key credit limits, request history, and full logs in the console.
- **Flexible billing**: top up with QRIS / Virtual Account (iPaymu) or crypto (BlockBee).

## Architecture at a glance

```text
Your application
    │  Authorization: Bearer sk-…
    ▼
api.hostlinku.com  ──►  Hostlinku Gateway  ──►  Routing & failover
(v1/chat/completions)        │                        │
                             │                        ├─► OpenAI
                             ├─ Reserve balance      ├─► Anthropic
                             ├─ Telemetry & logs     ├─► Google
                             └─ Commit actual cost   └─► …and more
```

Every request follows the same path: API key authentication, credit-limit checks, balance reservation (estimate), forwarding to the model service (with automatic retries on failure), then committing the actual cost based on tokens used and recording telemetry.

The Hostlinku Console (`console.hostlinku.com`) uses the same backend: API keys, balance, request history, and audit logs all come from real gateway data.
