Gateway Hostlinku memakai API key berformat `sk-…` untuk endpoint `/v1/*`:

```http
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

Header `x-api-key: sk-…` juga diterima. Buat dan kelola key di [Console](https://console.hostlinku.com) → **API Keys**.

<Callout type="important" title="API key dan sesi Console">

API key digunakan untuk `/v1/chat/completions`, `/v1/messages`, `/v1/responses`, dan `/v1/models`. Endpoint akun yang dilindungi pada `/api/*` memakai sesi login Console dan menolak autentikasi API key dengan `403 API_KEY_NOT_ALLOWED`. Cookie login tidak menggantikan API key pada `/v1/*`.

</Callout>

## Login Console

[Masuk](https://api.hostlinku.com/api/auth2/login) atau [daftar](https://api.hostlinku.com/api/auth2/register) untuk membuka login Keycloak, lalu kembali ke Console.

Console memakai sesi server `hl_sid`; `hl_session` adalah cookie JWT untuk sebagian alur. Browser mengelolanya otomatis. Passkey, TOTP, dan recovery codes tersedia di **Settings → Security**.

## Membuat dan mengelola API key

1. Buka **API Keys → Buat API key**.
2. Isi nama (maksimal 64 karakter) dan pilih **Service Mode**: **Performance**, **Low-Cost**, atau **Dedicated**. Default form adalah Performance. Mode menentukan katalog, routing, dan harga yang berlaku untuk key tersebut.
3. Pilih masa berlaku: **30 hari** (default), **60 hari**, **90 hari**, atau **Tidak pernah**.
4. Jika perlu, aktifkan **Monthly Spending Limit** dan isi batas kredit bulanan.
5. Salin secret yang tampil sekali dan simpan di environment variable server.

Tidak ada pilihan scope endpoint pada form API key saat ini. Key tetap dibatasi Service Mode, saldo, masa berlaku, limit kredit, dan rate limit. Daftar model yang benar untuk key kamu diperoleh dari [`GET /v1/models`](/models).

Secret disimpan sebagai hash SHA-256, sehingga tidak dapat ditampilkan ulang. Console mendukung edit, nonaktifkan/aktifkan, dan hapus key. Jika secret hilang atau bocor, buat penggantinya, verifikasi request, lalu nonaktifkan key lama.

## Limit kredit per API key

Console menawarkan **Monthly Spending Limit**. API pengelolaan key mendukung periode berikut (kalender UTC):

| Periode | Jendela biaya menurut kalender UTC |
|---|---|
| `daily` | Sejak 00:00 UTC hari berjalan |
| `weekly` | Sejak Senin 00:00 UTC minggu berjalan |
| `monthly` | Sejak tanggal 1, 00:00 UTC bulan berjalan |
| `lifetime` / tanpa reset | Total selama masa aktif key |

Akumulasi memakai biaya request yang tercatat untuk key. Setelah limit tercapai, request berikutnya ditolak dengan `402 PAYMENT_REQUIRED`. Limit per key berbeda dari saldo kredit organisasi: top-up menambah saldo, tetapi tidak menaikkan limit key. Lihat [Billing & Saldo](/billing).

## Rate limit dan error

Kuota dipakai bersama oleh semua API key dan anggota organisasi **untuk setiap Service Mode**. Menambah key atau akun anggota tidak menambah kuota. Angka batas dan cara menangani 429 ada di [Pemakaian & Limit](/usage-and-limits).

| Kondisi | HTTP | Kode |
|---|---|---|
| Key tidak ada, tidak valid, nonaktif, atau kedaluwarsa | 401 | `UNAUTHORIZED` |
| API key digunakan sebagai autentikasi endpoint akun Console | 403 | `API_KEY_NOT_ALLOWED` |
| Saldo tersedia kurang atau limit kredit key tercapai | 402 | `PAYMENT_REQUIRED` |
| Rate limit terlampaui | 429 | `RATE_LIMITED` |

<Callout type="tip" title="Simpan key di server">

Gunakan `HOSTLINKU_API_KEY` pada environment server. Buat key terpisah per aplikasi atau lingkungan, beri masa berlaku dan limit yang sesuai, dan jangan memasukkan secret ke browser atau repositori publik.

</Callout>
