HostlinkuはOpenAI Chat Completions、Anthropic Messages、Responses APIを1つのゲートウェイで提供します。APIキーには**Performance**、**Low-Cost**、**Dedicated**のService Modeが設定され、そのモードに応じたモデルと料金を利用できます。

## 最初のリクエスト

[Console](https://console.hostlinku.com)で登録し、組織の残高をチャージしてAPIキーを作成してください。キーのモデル一覧からslugを選び、必要に応じて例を変更します。[クイックスタート](/ja/getting-started)。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-5","messages":[{"role":"user","content":"Hello"}]}'
```
