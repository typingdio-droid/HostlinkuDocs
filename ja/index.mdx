**Hostlinku** はOpenAI Chat Completions、Anthropic Messages、Responses API形式を提供するAIゲートウェイです。パラメータと機能の対応はモデルとエンドポイントに依存します。APIキーは作成時に選択する **Service Mode**（**Performance**、**Low-Cost**、**Dedicated**）のモデル一覧にアクセスします。最新のモデルと価格は [モデル一覧](/ja/models) と、そのキーによる `GET /v1/models` で確認してください。

Hostlinkuを使えば、プロバイダーごとに異なるアカウント、APIキー、リクエスト形式を個別に管理する必要がなくなります：

- 選択したService Modeのモデルに**1つのAPIキー**（`sk-…`）。
- **OpenAIとの互換性**：OpenAI（`openai-python`、`openai-node`）の公式SDKを使用する場合は、`base_url`を置き換えるだけで十分です。
- **SSEストリーミング**：OpenAIと同様に、`text/event-stream`という形式のトークンごとの応答。
- **一元化されたモデルカタログ**：スラッグ、トークンあたりの価格、コンテキスト、および機能を1か所に集約。
- **利用状況の管理**：APIキーごとのクレジット上限、リクエスト履歴、およびコンソール上の詳細なログ。
- **前払い決済**：QRIS／Virtual Account（iPaymu Direct）、暗号資産（Heleketのホスト型決済）で組織にチャージできます。サービスクレジットの単位は **1クレジット = $1** です。

## 概要

```text
あなたのアプリケーション
    │  Authorization: Bearer sk-…
    ▼
api.hostlinku.com  ──►  Gateway Hostlinku  ──►  Routing & failover
(v1/chat/completions)        │                        │
                             │                        ├─► OpenAI
                             ├─ Reservasi saldo       ├─► Anthropic
                             ├─ Telemetri & log       ├─► Google
                             └─ Commit biaya nyata    └─► …dan lainnya
```

リクエストはAPIキー認証、上限確認、残高予約、モデルサービスへの転送を経由します。終了後に上流のusage、またはusage欠落時の推定値で費用を確定し、テレメトリを記録します。

コンソール Hostlinku (`console.hostlinku.com`) は同じバックエンドを使用しています。API キー、残高、リクエスト履歴、監査ログはすべて、実際のデータゲートウェイからのものです。
