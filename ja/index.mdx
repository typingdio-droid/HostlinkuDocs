Hostlinkuは、1つのゲートウェイを通じてOpenAI Chat Completions、Anthropic Messages、およびResponses APIを提供しています。APIキーは、サービスモード**Performance**、**Low-Cost**、または**Dedicated**に紐付けられており、モデルと価格はそれぞれのモードに従います。

<a id="request-pertama"></a>

## 最初のリクエスト

[Console](https://console.hostlinku.com) に登録し、組織の残高を補充してから、APIキーを作成してください。以下の例では、キーカタログのモデルを使用しています。必要に応じてスラグを変更してください。[完全ガイド](/ja/getting-started)。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-5","messages":[{"role":"user","content":"Hello"}]}'
```
