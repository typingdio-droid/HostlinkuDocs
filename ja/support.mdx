## 問い合わせ先

| 連絡先 | 用途 |
|---|---|
| [halo@hostlinku.com](mailto:halo@hostlinku.com) | 技術、アカウント、課金の質問 |
| [Console](https://console.hostlinku.com) | 残高、APIキー、リクエストログ、監査 |
| [Status](https://status.hostlinku.com) | 発生中の障害とインシデント |

少人数のチームが平日にできるだけ早くメールに返信します（ベストエフォート）。インシデントの更新はStatusページに掲載されます。

## 報告に添える情報

1. レスポンスまたはConsoleログで取得できた場合の `x-request-id`。
2. タイムゾーンを含む発生時刻、エンドポイント、モデルのslug。
3. HTTPステータスとエラー本文。コード／タイプは [API形式](/ja/errors) によって異なります。
4. APIキーや機密情報を除いた、再現可能な最小リクエスト。

```text
時刻: 2026-11-06 14:32 UTC+7
Request ID: <x-request-id>
Endpoint: /v1/chat/completions
Model: gpt-5-5
HTTP: 503
Error: UPSTREAM_TIMEOUT ("The request timed out. Please retry.")
補足: 直近10分で3回発生。
```

## セキュリティの問題

セキュリティの発見は、件名を `[SECURITY]` として [halo@hostlinku.com](mailto:halo@hostlinku.com) へ非公開で送ってください。対応前の詳細公開は控えてください。サポートはAPIキー、パスワード、OTPコードを求めません。報告にシークレットを含めないでください。
