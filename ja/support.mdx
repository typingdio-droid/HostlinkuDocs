## サポートチャネル

| チャネル | 用途 |
|---|---|
| [halo@hostlinku.com](mailto:halo@hostlinku.com) | 技術的な質問、アカウント、および請求 |
| [Console](https://console.hostlinku.com) | 残高、APIキー、リクエストログ、および監査 |
| [ステータス](https://status.hostlinku.com) | 現在発生中の障害およびインシデント |

メールへの返信は、小規模なチームによって営業日中にできるだけ早く行われます（ベストエフォート）。インシデントの最新情報は「ステータス」ページで発表されます。

<a id="informasi-untuk-laporan"></a>

<a id="報告に添える情報"></a>

## レポートに関する情報

1. `x-request-id`は、Consoleのレスポンスまたはログに存在する場合に限る。
2. 発生時刻（タイムゾーン付き）、エンドポイント、およびモデルのスラグ。
3. HTTPステータスおよびエラー本文；コード／タイプは[APIフォーマット](/ja/errors)によって異なります。
4. APIキーおよび機密データを削除した、再現可能な最小限のリクエスト例。

```text
Waktu: 2026-11-06 14:32 UTC+7
Request ID: <x-request-id>
Endpoint: /v1/chat/completions
Model: gpt-5-5
HTTP: 503
Error: UPSTREAM_TIMEOUT ("The request timed out. Please retry.")
Catatan: Terjadi 3 kali dalam 10 menit terakhir.
```

## セキュリティ上の問題

セキュリティ上の発見事項は、件名を `[SECURITY]` として、[halo@hostlinku.com](mailto:halo@hostlinku.com) へ非公開で送信してください。対応が完了するまでは、詳細を公開しないでください。サポートチームはAPIキー、パスワード、OTPコードを要求することはありません。レポートにシークレットを含めないでください。
