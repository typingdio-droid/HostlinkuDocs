Hostlinku は、一元化されたモデルカタログを提供します。 各モデルには、[Chat Completions](/ja/chat-completions)の`model`パラメータで使用される一意の**slug**があり、コンテキストサイズ、機能、トークンあたりの価格も記載されています。

## `GET /v1/models`

ステータスが `available` で、まだ非推奨になっておらず、使用中の **Service Mode API key**（Performance、Low-Cost、Dedicated）で利用可能なすべてのモデル、およびそのモードにおける 1M トークンあたりの <CreditIcon /> の価格を一覧表示します。

```http
GET https://api.hostlinku.com/v1/models
Authorization: Bearer sk-your-api-key
```

例：

```bash
curl https://api.hostlinku.com/v1/models \
  -H "Authorization: Bearer sk-your-api-key"
```

レスポンス（例は一部省略されています。お客様のアカウントの正確な値は、このエンドポイントから取得されます）：

```json
{
  "object": "list",
  "service_mode": "performance",
  "data": [
    {
      "id": "claude-haiku-4-5",
      "object": "model",
      "created": 1791380432,
      "owned_by": "hostlinku",
      "context_window": 200000,
      "capabilities": [
        "text",
        "tool-calling",
        "function-calling",
        "structured-outputs",
        "json-mode",
        "streaming",
        "code-generation",
        "long-context",
        "multilingual"
      ],
      "service_mode": "performance",
      "pricing": {
        "input": 0.84,
        "output": 4.2,
        "cache_read": 0.084,
        "cache_write": 1.05,
        "unit": "1M_tokens",
        "currency": "🪙"
      },
      "health": "operational"
    }
  ]
}
```

| フィールド | 意味 |
|---|---|
| `service_mode`（レベル一覧および項目） | Service Mode API keyで使用されるモデル：`performance`、`low_cost`、`dedicated`。モデル一覧はモードごとに異なります。 |
| `id` | slugモデル。`/v1/chat/completions`、`/v1/messages`、および`/v1/responses`の`model`フィールドで使用される値。 |
| `created` | モデルがカタログに追加された時刻（Unixエポック、秒）。 |
| `owned_by` | 常に `"hostlinku"` - このモデルがカタログ Hostlinku によって管理されていることを示すマーカー。 |
| `context_window` | トークン内の最大コンテキストサイズ（入力＋出力）。 |
| `capabilities` | 機能一覧（例：`vision`、`tool-calling`、`json-mode`、`reasoning`、`long-context`）。 |
| `pricing` | Service Modeにおける価格の対象は、`null`（そのモードでモデルにまだ価格がない場合）。 `pricing.unit`は常に`"1M_tokens"`であり、`pricing.currency`にはクレジット記号が含まれます（1 <CreditIcon /> = \$1）。 |
| `pricing.input` / `pricing.output` | プロンプトトークン／回答トークンの価格は、**1Mトークン**あたり（1トークンあたりや1Kあたりではありません）です。 |
| `pricing.cache_read` / `pricing.cache_write` | キャッシュ読み取り／5分間のキャッシュ書き込みの100万トークンあたりの価格。設定のない料金は省略される場合があります。[プロンプトキャッシュ](/ja/prompt-caching)を参照してください。 |

<Callout type="note" title="Pricingは利用者向け価格です">
`pricing` はマージンを含む、キーのService Modeにおける利用者向け価格です。非ストリーミングレスポンスには `hostlinku.cost` が含まれます。使用量と費用はコンソールのログでも確認できます。
</Callout>

## 公開カタログ（認証不要）

APIキーなしでモデルとService Modeを比較するには、次のエンドポイントを使用します。

```http
GET https://api.hostlinku.com/api/public/models-v2
GET https://api.hostlinku.com/api/public/service-modes
```

`models-v2` は `{status, currency, models}` を返します。各モデルには `slug`、`displayName`、`contextTokens`、記載がある場合の `maxOutputTokens`、`capabilities`、`serviceModes`、および `modes` 内のモード別価格が含まれます。`service-modes` はモードの概要とモデル一覧を含む `{status, data}` を返します。

特定のAPIキーで利用できるモデルと価格は、`GET /v1/models` で確認してください。

## モデルの選び方

1. **要件を特定する**：通常のチャット、推論（_reasoning_）、ビジョン／マルチモーダル、ツール呼び出し、または構造化されたJSON出力。フィールド`capabilities`を確認してください。
2. **コンテキストのサイズに注意**：`context_window`が、あなたのプロンプトと出力に対して十分な容量であることを確認してください。
3. **価格の比較**：プロンプトトークンは`pricing.input`、回答トークンは`pricing.output`です。推論モデルは一般的に出力コストが高くなります。
4. **小型モデルから始める**：開発段階では、軽量クラスのモデル（例：`gpt-6-luna`、`deepseek-v4-1-flash`、`qwen3-6-plus`）の方がはるかに安価です。品質に問題がある場合にのみ、上位モデルに切り替えてください。
5. **コンソールを参照**：[console.hostlinku.com](https://console.hostlinku.com) の **モデル** メニューには、価格や仕様が同じカタログに加え、各モデルの詳細ページが表示されます。

<Callout type="tip" title="モデルID">
`GET /v1/models` のslugをそのまま `model` フィールドにコピーしてください。不明なslugは `MODEL_NOT_FOUND`、キーで利用できないモデルは `MODEL_NOT_IN_SERVICE_MODE` または `MODEL_UNAVAILABLE` を返す場合があります。
</Callout>

## ルーティングとフェイルオーバー

ゲートウェイはモデルとキーのService Modeに応じたサービス経路を選択します。再試行やフェイルオーバーは利用可能な経路と障害の種類に依存し、すべてのモデルに予備経路があるわけではありません。リクエストのモデルIDは変更しません。
