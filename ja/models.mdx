Hostlinkuは、一元化されたモデルカタログを提供しています。各モデルには一意の**slug**があり、
[Chat Completions](/ja/chat-completions)の`model`パラメータで使用され、コンテキストサイズ、
機能、およびトークンあたりの価格が記載されています。

## `GET /v1/models`

ステータスが `available` で、まだ非推奨になっておらず、使用中の
**サービスモード API キー**（Performance、Low-Cost、または Dedicated）で利用可能なすべてのモデルを、そのモードにおける 1M トークンあたりの価格 <CreditIcon /> とともに
返します。

```http
GET https://api.hostlinku.com/v1/models
Authorization: Bearer sk-your-api-key
```

例：

```bash
curl https://api.hostlinku.com/v1/models \
  -H "Authorization: Bearer sk-your-api-key"
```

レスポンス（例は一部省略されています。お客様のアカウントの正確な値は、このエンドポイントから取得されます）：

```json
{
  "object": "list",
  "service_mode": "performance",
  "data": [
    {
      "id": "claude-haiku-4-5",
      "object": "model",
      "created": 1791380432,
      "owned_by": "hostlinku",
      "context_window": 200000,
      "capabilities": [
        "text",
        "tool-calling",
        "function-calling",
        "structured-outputs",
        "json-mode",
        "streaming",
        "code-generation",
        "long-context",
        "multilingual"
      ],
      "service_mode": "performance",
      "pricing": {
        "input": 0.84,
        "output": 4.2,
        "cache_read": 0.084,
        "cache_write": 1.05,
        "unit": "1M_tokens",
        "currency": "🪙"
      },
      "health": "operational"
    }
  ]
}
```

| フィールド | 意味 |
|---|---|
| `service_mode`（リストレベルおよび項目レベル） | 使用されるサービスモードのAPIキー：`performance`、`low_cost`、または`dedicated`。モードごとにモデル一覧が異なります。 |
| `id` | モデルのスラグは、`/v1/chat/completions`、`/v1/messages`、および`/v1/responses`の`model`フィールドで使用される値です。 |
| `created` | モデルがカタログに追加された時刻（Unixエポック、秒）。 |
| `owned_by` | 常に `"hostlinku"` と表記すること。これは、モデルがHostlinkuカタログによって管理されていることを示すマーカーです。 |
| `context_window` | トークン単位での最大コンテキストサイズ（入力＋出力）。 |
| `capabilities` | 機能一覧（例：`vision`、`tool-calling`、`json-mode`、`reasoning`、`long-context`）。 |
| `pricing` | 当該サービスモードにおける価格オブジェクト。モデルがそのモードでまだ価格を持っていない場合は `null` とする。`pricing.unit` は常に `"1M_tokens"` であり、`pricing.currency` にはクレジットのシンボルが含まれる（1 <CreditIcon /> = \$1）。 |
| `pricing.input` / `pricing.output` | プロンプトトークン／回答トークンの価格は、**1Mトークン**あたり（1トークンあたりや1Kあたりではない）です。 |
| `pricing.cache_read` / `pricing.cache_write` | 5分間のキャッシュ読み取り／キャッシュ書き込みあたりの1Mトークンあたりの価格。利用できない料金については記載しなくても構いません。[プロンプトキャッシュ](/ja/prompt-caching)を参照してください。 |

<Callout type="note" title="Pricingは顧客価格です">
`pricing`は、マージンを含むサービスモードキーの顧客価格です。非ストリーミングのレスポンスでは、コストは`hostlinku.cost`で確認できます。使用状況とコストは、Consoleのログでも確認できます。
</Callout>

## 公開カタログ（認証不要）

APIキーがない場合は、モデルとサービスモードを比較するために以下のエンドポイントを使用してください：

```http
GET https://api.hostlinku.com/api/public/models-v2
GET https://api.hostlinku.com/api/public/service-modes
```

`models-v2`は`{status, currency, models}`を返します。 各モデルには、`slug`、`displayName`、`contextTokens`、利用可能な場合は`maxOutputTokens`、`capabilities`、`serviceModes`、および`modes`内のモードごとの価格が格納されています。`service-modes`は、モードとモデルの概要を含む`{status, data}`を返します。

特定のAPIキーに適用されるリストや価格については、`GET /v1/models`を使用してください。

## モデルの選び方

1. **要件を特定**：通常のチャット、推論（_reasoning_）、ビジョン／マルチモーダル、ツール呼び出し、
   または構造化されたJSON出力。`capabilities`フィールドを確認してください。
2. **コンテキストのサイズに注意**：`context_window`がプロンプトと出力に対して十分なサイズであることを確認してください。
3. **価格の比較**：プロンプトトークンには `pricing.input`、回答トークンには `pricing.output` を使用します。
   推論モデルの場合、出力側の価格が一般的に高くなります。
4. **小規模なモデルから始める**：開発においては、軽量クラスのモデル（例：`gpt-6-luna`、
   `deepseek-v4-1-flash`、`qwen3-6-plus`）の方がはるかに安価です。モデルのクラスを上げるのは、
   品質が不十分な場合に限ってください。
5. **コンソールを参照**：[console.hostlinku.com](https://console.hostlinku.com) の **モデル** メニュー
   には、価格や機能が同じカタログに加え、モデルごとの詳細ページが表示されます。

<Callout type="tip" title="モデルID">
`GET /v1/models` のスラグをそのまま `model` フィールドにコピーしてください。未知のスラグは `MODEL_NOT_FOUND` を、キーに存在しないモデルは `MODEL_NOT_IN_SERVICE_MODE` または `MODEL_UNAVAILABLE` を返す可能性があります。
</Callout>

## ルーティングとフェイルオーバー

Gatewayは、モデルとService Modeキーに基づいてサービス経路を選択します。リトライやフェイルオーバーは、利用可能な経路と障害の種類によって異なります。すべてのモデルに予備の経路があるわけではありません。リクエストにおけるモデルIDは変更されません。
