Hostlinkuでは、相互に補完し合う3つの層で利用制限が設けられています。それは、**レート制限**（一定時間あたりのリクエスト数）、**APIキーごとのクレジット制限**（リセット期間ごとの費用）、および**アカウント残高**（資金源）です。 これら3つは、リクエストがプロバイダーに転送される前に、サーバー側でチェックされます。

## レート制限

| 適用範囲 | 境界 | 境界の決定要因 |
|---|---|---|
| `POST /v1/chat/completions` | **600リクエスト／分** | APIキー（`sk-…`）あたり |
| コンソールおよびパブリックエンドポイント (`/api/*`) | **120リクエスト／分** | IPアドレスごと |
| 認証エンドポイント（ログイン、登録、OTP、パスワードリセット） | **30回の試行 / 15分** | IPアドレスごと |

リミッターを通過するすべての応答には、標準ヘッダー（IETF `RateLimit-*` 形式）が含まれます：`RateLimit-Limit`、`RateLimit-Remaining`、および `RateLimit-Reset`。 `Reset`の値を確認することで、次のウィンドウがいつ開始されるかを知ることができます。

制限を超えた際の反応は：

```http
HTTP/1.1 429 Too Many Requests
```

```json
{
  "status": "error",
  "error": {
    "code": "RATE_LIMITED",
    "message": "Rate limit terlampaui. Tingkat plan untuk limit lebih tinggi."
  }
}
```

<Callout type="tip" title="正しいバックオフ戦略">
429の場合、`RateLimit-Reset`に従って待機し（または、ジッターを伴う1秒→2秒→4秒…という指数関数的なバックオフを行い）、その後再試行してください。間隔を空けずに再送信しないでください。そうすると、実行中のウィンドウでのブロック時間が長引くだけです。
</Callout>

## APIキーごとのクレジット上限

レート制限とは別に、各APIキーには、**費用制限**（USD）を設定できます。リセット間隔は、毎日、毎週、毎月（UTCカレンダー）、またはリセットなしの合計額から選択可能です。使用量は、APIキーごとの実際のリクエスト費用に基づいて計算されます。 制限に達したAPIキーは、次のリセット期間が開始されるまで**402 PAYMENT_REQUIRED**として拒否されます。設定の詳細については、[認証](/ja/authentication)をご覧ください。

## リクエスト時の残高確保

各リクエストに対して、ゲートウェイは：

1. **予約** 見積もり費用（プロンプトの長さと`max_tokens`に基づく）を口座残高から引き落とす。
2. リクエストをプロバイダーに転送します。
3. **コミット**：使用されたトークンに基づいて実際の費用を確定し、残りの予約を解除する。

つまり、コンソールの残高は `balance`（合計）と `reserved`（保留中のリクエスト）に分かれています。新しいリクエストに使用できるのは `balance − reserved`（`available`）です。 失敗したリクエストには**料金は発生しません**。予約は自動的に解除されます。

## コンソールでの使用状況を監視する

[console.hostlinku.com](https://console.hostlinku.com) にアクセスしてください：

| メニュー | 目次 |
|---|---|
| **ダッシュボード / 利用状況** | リクエスト、トークンの入出、キャッシュ、および期間ごとのコスト（24時間、7日、30日、90日）の概要。 |
| **リクエストログ** | リクエストの完全な一覧：モデル、ステータス、トークン、コスト、レイテンシ（ストリーミング用のTTFTを含む）、およびリクエストごとの詳細。 |
| **監査ログ** | アカウントの操作履歴：APIキーの作成・無効化、チャージ、設定の変更など。 |
| **APIキー** | APIキーごとの使用状況：リクエスト、トークン、料金、`lastUsed`、有効期限、および制限。 |

すべての数値は、課金に使用されているものと同じバックエンドのテレメトリテーブルから取得されており、表示側での推定値は含まれていません。

<Callout type="note" title="API 1件あたりのリクエスト費用">
ご自身のアプリケーションの場合、各チャット補完レスポンス内のブロック「`hostlinku.cost`」にはそのリクエストの費用が含まれており、ヘッダー「`x-request-id`」によってコンソールのログ行と関連付けられています。
</Callout>

## 429および402の挙動の概要

| コード | 意味 | やるべきこと |
|---|---|---|
| `429 RATE_LIMITED` | 指定された期間内にリクエストが多すぎます | `RateLimit-Reset`を待機するか、バックオフするか、あるいは競合を減らす |
| `402 PAYMENT_REQUIRED` | クレジットに関する問題：残高不足 **または** API キーの制限に達しました | エラーメッセージを確認してください。「APIキーのクレジット上限」と表示されている場合は、リセットされるまで待つか、上限を引き上げてください。「クレジット残高が不足しています」と表示されている場合は、チャージを行ってください（[請求・残高](/ja/billing)）。 |
