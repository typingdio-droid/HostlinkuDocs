Hostlinkuの主要なエンドポイント。リクエストおよびレスポンスのフォーマットは
[OpenAI Chat Completions API](https://platform.openai.com/docs/api-reference/chat)と互換性があるため、
公式のOpenAI SDKを、`base_url`を`https://api.hostlinku.com/v1`に置き換えるだけで使用できます。

```http
POST https://api.hostlinku.com/v1/chat/completions
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

成功レスポンスには `x-request-id` が含まれます。非ストリーミングの成功レスポンスには、`x-model`（モデルのパブリックスラグ）も含まれます。

Service Mode APIキーで利用可能なモデルを選択してください。Vision、JSONスキーマ、推論、およびツール呼び出しのサポートは、モデルおよびそのプロトコルパスに従います。[互換性の制限](/ja/responses)を参照してください。

<a id="parameter-body"></a>

<a id="bodyパラメータ"></a>

## ボディパラメータ

| パラメータ | タイプ | デフォルト | 備考 |
|---|---|---|---|
| `model` | `string` | なし | **必須。** モデルのスラグ（例：`gpt-5-5`）。[モデル](/ja/models)を参照してください。 |
| `messages` | `array` | なし | **必須。** 最低1件のメッセージ。各項目：`{ role, content, name? }` であり、`role` は `system`、`developer`、`user`、`assistant`、`tool` のいずれかです。 |
| `temperature` | `number` | プロバイダー固有 | 範囲は `0`–`2`。数値が大きいほどランダム性が高くなります。 |
| `top_p` | `number` | プロバイダー固有 | 範囲は `0`–`1` です。`temperature` の代替として _nucleus sampling_ があります。 |
| `n` | `integer` | `1` | 回答選択肢の数：`1`～`8`。 |
| `stream` | `boolean` | `false` | SSEストリーミングレスポンスの場合は`true`（以下を参照）。 |
| `stop` | `string` \| `string[]` | なし | 生成を停止させる1つまたは複数のテキストシーケンス。 |
| `max_tokens` | `integer` | モデルのデフォルト | トークン出力の上限（正の値）。 |
| `max_completion_tokens` | `integer` | なし | 現代的な代替表現として `max_tokens` があります（一部のプロバイダーで使用されています）。 |
| `presence_penalty` | `number` | `0` | 範囲 `-2`–`2`。 |
| `frequency_penalty` | `number` | `0` | 範囲 `-2`–`2`。 |
| `user` | `string` | なし | 不正利用の追跡のためのエンドユーザー識別子。 |
| `tools` | `array` | なし | ツール／関数呼び出しの定義（OpenAI形式）。 |
| `tool_choice` | `any` | なし | ツール選択の制御（`"auto"`、`"none"`、`{...}`）。 |
| `response_format` | `any` | なし | 例：JSON出力の場合、`{ "type": "json_object" }`（モデルのサポート状況による）。 |
| `seed` | `integer` | なし | シードの決定性（ベストエフォート、プロバイダーによる）。 |

<Callout type="note" title="パラメータの検証">
  上記のリストは主要なパラメータです。スキーマでは、`top_k`、`web_search_options`、`reasoning_effort`、`parallel_tool_calls`、`logprobs`、 `top_logprobs`、`logit_bias`、`stream_options`、`metadata`、`thinking`、`verbosity`、`service_tier`、`store`、`prompt_cache_key`、`safety_identifier`、および`truncation`を受け入れます。未知のトップレベルフィールドは破棄されます。 `messages[]`内の追加フィールド（`tool_calls`、`tool_call_id`、`function_call`、および`reasoning_content`を含む）は保持されます。 マルチモーダルなパラメータおよびコンテンツのサポートは、引き続きモデル／プロトコルに依存します。無効なボディは、フィールドの詳細とともに `422 VALIDATION_FAILED` として拒否されます。
</Callout>

<a id="contoh-request-non-streaming-curl"></a>

## 例：非ストリーミングリクエスト（curl）

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [
      { "role": "system", "content": "Kamu adalah asisten yang ringkas." },
      { "role": "user", "content": "Jelaskan apa itu API gateway dalam dua kalimat." }
    ],
    "temperature": 0.7,
    "max_tokens": 256
  }'
```

回答（抜粋）：

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "created": 1770000000,
  "model": "gpt-5-5",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "API gateway adalah …" },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 30, "completion_tokens": 55, "total_tokens": 85 },
  "hostlinku": {
    "cost": 0.00021,
    "latencyMs": 940
  }
}
```

`model`にはHostlinkuのパブリックスラグが含まれます。非ストリーミングの成功レスポンスにおける`hostlinku`ブロックには、コスト、サービスモード、およびレイテンシが含まれます。このブロックは、すべてのSSEチャンクで保証される部分ではありません：

| フィールド | 意味 |
|---|---|
| `cost` | クレジット単位の費用 🪙；1クレジット＝1ドル。 |
| `latencyMs` | ゲートウェイでの受信から完了までのリクエストの総遅延時間（ミリ秒）。 |

<a id="streaming-stream-true"></a>

## ストリーミング (`stream: true`)

`stream: true`の場合、ゲートウェイは`Content-Type: text/event-stream` (SSE)で応答し、
OpenAI互換のフォーマットでチャンクをストリーミングします （各チャンクはHostlinkuの公開`id`
および同一のモデルスラッグを使用）でチャンクをストリーミングし、最後に`data: [DONE]`でストリームを終了します：

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Hitung 1 sampai 5." }],
    "stream": true
  }'
```

```text
data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"role":"assistant","content":""}}]}

data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":"1"}}]}

data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":", 2"}}]}

data: [DONE]
```

重要な注意事項：

- ストリームが失敗した場合は、エラーイベントを処理し、接続切断を失敗として扱ってください。`[DONE]`というマーカーだけではリクエストが成功したとは証明されません。エラーを確認し、`x-request-id`を含むリクエストログを確認してください。
- 最終的な費用は「usage」または「upstreamの費用」を使用します。空またはゼロの場合、ゲートウェイは予約見積もりを使用できます。
- ヘッダー `x-request-id` は、ストリーミングレスポンスでも送信され、
  コンソールのログと関連付けられます。

<a id="contoh-python-sdk-resmi-openai"></a>

## 例：Python（OpenAI公式SDK）

`base_url` 以外のコードの変更はありません。OpenAI SDK はそのまま使用可能です：

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key="sk-your-api-key",
)

# Non-streaming
response = client.chat.completions.create(
    model="gpt-5-5",
    messages=[
        {"role": "system", "content": "Kamu adalah asisten yang ringkas."},
        {"role": "user", "content": "Halo dari SDK OpenAI!"},
    ],
)
print(response.choices[0].message.content)

# Streaming
stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
```

<Callout type="tip" title="他のライブラリ内の「base_url」を置き換えてください">
  同様のルールは、`openai-node`（`new OpenAI({ baseURL: 'https://api.hostlinku.com/v1' })`）、
  LangChain（`baseURL`/`openai_api_base`）、および
  OpenAI互換のエンドポイントをサポートするその他のツールにも適用されます。
</Callout>

<a id="error-yang-umum-di-endpoint-ini"></a>

## このエンドポイントでよく発生するエラー

| 事例 | HTTP | `error.code` |
|---|---|---|
| Bodyは検証に合格していません（フィールドが間違っている／型が間違っている／`messages`が空です） | 422 | `VALIDATION_FAILED` |
| APIキーが無効か、有効期限が切れています | 401 | `UNAUTHORIZED` |
| APIキーの残高または制限が不足しています | 402 | `PAYMENT_REQUIRED` |
| モデルのスラグはカタログに存在しません | 404 | `MODEL_NOT_FOUND` |
| `max_tokens`はモデルの出力制限を超えています | 400 | `BAD_REQUEST` |
| モデルは非推奨／現在利用不可 | 503 | `MODEL_UNAVAILABLE` |
| 組織全体のクォータを超過しました | 429 | `RATE_LIMITED` |
| アップストリームが利用不可／一時的な障害（再試行可能） | 503 | `UPSTREAM_ERROR` |

エラーエンベロープの完全なフォーマットは [Error](/ja/errors) に記載されています。
