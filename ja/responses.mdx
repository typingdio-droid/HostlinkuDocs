Hostlinkuは、
[OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses) — **Codex CLI**、**OpenAI Agents SDK**、およびOpenAI SDKの`client.responses.create()`メソッドで使用される
フォーマットです。
base URLを変更するだけで済みます。APIキー、残高、サービスモード、レート制限、およびリクエストログは、
`/v1/chat/completions`および`/v1/messages`と同じです。

```http
POST https://api.hostlinku.com/v1/responses
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

成功レスポンスには `x-request-id` が含まれます。非ストリーミングの成功レスポンスには、`x-model`（モデルのパブリックスラグ）も含まれます。

<Callout type="note" title="モデルおよびツールの互換性">
  `model`は、[モデルカタログ](/ja/models)のパブリックスラグを使用しています。ゲートウェイは、デプロイメントモデルに応じて、ネイティブおよびブリッジ経由のChat Completionsへのレスポンスパスを提供します。 Service ModeのPerformanceおよびLow-Costでは、CodexはOpenAI/GPTモデルのみをサポートしており、Claudeモデルおよび国内モデルはサポートされていません。Dedicatedの場合、ツールのサポートはモデルおよびデプロイメントによって異なります。レスポンス形式のサポートは、すべてのモデルがResponsesの全機能やCodexツールをサポートしていることを意味するものではありません。
</Callout>

Service Mode APIキーで利用可能なモデルを選択してください。Vision、reasoning、caching、JSONスキーマ、およびツール呼び出しは、モデルの機能に従います。ネイティブのレスポンスはアップストリームの機能を継承します。ブリッジChat Completionsは、メッセージ、モデルがサポートする画像、および`type: "function"`のツールをサポートします。ホスト型/カスタムツールおよび暗号化されたreasoningには、ネイティブのサポートが必要です。

## クイック設定

各ツールの詳細なガイドは、[Codex CLI](/ja/integrations/codex-cli) および
[OpenAI Agents SDK](/ja/integrations/agents-sdk) に掲載されています。

**Codex CLI** (`~/.codex/config.toml`)

```toml
model = "gpt-5-5"
model_provider = "hostlinku"

[model_providers.hostlinku]
name = "Hostlinku"
base_url = "https://api.hostlinku.com/v1"
env_key = "HOSTLINKU_API_KEY"
wire_api = "responses"
```

```bash
export HOSTLINKU_API_KEY=sk-your-api-key
codex
```

**Python（OpenAI公式SDK）**

```python
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.hostlinku.com/v1")

response = client.responses.create(
    model="gpt-5-5",
    instructions="Jawab singkat dalam bahasa Indonesia.",
    input="Apa itu API gateway?",
    max_output_tokens=256,
)
print(response.output_text)
print(response.usage.input_tokens, response.usage.output_tokens)
```

**Node.js**

```ts
import OpenAI from "openai";

const client = new OpenAI({ apiKey: "sk-your-api-key", baseURL: "https://api.hostlinku.com/v1" });
const response = await client.responses.create({
  model: "claude-sonnet-4-6",
  input: "Halo!",
  max_output_tokens: 256,
});
console.log(response.output_text);
```

**OpenAI Agents SDK (Python)**

```python
from agents import Agent, Runner, set_default_openai_client, set_tracing_disabled
from openai import AsyncOpenAI

set_default_openai_client(AsyncOpenAI(api_key="sk-your-api-key", base_url="https://api.hostlinku.com/v1"))
set_tracing_disabled(True)  # tracing OpenAI tidak tersedia lewat gateway

agent = Agent(name="Asisten", instructions="Jawab singkat.", model="gpt-5-5")
result = Runner.run_sync(agent, "Sebutkan 3 bahasa pemrograman.")
print(result.final_output)
```

## ボディパラメータ

| パラメータ | タイプ | 備考 |
|---|---|---|
| `model` | `string` | **必須。** Hostlinkuモデルのスラッグ。 |
| `input` | `string` \| `array` | **必須。** 単一のテキスト、または配列の項目：`message`（`role` + `content`には`input_text`/`input_image`/…が含まれる）、`function_call`、`function_call_output`、`reasoning`。 |
| `instructions` | `string` | システムプロンプト（開発者向けメッセージ）。 |
| `max_output_tokens` | `integer` | トークンの出力制限。モデルの出力制限を超えた場合、`400`で拒否されます。 |
| `stream` | `boolean` | SSEについては`true`（下記参照）。 |
| `tools`、`tool_choice`、`parallel_tool_calls` | - | 関数呼び出し形式のレスポンス（`{ "type": "function", "name", "parameters" }`）。 |
| `reasoning` | `object` | 例：`{ "effort": "low" \| "medium" \| "high", "summary": "auto" }`。 |
| `include` | `string[]` | 例：`["reasoning.encrypted_content"]`；暗号化された項目の利用可能性は、アップストリームのネイティブレスポンスのサポートに依存します。Bridgeチャットでは、暗号化された推論項目は保持されません。 |
| `text`、`truncation`、`temperature`、`top_p`、`metadata`、`user`、`prompt_cache_key`、`safety_identifier` | - | OpenAIの仕様に準拠し、モデルに転送されます。 |
| `store` | `boolean` | 常に `false` として扱われます（*Stateless* を参照）。 |
| `previous_response_id`、`conversation`、`background` | - | `previous_response_id` および `conversation` が null でない場合は `400 invalid_request_error` で拒否されます。`background: true` は拒否されます。フィールドは省略可能です。`background: false` は受け入れられます。 |

レスポンスのボディ内のその他のフィールドは転送されます。パラメータは、パスおよびアップストリームのサポートに応じて、転送、無視、または拒否される場合があります。スキーマの受け入れは、モデル機能の保証ではありません。無効なボディは `400 invalid_request_error` として拒否され、詳細は `error.details.issues` に記載されます。

<Callout type="important" title="Stateless - `input`に完全な履歴を送信する">
  `store: false` を指定して、`input` に完全な履歴を送信してください。`previous_response_id` および `conversation` が null でない場合、ならびに `background: true` は拒否されます。`GET`/`DELETE /v1/responses/{id}` は利用できません。 reasoningアイテムはネイティブパスで再利用可能であり、ブリッジチャットはこれをバイパスします。
</Callout>

## 非ストリーミング応答

```json
{
  "id": "resp_…",
  "object": "response",
  "created_at": 1791850828,
  "completed_at": 1791850829,
  "status": "completed",
  "error": null,
  "incomplete_details": null,
  "model": "gpt-5-5",
  "output": [
    { "id": "rs_…", "type": "reasoning", "summary": [], "encrypted_content": "…" },
    {
      "id": "msg_…",
      "type": "message",
      "status": "completed",
      "role": "assistant",
      "content": [{ "type": "output_text", "text": "API gateway adalah …", "annotations": [] }]
    }
  ],
  "usage": {
    "input_tokens": 20,
    "output_tokens": 19,
    "total_tokens": 39,
    "input_tokens_details": { "cached_tokens": 0 },
    "output_tokens_details": { "reasoning_tokens": 12 }
  },
  "previous_response_id": null,
  "store": false,
  "hostlinku": { "cost": 0.00031, "currency": "🪙", "serviceMode": "performance", "latencyMs": 1420 }
}
```

`id` および `model` は常に Hostlinku の公開識別子です。`hostlinku` ブロックは拡張子（OpenAI SDK
はこれを無視します）であり、コスト <CreditIcon />、サービスモードの API キー、およびレイテンシが含まれます。`status: "incomplete"` に対して
`incomplete_details.reason = "max_output_tokens"` の場合、出力は `max_output_tokens` によって切り詰められたことを意味します
- 実際のトークンに基づいて課金されます。

<Callout type="warning" title="推論モデル + `max_output_tokens` が小さい">
  推論モデル（例：DeepSeek V4、GPT-6、thinking機能付きClaude）では、推論トークンも
  `max_output_tokens` にカウントされます。値が小さい場合（例：`16`）、通常は `reasoning` 項目だけで上限に達してしまいます
  だけで使い切られてしまう → `status: "incomplete"` となり、`output` には `message` なしで `reasoning` 項目のみが含まれる。
  `max_output_tokens` を 256 以上に設定するか、`reasoning.effort` を `"low"` に下げる。
</Callout>

<Callout type="note" title="APIレスポンスの使用に関する規約">
  Chat Completionsと同様に、`input_tokens`にはキャッシュされたトークンが**すでに含まれています**。詳細は
  `input_tokens_details.cached_tokens`に記載されています。`output_tokens`には`reasoning_tokens`が含まれています。Hostlinkuの請求額は
  は、これらのコンポーネントの各単価に基づいて計算されます（[Billing](/ja/billing)を参照）。
</Callout>

<a id="streaming-stream-true"></a>

## ストリーミング (`stream: true`)

Gatewayは、APIレスポンスのフレーミング（`event:` + `data:`）を使用してSSEイベントを転送し、これには
アップストリームからの`sequence_number`が含まれます：

```text
event: response.created
data: {"type":"response.created","sequence_number":0,"response":{"id":"resp_…","object":"response","status":"in_progress","model":"gpt-5-5","output":[],…}}

event: response.in_progress
data: {"type":"response.in_progress","sequence_number":1,"response":{…}}

event: response.output_item.added
data: {"type":"response.output_item.added","sequence_number":2,"output_index":0,"item":{"id":"msg_…","type":"message","status":"in_progress","role":"assistant","content":[]}}

event: response.content_part.added
data: {"type":"response.content_part.added","sequence_number":3,"item_id":"msg_…","output_index":0,"content_index":0,"part":{"type":"output_text","text":"","annotations":[]}}

event: response.output_text.delta
data: {"type":"response.output_text.delta","sequence_number":4,"item_id":"msg_…","output_index":0,"content_index":0,"delta":"API gateway"}

event: response.output_text.done
data: {"type":"response.output_text.done","sequence_number":5,"item_id":"msg_…","output_index":0,"content_index":0,"text":"API gateway adalah …"}

event: response.content_part.done
data: {"type":"response.content_part.done","sequence_number":6,…}

event: response.output_item.done
data: {"type":"response.output_item.done","sequence_number":7,"output_index":0,"item":{"id":"msg_…","type":"message","status":"completed",…}}

event: response.completed
data: {"type":"response.completed","sequence_number":8,"response":{"id":"resp_…","status":"completed","model":"gpt-5-5","output":[…],"usage":{"input_tokens":20,"output_tokens":19,"total_tokens":39,…}}}
```

注：

- 最終的な使用量（Usage final）は、アップストリームで提供されている場合、`response.completed` または `response.incomplete` に含まれます。コストは当該使用量に基づいて計算されます。使用量が空またはゼロの場合、ゲートウェイは予約の推定値を使用することがあります。拡張子 `hostlinku.cost` は、非ストリーミングの成功レスポンスで利用可能です。すべての SSE イベントでこれを期待しないでください。
- ツール呼び出しは、`response.output_item.added` (`type: "function_call"`)、
  `response.function_call_arguments.delta`、および `response.function_call_arguments.done` を通じて配信されます。
- ストリームが途中で失敗した場合、ゲートウェイは `event: error` を
  `{"type":"error","code":…,"message":…}` の形式で送信し、偽の `response.completed` は**送信しません**。
- 最初のバイトが返される前のエラー（残高不足、モデルが存在しない、レート制限）は、
  正しいHTTPステータスを伴う通常のJSONレスポンスとして返されます。OpenAI SDKはこれを例外
  （`AuthenticationError`、`NotFoundError`、`RateLimitError`、…）にマッピングします。

<a id="ツールの呼び出し関数の呼び出し"></a>

## ツール呼び出し（関数呼び出し）

```python
tools = [{
    "type": "function",
    "name": "get_time",
    "description": "Waktu saat ini di sebuah kota",
    "parameters": {"type": "object", "properties": {"city": {"type": "string"}}, "required": ["city"]},
}]

r1 = client.responses.create(model="claude-sonnet-4-6", input="Jam berapa sekarang di Jakarta?", tools=tools, store=False)
call = next(o for o in r1.output if o.type == "function_call")

# Giliran berikutnya: kirim ulang riwayat + hasil tool (stateless)
r2 = client.responses.create(
    model="claude-sonnet-4-6",
    tools=tools,
    store=False,
    input=[
        {"type": "message", "role": "user", "content": [{"type": "input_text", "text": "Jam berapa sekarang di Jakarta?"}]},
        *[o.model_dump(exclude_none=True) for o in r1.output],
        {"type": "function_call_output", "call_id": call.call_id, "output": '{"time": "10:00 WIB"}'},
    ],
)
print(r2.output_text)
```

<a id="フォーマットエラー"></a>

## エラーの形式

```json
{ "error": { "message": "The API key is invalid or has been revoked.", "type": "authentication_error", "param": null, "code": "invalid_api_key" } }
```

| HTTP | `error.type` | `error.code` | 一般的な原因 |
|---|---|---|---|
| 400 | `invalid_request_error` | `invalid_request` / `model_not_in_service_mode` | Bodyが無効です。`max_output_tokens`がモデルの制限を超えています。`previous_response_id`が送信されています。Service Modeキーではモデルが利用できません。 |
| 401 | `authentication_error` | `invalid_api_key` | APIキーが不正、無効化、または期限切れの場合、あるいはAPIキーなしのリクエスト。 |
| 402 | `insufficient_quota` | `insufficient_quota` | 残高が不足しているか、APIキーのクレジット上限に達しました。 |
| 403 | `permission_error` | - | アカウントが停止されました／アクセスが拒否されました。 |
| 404 | `not_found_error` | `model_not_found` / `not_found` | モデルのスラッグは存在しないか、`GET /v1/responses/{id}`（ステートレス）である。 |
| 429 | `rate_limit_error` | `rate_limit_exceeded` | リクエスト制限に達しました（`Retry-After`ヘッダーを参照）。 |
| 503 | `server_error` | `model_unavailable` / `server_error` | モデル／アップストリームは利用できません。カタログや代替モデルを確認してください。一時的な障害の場合は、間隔を空けて再試行してください。 |

表は、プロトコルが処理するエラーを示しています。ハンドラー前のリクエストやボディの解析に関する制限については、Hostlinkuの一般的な形式を使用できます。[Error](/ja/errors)を参照してください。

エラーメッセージは、内部識別情報を隠蔽するためにサニタイズされていますが、アップストリームによる拒否理由の一部はそのまま表示される場合があります。
