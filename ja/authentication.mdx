Hostlinkuゲートウェイの `/v1/*` エンドポイントでは、`sk-…` 形式のAPIキーを使用します。

```http
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

`x-api-key: sk-…` ヘッダーも利用できます。[Console](https://console.hostlinku.com) の **API Keys** でキーを作成・管理してください。

<Callout type="important" title="APIキーとConsoleセッション">

`/v1/chat/completions`、`/v1/messages`、`/v1/responses`、`/v1/models` にはAPIキーを使用します。`/api/*` の保護されたアカウントエンドポイントはConsoleのログインセッションを使用し、APIキーによる認証には `403 API_KEY_NOT_ALLOWED` を返します。ログインCookieは `/v1/*` のAPIキーを代替できません。

</Callout>

## Consoleへのログイン

[ログイン](https://api.hostlinku.com/api/auth2/login) または [新規登録](https://api.hostlinku.com/api/auth2/register) からKeycloakへ移動し、Consoleに戻ります。

Consoleは `hl_sid` サーバーセッションを使用します。`hl_session` は一部フローのJWT Cookieです。ブラウザが自動管理します。パスキー、TOTP、リカバリーコードは **Settings → Security** で利用できます。

## APIキーの作成と管理

1. **API Keys → Create API key** を開きます。
2. 名前（最大64文字）を入力し、**Service Mode** を **Performance**、**Low-Cost**、**Dedicated** から選びます。初期値はPerformanceです。モードによりキーのモデル一覧、ルーティング、料金が決まります。
3. **30日**（初期値）、**60日**、**90日**、または **無期限（Never）** を選びます。
4. 必要に応じて **Monthly Spending Limit** を有効にし、月間クレジット上限を入力します。
5. 一度だけ表示されるシークレットをコピーし、サーバーの環境変数に保存します。

現在の作成フォームにはエンドポイントのスコープ選択はありません。Service Mode、残高、有効期限、利用上限、レート制限は適用されます。キーで利用可能なモデルは [`GET /v1/models`](/ja/models) で確認してください。

サーバーはシークレットをSHA-256ハッシュとして保存するため、再表示できません。Consoleではキーの編集、無効化・有効化、削除が可能です。紛失・漏洩した場合は新しいキーを作成し、リクエストを確認してから古いキーを無効化してください。

## APIキーごとの利用上限

Consoleは **Monthly Spending Limit** を提供します。キー管理APIはUTC暦の以下の期間に対応します。

| 期間 | UTC暦での費用集計期間 |
|---|---|
| `daily` | 当日の00:00 UTC以降 |
| `weekly` | 当週の月曜日00:00 UTC以降 |
| `monthly` | 当月1日の00:00 UTC以降 |
| `lifetime` / リセットなし | キーの有効期間全体の合計 |

キーに記録されたリクエスト費用を合計し、上限到達後のリクエストは `402 PAYMENT_REQUIRED` になります。キーの上限と組織のクレジット残高は別です。チャージで残高は増えますが、キーの上限は増えません。[課金と残高](/ja/billing) を参照してください。

## レート制限とエラー

利用枠は **毎分 600 リクエスト、6,500,000 入力 token、200,000 出力 token** で、同じ組織内で共有します。上限に達すると、その組織のすべての API キーとメンバーが影響を受けます。 利用枠と 429 の対応は[使用状況と制限](/ja/usage-and-limits)を参照してください。

| 状況 | HTTP | コード |
|---|---|---|
| キーが未指定、無効、無効化済み、または期限切れ | 401 | `UNAUTHORIZED` |
| ConsoleのアカウントエンドポイントでAPIキー認証を使用 | 403 | `API_KEY_NOT_ALLOWED` |
| 利用可能残高の不足またはキー上限到達 | 402 | `PAYMENT_REQUIRED` |
| レート制限超過 | 429 | `RATE_LIMITED` |

<Callout type="tip" title="キーはサーバーに保存">

サーバーの環境変数 `HOSTLINKU_API_KEY` を使用してください。アプリや環境ごとにキーを分け、有効期限と上限を設定し、ブラウザや公開リポジトリにシークレットを置かないでください。

</Callout>
