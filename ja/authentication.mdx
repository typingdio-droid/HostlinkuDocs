Hostlinkuのゲートウェイは、エンドポイント `/v1/*` に対して `sk-…` 形式のAPIキーを使用します：

```http
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

ヘッダー `x-api-key: sk-…` も使用可能です。キーの作成と管理は、[Console](https://console.hostlinku.com) → **API Keys** で行ってください。

<Callout type="important" title="APIキーとConsoleのセッション">

APIキーは、`/v1/chat/completions`、`/v1/messages`、`/v1/responses`、および`/v1/models`で使用されます。`/api/*`上の保護されたアカウントのエンドポイントは、Consoleのログインセッションを使用し、APIキーによる認証を`403 API_KEY_NOT_ALLOWED`で拒否します。 ログインクッキーは、`/v1/*` における API キーの代わりにはなりません。

</Callout>

<a id="login-console"></a>

## Consoleへのログイン

[ログイン](https://api.hostlinku.com/api/auth2/login) または [登録](https://api.hostlinku.com/api/auth2/register) して Keycloak のログイン画面を開き、その後 Console に戻ってください。

Consoleはサーバーセッション`hl_sid`を使用します。`hl_session`は、一部のフローにおけるJWTクッキーです。ブラウザが自動的に管理します。Passkey、TOTP、およびリカバリーコードは、**[設定] → [セキュリティ]**で利用可能です。

<a id="membuat-dan-mengelola-api-key"></a>

## APIキーの作成と管理

1. **API Keys → APIキーの作成**を開きます。
2. 名前（最大64文字）を入力し、**サービスモード**として**Performance**、**Low-Cost**、または**Dedicated**を選択してください。デフォルトはPerformanceです。モードによって、そのキーに適用されるカタログ、ルーティング、および価格が決定されます。
3. 有効期間を選択してください：**30日**（デフォルト）、**60日**、**90日**、または**無期限**。
4. 必要に応じて、**Monthly Spending Limit** を有効にし、月間利用限度額を入力してください。
5. 一度だけ表示されるシークレットをコピーし、サーバーの環境変数に保存してください。

現在のAPIキーフォームには、エンドポイントのスコープ選択オプションはありません。キーは引き続き、サービスモード、残高、有効期間、クレジット限度額、レート制限に制限されます。キーに対応する正しいモデルの一覧は、[`GET /v1/models`](/ja/models)から取得できます。

SecretはSHA-256ハッシュとして保存されるため、復元することはできません。Consoleでは、キーの編集、無効化／有効化、および削除が可能です。Secretが紛失または漏洩した場合は、代替のSecretを作成し、リクエストを検証した上で、古いキーを無効化してください。

## APIキーごとのクレジット制限

Consoleでは**Monthly Spending Limit**が提供されています。キー管理APIは、以下の期間（UTCカレンダー）に対応しています：

| 期間 | UTCカレンダーに基づく費用の期間 |
|---|---|
| `daily` | 当日の00:00 UTCから |
| `weekly` | 今週の月曜日 00:00 UTC から |
| `monthly` | 当月の1日 00:00 UTCより |
| `null` / リセットなし | キーの有効期間中の合計 |

キーごとに、記録されたリクエストの累積利用料が課金されます。制限に達すると、それ以降のリクエストは `402 PAYMENT_REQUIRED` で拒否されます。キーごとの制限は、組織のクレジット残高とは異なります。チャージを行うと残高は増加しますが、キーの制限は引き上げられません。[課金と残高](/ja/billing) をご覧ください。

<a id="rate-limit-dan-error"></a>

## レート制限とエラー

クォータは、**各サービスモード**において、すべてのAPIキーおよび組織メンバーによって共有されます。キーやメンバーアカウントを追加しても、クォータは増加しません。制限値および429エラーの対処方法については、[使用状況と制限](/ja/usage-and-limits)をご参照ください。

| 条件 | HTTP | コード |
|---|---|---|
| キーが存在しない、無効、無効化されている、または有効期限が切れている | 401 | `UNAUTHORIZED` |
| APIキーは、Consoleアカウントのエンドポイント認証に使用されます | 403 | `API_KEY_NOT_ALLOWED` |
| 利用可能な残高が不足しているか、キーのクレジット上限に達しています | 402 | `PAYMENT_REQUIRED` |
| レート制限を超過しました | 429 | `RATE_LIMITED` |

<Callout type="tip" title="keyをサーバーに保存する">

サーバー環境では `HOSTLINKU_API_KEY` を使用してください。アプリケーションや環境ごとに個別のキーを作成し、適切な有効期限と制限を設定してください。また、シークレットをブラウザや公開リポジトリに入力しないでください。

</Callout>
