**Dedicated**は、Hostlinkuのサービスモードの一つであり、そのモードで利用可能なモデル群を指します。[Console](https://console.hostlinku.com)でAPIキーを作成する際は、**Dedicated**を選択してください。モードはキーに紐付けられており、リクエストでモードを変更するための追加パラメータは必要ありません。

<Callout type="note" title="1つのAPIキー = 1つのサービスモード">
「Performance」と「Low-Cost」を同時に使用するには、別々のAPIキーを作成してください。呼び出し可能なモデルと価格はサービスモードのキーに準じます。そのキーを使用して `GET /v1/models` を確認してください。
</Callout>

3つのモードの比較およびキーの選択方法については、[Service Mode](/ja/service-modes)をご覧ください。

<a id="endpoint-dan-autentikasi"></a>

## エンドポイントと認証

Base URLは `https://api.hostlinku.com` のままとします。以下のAPIフォーマットが利用可能です。一部のモデルでは、フォーマットを調整するためにブリッジを使用しています。ベンダーのすべての機能やアプリケーションに組み込まれたツールのサポートについては、個別に確認する必要があります。

| フォーマット | エンドポイント | 認証ヘッダー |
|---|---|---|
| OpenAI Chat | `POST /v1/chat/completions` | `Authorization: Bearer <API_KEY>` |
| OpenAIの応答 | `POST /v1/responses` | `Authorization: Bearer <API_KEY>` |
| Anthropic Messages | `POST /v1/messages` | `x-api-key: <API_KEY>` |

<a id="harga"></a>

## 価格

Service Mode APIキーの使用量に基づいて課金されます。**1 <CreditIcon /> = \$1**。[Dedicatedの料金](https://hostlinku.com/models?mode=dedicated)を確認するか、Dedicatedキーを使用して`GET /v1/models`を実行してください。

<a id="prompt-caching"></a>

<a id="プロンプトキャッシュ"></a>

## プロンプトのキャッシュ

自動キャッシュをサポートするモデルでは、プレフィックスが繰り返されると、`cache_control` なしでキャッシュヒットが発生する可能性があります。ヒットおよびキャッシュの有効期間はアップストリームに従います。キャッシュの使用状況は、利用可能な場合、Chat Completions の `cached_tokens` または Messages の `cache_read_input_tokens` を通じて報告されます。 [プロンプトのキャッシュ](/ja/prompt-caching)を参照してください。

<a id="batasan"></a>

<a id="制限"></a>

## 制限事項

- サービスモードのキーにはモデルが用意されている必要があります。他のモードへの自動フォールバックはありません。
- 機能および出力の制限は、モデルおよびプロトコルに従います。アプリケーションに組み込まれているツールは、必ずしもブリッジでサポートされるとは限りません。
