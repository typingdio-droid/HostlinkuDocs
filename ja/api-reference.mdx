ゲートウェイはAPIキー、Consoleの`/api/*`はログインセッションを使います。パラメータ、vision、reasoning、cache、tool callingはモデルとプロトコル経路によって異なります。

| エンドポイント | 用途 | ガイド |
|---|---|---|
| `GET /v1/models` | キーのService Modeのモデル一覧 | [Models](/ja/models) |
| `POST /v1/chat/completions` | チャットとSSE | [Chat Completions](/ja/chat-completions) |
| `POST /v1/messages` | Anthropic形式のメッセージ | [Anthropic Messages](/ja/anthropic-messages) |
| `POST /v1/messages/count_tokens` | 無料のAnthropic形式token数計算 | [Count tokens](/ja/anthropic-messages) |
| `POST /v1/responses` | ステートレスResponses | [Responses API](/ja/responses) |

## Base URLと認証

OpenAI SDKのURLは`https://api.hostlinku.com/v1`、Anthropic SDKは`https://api.hostlinku.com`です。`Authorization: Bearer sk-your-api-key`または`x-api-key`を使用できます。[認証](/ja/authentication)。

## モデルとツールの互換性

キーの一覧にあるslugを対応エンドポイントで使用してください。形式の互換性はすべてのクライアント機能を保証しません。[Responsesの制限](/ja/responses)と[連携ガイド](/ja/integrations)を確認してください。

## 組織で共有する利用枠

各Service Modeの毎分利用枠は**600リクエスト、入力6,500,000token、出力200,000token**です。組織のすべてのキーとメンバーで共有します。ログイン、Console、checkoutのIP別制限は独立しています。[使用状況と制限](/ja/usage-and-limits)。

## エラーコード

エラー形式はエンドポイントによって異なります。ハンドラー到達前のエラーはHostlinku共通形式になる場合があります。コードと対処は[Error](/ja/errors)、固有形式は[Anthropic Messages](/ja/anthropic-messages)と[Responses](/ja/responses)を参照してください。

## 利用可能なモデルの取得

`GET /v1/models`はキーのService Modeに応じたモデルと料金を返します。サイトのモデル一覧は`GET /api/public/models-v2`を使います。機能と料金は[モデル](/ja/models)を参照してください。

## 料金とストリーミング

非streamのchat応答には`hostlinku.cost`と`hostlinku.latencyMs`が含まれます。stream完了後の料金はLogs / Analytics / Billingで確認してください。各chunkに料金が含まれるとは限りません。`x-request-id`があれば記録してください。[課金と残高](/ja/billing)。

## メトリクスと表示例の意味

| メトリクス | 意味 |
|---|---|
| `hostlinku.latencyMs` | gateway の受信から応答完了までの時間。 |
| TTFT | stream の最初の token を観測するまでの時間。非 stream では空の場合があります。 |
| TPS | 条件を満たす stream サンプルの最初の token 以降の出力 token/秒。 |

- **landingアニメーション**は固定の例示値を使い、再生中の推論リクエストから計測した値ではありません。
- **モデル詳細の60本の棒グラフ**は平均・P95レイテンシと失敗数の集計から生成します。各棒は合成された表示で、リクエストやprobeの時系列ではありません。Consoleの使用量グラフはリクエストデータの集計を使います。
- **landingフッターバッジ**は固定の状態値です。監視結果と障害は[Status](https://status.hostlinku.com)で確認してください。
- **Reachable**は401/403/404を含む500未満のHTTP応答を意味します。到達性を示すもので、ログインや推論の成功は対応する機能で確認します。

同じ期間・Service Mode・サンプルのメトリクスを比較してください。アニメーション、容量仕様、トラフィック集計、benchmarkはそれぞれ異なる情報源です。
