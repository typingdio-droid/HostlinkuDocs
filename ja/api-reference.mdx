ゲートウェイのエンドポイントにはAPIキーを使用してください。`/api/*`にあるConsoleアカウントのエンドポイントは、ログインセッションを使用します。パラメータ、ビジョン、推論、キャッシュ、およびツール呼び出しのサポートは、モデルおよびプロトコルパスに従います。

| エンドポイント | 用途 | ガイド |
|---|---|---|
| `GET /v1/models` | サービスモードのキーに関するカタログ | [Models](/ja/models) |
| `POST /v1/chat/completions` | チャットおよびSSEストリーミング | [チャット補完](/ja/chat-completions) |
| `POST /v1/messages` | Anthropic形式のメッセージ | [Anthropic Messages](/ja/anthropic-messages) |
| `POST /v1/messages/count_tokens` | Anthropic形式のトークンを無料で計算する | [トークン数](/ja/anthropic-messages) |
| `POST /v1/responses` | レスポンスはステートレスです | [レスポンスAPI](/ja/responses) |

<a id="base-url-dan-autentikasi"></a>

<a id="base-urlと認証"></a>

## ベースURLと認証

OpenAI SDKでは `https://api.hostlinku.com/v1` を使用し、Anthropic SDKでは `https://api.hostlinku.com` を使用します。ゲートウェイは `Authorization: Bearer sk-your-api-key` または `x-api-key` を受け付けます。 [認証](/ja/authentication)を参照してください。

<a id="kompatibilitas-model-dan-tool"></a>

<a id="モデルとツールの互換性"></a>

## モデルおよびツールの互換性

キーカタログに表示される「Slug」は、サポートされているエンドポイントで使用できます。フォーマットの互換性は、すべてのクライアントにおける全機能を保証するものではありません。[レスポンス](/ja/responses)および[使用されている統合機能](/integrations)の制限を確認してください。

<a id="kuota-bersama-organisasi"></a>

<a id="組織で共有する利用枠"></a>

## 組織全体のクォータ

各サービスモードには、**1分あたり600リクエスト、6,500,000トークンの入力、および200,000トークンの出力**というクォータがあり、すべてのAPIキーおよび組織メンバーで共有されます。ログイン、コンソール、およびチェックアウトには、IPごとの個別の制限があります。 [使用状況と制限](/ja/usage-and-limits)。

<a id="error-codes"></a>

## エラーコード

エラーのフォーマットはエンドポイントに準拠します。ハンドラー以前に発生したエラーについては、Hostlinkuの一般的なエンベロープを使用できます。エラーコードの一覧とエラーへの対処方法は、[Error](/ja/errors)に記載されています。 特定のフォーマットについては、[Anthropic Messages](/ja/anthropic-messages#format-error) および [Responses](/ja/responses#format-error) を参照してください。

<a id="query-available-models"></a>

<a id="利用可能なモデルの取得"></a>

## 利用可能なモデルを照会する

`GET /v1/models` は、Service Modeキーのモデルと価格を返します。サイトカタログでは `GET /api/public/models-v2` を使用します。リスト、機能、および料金の確認方法については、[モデル](/ja/models)を参照してください。

<a id="biaya-dan-streaming"></a>

<a id="料金とストリーミング"></a>

## 費用とストリーミング

非ストリーミングのチャットレスポンスには、`hostlinku.cost` および `hostlinku.latencyMs` が含まれます。ストリーミングが完了したら、[Logs] / [Analytics] / [Billing] で料金を確認してください。各チャンクごとに料金が発生するとは期待しないでください。利用可能な場合は、`x-request-id` を記録してください。 [請求・残高](/ja/billing)。

<a id="arti-metrik-dan-contoh-angka"></a>

<a id="メトリクスと表示例の意味"></a>

## メトリクスの意味と数値例

| メトリクス | 意味 |
|---|---|
| `hostlinku.latencyMs` | リクエストがゲートウェイで受信されてからレスポンスが完了するまでの時間。 |
| TTFT | ストリーム上で最初のトークンが検出されるまでの時間。非ストリーミングの場合は空欄でもよい。 |
| TPS | 最初のトークン以降の1秒あたりのトークン出力数（条件を満たすサンプルストリームから）。 |

- **ランディングアニメーション**では、固定の例示数値を使用します。アニメーション内の数値は、再生時にリクエストから推測されるものではありません。
- **モデル詳細の60本の棒グラフ**は、レイテンシの平均値／P95値および障害件数の集計値から構成されています。各棒は合成された可視化であり、単一のリクエストや連続したプローブを表すものではありません。Consoleの使用状況グラフは、リクエストデータの集計値を使用しています。
- **ランディングページのフッターバッジ**は固定ステータスを表示します。監視結果やインシデントについては、[ステータス](https://status.hostlinku.com)をご確認ください。
- **Reachable**とは、401/403/404を含む500未満のHTTPレスポンスを意味します。このチェックはエンドポイントの到達可能性を示すものであり、ログインの成功や推論については、それぞれの機能を通じて確認されます。

期間、サービスモード、およびサンプルが同一であるメトリクスを比較してください。アニメーションの結果、容量仕様、トラフィックの集計、およびベンチマークは、それぞれ異なる情報源に基づいています。
