curlとクレジット残高を用意し、次の手順に従ってください。

<Steps>

### ログインしてチャージする

[新規登録](https://api.hostlinku.com/api/auth2/register)または[ログイン](https://api.hostlinku.com/api/auth2/login)を開きます。ログインはKeycloakが処理します。[Console](https://console.hostlinku.com)の **Billing** で、リクエスト前に残高をチャージしてください。決済方法は [Billing](/ja/billing) を参照してください。

### APIキーを作成する

**API Keys → APIキーを作成** で名前を入力し、**Performance**（初期値）、**Low-Cost**、**Dedicated** を選びます。Service Modeによってモデルと価格が決まります。一度だけ表示される `sk-…` シークレットをコピーし、サーバーの環境変数に保存してください。有効期限、利用上限、パスキー／2FAの設定は [認証](/ja/authentication) に記載されています。

### 最初のリクエストを送信する

キーのService Modeで利用できるモデルを使います。この例は `gpt-5-5` です。Dedicatedキーや別のモデルを使う場合は、[`GET /v1/models`](/ja/models) からslugを取得してください。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{"role": "user", "content": "こんにちは。簡単に自己紹介してください。"}]
  }'
```

非ストリーミングのレスポンスはJSONです。以下は省略した例で、トークン数、費用、レイテンシは説明用の値です：

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "こんにちは。私は …"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60},
  "hostlinku": {
    "cost": 0.000123,
    "currency": "🪙",
    "serviceMode": "performance",
    "latencyMs": 812
  }
}
```

### 結果を確認する

**Logs** でトークン数、費用、レイテンシを、**Billing** で組織の残高を確認します。失敗した場合は [エラーコード](/ja/errors) を参照してください。APIキーは `/v1/*` で使い、Consoleのアカウント用エンドポイントにはログインセッションを使います。

</Steps>
