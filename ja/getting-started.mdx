curlとクレジット残高を準備し、以下の手順に従ってください。

<Steps>

<a id="masuk-dan-isi-saldo"></a>

<a id="ログインしてチャージする"></a>

### ログインして残高を補充する

[一覧](https://api.hostlinku.com/api/auth2/register) または [ログイン](https://api.hostlinku.com/api/auth2/login) を開いてください。 ログインはKeycloakによって提供されています。[コンソール](https://console.hostlinku.com)で**Billing**を開き、リクエストを送信する前にクレジット残高を補充してください。お支払い方法については、[Billing](/ja/billing)をご覧ください。

<a id="buat-api-key"></a>

### APIキーを作成する

**API Keys → APIキーの作成**を開き、名前を付けてから、**Performance**（デフォルト）、**Low-Cost**、または**Dedicated**を選択してください。サービスモードによってモデルと価格が決定されます。 一度だけ表示されるシークレット `sk-…` をコピーし、サーバー環境に保存してください。有効期限、クレジット制限、およびパスキー/2FAの設定については、[認証](/ja/authentication)で説明されています。

<a id="kirim-request-pertama"></a>

### 最初のリクエストを送信する

Service Modeキーには利用可能なモデルを使用してください。以下の例では`gpt-5-5`を使用しています。Dedicatedキーやその他のオプションについては、[`GET /v1/models`](/ja/models)からスラッグを取得してください。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{"role": "user", "content": "Halo! Perkenalkan dirimu singkat saja."}]
  }'
```

非ストリーミングのレスポンスはJSON形式です。以下の例は一部抜粋であり、トークン、コスト、レイテンシはあくまで例示です：

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Halo! Saya adalah …"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60},
  "hostlinku": {
    "cost": 0.000123,
    "currency": "🪙",
    "serviceMode": "performance",
    "latencyMs": 812
  }
}
```

<a id="periksa-hasil"></a>

<a id="結果を確認する"></a>

### 結果を確認してください

**Logs** を開くと、トークン、コスト、リクエストのレイテンシを確認できます。**Billing** には組織の残高が表示されます。リクエストが失敗した場合は、[エラーコード](/ja/errors)を確認してください。APIキーは `/v1/*` で使用されます。Consoleアカウントのエンドポイントでは、ログインセッションが使用されます。
