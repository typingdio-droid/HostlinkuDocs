## 概要

OpenAIのモデルは、複雑なコーディングやエージェント型ワークフロー向けに構築されています。 テキストおよび画像入力、テキスト出力；推論の負荷：なし／低／中／高／超高／最大；コンテキスト容量1,050,000、最大出力128K。入力トークン数が272Kを超えるプロンプトについては、ロングコンテキスト料金が適用されます。

## 価格

| 項目 | 価格 |

価格は、APIキーHostlinkuにおける**1Mトークン**あたりの顧客価格であり、1 <CreditIcon /> = $1となります。 リクエストごとの実際の価格は引き続きService Mode API keyに基づいており、変更される可能性があります。適用される値については、[コンソール](https://console.hostlinku.com/models)または`GET /v1/models`をご確認ください。

## 対応エンドポイント

| エンドポイント | フォーマット | サポート |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 利用可能 |
| `POST /v1/messages` | Anthropic Messages | アダプト（ブリッジ） |
| `POST /v1/responses` | OpenAI Responses | ネイティブ |

エンドポイントおよびモデルの利用可能性は、カタログおよび使用されるService Mode API keyに従います。そのモードに対応するモデルが利用できない場合、リクエストは`400 MODEL_NOT_IN_SERVICE_MODE`により拒否されることがあります。

## リクエストの例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-6-sol",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
