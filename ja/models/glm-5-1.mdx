## 概要

GLM-5.1は、Zhipuの主力テキストモデルであり、20万のコンテキストと12万8千の最大出力を持つ。長期計画、エージェント的コーディング、ツールの使用、構造化出力、コンテキストキャッシュ、およびMCPの面で強化されている。

| プロパティ | 値 |
|---|---|
| プロバイダー | Zhipu |
| slug | `glm-5-1` |
| コンテキスト | 200,000トークン |
| 最大出力 | 128,000トークン |
| 入力 | text |
| 出力 | text |
| リリース | 2026-06-14 |

価格は、APIキーHostlinkuにおける**1Mトークン**あたりの顧客価格であり、1 <CreditIcon /> = $1となります。 リクエストごとの実際の料金は引き続きService Mode API keyに基づいており、変更される可能性があります。適用される料金については、[コンソール](https://console.hostlinku.com/models)または`GET /v1/models`をご確認ください。

## 対応エンドポイント

| エンドポイント | フォーマット | サポート |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 利用可能 |
| `POST /v1/messages` | Anthropic Messages | アダプト（ブリッジ） |
| `POST /v1/responses` | OpenAI Responses | アダプト（ブリッジ） |

エンドポイントおよびモデルの利用可能性は、カタログおよび使用されるService Mode API keyに従います。そのモードに対応するモデルが利用できない場合、リクエストは`400 MODEL_NOT_IN_SERVICE_MODE`で拒否されることがあります。

## リクエストの例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5-1",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
