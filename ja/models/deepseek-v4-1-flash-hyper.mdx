## 概要

DeepSeek-V4.1-Flashは、非対称な因果エンコーダー・デコーダーアーキテクチャに基づいて構築されたマルチモーダルなミクスチャー・オブ・エキスパートモデルであり、ネイティブな視覚理解機能を備えています。 100万トークンのコンテキストウィンドウ、最大384Kの出力トークン、思考モードと非思考モード、ツール呼び出し、構造化されたJSON出力をサポートしています。スループットの高いレーンを備えたHostlinku専用チャネルで利用可能です。

| 入力 | テキスト、画像 |

## 対応エンドポイント

| エンドポイント | フォーマット | サポート |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 利用可能 |
| `POST /v1/messages` | Anthropic Messages | アダプト（ブリッジ） |
| `POST /v1/responses` | OpenAI Responses | アダプト（ブリッジ） |

エンドポイントおよびモデルの利用可能性は、カタログおよび使用されるService Mode API keyに従います。そのモードに対応するモデルが利用できない場合、リクエストは`400 MODEL_NOT_IN_SERVICE_MODE`で拒否されることがあります。

## リクエストの例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-1-flash-hyper",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
