## 概要

GLM-5.2は、長文コンテキスト処理の時代に向けて設計されたフラッグシップモデルです。 実環境でのテストにおいてプロジェクトレベルのエンジニアリングコンテキストを処理できる、真に実用的な100万トークンのコンテキストウィンドウをサポートし、長期間にわたるタスクの実行における安定性と、エンジニアリング標準への準拠における信頼性を高めることで、開発シナリオにおける成功率をさらに向上させます。 これにより、要件定義からマルチプラットフォームでデプロイ可能な成果物に至るまでの開発ライフサイクル全体を、単一のタスクで完了させることが可能になります。

## 対応エンドポイント

| エンドポイント | フォーマット | サポート |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 利用可能 |
| `POST /v1/messages` | Anthropic Messages | アダプト（ブリッジ） |
| `POST /v1/responses` | OpenAI Responses | アダプト（ブリッジ） |

エンドポイントおよびモデルの利用可能性は、カタログおよび使用されるService Mode API keyに従います。そのモードに対応するモデルが利用できない場合、リクエストは`400 MODEL_NOT_IN_SERVICE_MODE`で拒否されることがあります。

## リクエストの例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5-2",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
