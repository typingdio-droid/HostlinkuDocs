## 概要

Kimi K2.7 Codeは、Kimiがこれまでに開発した中で最も高度なコーディングモデルです。長いコンテキストにおいても指示をより確実に実行し、プログラミングタスクをより高い成功率で完了させることができます。テキスト入力に対応しており、思考モード、対話、およびエージェントタスクのみをサポートしています。

| コンテキスト | 256,000トークン |
| 最大出力 | 非公開 |

## 対応エンドポイント

| エンドポイント | フォーマット | サポート |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 利用可能 |
| `POST /v1/messages` | Anthropic Messages | アダプト（ブリッジ） |
| `POST /v1/responses` | OpenAI Responses | アダプト（ブリッジ） |

エンドポイントおよびモデルの利用可能性は、カタログおよび使用されるService Mode API keyに従います。そのモードに対応するモデルが利用できない場合、リクエストは`400 MODEL_NOT_IN_SERVICE_MODE`で拒否されることがあります。

## リクエストの例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2-7-code",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
