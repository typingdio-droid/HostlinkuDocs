## 概要

GLM-5.3-Flashは、Zhipu AIが提供する、GLM-5.3の軽量版マルチモーダルモデルであり、日常的な分析やエージェント業務向けに設計されています。 スループットの高いレーンを備えたHostlinku専用チャネルで利用可能です。コーディングエージェントというよりは、短いコンテキストのチャットアプリケーション向けに最適化されています。

| プロパティ | 値 |
|---|---|
| プロバイダー | Zhipu |
| slug | `glm-5-3-flash-hyper-chat` |
| コンテキスト | 1,000,000トークン |
| 最大出力 | 64,000トークン |
| 入力 | テキスト、画像 |
| 出力 | text |
| リリース | 2026-08-17 |
| タグ | フラッグシップ、推論、専用、フラッシュ |

## 対応エンドポイント

| エンドポイント | フォーマット | サポート |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 利用可能 |
| `POST /v1/messages` | Anthropic Messages | アダプト（ブリッジ） |
| `POST /v1/responses` | OpenAI Responses | アダプト（ブリッジ） |

エンドポイントおよびモデルの利用可能性は、カタログおよび使用されるService Mode API keyに従います。そのモードに対応するモデルが利用できない場合、リクエストは`400 MODEL_NOT_IN_SERVICE_MODE`で拒否されることがあります。

## リクエストの例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5-3-flash-hyper-chat",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
