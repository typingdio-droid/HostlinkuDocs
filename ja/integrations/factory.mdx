[Droid](https://docs.factory.ai/cli/byok/overview) - Factoryのコーディングエージェント - **BYOK
カスタムモデル**をサポートしています。カスタムモデルは `~/.factory/settings.json` から読み込まれ、Droid CLI および
Factory デスクトップアプリケーションで利用可能です（Factory のウェブ/モバイルプラットフォームでは利用できません）。API キーはローカルに保持され、
Factory サーバーには送信されません。

<Steps>

<a id="simpan-api-key-di-environment"></a>

<a id="apiキーを環境変数に保存する"></a>

### APIキーは環境変数に保存してください

```bash
export HOSTLINKU_API_KEY=sk-your-api-key
```

永続化させるために `~/.zshrc` / `~/.bashrc` に追加してください。Droidは `settings.json` から `${HOSTLINKU_API_KEY}`
を参照します。

<a id="daftarkan-model-di-settingsjson"></a>

<a id="settingsjson-にモデルを登録する"></a>

### settings.jsonにモデルを登録してください

`~/.factory/settings.json` を開く（または作成する）し、`customModels` を追加します：

```json
{
  "customModels": [
    {
      "model": "claude-sonnet-4-6",
      "displayName": "Claude Sonnet 4.6 (Hostlinku)",
      "baseUrl": "https://api.hostlinku.com",
      "apiKey": "${HOSTLINKU_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 64000
    },
    {
      "model": "gpt-5-5",
      "displayName": "GPT-5.5 (Hostlinku)",
      "baseUrl": "https://api.hostlinku.com/v1",
      "apiKey": "${HOSTLINKU_API_KEY}",
      "provider": "generic-chat-completion-api",
      "maxOutputTokens": 64000
    },
    {
      "model": "deepseek-v4-flash",
      "displayName": "DeepSeek V4 Flash (Hostlinku)",
      "baseUrl": "https://api.hostlinku.com/v1",
      "apiKey": "${HOSTLINKU_API_KEY}",
      "provider": "generic-chat-completion-api",
      "maxOutputTokens": 32000
    }
  ]
}
```

| `provider` | APIのフォーマット | Base URL Hostlinku |
|---|---|---|
| `anthropic` | Anthropic Messages | `https://api.hostlinku.com`（`/v1`を除く） |
| `generic-chat-completion-api` | OpenAIチャット補完 | `https://api.hostlinku.com/v1` |

<a id="pilih-model-di-droid"></a>

<a id="droidでモデルを選択"></a>

### Droidでモデルを選択する

`droid`を実行し、`/model`と入力して、**Custom models**セクションでモデルを選択してください（名前は
`displayName`に準拠）。最初のリクエストはコンソールの**リクエストログ**に表示されます。

</Steps>

<a id="yang-perlu-diketahui"></a>

<a id="知っておくべきこと"></a>

## 留意事項

<Callout type="tip" title="Anthropic社のプロバイダー経由のClaudeモデル">
  プロバイダー `anthropic` は Messages API を使用しているため、`cache_control` が転送され、プロンプトのキャッシュ機能が
  完全に機能します。Droid の `/cost` またはリクエストログの *cache* 列で、その節約効果を確認してください。
</Callout>

- **GPTおよびその他のモデル**（DeepSeek、GLM、Qwen、Kimi）は、
  `generic-chat-completion-api` 経由で最も互換性が高いです。Droidの `openai` プロバイダーは Responses API を使用しています。Hostlinku
  は Responses を *ステートレス* で提供しています ([詳細](/ja/responses)) ため、迷った場合は Chat Completions を選択してください
  。
- **`maxOutputTokens`** は、[カタログ](/ja/models)に記載されているモデルの出力制限を超えないようにしてください。
- **汎用プロバイダー向けのプロンプトキャッシュ**は、対象モデルによって異なります。

<a id="troubleshooting"></a>

## トラブルシューティング

| 症状 | 解決策 |
|---|---|
| 「Model」は `/model` には表示されません | JSONが無効、または`provider`のスペルミスがあります。`jq . ~/.factory/settings.json`で確認してください。 |
| 変数「Error」が見つかりません | `HOSTLINKU_API_KEY`は、`droid`を実行しているシェルではまだエクスポートされていません。 |
| すべてのリクエストにおける `404` | Base URLが入れ替わっています：`anthropic`には`/v1`がなく、`generic-chat-completion-api`には`/v1`が付いています。 |
| `404 model_not_found` | `model`は、`GET /v1/models`のスラッグと完全に一致させる必要があります。 |
