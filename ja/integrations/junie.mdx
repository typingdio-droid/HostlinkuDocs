[Junie CLI](https://junie.jetbrains.com/docs/custom-llm-models.html) - JetBrainsのターミナル用エージェント
ターミナル用 - JSONファイル形式の**カスタムモデルプロファイル**をサポートしています。1つのプロファイルには、エンドポイント、
API形式、APIキー、および軽作業用のメインモデルと高速モデル（*faster model*）が含まれます。

JetBrains IDE内のAIアシスタントについては、[JetBrains AI Assistant](/ja/integrations/jetbrains)を参照してください。

<Steps>

<a id="instal-junie-cli-dan-simpan-api-key"></a>

<a id="junie-cli-をインストールしapi-キーを保存する"></a>

### Junie CLIをインストールし、APIキーを保存してください

```bash
curl -fsSL https://junie.jetbrains.com/install.sh | bash
export HOSTLINKU_API_KEY=sk-your-api-key
```

<a id="buat-profil-hostlinku"></a>

### Hostlinkuのプロフィールを作成する

Junieは、`~/.junie/models/*.json`（ユーザーレベル）および`.junie/models/*.json`（
プロジェクトレベル）でプロファイルを検索します。`.json`を含まないファイル名がプロファイルIDとなります。 `~/.junie/models/hostlinku.json` を作成します：

```json
{
  "displayName": "Hostlinku",
  "id": "claude-sonnet-4-6",
  "baseUrl": "https://api.hostlinku.com/v1/chat/completions",
  "apiType": "OpenAICompletion",
  "apiKey": "${HOSTLINKU_API_KEY}",
  "maxContextLength": 1000000,
  "fasterModel": {
    "id": "claude-haiku-4-5",
    "maxContextLength": 200000
  }
}
```

<Callout type="important" title="baseUrlは完全なエンドポイントURLです">
  Junieは`baseUrl`にパスを**追加しない**。`OpenAICompletion`の場合は
  `/v1/chat/completions`まで、`Anthropic`の場合は`/v1/messages`まで記述する。
</Callout>

<a id="jalankan-dengan-profil"></a>

<a id="プロファイルで実行する"></a>

### プロファイルで実行

```bash
junie --model custom:hostlinku
```

「プロファイル」は、TUIのモデル一覧の**「カスタム」**タブや、コマンド `/model` でも表示されます。最初のリクエスト
はコンソールの**「リクエストログ」**に表示されます。

</Steps>

<a id="varian-format-anthropic"></a>

## バリエーション：Anthropic形式

Messages API（完全なプロンプトキャッシュ）を備えたClaudeモデルの場合、2つ目のプロファイルを作成してください。例：
`~/.junie/models/hostlinku-claude.json`:

```json
{
  "displayName": "Hostlinku (Anthropic)",
  "id": "claude-sonnet-4-6",
  "baseUrl": "https://api.hostlinku.com/v1/messages",
  "apiType": "Anthropic",
  "apiKey": "${HOSTLINKU_API_KEY}",
  "fasterModel": { "id": "claude-haiku-4-5" }
}
```

その後、`junie --model custom:hostlinku-claude` を実行してください。

<a id="yang-perlu-diketahui"></a>

<a id="知っておくべきこと"></a>

## 留意事項

- **`${HOSTLINKU_API_KEY}`** は、プロファイルの読み込み時に環境変数から読み込まれます。変数がまだ
  設定されていない場合、プロファイルの読み込みは失敗し、Junieは欠落している変数名を通知します。これは、リポジトリ（`.junie/models/`）に
  コミットされたプロファイルであっても安全です。
- **メインモデルと高速モデル。** メインモデルには、強力な*ツール呼び出し*機能を備えたモデルを選択してください
  （`claude-sonnet-4-6`、`gpt-5-5`）；`claude-haiku-4-5`や`deepseek-v4-flash`のような低コストモデルは
  ファスターモデル（要約・分類）には十分です。
- **Responses API (`OpenAIResponses`)** も `https://api.hostlinku.com/v1/responses` で利用可能ですが、
  *ステートレス* です ([詳細](/ja/responses))。`OpenAICompletion` が最も
  選択肢です。

<a id="troubleshooting"></a>

## トラブルシューティング

| 症状 | 解決策 |
|---|---|
| `404` | `baseUrl`は不完全です。末尾は `/v1/chat/completions` または `/v1/messages` で終わる必要があります。 |
| プロファイルが表示されない | ファイル名またはファイルの場所が間違っているか、JSONが無効です。Profile = `.json` を除いたファイル名。 |
| 環境変数「Error」 | `junie` を実行しているシェルで `HOSTLINKU_API_KEY` をエクスポートしてください。 |
| ツール呼び出しの失敗／エージェントがループしている | [カタログ](/ja/models)で、ツールの呼び出し対応状況とモデルの制限を確認してください。モデルを変更する前に、リクエストログを確認してください。 |
