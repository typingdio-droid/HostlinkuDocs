[OpenCode](https://opencode.ai/docs/providers/)はAI SDKを採用しているため、
OpenAI互換のプロバイダーであれば、`opencode.json`を介して追加可能です。認証情報は、コマンド
`/connect`によって個別に保存されます。

<Steps>

<a id="simpan-kredensial"></a>

### 認証情報を保存する

OpenCode内で`/connect`を実行し、**Other**までスクロールして、プロバイダーIDに`hostlinku`を入力し、APIキー`sk-…`を貼り付けてください。キーは`~/.local/share/opencode/auth.json`に保存されています。

```text
/connect  →  Other  →  provider id: hostlinku  →  API key: sk-…
```

<a id="definisikan-provider"></a>

### プロバイダーを定義する

プロジェクトのルートディレクトリ（グローバル設定の場合は `~/.config/opencode/opencode.json`）で `opencode.json` を作成または変更してください：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "hostlinku": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Hostlinku",
      "options": {
        "baseURL": "https://api.hostlinku.com/v1"
      },
      "models": {
        "claude-sonnet-4-6": {
          "name": "Claude Sonnet 4.6",
          "limit": { "context": 1000000, "output": 64000 }
        },
        "gpt-5-5": {
          "name": "GPT-5.5",
          "limit": { "context": 1000000, "output": 64000 }
        },
        "deepseek-v4-flash": {
          "name": "DeepSeek V4 Flash",
          "limit": { "context": 1000000, "output": 32000 }
        }
      }
    }
  },
  "model": "hostlinku/claude-sonnet-4-6",
  "small_model": "hostlinku/deepseek-v4-flash"
}
```

`opencode.json`内のプロバイダーIDは、`/connect`時に指定したものと**一致している必要があります**。
`models`内のキーはHostlinkuのスラッグです。`limit`は、OpenCodeが残りのコンテキストを計算するのに役立ちます。

<a id="pilih-model"></a>

### モデルを選択

`/models` を実行すると、登録したモデルを含む **Hostlinku** グループが表示されます。`small_model`
は軽微なタスク（セッションタイトル、要約）に使用されるため、長時間のセッションでもリソースを節約できます。

</Steps>

<a id="variasi-konfigurasi"></a>

<a id="構成のバリエーション"></a>

## 設定のバリエーション

**環境変数からのAPIキー**（`/connect`を除く）：

```json
{
  "provider": {
    "hostlinku": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Hostlinku",
      "options": {
        "baseURL": "https://api.hostlinku.com/v1",
        "apiKey": "{env:HOSTLINKU_API_KEY}"
      }
    }
  }
}
```

**Responses API 経由** - `npm` を `@ai-sdk/openai` に変更してください。OpenCode は
[`/v1/responses`](/ja/responses)を使用します。GPT-5.xモデルで*推論サマリー*を取得したい場合に便利です。
ほとんどのユーザーにとっては、`@ai-sdk/openai-compatible`（Chat Completions）で十分です。

<Callout type="note" title="推論が織り込まれたモデル">
  `reasoning_content` を返すモデル（例：DeepSeek V4、GLM 5）には、モデル定義に
  `"reasoning": true` および `"interleaved": { "field": "reasoning_content" }` というオプションを指定できます
  ことで、OpenCodeに推論の過程を表示させることができます。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

- **プロバイダーが `/models` に表示されない** - `/connect` および `opencode.json` 内の ID が異なるか、JSON
  が無効です。`opencode auth list` を確認してください。
- **`401`** - そのIDに対応するキーがまだ保存されていません。`/connect`を再実行してください。
- **`404 model_not_found`** - `models` キーは、`GET /v1/models` のスラッグと完全に一致する必要があります。
