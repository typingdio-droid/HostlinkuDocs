[Claude Code](https://code.claude.com/docs)はAnthropic Messagesプロトコルに対応しています。Hostlinku
は[`POST /v1/messages`](/ja/anthropic-messages) （
`/v1/messages/count_tokens` を含む）を提供しているため、Claude Code は環境変数を設定するだけで Hostlinku にリダイレクトでき、
追加のプロキシは不要です。

<Steps>

<a id="instal-claude-code"></a>

### Claude Codeをインストールする

お使いのオペレーティングシステムに応じて、インストール方法を選択してください：

**macOS / Linux / WSL:**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell:**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**npm（Node.js 18以上が必要）：**

```bash
npm install -g @anthropic-ai/claude-code
```

以前にAnthropic/Claudeアカウントでログインしたことがある場合は、`claude`を実行し、
`/logout`と入力して、保存されているOAuth認証情報がゲートウェイの設定に優先されないようにしてください。

<a id="arahkan-ke-hostlinku"></a>

<a id="hostlinku-へ移動してください"></a>

### Hostlinkuへ誘導してください

最も手っ取り早い方法 - シェルでのエクスポート（`~/.zshrc` / `~/.bashrc`）：

```bash
export ANTHROPIC_BASE_URL=https://api.hostlinku.com
export ANTHROPIC_AUTH_TOKEN=sk-your-api-key

# Pin model untuk alias yang dipakai Claude Code
export ANTHROPIC_DEFAULT_SONNET_MODEL=claude-sonnet-4-6
export ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-4-6
export ANTHROPIC_DEFAULT_HAIKU_MODEL=claude-haiku-4-5

claude
```

永続化方法 - `~/.claude/settings.json` 内の `env` ブロック（すべてのプロジェクトに適用）または
プロジェクトルートにある `.claude/settings.local.json`（そのプロジェクトのみ；このファイルは通常 gitignore に追加されます）：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.hostlinku.com",
    "ANTHROPIC_AUTH_TOKEN": "sk-your-api-key",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-6",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-6",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5"
  }
}
```

`settings.json`内の値は、export shellの値に**優先**されます。

<Callout type="tip" title="JSONを編集せずにGUIで管理したいですか？">
  デスクトップアプリ [CC Switch](/ja/integrations/cc-switch) を使用して、`/v1/models` からモデルのリストを自動的に取得し、
  ワンクリックで Claude Code のプロファイルやモデルを切り替えることができます。
</Callout>

<a id="verifikasi"></a>

<a id="確認"></a>

### 検証

Claude Codeのセッション内で `/status` と入力してください：*API* セクションには、ベースURL
`https://api.hostlinku.com` および認証方法 *auth token* が表示される必要があります。簡単なプロンプトを1つ送信し、
使用しているAPIキーで、コンソールの → **リクエストログ** にそのリクエストが表示されるか確認してください。

<a id="opsional-ganti-model-dari-dalam-sesi"></a>

<a id="オプションセッション内でモデルを切り替える"></a>

### （オプション）セッション内のモデルを置き換える

`/model` には、上記でピン留めしたエイリアス `sonnet` / `opus` / `haiku` が表示されます。
他のスラグを一度だけ使用するには：

```bash
claude --model deepseek-v4-flash
# atau pin default lewat env: export ANTHROPIC_MODEL=gpt-5-5
```

</Steps>

<a id="autentikasi-auth_token-atau-api_key"></a>

<a id="認証auth_token-それとも-api_key"></a>

## 認証：`AUTH_TOKEN` または `API_KEY`？

| 変数 | 送信されるヘッダー | Hostlinkuによるサポート |
|---|---|---|
| `ANTHROPIC_AUTH_TOKEN` | `Authorization: Bearer sk-…` | はい（推奨） |
| `ANTHROPIC_API_KEY` | `x-api-key: sk-…` | はい |

「Keduanya」はゲートウェイで受け入れられます。どちらか一方を選択し、異なる値を両方とも入力しないでください。

<a id="ekstensi-vs-code--jetbrains"></a>

## VS Code および JetBrains の拡張機能

Claude Code拡張機能はログイン情報を自身で検証するため、設定でも同じ変数を指定する必要があります
拡張機能 - VS Code: `settings.json`内の`claudeCode.environmentVariables`:

```json
{
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.hostlinku.com" },
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "sk-your-api-key" },
    { "name": "ANTHROPIC_DEFAULT_SONNET_MODEL", "value": "claude-sonnet-4-6" },
    { "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL", "value": "claude-haiku-4-5" }
  ]
}
```

JetBrainsでは、*設定 → ツール → Claude Code → 環境変数*で同じ変数を設定してください
（または、その変数がエクスポートされているシェルからIDEが実行されていることを確認してください）。

<a id="pakai-model-non-claude"></a>

<a id="非claudeモデルを使用する"></a>

## 非Claudeモデルを使用してください

Service Mode Performance の Claude Code は、Claude モデルに加え、DeepSeek、Qwen、GLM、Kimi、MiniMax、MiMo などの国内モデルもサポートしています。Low-Cost では、Low-Cost カタログに国内モデルが含まれていないため、Claude Code は Claude モデルのみをサポートします。 どちらのモードにおいても、Claude CodeではGPTモデルはサポートされていません。GPTモデルを使用する場合は、Codex CLI、Chat、またはResponses APIをご利用ください。ゲートウェイがプロトコルを変換するため、`sonnet`や`haiku`といったエイリアスには、[カタログ](/ja/models)からClaudeまたは国内モデルのスラグを指定できます：

```bash
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
```

モデルの機能に依存する機能（ツールの使用、*extended thinking*、ビジョン）は、
対象モデルの機能に従う — カタログの `capabilities` フィールドを確認してください。

<Callout type="note" title="Claude Codeは、Claude以外のモデル名は認識しません">
  `deepseek-v4-pro`や`deepseek-v4-flash`のようなスラグを使用する場合、Claude Codeは`unrecognized_model`という警告を表示し、200kトークンのコンテキストを想定します。対象モデルがより大きなウィンドウを持つ場合は、クライアント側でコンテキストを調整してください。
</Callout>

<Callout type="tip" title="サブエージェントの残高を節約する">
  Claude Codeは、軽微なタスク（要約、セッションタイトル、簡易サブエージェント）に*haiku*というエイリアスを使用します。
  `claude-haiku-4-5` や `deepseek-v4-flash` を指定することで、メインモデルの品質を損なうことなく、
  長時間のセッションにかかるコストを大幅に削減できます。
</Callout>

<Callout type="note" title="大枠の文脈とキャッシュ">
  Hostlinkuは`cache_control`（プロンプトキャッシュ）を転送し、`usage`内で`cache_read_input_tokens` /
  `cache_creation_input_tokens`を報告します。Claude Codeはこれを自動的に活用します。 請求は、
  該当するキャッシュモデルの価格に基づきます（[Billing](/ja/billing)を参照）。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

- **`401 authentication_error` なのにキーは正しい** - 古いOAuth認証情報がまだ使用されています。
  `/logout` を実行し、セッションを終了させて、`ANTHROPIC_BASE_URL` が読み取れることを確認してください（`/status`）。
- **モデルが見つかりません（`404`）** - エイリアスがまだピン留めされていないため、Claude Codeはデフォルトのモデル名を送信しています。
  `ANTHROPIC_DEFAULT_*_MODEL` をカタログのスラグで置き換えてください。
- **`400 max_tokens melebihi batas`** - ターゲットモデルの出力上限がこれより小さい場合は、`CLAUDE_CODE_MAX_OUTPUT_TOKENS` を通じて `max_tokens` を下げてください
  （例：`32000`）。
- **レート制限 (`429`)** - Claude Codeは複数のサブエージェントを並行して実行できます。制限については
  [使用状況と制限](/ja/usage-and-limits)をご覧ください。
