[Aider](https://aider.chat/docs/llms/openai-compat.html)は内部でLiteLLMを使用しています。
OpenAI互換のエンドポイントには`OPENAI_API_BASE`を指定し、モデル名は`openai/`で始まるものを使用します。

<Steps>

<a id="instal-aider"></a>

### Aiderをインストールする

```bash
python -m pip install -U aider-chat
# atau: pipx install aider-chat
```

<a id="arahkan-ke-hostlinku"></a>

<a id="hostlinku-へ移動してください"></a>

### Hostlinkuへ誘導してください

```bash
export OPENAI_API_BASE=https://api.hostlinku.com/v1
export OPENAI_API_KEY=sk-your-api-key   # API key Hostlinku

aider --model openai/claude-sonnet-4-6
```

プレフィックス `openai/` は必須です。これにより、Aiderは
`OPENAI_API_BASE` を使用してOpenAI互換のパスを使用するよう指示されます。プレフィックス以降の部分は、Hostlinkuのスラッグです。

<a id="disarankan-simpan-di-berkas-konfigurasi"></a>

<a id="推奨設定ファイルに保存する"></a>

### （推奨）設定ファイルに保存してください

ホームディレクトリまたはリポジトリのルートにある `.aider.conf.yml`：

```yaml
openai-api-base: https://api.hostlinku.com/v1
model: openai/claude-sonnet-4-6
weak-model: openai/claude-haiku-4-5      # commit message & ringkasan
editor-model: openai/deepseek-v4-flash   # mode architect (opsional)
```

APIキーは`.env`（gitignore対象）に保存し、コミットされないようにしてください：

```bash
OPENAI_API_KEY=sk-your-api-key
```

<a id="beri-tahu-aider-ukuran-konteks--harga"></a>

### Aiderにコンテキストの規模と価格を伝えてください

AiderはHostlinkuのスラッグを認識しないため、*「model is unknown」*という警告を表示し、
文脈を推測します。`.aider.model.metadata.json`（ホーム／リポジトリのルート）を作成してください：

```json
{
  "openai/claude-sonnet-4-6": {
    "max_input_tokens": 1000000,
    "max_output_tokens": 64000,
    "input_cost_per_token": 0.0000024,
    "output_cost_per_token": 0.0000120,
    "litellm_provider": "openai",
    "mode": "chat"
  },
  "openai/claude-haiku-4-5": {
    "max_input_tokens": 200000,
    "max_output_tokens": 16000,
    "input_cost_per_token": 0.0000008,
    "output_cost_per_token": 0.0000040,
    "litellm_provider": "openai",
    "mode": "chat"
  }
}
```

上記の `max_input_tokens` および `max_output_tokens` の値は、Aiderのローカル制限の例です。[カタログ](/ja/models)に記載されているモデルの制限に合わせて調整してください。値が小さいほど、ツールでの使用が制限されます。

上記の価格数値はあくまで例です（Performanceモード）— [カタログ](/ja/models) の `pricing` から転載したもので、
**1Mトークン** あたりで表記されているため、Aiderでは1トークンあたりの価格を使用しているため、**1,000,000で割る**必要があります
（例：`pricing.input: 2.4` → `input_cost_per_token: 0.0000024`）。
Aiderによる費用見積もりは、コンソール上の実際の請求額に近い値となります。

<a id="2つのモデルを備えたモードアーキテクト"></a>

## 2つのモデルを持つアーキテクトモード

```bash
aider --architect \
  --model openai/claude-opus-4-6 \
  --editor-model openai/claude-sonnet-4-6
```

*architect*モデルは変更を設計し、*editor*モデルはdiffを作成します。両者は同じ残高から請求され、
**リクエストログ**に別々に記録されます。

<Callout type="tip" title="モデルごとの追加設定">
  特定のモデルに追加パラメータ（例：`reasoning_effort`、`temperature`）を渡すには、
  `.aider.model.settings.yml` の `extra_params` キーを使用してください。Aiderの*Advanced
  model settings*のドキュメントを参照してください。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

- **`AuthenticationError`** - `OPENAI_API_KEY` がエクスポートされていないか、`.env` が読み取れない（Aiderは
  作業ディレクトリ／Gitルートから `.env` を読み取ります）。
- **`NotFoundError` モデル** - `openai/` というプレフィックスが抜けていたり、スラッグが間違っていたりする場合。
- **警告 *unknown context window*** - `.aider.model.metadata.json` が存在しません。手順 4 を参照してください。
- **回答が切り詰められています** - メタデータで `max_output_tokens` を増やすか、出力制限が
  大きいモデルを選択してください。
