[Continue](https://docs.continue.dev)は`config.yaml`を通じて設定されます。各モデルには
`provider`、`apiBase`、`apiKey`、および`roles`（chat、edit、applyなど）のリストが割り当てられます。
Hostlinkuでは、`openai`プロバイダーと`apiBase`としてgatewayを使用します。

<Steps>

<a id="buka-konfigurasi"></a>

### 設定を開く

「Continue」パネルで歯車アイコンをクリックし、**Open config file**を選択するか、直接
`~/.continue/config.yaml`（グローバル）または `.continue/config.yaml`（プロジェクト単位）を編集してください。

<a id="tambahkan-model-hostlinku"></a>

<a id="モデル-hostlinku-を追加する"></a>

### Hostlinkuモデルを追加してください

```yaml
name: Hostlinku
version: 0.0.1
schema: v1

models:
  - name: Claude Sonnet 4.6 (Hostlinku)
    provider: openai
    model: claude-sonnet-4-6
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply]
    defaultCompletionOptions:
      contextLength: 1000000
      maxTokens: 32000

  - name: GPT-5.5 (Hostlinku)
    provider: openai
    model: gpt-5-5
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply]

  - name: DeepSeek V4 Flash (Hostlinku)
    provider: openai
    model: deepseek-v4-flash
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply, summarize]
```

<a id="simpan-api-key-sebagai-secret"></a>

<a id="apiキーをシークレットとして保存する"></a>

### APIキーはシークレットとして保存してください

`~/.continue/.env` ファイル（コミット対象外）を作成し、以下の内容を記述してください：

```bash
HOSTLINKU_API_KEY=sk-your-api-key
```

あるいは、設定ファイルが
実際に非公開である場合は、`${{ secrets.HOSTLINKU_API_KEY }}` をキーの値そのものに置き換えてください。

<a id="muat-ulang-dan-uji"></a>

<a id="再読み込みしてテストする"></a>

### 再読み込みしてテストしてください

「Continue」パネルで**Reload config**をクリックします（またはファイルを保存してください。Continueは変更を監視します）。ドロップダウンから
モデル *Claude Sonnet 4.6 (Hostlinku)* を選択し、メッセージを送信してから、コンソール → **リクエストログ**
を確認してください。

</Steps>

<a id="peran-roles-yang-didukung"></a>

<a id="サポートされている役割roles"></a>

## サポートされているロール（roles）

| Role | Hostlinkuによるサポート | 注記 |
|---|---|---|
| `chat` | はい | すべてのカタログモデル。 |
| `edit`、`apply` | はい | ツール呼び出しにはモデルを使用してください。`claude-sonnet-4-6`は*apply*に最適です。 |
| `summarize` | はい | `deepseek-v4-flash` / `claude-haiku-4-5` のような低コストなモデル。 |
| `autocomplete` | いいえ | `/v1/completions` 経由で FIM モデルが必要です。このロールは他のプロバイダー（例：ローカルモデル）に任せてください。 |
| `embed`、`rerank` | いいえ | Hostlinkuでは、embeddings/rerankエンドポイントはまだ提供されていません。 |

`edit`/`apply`に特定のモデルが指定されていない場合は、アクティブなモデル`chat`を引き続き使用してください。

<Callout type="tip" title="YAMLアンカーを使用して、繰り返しを削減する">
  `apiBase` および `apiKey` を一度だけアンカー（`&hostlinku`）として定義し、その後、各モデルで
  `<<: *hostlinku` を使用してください。`config.yaml` のリファレンスを参照してください。Continue。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

- **モデルがドロップダウンに表示されない** - YAMLのインデントが間違っているか、`roles`に`chat`が含まれていません。
  VS Codeの*Output → Continue*を参照してください。
- **`401`** - `~/.continue/.env` が読み込まれていません。設定を再読み込みするか、IDEを再起動してください。
- **`404 model_not_found`** - `model:` は、`GET /v1/models` のスラッグと完全に一致する必要があります。
- **ストリーミングが途切れる** - 企業のプロキシが `text/event-stream` をバッファリングしていないことを確認してください。
