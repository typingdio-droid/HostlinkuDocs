[Xum](https://xum.cdr.dev/config/providers)（旧称 **Mux**）は、デスクトップまたはブラウザから、それぞれ隔離されたワークスペースを持つ複数のコーディングエージェントを並行して実行します。 Xumは、任意のAPI形式による**カスタムプロバイダー**をサポートしています。これは、組み込みのプロバイダーOpenAI/Anthropicを変更することなく、Hostlinkuを追加するための最も洗練された方法です。

<Steps>

### APIキーをファイルに保存する

```bash
mkdir -p ~/.config/hostlinku
printf '%s' 'sk-isi-api-key-kamu' > ~/.config/hostlinku/api-key
chmod 600 ~/.config/hostlinku/api-key
```

### プロバイダー Hostlinku を追加する

`~/.xum/providers.jsonc` を編集し、新しいプロバイダーを追加してください：

```jsonc
{
  // Semua model katalog lewat Chat Completions
  "hostlinku": {
    "providerType": "openai-compatible",
    "displayName": "Hostlinku",
    "baseUrl": "https://api.hostlinku.com/v1",
    "apiKeyFile": "~/.config/hostlinku/api-key",
    "models": ["claude-sonnet-4-6", "gpt-5-5", "deepseek-v4-flash"],
  },
  // Opsional: model Claude lewat Anthropic Messages (prompt caching penuh)
  "hostlinku-claude": {
    "providerType": "anthropic-messages",
    "displayName": "Hostlinku (Anthropic)",
    "baseUrl": "https://api.hostlinku.com",
    "apiKeyFile": "~/.config/hostlinku/api-key",
    "models": ["claude-sonnet-4-6", "claude-haiku-4-5"],
  },
}
```

`anthropic-messages`については、Xumが独自に`/v1`を追加したため、ベースURLには`/v1`を**含めない**で記述します。 プロバイダーID（`hostlinku`、`hostlinku-claude`）は小文字で記述し、デフォルトのプロバイダー名と重複してはなりません。

### モデルを選択

モデルピッカー（または`/model`）を開き、**Hostlinku**グループからモデルを選択してください。`models`はあくまで候補リストです。[カタログ](/ja/models)にある他のslugについては、引き続き直接入力することができます。 リクエストはコンソールの → **リクエストログ** に表示されます。

</Steps>

## 代替案：標準搭載のプロバイダー OpenAI

1つのプロバイダーのみを使用したい場合は、デフォルトのプロバイダー**OpenAI**を、ワイヤー形式Chat Completionsを使用してHostlinkuにリダイレクトしてください （**設定 → プロバイダー → OpenAI**、または `providers.jsonc`）：

```jsonc
{
  "openai": {
    "apiKey": "sk-isi-api-key-kamu",
    "baseUrl": "https://api.hostlinku.com/v1",
    "wireFormat": "chatCompletions",
  },
}
```

<Callout type="note" title="なぜchatCompletionsなのか？">
OpenAI のデフォルトのワイヤ形式プロバイダーは Responses API ですが、Responses および Hostlinku は *ステートレス* です ([詳細](/ja/responses))。 Chat Completionsは、その制限なしに、Claudeを含むすべてのカタログモデルを受け入れます。
</Callout>

## トラブルシューティング

| 症状 | Solusi |
|---|---|
| `401` | ファイル `apiKeyFile` の内容が不正です（改行やスペースが含まれている）、またはキーが取り外されています。 |
| `404` | `anthropic-messages` と `/v1` が重複しています — ベース URL として `https://api.hostlinku.com` を指定してください。 |
| プロバイダーが表示されない | プロバイダーIDに大文字やピリオドが含まれているか、またはデフォルトのプロバイダー名と重複しています。 |
| `404 model_not_found` | slugの入力ミス — `GET /v1/models`からコピーしました。 |
