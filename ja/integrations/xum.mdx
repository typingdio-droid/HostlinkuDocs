[Xum](https://xum.cdr.dev/config/providers)（旧称 **Mux**）は、デスクトップまたはブラウザから、
それぞれが隔離されたワークスペースを持つ複数のコーディングエージェントを並行して実行します。Xumは
**カスタムプロバイダー**を任意のAPI形式でサポートしています。これは、デフォルトのOpenAI/Anthropicプロバイダーを変更することなく
Hostlinkuを追加するための最も洗練された方法です。

<Steps>

<a id="simpan-api-key-di-file"></a>

<a id="apiキーをファイルに保存する"></a>

### APIキーをファイルに保存してください

```bash
mkdir -p ~/.config/hostlinku
printf '%s' 'sk-your-api-key' > ~/.config/hostlinku/api-key
chmod 600 ~/.config/hostlinku/api-key
```

<a id="tambahkan-provider-hostlinku"></a>

<a id="プロバイダー-hostlinku-を追加する"></a>

### Hostlinkuプロバイダーを追加してください

`~/.xum/providers.jsonc` を編集し、新しいプロバイダーを追加してください：

```jsonc
{
  // Semua model katalog lewat Chat Completions
  "hostlinku": {
    "providerType": "openai-compatible",
    "displayName": "Hostlinku",
    "baseUrl": "https://api.hostlinku.com/v1",
    "apiKeyFile": "~/.config/hostlinku/api-key",
    "models": ["claude-sonnet-4-6", "gpt-5-5", "deepseek-v4-flash"],
  },
  // Opsional: model Claude lewat Anthropic Messages (prompt caching penuh)
  "hostlinku-claude": {
    "providerType": "anthropic-messages",
    "displayName": "Hostlinku (Anthropic)",
    "baseUrl": "https://api.hostlinku.com",
    "apiKeyFile": "~/.config/hostlinku/api-key",
    "models": ["claude-sonnet-4-6", "claude-haiku-4-5"],
  },
}
```

`anthropic-messages`については、Xumが独自に`/v1`を追加するため、ベースURLは`/v1`を**含めずに**記述してください。
プロバイダーID（`hostlinku`、`hostlinku-claude`）は小文字とし、デフォルトのプロバイダー名と
同一にしてはなりません。

<a id="pilih-model"></a>

### モデルを選択

モデルピッカー（または `/model`）を開き、**Hostlinku** グループからモデルを選択してください。`models` はあくまで
推奨リストです。[カタログ](/ja/models) の他のスラグは、引き続き直接入力可能です。リクエストは
コンソール → **リクエストログ** に表示されます。

</Steps>

<a id="alternatif-provider-openai-bawaan"></a>

<a id="代替案標準搭載のプロバイダー-openai"></a>

## 代替案：組み込みのOpenAIプロバイダー

1つのプロバイダーのみを使用したい場合は、デフォルトの**OpenAI**プロバイダーを、Chat Completions形式でHostlinkuにワイヤ接続するように設定してください
（**設定 → プロバイダー → OpenAI**、または`providers.jsonc`内）：

```jsonc
{
  "openai": {
    "apiKey": "sk-your-api-key",
    "baseUrl": "https://api.hostlinku.com/v1",
    "wireFormat": "chatCompletions",
  },
}
```

<Callout type="note" title="なぜ「chatCompletions」なのか？">
  OpenAIプロバイダーのデフォルトのワイヤ形式はResponses APIですが、HostlinkuのResponsesは
  *ステートレス*です（[詳細](/ja/responses)）。Chat Completionsは、その制限なしに、
  Claudeを含むすべてのカタログモデルを受け入れます。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

| 症状 | 解決策 |
|---|---|
| `401` | `apiKeyFile`ファイルの内容が不正です（改行やスペースが含まれている）、またはキーが無効化されています。 |
| `404` | `anthropic-messages` に `/v1` が二重に付いている場合は、ベースURLを `https://api.hostlinku.com` と記述してください。 |
| 「Provider」は登場しません | プロバイダーIDは、大文字やピリオドを使用している場合、または組み込みのプロバイダー名と重複する場合は、そのまま使用してください。 |
| `404 model_not_found` | Slugのスペルミス - `GET /v1/models`からコピーしてください。 |
