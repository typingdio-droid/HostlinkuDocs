[Codex CLI](https://developers.openai.com/codex/cli) は OpenAI Responses プロトコルを使用しています。カスタムプロバイダーを [`POST /v1/responses`](/ja/responses) にリダイレクトしてください。ツールの適合性と推論は、使用されるモデルおよび Responses のパスによって異なります。

<Steps>

<a id="instal-codex-cli"></a>

<a id="codex-cli-をインストールする"></a>

### Codex CLIをインストールする

```bash
npm install -g @openai/codex
# atau: brew install codex
```

<a id="tambahkan-provider-hostlinku"></a>

<a id="プロバイダー-hostlinku-を追加する"></a>

### Hostlinkuプロバイダーを追加してください

`~/.codex/config.toml` を編集してください（存在しない場合は作成してください）。プロバイダーは、このユーザーファイルで**必ず**定義する必要があります。
プロジェクト内の `.codex/config.toml` は、セキュリティ上の理由から `model_providers` を上書きしてはなりません。

```toml
model = "gpt-5-3-codex"
model_provider = "hostlinku"
model_reasoning_effort = "medium"

[model_providers.hostlinku]
name = "Hostlinku"
base_url = "https://api.hostlinku.com/v1"
env_key = "HOSTLINKU_API_KEY"
wire_api = "responses"
```

<a id="set-api-key-dan-jalankan"></a>

<a id="apiキーを設定して実行する"></a>

### APIキーを設定して実行してください

```bash
export HOSTLINKU_API_KEY=sk-your-api-key   # simpan di ~/.zshrc / ~/.bashrc
codex
```

Codexは、`env_key`で指定された変数からキーを読み取ります。キーは
`config.toml`には決して記述されません。

<Callout type="tip" title="GUIからワンクリックで管理したいですか？">
  デスクトップアプリ [CC Switch](/ja/integrations/cc-switch) を使用して、
  `config.toml` を手動で編集することなく、Codexのプロバイダーやモデルを追加・切り替えできます。
</Callout>

<a id="verifikasi"></a>

<a id="確認"></a>

### 検証

1つの簡単な指示（例：*「このリポジトリの構造を説明してください」*）を送信してください。リクエストは
console → **リクエストログ** に、モデル `gpt-5-3-codex` として表示されます。Codexを開く前に
エンドポイントを確認したい場合は：

```bash
curl https://api.hostlinku.com/v1/responses \
  -H "Authorization: Bearer $HOSTLINKU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "gpt-5-3-codex", "input": "Halo" }'
```

</Steps>

<a id="beberapa-model-lewat-profile"></a>

<a id="プロフィールに表示されるいくつかのモデル"></a>

## プロファイル経由での複数のモデル

`cepat` および `kuat` は、Codex や Hostlinku のデフォルトのプロファイル名ではなく、自由に選択できる例示用の名前です。プロファイル名には、英字、数字、ハイフン、およびアンダーバーを含めることができます。

Codexは`~/.codex/config.toml`を読み込みます。`--profile <nama>`を実行すると、Codexは`~/.codex/<nama>.config.toml`も読み込みます。各プロファイルごとに個別のファイルを作成し、設定はルートレベルで行ってください。`[profiles.*]`セクションは使用しないでください。[Codexの公式プロファイルガイド](https://developers.openai.com/codex/config-advanced/#profiles)を参照してください。

ファイル `~/.codex/cepat.config.toml`:

```toml
model = "gpt-5-6-luna"
model_provider = "hostlinku"
model_reasoning_effort = "low"
```

ファイル `~/.codex/kuat.config.toml`:

```toml
model = "gpt-6-astra"
model_provider = "hostlinku"
```

プロバイダー `hostlinku` は `~/.codex/config.toml` で定義されています。Codex を実行する際にプロファイルを選択してください：

```bash
codex --profile kuat
codex --profile cepat "tulis unit test untuk utils/date.ts"
```

<Callout type="warning" title="モデルおよびツールの互換性">
  お使いのCodexツールに対応したOpenAI/GPTモデルを使用してください。 Service Modeの「Performance」および「Low-Cost」では、CodexはClaudeモデルや、DeepSeek、Qwen、GLM、Kimi、MiniMax、MiMoなどの国内モデルをサポートしていません。Bridge Chat Completionsはテキストおよび関数呼び出しをサポートしていますが、カスタムツール（shell/patch）および暗号化された推論にはネイティブサポートが必要です。 `The requested tool type is not supported by this model`が表示された場合は、OpenAI/GPTモデルに切り替えるか、他のモデルの場合はClaude Code/Chatを使用してください。Dedicatedの場合、ツールのサポートはモデルおよびデプロイメントに依存します。本番環境導入前にテストを行ってください。[Responses API](/ja/responses)を参照してください。
</Callout>

<Callout type="note" title="ステートレス">
  `input` に完全な履歴を送信し、`store: false` を使用してください。Hostlinku は、null ではない `previous_response_id` または `conversation`、および `background: true` を拒否します。暗号化された推論項目は、アップストリーム経路がそれをサポートしている場合にのみ使用できます。[Responses API](/ja/responses) を参照してください。
</Callout>

<Callout type="tip" title="デフォルトのOpenAIエンドポイントのみを変更したいのですか？">
  新しいプロバイダーを使用しない代替案：`config.toml` で `openai_base_url = "https://api.hostlinku.com/v1"` を設定し、
  `OPENAI_API_KEY=sk-…`（HostlinkuのAPIキー）を設定します。カスタムプロバイダーの使用は引き続き推奨されます
  。その理由は、UI上でプロバイダー名が明確に表示され、キーが本来のOpenAIキーとは別になっているためです。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

- **`401`** - `codex`が実行されているシェルでは、`env_key`内の変数がまだエクスポートされていません。
- **シェルツール／パッチが実行されない** — モデルおよびレスポンスパスにおけるツールのサポートを確認してください。テキストによる回答だけでは、ツールが実行されたことを証明するものではありません。
- **`400 previous_response_id`** — `previous_response_id`/`conversation` を削除し、`input` 内に履歴全体を再送信し、`store: false` を使用してください。
- **モデルが表示されない / `404`** - スラグが間違っています；`/v1/models` には、
  あなたのキーに対応する有効なリストが表示されます。
- **旧バージョンのクライアント** — Codexを更新し、[公式の設定リファレンス](https://developers.openai.com/codex/config-reference/)に従って `wire_api = "responses"` を使用してください。
