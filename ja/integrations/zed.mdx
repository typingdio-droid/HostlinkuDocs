[Zed](https://zed.dev/docs/ai/use-api-access) は、`settings.json` を通じて **OpenAI 互換** のカスタムプロバイダーをサポートしています。 モデルは明示的に宣言する必要があります（Zedは自動検出を行いません）。その後、APIキーをAgent Panelまたは環境変数を通じて一度設定してください。

<Steps>

### プロバイダーとモデルを宣言する

`zed: open settings` を開き（⌘/Ctrl + ,）、以下を追加してください：

```json
{
  "language_models": {
    "openai_compatible": {
      "hostlinku": {
        "api_url": "https://api.hostlinku.com/v1",
        "available_models": [
          {
            "name": "claude-sonnet-4-6",
            "display_name": "Claude Sonnet 4.6 (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": true, "parallel_tool_calls": true }
          },
          {
            "name": "gpt-5-5",
            "display_name": "GPT-5.5 (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": true, "parallel_tool_calls": true }
          },
          {
            "name": "deepseek-v4-flash",
            "display_name": "DeepSeek V4 Flash (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": false }
          }
        ]
      }
    }
  },
  "agent": {
    "default_model": { "provider": "hostlinku", "model": "claude-sonnet-4-6" }
  }
}
```

`api_url`は、末尾にスラッシュを付けずに`/v1`で終わらなければなりません。 `max_tokens`はモデルのコンテキストサイズです（[カタログ](/ja/models)の`context_window`を参照）。`name`はslugが完全に一致している必要があります。

### APIキーを入力してください

いずれかを選択してください：

- **エージェントパネル** → 設定アイコン (`agent: open settings`) → プロバイダー「**hostlinku**」を検索 → APIキー `sk-…` を貼り付けます。Zedはこれを`settings.json`ではなく、システムのキーチェーンに保存します。
- プロバイダーIDを大文字で表記した名前の**環境変数** + `_API_KEY`：

```bash
export HOSTLINKU_API_KEY=sk-isi-api-key-kamu
```

その変数をエクスポート済みのシェルからZedを実行してください（あるいは、シェルプロファイルに追加してから再ログインしてください）。

### エージェントパネルでモデルを選択してください

エージェントパネル（⌘/Ctrl + ?）を開き、モデルセレクターから**hostlinku**グループを選択します。メッセージを1件送信し、コンソールの**リクエストログ**でリクエストを確認してください。

</Steps>

## 高度なモデルオプション

| フィールド | いつ使うのか |
|---|---|
| `reasoning_effort` (`"low"`/`"medium"`/`"high"`) | 推論モデル（GPT-5.x、Claude 4.6、DeepSeek V4）。 |
| `capabilities.max_tokens_parameter: true` | モデルが`max_completion_tokens`を拒否し、Hostlinkuが両方を承認する場合に限り、デフォルトのままにしておきます。 |
| `capabilities.chat_completions: false` | モデルを Responses API (`/v1/responses`) に移行する - Hostlinku でもサポートされているが、Zed ではデフォルトの Chat Completions の方が十分に検証されている。 |

<Callout type="note" title="「予測の編集」は含まれません">
Zedの「予測の編集」（インラインオートコンプリート）機能は、`edit_predictions`で個別に構成され、Hostlinkuでは提供されていない`/v1/completions`（FIM）エンドポイントを使用します。 Agent Panel、インラインアシスタント、およびスレッドにはHostlinkuを使用し、予測の編集はデフォルトのプロバイダーのままにしてください。
</Callout>

## トラブルシューティング

- **プロバイダーが表示されない** - `settings.json` が無効です（コンマ／括弧）。`zed: open log` を確認してください。
- **`401`** - プロバイダ `hostlinku` のキーが入力されていないか、Zed の起動後に環境変数がエクスポートされました。Zed を再起動してください。
- **ツール呼び出しは無視されます** - 当該モデルで `capabilities.tools: true` であることを確認してください。
- **コンテキスト全体が早すぎる** - `max_tokens`は`context_window`モデルに比べて小さすぎる；カタログに合わせて調整してください。
