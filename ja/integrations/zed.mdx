[Zed](https://zed.dev/docs/ai/use-api-access)は、`settings.json`を通じてカスタム**OpenAI互換**プロバイダーをサポートしています。
モデルは明示的に宣言する必要があります（Zedは自動検出を行いません）。その後、
APIキーは、エージェントパネルまたは環境変数を通じて一度だけ入力します。

<Steps>

<a id="deklarasikan-provider-dan-model"></a>

### プロバイダーとモデルを宣言する

`zed: open settings` (⌘/Ctrl + ,) を開き、以下を追加してください：

```json
{
  "language_models": {
    "openai_compatible": {
      "hostlinku": {
        "api_url": "https://api.hostlinku.com/v1",
        "available_models": [
          {
            "name": "claude-sonnet-4-6",
            "display_name": "Claude Sonnet 4.6 (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": true, "parallel_tool_calls": true }
          },
          {
            "name": "gpt-5-5",
            "display_name": "GPT-5.5 (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": true, "parallel_tool_calls": true }
          },
          {
            "name": "deepseek-v4-flash",
            "display_name": "DeepSeek V4 Flash (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": false }
          }
        ]
      }
    }
  },
  "agent": {
    "default_model": { "provider": "hostlinku", "model": "claude-sonnet-4-6" }
  }
}
```

`api_url`は、末尾にスラッシュを付けずに`/v1`で終わらなければなりません。`max_tokens`はコンテキストのサイズです
（[カタログ](/ja/models)の`context_window`を参照）。`name`はスラグと完全に一致させる必要があります。

<a id="masukkan-api-key"></a>

### APIキーを入力してください

以下のいずれかを選択してください：

- **Agent Panel** → 設定アイコン (`agent: open settings`) → プロバイダー **hostlinku** を検索 → 貼り付け
  APIキー `sk-…`。Zedはこれを`settings.json`ではなく、システムのキーチェーンに保存します。
- **環境変数**：プロバイダーIDを大文字で表記し、`_API_KEY`を付加したもの：

```bash
export HOSTLINKU_API_KEY=sk-your-api-key
```

それらの変数がエクスポートされているシェルからZedを実行してください（またはシェルプロファイルに追加して
再ログインしてください）。

<a id="pilih-model-di-agent-panel"></a>

### エージェントパネルでモデルを選択してください

エージェントパネル（⌘/Ctrl + ?）を開き、モデルセレクターから**hostlinku**グループを選択してください。メッセージを1件送信し、コンソールの**リクエストログ**でそのリクエストを確認してください。

</Steps>

<a id="opsi-model-lanjutan"></a>

## 高度なモデルオプション

| フィールド | 使用場面 |
|---|---|
| `reasoning_effort` (`"low"`/`"medium"`/`"high"`) | 推論モデル（GPT-5.x、Claude 4.6、DeepSeek V4）。 |
| `capabilities.max_tokens_parameter: true` | モデルが `max_completion_tokens` を拒否する場合に限り、Hostlinkuは両方を許容するため、デフォルトのままにします。 |
| `capabilities.chat_completions: false` | モデルをResponses API (`/v1/responses`) に移行する — Hostlinkuでもサポートされているが、ZedではデフォルトのChat Completionsの方が十分に検証されている。 |

<Callout type="note" title="「Predictions」の編集は対象外です">
  Zedの*edit predictions*（インラインオートコンプリート）機能は、`edit_predictions`で個別に設定され、
  Hostlinkuでは提供されていないエンドポイント `/v1/completions`（FIM）を使用します。Agent Panel、インラインアシスタント、スレッドについてはHostlinku
  をAgent Panel、インラインアシスタント、スレッドに使用し、編集予測はデフォルトのプロバイダーのままにしてください。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

- **プロバイダーが表示されない** - `settings.json`が無効です（コンマ/括弧）。`zed: open log`を確認してください。
- **`401`** - プロバイダー `hostlinku` に対してキーが入力されていないか、Zed の起動後に環境変数がエクスポートされています
  。Zed を再起動してください。
- **ツール呼び出しは無視** - 当該モデルで `capabilities.tools: true` であることを確認してください。
- **コンテキストの取得が早すぎる** - `max_tokens` がモデルの `context_window` に対して小さすぎる；
  カタログに合わせて調整してください。
