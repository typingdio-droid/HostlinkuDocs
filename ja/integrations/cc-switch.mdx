[CC Switch](https://github.com/farion1231/cc-switch)は、**Claude Code**、**Codex CLI**、および
**OpenCode**の設定を単一のグラフィカルインターフェースから管理するためのアプリケーションです。`~/.claude/settings.json`や
`~/.codex/config.toml`を手動で編集する代わりに、Hostlinkuプロバイダーのプロフィールを保存したり、
`/v1/models`からモデルリストを自動的に取得したり、ワンクリック（または
*システムトレイ*のアイコンから）でモデルやキーを切り替えたりすることができます。

<a id="instal-cc-switch"></a>

<a id="cc-switch-をインストールする"></a>

## CC Switchをインストールする

お使いのオペレーティングシステムに応じて、インストール方法を選択してください：

**macOS (Homebrew):**

```bash
brew tap farion1231/ccswitch
brew install --cask cc-switch
```

または、
[GitHub Releases](https://github.com/farion1231/cc-switch/releases) から `.dmg` / `.tar.gz` ファイルをダウンロードしてください。

**Windows:**

インストーラー `CC-Switch-v*-Windows.msi` またはポータブル版 `.zip` を
[GitHub Releases](https://github.com/farion1231/cc-switch/releases) からダウンロードしてください。

**Linux:**

```bash
# Arch Linux (AUR)
paru -S cc-switch-bin
```

Ubuntu/Debian/Fedoraおよびその他のディストリビューションについては、
[GitHub Releases](https://github.com/farion1231/cc-switch/releases) から `.deb`、`.rpm`、または `.AppImage` パッケージをダウンロードしてください。

## ワンクリックでのクイックインポート（ディープリンク）

CC Switchは`ccswitch://v1/import`プロトコルをサポートしています。CC Switchのインストール後、ターミナルで
以下のコマンドを実行するか（またはブラウザでURLを開く）、Hostlinkuのプロバイダーフォームに
自動的に入力されます。確認ダイアログにAPIキー`sk-…`を貼り付けるだけで完了です。

**Claude Code用のHostlinkuプリセットをインポート：**

```bash
# macOS: open "ccswitch://..." | Linux: xdg-open "ccswitch://..." | Windows: start "" "ccswitch://..."
open "ccswitch://v1/import?resource=provider&app=claude&name=Hostlinku&homepage=https%3A%2F%2Fhostlinku.com&endpoint=https%3A%2F%2Fapi.hostlinku.com&model=claude-sonnet-4-6&haikuModel=deepseek-v4-flash&sonnetModel=claude-sonnet-4-6&opusModel=claude-opus-4-6"
```

**Codex CLI用のHostlinkuプリセットをインポート：**

```bash
open "ccswitch://v1/import?resource=provider&app=codex&name=Hostlinku&homepage=https%3A%2F%2Fhostlinku.com&endpoint=https%3A%2F%2Fapi.hostlinku.com%2Fv1&model=gpt-5-3-codex"
```

<a id="cc-switch-で-claude-code-を接続する"></a>

## CC Switchを介してClaude Codeを接続する

<Steps>

<a id="buat-api-key-di-console"></a>

<a id="コンソールで-api-キーを発行する"></a>

### ConsoleでAPIキーを作成する

[console.hostlinku.com](https://console.hostlinku.com) → **API Keys** を開き、新しいキー（例：
`cc-switch-claude`）を作成し、`sk-…` の値をコピーしてください。

<a id="tambahkan-provider-di-tab-claude"></a>

<a id="claude-タブにプロバイダーを追加する"></a>

### 「Claude」タブにプロバイダーを追加してください

1. **CC Switch** を開き、上部のバーから **Claude** アプリを選択してください。
2. 右上の**+**ボタン（*Add Provider*）をクリックし、**Custom Configuration**を選択してください。
3. 以下の主要なフィールドに入力してください：

| フィールド | 値 |
|---|---|
| **プロバイダー名** | `Hostlinku` |
| **ウェブサイトのURL** | `https://hostlinku.com` |
| **APIキー** | `sk-your-api-key` |
| **リクエストURL（ベースURL）** | `https://api.hostlinku.com` |
| **API フォーマット** | `Anthropic Messages (Native)` |

<a id="isi-atau-tarik-daftar-model-otomatis"></a>

<a id="モデル一覧を自動取得または手動入力する"></a>

### モデルリストを自動生成または取得する

モデル設定セクションの**Auto-Fetch Models**ボタンをクリックしてください。CC Switchは、
`GET https://api.hostlinku.com/v1/models`をあなたのAPIキーを使用して呼び出し、そのService Modeキーで利用可能なすべてのモデルを
表示します。

あるいは、マニュアルには推奨される組み合わせで記述してください：

| Slot Model Claude Code | Hostlinkuのスラグに関する推奨事項 | 注記 |
|---|---|---|
| **デフォルトモデル** | `claude-sonnet-4-6` | コーディングセッションの主要なモデル。 |
| **Opusモデル** | `claude-opus-4-6` | 計画（*plan mode*）および大規模なリファクタリングについて。 |
| **Sonnetモデル** | `claude-sonnet-4-6` | 毎日のコード実行。 |
| **Haiku (Fast) モデル** | `deepseek-v4-flash` または `claude-haiku-4-5` | バックグラウンドのサブエージェントとコスト削減の概要。 |

<a id="aktifkan-provider"></a>

<a id="プロバイダーを有効化する"></a>

### プロバイダーを有効にする

**Add**をクリックし、**Hostlinku**カードで**Enable**をクリックします（または*システムトレイ*のメニューから選択します）。
CC Switchは自動的に`env`ブロックを`~/.claude/settings.json`に書き込みます。新しいターミナルを開き、
`claude`を実行し、`/status`と入力して、`ANTHROPIC_BASE_URL`が
`https://api.hostlinku.com`を指していることを確認してください。

</Steps>

<a id="cc-switch-で-codex-cli-を接続する"></a>

## CC Switchを介してCodex CLIを接続する

<Steps>

<a id="pilih-tab-codex-dan-tambah-provider"></a>

<a id="codex-タブを選択してプロバイダーを追加する"></a>

### 「Codex」タブを選択し、プロバイダーを追加してください

1. CC Switchで、上部バーから**Codex**アプリを選択してください。
2. **+**（*Add Provider*）→ **Custom Configuration** をクリックします。
3. 以下の設定内容：

| フィールド | 値 |
|---|---|
| **プロバイダー名** | `Hostlinku` |
| **APIキー** | `sk-your-api-key` |
| **エンドポイント（ベースURL）** | `https://api.hostlinku.com/v1` |
| **モデル** | `gpt-5-3-codex`（または `gpt-5-5`、`gpt-6-astra`） |

下部の `config.toml` のプレビューで、`wire_api` フィールドの値が `"responses"` になっていることを確認してください：

```toml
model = "gpt-5-3-codex"
model_provider = "hostlinku"

[model_providers.hostlinku]
name = "Hostlinku"
base_url = "https://api.hostlinku.com/v1"
wire_api = "responses"
```

<a id="aktifkan-dan-jalankan-codex"></a>

<a id="有効化して-codex-を実行する"></a>

### Codexを有効にして実行する

**Hostlinku**カードで**Add**をクリックし、次に**Enable**をクリックしてください。CC Switchは自動的に
`~/.codex/config.toml`を更新し、APIキーを`~/.codex/auth.json`に保存します。ターミナルで`codex`を実行して
作業を開始してください。

</Steps>

<Callout type="tip" title="サービスモードごとにプロファイルを分けてください">
  CC Switchでは、3つの異なるプロバイダーカードを作成できます。例えば、**Hostlinku (Performance)**、
  **Hostlinku (Low-Cost)**、および**Hostlinku (Dedicated)**などです。それぞれに対応するAPIキーが割り当てられます。
  エコモードから高速モードに切り替えたい場合は、CC Switch上で目的のカードをクリックするだけで、
  端末に触れる必要はありません。
</Callout>

<Callout type="warning" title="環境変数の競合検出">
  以前に `~/.zshrc` / `~/.bashrc` に `export ANTHROPIC_BASE_URL` や `export OPENAI_API_KEY` を記述したことがある場合、
  CC Switch は、シェル変数が
  GUIの設定を上書きしたり、競合したりする可能性があるため、黄色い警告バナーが表示されます。シェルプロファイルファイルから古いexportを削除し、
  ターミナルを再起動して、CC Switchの設定を完全に適用してください。
</Callout>

<a id="troubleshooting"></a>

## トラブルシューティング

| 症状 | 原因と解決策 |
|---|---|
| CC Switchの設定は、Claude Codeには影響しません | `~/.zshrc` に Anthropic の OAuth ログインセッションや `ANTHROPIC_*` 変数が残っている場合があります。`claude` 内で `/logout` を実行し、シェル内の古いエクスポートを削除してください。 |
| *Auto-Fetch Models* ボタンが機能しない | **Request URL**には `https://api.hostlinku.com`（二重スラッシュなし）が入力され、**API Key**が正しく入力されていることを確認してください。 |
| Codexは、有効化後にシェルツールの使用を拒否します | 「Codex」タブで選択するモデルは、*Responses-native* な `gpt-*` モデル（`gpt-5-3-codex`、`gpt-5-5`、`gpt-6-astra` など）でなければなりません。 Codexでは、OpenAI以外のモデルや`gpt-5-6-terra`を選択しないでください。 |
| `400 not available in Service Mode` | 選択したモデルは、そのAPIキーのサービスモードでは有効ではありません。**Auto-Fetch Models**ボタンを使用すると、そのキーに一致するモデルのみが表示されます。 |
