[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) は、DeepSeek が開発した
オープンソースの AI コーディングエージェントです。選択したローカルワークスペース内で、ファイルの読み取り、
コードの編集、シェルコマンドの実行、複数ステップのタスク完遂を、Web UI・ヘッドレスモード・SDK・ACP 経由で
行えます。

`dsh` は **Anthropic Messages** プロトコルを使用します。Hostlinku は
[`POST /v1/messages`](/ja/anthropic-messages) でネイティブ対応しているため、追加のプロキシやプラグインなしで
2 つの環境変数を設定するだけで `dsh` を Hostlinku に接続できます。

<Callout type="note" title="検証済みバージョン">
  本ガイドは `@deepseek-ai/dsh` **0.2.1-rc.5** でエンドツーエンド検証済みです（ヘッドレスモードでエージェントが
  ツール経由でファイルを読み取り回答を返す動作を確認）。DeepSeek Harness は現在 *development preview* であり、
  将来のリリースで設定ファイルパスやパラメータの挙動が変更される可能性があります。
</Callout>

## 始める前に

- **最新の Node.js LTS** (`node --version`)。`dsh` パッケージは数百個の依存関係を取得するため、初回の
  インストールには 1〜3 分かかる場合があります。
- **Hostlinku API キー** (`sk-…`) — [console.hostlinku.com](https://console.hostlinku.com) → **API Keys** で発行。
- **十分なクレジット残高**または利用上限。
- **安全なテスト用フォルダ。** `dsh` を起動したディレクトリがデフォルトのワークスペースになります。ホーム
  ディレクトリや重要なデータが含まれるフォルダで直接起動しないでください。

<Steps>

### DeepSeek Harness をインストールする

```bash
npm install -g @deepseek-ai/dsh
dsh --version
```

グローバルインストールせずに実行する場合は `npx @deepseek-ai/dsh web` を使用します。

### Hostlinku に接続する

`dsh` は `DEEPSEEK_BASE_URL` からエンドポイントを、`DEEPSEEK_API_KEY` から API キーを読み取ります。

**macOS / Linux / WSL**（`~/.zshrc` または `~/.bashrc` に保存）：

```bash
export DEEPSEEK_BASE_URL=https://api.hostlinku.com
export DEEPSEEK_API_KEY=sk-your-api-key
```

**Windows PowerShell:**

```powershell
$env:DEEPSEEK_BASE_URL = "https://api.hostlinku.com"
$env:DEEPSEEK_API_KEY  = "sk-your-api-key"
```

`dsh` は自動的に `/v1/messages` を付与します。ベース URL として `https://api.hostlinku.com/v1` も指定可能です
（末尾の `/v1` は再利用され、重複しません）。

### モデルと最大出力トークンを設定する

`dsh` のデフォルトモデル（`deepseek-flash`）は Hostlinku のカタログスラッグではなく、また `dsh` はデフォルトで
`max_tokens: 256000` を送信するため、ほとんどのモデルの出力上限を超過します。ホームディレクトリのパッチファイル
`~/.dsh/cordis.patch.yml`（`DSH_HOME` を設定している場合は `$DSH_HOME/cordis.patch.yml`）で両方を設定します。

```yaml
- id: agent-default-model
  config:
    provider: deepseek-official
    model: deepseek-v4-flash
- id: llm-deepseek
  config:
    apiKeyEnv: DEEPSEEK_API_KEY
    maxTokens: 32000
```

<Callout type="important" title="パッチは config ブロック全体を置き換えます">
  Cordis のパッチは個別のフィールドをマージするのではなく、デフォルトの `config` ブロック全体を**置き換え**ます。
  そのため `provider: deepseek-official` と `apiKeyEnv` も必ず記述してください。省略すると
  `$.provider missing required value` で起動に失敗します。
</Callout>

### 実行する

ヘッドレスモードで素早く動作を確認します（1 つのタスクを実行し、最終回答を出力して終了します）：

```bash
mkdir dsh-test && cd dsh-test
echo "the secret word is PINEAPPLE" > hello.txt
dsh --profile headless "Read hello.txt and reply with only the secret word."
```

期待される出力：`PINEAPPLE`。これでエージェントが Hostlinku 経由でファイル読み取りツールを呼び出し、回答したことが
確認できます。ブラウザでフル UI を起動するには：

```bash
dsh web
```

### 確認する

コンソール → **リクエストログ** を開きます。`dsh` からのリクエストが、選択したモデル、トークン数、コスト、使用した
API キーとともに記録されます。

</Steps>

## おすすめのモデル

`model` フィールドには、ツール呼び出しをサポートする[カタログ](/ja/models)内の任意のスラッグを指定できます。
お使いのキーで利用可能な一覧は `GET /v1/models` で確認できます。

| 用途 | スラッグ | 備考 |
|---|---|---|
| 日常のデフォルト（高速・低コスト） | `deepseek-v4-flash` | 1M コンテキスト、推論、ツール呼び出し対応。 |
| 画像入力が必要な場合（スクリーンショット、図表） | `deepseek-v4-1-flash` | ビジョン（画像認識）対応。 |
| 重いタスク / 大規模リファクタリング | `deepseek-v4-pro` | 1M コンテキスト、より深い推論。 |
| オープンウェイトの代替モデル | `kimi-k2-7-code`, `glm-5-3` | ツール呼び出しと推論に対応。 |

<Callout type="tip" title="モデルに合わせて maxTokens を調整する">
  `maxTokens` は 1 リクエストあたりの最大出力トークン数であり、コンテキストウィンドウではありません。`32000` は
  ほぼすべてのモデルで安全な値です。モデルごとの最大出力値（例：`deepseek-v4-flash` は `131072`）は各モデルの
  カタログページに記載されています。
</Callout>

## セキュリティ

- タスク実行中、プロンプト、コードの抜粋、ファイル内容、ツールの実行結果が推論のために Hostlinku へ送信されます。
  許可なく営業秘密や個人情報を含むプロジェクトで `dsh` を実行しないでください。
- 万が一漏洩した場合にすぐ失効できるよう、クレジット上限を設定した **`dsh` 専用の API キー**を使用してください。
  詳細は[認証](/ja/authentication)を参照してください。
- `cordis.patch.yml` に API キーの文字列を直接書き込まないでください。`apiKeyEnv` には環境変数の**名前**のみを
  指定し、実際のキーの値はシェル環境から読み取らせます。

## トラブルシューティング

| 症状 | 原因と解決策 |
|---|---|
| `INVALID_REQUEST: max_tokens (256000) exceeds the output limit of model …` | `maxTokens` が未設定です。`llm-deepseek` ブロックに `maxTokens: 32000` を追加してください。 |
| `startup failed … $.provider missing required value` | パッチの `agent-default-model` ブロックに `provider` が含まれていません。上記の例の通りブロック全体を記述してください。 |
| `MISSING_CREDENTIAL` | `dsh` を実行しているシェルで `DEEPSEEK_API_KEY` がエクスポートされていません。 |
| `401` / *invalid API key* | キーが誤っているか、失効または期限切れです。コンソールで新しいキーを発行してください。 |
| `404 model not found` | スラッグの誤記、またはデフォルトの `deepseek-flash` のままになっています。`GET /v1/models` から正確なスラッグをコピーしてください。 |
| 画像添付が失敗する | `dsh` は最初に `/v1/files` でのアップロードを試み、その後自動的にインラインの base64 画像送信へフォールバックします。選択したモデルがビジョンに対応していること（例：`deepseek-v4-1-flash`）を確認してください。 |
