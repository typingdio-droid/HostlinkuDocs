ストリームモードでは、SSE（`text/event-stream`）を介してトークン単位で応答を送信します。トークンは、応答全体が完了するのを待たずに、モデルが応答を開始した時点で表示可能です。最初のトークンが送信されるタイミングは、モデルおよびプロバイダーによって異なります。`"stream": true` を指定して有効化します。

<a id="ringkas-curl"></a>

<a id="概要curl"></a>

## 要約：curl

```bash
curl -N https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Hitung 1 sampai 5." }],
    "stream": true
  }'
```

フラグ `-N` は重要です。これがないと、curl はバッファが満杯になるか、ストリームが終了するまで出力を保留します。

チャンクの形式：

```text
data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":"1"}}]}

data: [DONE]
```

<a id="python---sdk-openai"></a>

## Python - OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key="sk-your-api-key",
)

stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
```

## Python - requests

リクエストでは `stream=True` を使用し、`iter_lines()` を読み取ってください。`data: [DONE]` を受信したら停止してください。

```python
import json
import requests

response = requests.post(
    "https://api.hostlinku.com/v1/chat/completions",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json",
    },
    json={
        "model": "gpt-5-5",
        "messages": [{"role": "user", "content": "Halo!"}],
        "stream": True,
    },
    stream=True,
)

for line in response.iter_lines():
    if not line:
        continue
    text = line.decode("utf-8")
    if not text.startswith("data: "):
        continue
    payload = text[6:]
    if payload == "[DONE]":
        break
    chunk = json.loads(payload)
    if "error" in chunk:
        raise RuntimeError(chunk["error"])
    delta = chunk["choices"][0].get("delta", {}).get("content")
    if delta:
        print(delta, end="", flush=True)
```

<a id="nodejs---sdk-openai"></a>

## Node.js - OpenAI SDK

```js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.hostlinku.com/v1",
  apiKey: process.env.HOSTLINKU_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "gpt-5-5",
  messages: [{ role: "user", content: "Halo!" }],
  stream: true,
});

for await (const chunk of stream) {
  const delta = chunk.choices[0]?.delta?.content;
  if (delta) process.stdout.write(delta);
}
```

## Hostlinkuの注記

- ヘッダー `x-request-id` は、ストリーミングレスポンスでも引き続き送信されます。
- ストリームが途中で失敗した場合、ゲートウェイはイベント `data: {"error": {...}}` を送信し、偽の `[DONE]` は**送信しません**。
- 費用は、ストリーム終了後の実際の使用量に基づいて計算されます。使用量が確認できない場合は、予約に基づく見積もりが請求に適用されます。
- リバースプロキシやCDNでレスポンスをバッファリングしないでください。`text/event-stream`をそのまま転送してください。

<Callout type="tip" title="いつストリーミングするのが適切ですか？">
  レスポンスの速さが求められるチャットアプリやエージェントでは、`stream: true`を使用してください。進行状況を表示しないバッチ/ジョブの場合は、非ストリーミングの方がシンプルです。
</Callout>
