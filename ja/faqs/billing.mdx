Hostlinkuでは、米ドル建てのプリペイド残高を使用します（1 <CreditIcon /> = $1）。月額サブスクリプションはなく、料金はアップストリームトークンの使用量、または使用量が確認できない場合は推定値に基づいて算出されます。[請求と残高](/ja/billing)をご覧ください。

<a id="kenapa-muncul-402-padahal-saldo-ada"></a>

## 残高があるのに、なぜ402エラーが表示されるのですか？

以下の2点を確認してください：

1. **利用可能残高** - すでに使用済みまたは予約済みの残高は、これ以上使用できません。残高の確認は、Consoleの**Billing**で行ってください。
2. **APIキーのクレジット制限** - キーには、日次、週次、月次、または総計の制限が設定される場合があります。制限に達した場合、アカウントの残高が残っていてもリクエストは拒否されます。制限を変更するか、リセット期間を待ってください。

<a id="bagaimana-cara-top-up"></a>

## チャージの方法は？

Console → **Billing** を開きます。利用可能な決済方法はチャージページに表示されます（現在はQRIS/バーチャルアカウントおよび暗号資産）。最低・最高金額および為替レートは、チェックアウト時に表示される内容に従います。

<a id="apakah-pembayaran-langsung-masuk"></a>

<a id="支払いはすぐに反映されますか"></a>

## 支払いは直接入金されますか？

支払いが確認されると、残高に反映されます。ステータスが「保留中」のままである場合は、再度チャージを行う前に、Consoleで取引履歴を確認してください。サポートに連絡する際は、取引IDを明記してください。

<a id="apakah-saldo-bisa-dikembalikan"></a>

<a id="残高は返金されますか"></a>

## 残高は返金可能ですか？

未使用のチャージ残高については、[返金ポリシー](/ja/legals/refund-policy)に従って申請することができます。ボーナスやプロモーションには現金価値はありません。
