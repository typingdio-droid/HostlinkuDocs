OpenAIのフォーマットに加え、Hostlinkuは
[Anthropic Messages API](https://docs.anthropic.com/en/api/messages)と互換性のあるエンドポイントも提供しています。Anthropicの公式SDKである
**Claude Code**、Cursor、Cline、およびAnthropicプロトコルに対応したその他のツールは、
ベースURLを変更するだけで利用可能です。1つのAPIキーと1つのHostlinku残高で、両方のフォーマットに対応しています。

```http
POST https://api.hostlinku.com/v1/messages
x-api-key: sk-your-api-key
anthropic-version: 2023-06-01
Content-Type: application/json
```

認証では、ヘッダー `x-api-key`（Anthropicスタイル）**または** `Authorization: Bearer sk-…` を受け付けます。
成功レスポンスには、ヘッダー `request-id` / `x-request-id`（HostlinkuのリクエストID、形式 `msg_…`）が含まれます。非ストリーミングの成功レスポンスには、`x-model` も含まれます。ハンドラー到達前のエラーには、このIDが含まれない場合があります。

<Callout type="note" title="モデルはすべて対象であり、Claudeだけではありません">
  `model`は、[モデルカタログ](/ja/models)と同じHostlinkuのパブリックスラグを使用しています。例：`claude-sonnet-4-6`、`deepseek-v4-pro`、`glm-5-3-flash`。Anthropic MessagesエンドポイントはClaude以外のモデルを呼び出すことができますが、エージェントクライアントのサポートは異なります。Service Mode PerformanceおよびLow-CostのClaude Codeは、GPTモデルではなく、Claudeモデルおよび国内モデルをサポートしています。 各クライアントの制限については、[統合ガイド](/ja/integrations)をご確認ください。
</Callout>

<a id="konfigurasi-cepat"></a>

## クイック設定

各ツール（Claude Code、Clineなど）ごとのステップバイステップガイドは、
[IDE & エージェントの統合](/integrations) にあります。

**Claude Code**

```bash
export ANTHROPIC_BASE_URL=https://api.hostlinku.com
export ANTHROPIC_API_KEY=sk-your-api-key
export ANTHROPIC_MODEL=claude-sonnet-4-6
claude
```

**Python（Anthropic公式SDK）**

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-your-api-key",
    base_url="https://api.hostlinku.com",
)

message = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Jelaskan apa itu API gateway dalam dua kalimat."}],
)
print(message.content[0].text)
print(message.usage.input_tokens, message.usage.output_tokens)
```

**Node.js**

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({ apiKey: "sk-your-api-key", baseURL: "https://api.hostlinku.com" });
const msg = await client.messages.create({
  model: "claude-haiku-4-5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Halo!" }],
});
```

<a id="parameter-body"></a>

<a id="bodyパラメータ"></a>

## ボディパラメータ

| パラメータ | タイプ | 備考 |
|---|---|---|
| `model` | `string` | **必須。** Hostlinkuモデルのスラッグ。 |
| `messages` | `array` | **必須。** `{ role: "user" \| "assistant", content }`; `content` は文字列またはブロック配列（`text`、`image`、`tool_use`、`tool_result`、…）です。 |
| `max_tokens` | `integer` | **必須**（Anthropicの仕様に準拠）。モデルの出力制限を超えた場合は`400`で拒否されます。 |
| `system` | `string` \| `array` | システムプロンプト；ブロック配列は `cache_control` をサポートしています。 |
| `stream` | `boolean` | SSEについては`true`（下記参照）。 |
| `temperature` | `number` | `0`–`1`。 |
| `top_p`、`top_k` | `number`、`integer` | 代替のサンプリング例。 |
| `stop_sequences` | `string[]` | 最大16。 |
| `tools`、`tool_choice` | `array`、`any` | ツールはAnthropicのフォーマットを使用します（`input_schema`を含む）。 |
| `thinking` | `object` | 拡張的な解釈、例：`{ "type": "enabled", "budget_tokens": 1024 }`。 |
| `metadata` | `object` | 例：`{ "user_id": "…" }`。 |
| `mcp_servers`、`context_management`、`output_format` | - | そのまま転送する（モデルのサポート状況による）。 |

リスト外のフィールドは削除されます。無効なボディは `400 invalid_request_error` で拒否され、
フィールドごとの詳細は `error.details.issues` に記載されます。

## 非ストリーミング応答

```json
{
  "id": "msg_…",
  "type": "message",
  "role": "assistant",
  "model": "claude-haiku-4-5",
  "content": [{ "type": "text", "text": "API gateway adalah …" }],
  "stop_reason": "end_turn",
  "stop_sequence": null,
  "usage": {
    "input_tokens": 30,
    "output_tokens": 55,
    "cache_creation_input_tokens": 0,
    "cache_read_input_tokens": 0,
    "cache_creation": { "ephemeral_5m_input_tokens": 0, "ephemeral_1h_input_tokens": 0 }
  },
  "hostlinku": { "cost": 0.00021, "currency": "🪙", "serviceMode": "performance", "latencyMs": 940 }
}
```

`id` および `model` は常に Hostlinku の公開識別子です。`hostlinku` ブロックは拡張機能（AnthropicのSDKは
これを無視します）であり、コスト <CreditIcon />、サービスモードのAPIキー、およびレイテンシが含まれています。

<Callout type="note" title="Anthropicの用語使用規約">
  Anthropicの仕様によると、`input_tokens`にはキャッシュトークンは**含まれません**。キャッシュトークンは
  `cache_read_input_tokens` / `cache_creation_input_tokens`で別途報告されます。Hostlinkuの請求では、これら
  これら3つをそれぞれ個別の料金で計算します。これは `/v1/chat/completions` パスと同様です
  （[Billing](/ja/billing)を参照）。
</Callout>

<a id="streaming-stream-true"></a>

## ストリーミング (`stream: true`)

Gatewayは、Anthropicのフレーミング（`event:` + `data:`）でSSEイベントを転送します：

```text
event: message_start
data: {"type":"message_start","message":{"id":"msg_…","type":"message","role":"assistant","model":"claude-haiku-4-5","content":[],"usage":{"input_tokens":22,"output_tokens":1,…}}}

event: content_block_start
data: {"type":"content_block_start","index":0,"content_block":{"type":"text","text":""}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"Apel"}}

event: content_block_stop
data: {"type":"content_block_stop","index":0}

event: message_delta
data: {"type":"message_delta","delta":{"stop_reason":"end_turn","stop_sequence":null},"usage":{"input_tokens":22,"output_tokens":7,…}}

event: message_stop
data: {"type":"message_stop"}
```

注：

- 最終的な使用量は `message_delta` にあり、費用は `message_stop` 後の実際の使用量に基づいて計算されます。
- ストリームが途中で失敗した場合、ゲートウェイは `event: error` を
  `{"type":"error","error":{"type":…,"message":…}}` の形式で送信し、偽の `message_stop` は**送信しない**。
- 最初のバイトが返される前のエラー（残高不足、モデルが存在しない、レート制限）は、
  正しいHTTPステータスを伴う通常のJSONレスポンスとして返されます。AnthropicのSDKはこれを例外
  （`AuthenticationError`、`NotFoundError`、`RateLimitError`、…）にマッピングします。

<a id="hitung-token"></a>

<a id="トークンの数を数える"></a>

## トークンの計算

```http
POST https://api.hostlinku.com/v1/messages/count_tokens
```

Body: `model`、`messages`、オプションで `system`、`tools`、`tool_choice`、`thinking`。レスポンス
`{ "input_tokens": 15 }`。課金対象外。

<a id="format-error"></a>

<a id="フォーマットエラー"></a>

## エラーの形式

```json
{ "type": "error", "error": { "type": "authentication_error", "message": "The API key is invalid or has been revoked." } }
```

| HTTP | `error.type` | 一般的な原因 |
|---|---|---|
| 400 | `invalid_request_error` | Bodyは無効です。`max_tokens`がモデルの制限を超えています。モデルはService Mode keyでは利用できません。 |
| 401 | `authentication_error` | APIキーが不正、無効化、または期限切れです。 |
| 402 | `billing_error` | 残高が不足しているか、APIキーのクレジット上限に達しました。 |
| 403 | `permission_error` | アカウントが停止されました／アクセスが拒否されました。 |
| 404 | `not_found_error` | モデルのスラグはカタログに存在しません。 |
| 429 | `rate_limit_error` | リクエスト制限に達しました。 |
| 503 | `overloaded_error` | モデル／アップストリームは利用できません。カタログや代替モデルを確認してください。一時的な障害の場合は、間隔を空けて再試行してください。 |

表は、プロトコルが処理するエラーを示しています。ハンドラー前のリクエストやボディの解析に関する制限については、Hostlinkuの一般的な形式を使用できます。[Error](/ja/errors)を参照してください。

エラーメッセージは、内部識別情報を隠蔽するためにサニタイズされていますが、アップストリームによる拒否理由の一部はそのまま表示される場合があります。[Error](/ja/errors)。
