1つのAPIキーは3つのダイアレクトすべてで有効です。異なるのは**base URL**と**header auth**のみです：

| 方言 | Base URL | ヘッダー |
|---|---|---|
| Anthropic Messages | `https://api.hostlinku.com`（`/v1`を除く） | `x-api-key: <API_KEY>` |
| OpenAIチャット補完 | `https://api.hostlinku.com/v1` | `Authorization: Bearer <API_KEY>` |
| OpenAIの応答 | `https://api.hostlinku.com/v1` | `Authorization: Bearer <API_KEY>` |

モデルの名称は、[カタログ](/ja/models)のスラグに置き換えてください。以下の例では、
Service Mode Performanceで利用可能なモデルを使用しています。

<Callout type="note" title="モデルおよびツールの互換性">
  Service Mode APIキーで利用可能なモデルを選択してください。Vision、JSONスキーマ、推論、およびツール呼び出しのサポートは、モデルおよびそのプロトコルパスに従います。[互換性の制限](/ja/responses)を参照してください。
</Callout>

## Python

### Anthropic Messages

```bash
pip install anthropic
```

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-your-api-key",
    base_url="https://api.hostlinku.com",
)

message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Jelaskan API gateway dalam dua kalimat."}],
)
print(message.content[0].text)
print(message.usage.input_tokens, message.usage.output_tokens)
```

ストリーミング：

```python
with client.messages.stream(
    model="claude-sonnet-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

<a id="openai-chat-completions"></a>

### OpenAIチャット補完

```bash
pip install openai
```

```python
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.hostlinku.com/v1")

response = client.chat.completions.create(
    model="gpt-6-astra",
    messages=[
        {"role": "system", "content": "Kamu asisten yang ringkas."},
        {"role": "user", "content": "Halo dari SDK OpenAI!"},
    ],
)
print(response.choices[0].message.content)
```

ストリーミング：

```python
stream = client.chat.completions.create(
    model="gpt-6-astra",
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
```

<a id="openai-responses"></a>

### OpenAIの応答

```python
response = client.responses.create(
    model="gpt-6-astra",
    instructions="Jawab singkat dalam bahasa Indonesia.",
    input="Apa itu API gateway?",
    max_output_tokens=256,
)
print(response.output_text)
```

ストリーミング：

```python
with client.responses.stream(
    model="gpt-6-astra",
    input="Tulis satu paragraf pendek.",
) as stream:
    for event in stream:
        if event.type == "response.output_text.delta":
            print(event.delta, end="", flush=True)
```

## Node.js / TypeScript

### Anthropic Messages

```bash
npm install @anthropic-ai/sdk
```

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: "sk-your-api-key",
  baseURL: "https://api.hostlinku.com",
});

const message = await client.messages.create({
  model: "claude-sonnet-5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Halo!" }],
});
console.log(message.content[0].text);
```

ストリーミング：

```ts
const stream = client.messages.stream({
  model: "claude-sonnet-5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Tulis satu paragraf pendek." }],
});

stream.on("text", (text) => process.stdout.write(text));
await stream.finalMessage();
```

<a id="openai-chat-completions-1"></a>

### OpenAIチャット補完

```bash
npm install openai
```

```ts
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-your-api-key",
  baseURL: "https://api.hostlinku.com/v1",
});

const response = await client.chat.completions.create({
  model: "gpt-6-astra",
  messages: [{ role: "user", content: "Halo!" }],
});
console.log(response.choices[0].message.content);
```

ストリーミング：

```ts
const stream = await client.chat.completions.create({
  model: "gpt-6-astra",
  messages: [{ role: "user", content: "Tulis satu paragraf pendek." }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
```

<a id="openai-responses-1"></a>

### OpenAIの応答

```ts
const response = await client.responses.create({
  model: "gpt-6-astra",
  input: "Halo!",
  max_output_tokens: 256,
});
console.log(response.output_text);
```

ストリーミング：

```ts
const stream = await client.responses.create({
  model: "gpt-6-astra",
  input: "Tulis satu paragraf pendek.",
  stream: true,
});

for await (const event of stream) {
  if (event.type === "response.output_text.delta") {
    process.stdout.write(event.delta);
  }
}
```

## 注記

<Callout type="note" title="その他の言語">
  Java、Go、PHPでは同じパターンを採用します：`base_url`をHostlinkuに置き換え、その後、Anthropic（Messages）またはOpenAI（Chat/Responses）の公式SDKを使用してください。Hostlinku専用のライブラリはありません。
</Callout>

<Callout type="warning" title="クライアントごとの制限">
  **Codex CLIはOpenAIモデル専用**（`gpt-*`）です。Claudeモデルやその他の非OpenAIモデルは、
  ツールの種類の違いによりアップストリームで拒否されます。 **Claude Code**はClaude以外のモデルを使用できますが、
  `unrecognized_model`という警告が表示され、コンテキストは200kトークンとみなされます。
  詳細は[Codex](/ja/integrations/codex-cli)および
  [Claude Code](/ja/integrations/claude-code)のページに記載されています。
</Callout>
