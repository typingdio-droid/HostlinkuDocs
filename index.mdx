**Hostlinku** adalah gateway AI terpadu (_unified AI gateway_): satu API dengan format yang
kompatibel penuh dengan OpenAI. Request kamu diteruskan ke ratusan model dari berbagai provider
(OpenAI, Anthropic, Google, DeepSeek, Qwen, dan lainnya) lewat satu API key.

Dengan Hostlinku kamu tidak perlu mengelola akun, API key, dan format request yang berbeda-beda
untuk setiap provider:

- **Satu API key** untuk semua model (`sk-…`).
- **Kompatibel OpenAI**: pakai SDK resmi OpenAI (`openai-python`, `openai-node`) cukup dengan
  mengganti `base_url`.
- **Streaming SSE**: respons token-per-token dengan format `text/event-stream` seperti OpenAI.
- **Katalog model terpusat**: slug, harga per token, konteks, dan kapabilitas di satu tempat.
- **Kontrol pemakaian**: batas kredit per API key, riwayat request, dan log lengkap di console.
- **Billing fleksibel**: saldo yang bisa diisi via QRIS / Virtual Account (iPaymu) atau crypto
  (BlockBee).

## Arsitektur singkat

```text
Aplikasi kamu
    │  Authorization: Bearer sk-…
    ▼
api.hostlinku.com  ──►  Gateway Hostlinku  ──►  Routing & failover
(v1/chat/completions)        │                        │
                             │                        ├─► OpenAI
                             ├─ Reservasi saldo       ├─► Anthropic
                             ├─ Telemetri & log       ├─► Google
                             └─ Commit biaya nyata    └─► …dan lainnya
```

Setiap request melewati alur yang sama: autentikasi API key, pemeriksaan limit kredit, reservasi
saldo (estimasi), penerusan ke layanan model (dengan percobaan ulang otomatis bila ada
gangguan), lalu commit biaya berdasarkan token yang benar-benar terpakai dan pencatatan telemetri.

Console Hostlinku (`console.hostlinku.com`) memakai backend yang sama: API key, saldo, riwayat
request, dan log audit semuanya berasal dari data gateway yang nyata.
