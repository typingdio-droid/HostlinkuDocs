Hostlinku menyediakan OpenAI Chat Completions, Anthropic Messages, dan Responses API melalui satu gateway. API key terikat pada Service Mode **Performance**, **Low-Cost**, atau **Dedicated**; model dan harga mengikuti mode tersebut.

## Request pertama

Daftar di [Console](https://console.hostlinku.com), isi saldo organisasi, lalu buat API key. Contoh berikut memakai model dari katalog key; ganti slug bila perlu. [Panduan lengkap](/getting-started).

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-5","messages":[{"role":"user","content":"Hello"}]}'
```
