## Kanal dukungan

| Kanal | Kegunaan |
|---|---|
| [halo@hostlinku.com](mailto:halo@hostlinku.com) | Pertanyaan teknis, akun, dan billing |
| [Console](https://console.hostlinku.com) | Saldo, API key, log request, dan audit |
| [Status](https://status.hostlinku.com) | Gangguan dan insiden yang sedang berlangsung |

Email dibalas secepatnya pada hari kerja oleh tim kecil (best-effort). Pembaruan insiden diumumkan di halaman Status.

## Informasi untuk laporan

1. `x-request-id` bila tersedia pada respons atau log Console.
2. Waktu kejadian dengan zona waktu, endpoint, dan slug model.
3. HTTP status serta body error; kode/tipe berbeda menurut [format API](/errors).
4. Contoh request minimal yang dapat direproduksi, dengan API key dan data sensitif dihapus.

```text
Waktu: 2026-11-06 14:32 UTC+7
Request ID: <x-request-id>
Endpoint: /v1/chat/completions
Model: gpt-5-5
HTTP: 503
Error: UPSTREAM_TIMEOUT ("The request timed out. Please retry.")
Catatan: Terjadi 3 kali dalam 10 menit terakhir.
```

## Masalah keamanan

Kirim temuan keamanan secara privat ke [halo@hostlinku.com](mailto:halo@hostlinku.com) dengan subjek `[SECURITY]`. Hindari mempublikasikan detail sebelum ditangani. Tim dukungan tidak meminta API key, password, atau kode OTP; jangan sertakan secret dalam laporan.
