Siapkan curl dan saldo kredit, lalu ikuti langkah berikut.

<Steps>

### Masuk dan isi saldo

Buka [Daftar](https://api.hostlinku.com/api/auth2/register) atau [Masuk](https://api.hostlinku.com/api/auth2/login). Login dilayani Keycloak. Di [Console](https://console.hostlinku.com), buka **Billing** dan isi saldo kredit sebelum mengirim request. Lihat [Billing](/billing) untuk metode pembayaran.

### Buat API key

Buka **API Keys → Buat API key**, beri nama, lalu pilih **Performance** (default), **Low-Cost**, atau **Dedicated**. Service Mode menentukan model dan harga. Salin secret `sk-…` yang hanya tampil sekali dan simpan di environment server. Pengaturan kedaluwarsa, limit kredit, serta passkey/2FA dijelaskan di [Autentikasi](/authentication).

### Kirim request pertama

Gunakan model yang tersedia untuk Service Mode key. Contoh berikut memakai `gpt-5-5`; untuk key Dedicated atau pilihan lain, ambil slug dari [`GET /v1/models`](/models).

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{"role": "user", "content": "Halo! Perkenalkan dirimu singkat saja."}]
  }'
```

Respons non-streaming berbentuk JSON. Contoh berikut dipotong; token, biaya, dan latensi hanya ilustrasi:

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Halo! Saya adalah …"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60},
  "hostlinku": {
    "cost": 0.000123,
    "currency": "🪙",
    "serviceMode": "performance",
    "latencyMs": 812
  }
}
```

### Periksa hasil

Buka **Logs** untuk token, biaya, dan latensi request; **Billing** menampilkan saldo organisasi. Jika request gagal, periksa [kode error](/errors). API key dipakai pada `/v1/*`; endpoint akun Console memakai sesi login.

</Steps>
