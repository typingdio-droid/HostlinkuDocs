Hostlinku menyediakan satu katalog model terpusat. Setiap model punya **slug** unik yang dipakai
di parameter `model` pada [Chat Completions](/chat-completions), lengkap dengan ukuran
konteks, kapabilitas, dan harga per token.

## `GET /v1/models`

Mengembalikan semua model yang berstatus `available`, belum deprecated, dan tersedia untuk
**Service Mode API key** yang dipakai (Performance, Low-Cost, atau Dedicated), beserta harga <CreditIcon /> per 1M token
pada mode tersebut.

```http
GET https://api.hostlinku.com/v1/models
Authorization: Bearer sk-your-api-key
```

Contoh:

```bash
curl https://api.hostlinku.com/v1/models \
  -H "Authorization: Bearer sk-your-api-key"
```

Respons (contoh dipotong; nilai persis untuk akun kamu diambil dari endpoint ini):

```json
{
  "object": "list",
  "service_mode": "performance",
  "data": [
    {
      "id": "claude-haiku-4-5",
      "object": "model",
      "created": 1791380432,
      "owned_by": "hostlinku",
      "context_window": 200000,
      "capabilities": [
        "text",
        "tool-calling",
        "function-calling",
        "structured-outputs",
        "json-mode",
        "streaming",
        "code-generation",
        "long-context",
        "multilingual"
      ],
      "service_mode": "performance",
      "pricing": {
        "input": 0.84,
        "output": 4.2,
        "cache_read": 0.084,
        "cache_write": 1.05,
        "unit": "1M_tokens",
        "currency": "🪙"
      },
      "health": "operational"
    }
  ]
}
```

| Field | Arti |
|---|---|
| `service_mode` (level list & item) | Service Mode API key yang dipakai: `performance`, `low_cost`, atau `dedicated`. Daftar model berbeda per mode. |
| `id` | Slug model, nilai yang dipakai di field `model` pada `/v1/chat/completions`, `/v1/messages`, dan `/v1/responses`. |
| `created` | Waktu model ditambahkan ke katalog (Unix epoch, detik). |
| `owned_by` | Selalu `"hostlinku"` - penanda bahwa model dikelola oleh katalog Hostlinku. |
| `context_window` | Ukuran konteks maksimum dalam token (input + output). |
| `capabilities` | Daftar kapabilitas, mis. `vision`, `tool-calling`, `json-mode`, `reasoning`, `long-context`. |
| `pricing` | Objek harga pada Service Mode tersebut; `null` bila model belum punya harga di mode itu. `pricing.unit` selalu `"1M_tokens"` dan `pricing.currency` berisi simbol kredit (1 <CreditIcon /> = \$1). |
| `pricing.input` / `pricing.output` | Harga per **1M token** (bukan per 1 token atau per 1K) untuk token prompt / token jawaban. |
| `pricing.cache_read` / `pricing.cache_write` | Harga per 1M token untuk cache read / cache write 5 menit. Tarif yang tidak tersedia dapat tidak dicantumkan; lihat [Prompt Caching](/prompt-caching). |

<Callout type="note" title="Pricing adalah harga pelanggan">
`pricing` adalah harga pelanggan untuk Service Mode key, termasuk margin. Pada respons non-streaming, biaya tersedia di `hostlinku.cost`; penggunaan dan biaya juga dapat dilihat di log Console.
</Callout>

## Katalog publik (tanpa autentikasi)

Tanpa API key, gunakan endpoint berikut untuk membandingkan model dan Service Mode:

```http
GET https://api.hostlinku.com/api/public/models-v2
GET https://api.hostlinku.com/api/public/service-modes
```

`models-v2` mengembalikan `{status, currency, models}`. Setiap model memuat `slug`, `displayName`, `contextTokens`, `maxOutputTokens` bila tersedia, `capabilities`, `serviceModes`, serta harga per mode pada `modes`. `service-modes` mengembalikan `{status, data}` berisi ringkasan mode dan modelnya.

Untuk daftar dan harga yang berlaku pada API key tertentu, gunakan `GET /v1/models`.

## Cara memilih model

1. **Tentukan kebutuhan**: chat biasa, penalaran (_reasoning_), vision/multimodal, tool calling,
   atau output JSON terstruktur. Cek field `capabilities`.
2. **Perhatikan ukuran konteks**: pastikan `context_window` cukup untuk prompt + output kamu.
3. **Bandingkan harga**: `pricing.input` untuk token prompt dan `pricing.output` untuk token
   jawaban; model reasoning umumnya lebih mahal di output.
4. **Mulai dari model kecil**: untuk pengembangan, model kelas ringan (mis. `gpt-6-luna`,
   `deepseek-v4-1-flash`, `qwen3-6-plus`) jauh lebih murah; naikkan kelas model hanya bila
   kualitas kurang.
5. **Lihat konsol**: menu **Model** di [console.hostlinku.com](https://console.hostlinku.com)
   menampilkan katalog dengan harga dan kapabilitas yang sama, plus halaman detail per model.

<Callout type="tip" title="ID model">
Salin slug persis dari `GET /v1/models` ke field `model`. Slug yang tidak dikenal dapat menghasilkan `MODEL_NOT_FOUND`; model yang tidak tersedia pada key dapat menghasilkan `MODEL_NOT_IN_SERVICE_MODE` atau `MODEL_UNAVAILABLE`.
</Callout>

## Routing dan failover

Gateway memilih jalur layanan sesuai model dan Service Mode key. Retry atau failover bergantung pada jalur yang tersedia dan jenis kegagalan; tidak semua model memiliki jalur cadangan. ID model pada request tetap sama.
