## 账户与API密钥

### 如何开始？

[注册](https://api.hostlinku.com/api/auth2/register) 或 [登录](https://api.hostlinku.com/api/auth2/login)，打开 [Console](https://console.hostlinku.com)。在 **Billing** 充值，在 **API Keys** 创建密钥。参阅 [快速开始](/zh/getting-started)。

### 密钥有哪些设置？

名称、Service Mode **Performance / Low-Cost / Dedicated**、有效期 **30/60/90天或永不过期**、可选每月限额。默认Performance和30天，没有作用域选择。密钥管理API的其他周期请参阅 [身份验证](/zh/authentication)。

### 密钥如何保存？

只显示一次，服务器保存SHA-256哈希。请保管在服务器环境变量中。可编辑、停用/启用、删除；丢失或泄露后更换。

### 有通行密钥和2FA吗？

有。**Settings → Security** 提供Keycloak的WebAuthn通行密钥、TOTP验证器和恢复码。

## 余额与付款

### 信用额度是什么？

服务单位为 **1信用额度 = $1**。关联密钥共享组织余额，它不是自由消费的法币。退款遵循 [退款政策](/zh/legals/refund-policy)。

### 如何充值？

在 **Billing** 选择金额和方式。新QRIS/VA使用 **iPaymu Direct**，加密货币使用 **Heleket托管付款**。付款前显示金额、奖励、汇率、费用、期限，验证后自动到账。参阅 [计费与余额](/zh/billing)。

### 费用和发票在哪里？

**Logs** 展示请求费用，**Analytics** 展示用量汇总，**Billing** 展示交易和发票。非流式chat有 `hostlinku.cost`，SSE在结束后检查费用。usage缺失时可能估算。

浏览器可打印/保存PDF。Billing Profile保存在Console浏览器，因此Console打印件可能与Pay发票或其他设备不同。

### 有自动充值或低余额邮件吗？

当前Billing没有这些设置。请在生产使用前监控并充值。增加余额不会提高密钥限额。

## 错误与隐私

### 如何处理429和402？

服务配额为 **每分钟 600 次请求、6,500,000 输入 token 和 200,000 输出 token**，由同一组织共享。达到配额时，该组织所有 API 密钥和成员都会受到影响。 配额及 429 处理见[用量与限额](/zh/usage-and-limits)。

### 所有失败请求都免费吗？

无可计费用量的失败会释放预留。中断流或部分使用请查看Logs中的最终费用。

### 提示词和回答会保存吗？

Body logging **默认关闭**，但费用、Token、状态、延迟元数据仍记录。管理员开启后限制正文大小、遮蔽凭据字段，默认保留14天。提示词文本中的秘密不自动遮蔽。参阅 [隐私政策](/zh/legals/privacy-policy)。
