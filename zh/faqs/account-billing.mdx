## 账户与 API 密钥

### 如何开始使用Hostlinku？

在 [console.hostlinku.com](https://console.hostlinku.com) 免费注册，确认邮箱，然后在 **充值** 菜单中充值。 在**API密钥**菜单中创建**API密钥**，然后将SDK的`base_url`设置为`https://api.hostlinku.com/v1`。完整指南请参阅[入门指南](/zh/getting-started)。

### 如何创建和管理API密钥？

打开控制台 → **API密钥** → **创建API密钥**，输入名称并选择所需的范围。密钥仅在创建时显示一次；请将其保存在安全的地方。你可以为不同的应用程序创建多个密钥，并随时撤销它们。被撤销的密钥将立即被拒绝（401）。

### API密钥有哪些可用范围？

作用域取决于你账户中已启用的端点。当前，公共网关优先处理 `chat`（`POST /v1/chat/completions`）和模型列表（`GET /v1/models`）。请根据应用程序的需求，尽可能精简作用域。 详情请参阅 [身份验证](/zh/authentication)。

### 账户会被暂停吗？

可以。违反[使用政策](/zh/legals/acceptable-use-policy)或[条款与条件](/zh/legals/terms-of-service)的账户可能会被暂停；所有API密钥将停止生效。详细信息请参阅[条款与条件](/zh/legals/terms-of-service)。

## 余额与计费

### 什么是积分余额，它是如何运作的？

积分余额是用于支付 API 使用费的预付金额，以 **美元** 为单位（1 美元 = 1 积分）。无月费；费用将根据实际使用的Token数量按每次请求扣除。详情请参见 [计费与余额](/zh/billing)。

### 如何充值？

打开控制台 → **添加余额** / **充值**。充值页面会显示可用的支付方式（目前支持QRIS/虚拟账户和加密货币）。最低、最高金额及汇率以结算页面为准。支付验证通过后，余额将到账。

### 何时从余额中扣除：按需求扣除还是按日扣除？

按请求处理。请求执行期间，系统会暂时预留余额；请求完成后，实际扣除的将是Token费用。如果请求失败（超时、5xx 错误或上游错误），预留的金额将被释放，且不会向您收费。

### 在哪里可以查看使用情况和账单记录？

“控制台” → **使用情况** 显示Token和费用的摘要；**请求日志** 显示每个请求的详细信息（状态、延迟、Token）；**交易** 显示余额变动：充值、使用和调整。

### 余额有有效期吗？会产生休眠费用吗？

不会。余额不会过期，也不会产生休眠费用。此外，根据[退款政策](/zh/legals/refund-policy)，余额不可转让，也不可兑换现金。

### 大额充值有奖励吗？

是的。购买特定的预设充值套餐可获赠积分；套餐及赠费详情请参见充值页面。如需大额充值，请联系 [halo@hostlinku.com](mailto:halo@hostlinku.com)。

### 有免费套餐或试用版吗？

注册免费且无月费，但不提供免费试用额度。新账户余额从0美元开始；充值后仅按实际使用量付费。注册无需信用卡。

## 错误与性能

### 我的请求超时或返回5xx错误。我还会被收费吗？

不会。未成功处理的请求（超时、5xx 错误或上游故障）不会产生费用；预留的余额将自动释放。每个请求的状态详情可在 **请求日志** 中查看。另请参阅 [错误](/zh/errors)。

### 响应速度似乎很慢。该如何诊断？

打开**请求日志**，查看每个请求的响应时间，包括流式传输的“等待首个Token时间”（TTFT）。如果只有部分请求较慢，很可能是服务商当时的状况所致；请重试，或选择其他具有类似特性的模型。

## 隐私、安全与法律

### 我的API密钥是如何得到保护的？

Secret 在生成时仅显示一次；系统仅保存其前缀。密钥会在每次请求时进行验证，并可随时撤销。请勿将 API 密钥保存在浏览器或公开的代码中；请通过您的服务器调用 API。

### 我的数据是在哪里处理和存储的？

运营元数据（模型、Token数量、状态、延迟、费用）将用于计费和监控。提示词及响应内容均不会被保存。详情请参阅[隐私政策](/zh/legals/privacy-policy)。

### 如果我需要法律信息或我的个人数据，该怎么办？

如需查询个人数据，请访问 [支持](/zh/support) 或发送邮件至 [halo@hostlinku.com](mailto:halo@hostlinku.com)；如涉及法律事务，请使用 [legal@hostlinku.com](mailto:legal@hostlinku.com)。

### 我在哪里可以查阅 API 文档？

完整的文档可在 [docs.hostlinku.com](https://docs.hostlinku.com) 上查看，其中包括 [Chat Completions](/zh/chat-completions)、[模型](/zh/models) 和 [错误](/zh/errors)。
