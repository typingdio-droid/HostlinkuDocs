## 账户和 API 密钥

<a id="bagaimana-mulai"></a>

### 如何开始？

[注册](https://api.hostlinku.com/api/auth2/register) 或 [登录](https://api.hostlinku.com/api/auth2/login)，然后打开 [Console](https://console.hostlinku.com)。 在**Billing**中充值，并在**API Keys**中创建密钥。请按照[快速入门](/zh/getting-started)操作。

<a id="apa-pengaturan-key-yang-tersedia"></a>

<a id="密钥有哪些设置"></a>

### 有哪些可用的密钥设置？

选择名称、服务模式 **Performance / Low-Cost / Dedicated**、过期时间 **30/60/90 天或永不过期**，以及可选的月度限额。默认值为 Performance 和 30 天。 无作用域。密钥管理 API 支持额外的时间段；请参阅 [身份验证](/zh/authentication)。

<a id="bagaimana-secret-disimpan"></a>

<a id="密钥如何保存"></a>

### 密钥是如何存储的？

Secret 仅出现一次；服务器存储 SHA-256 哈希值。将其保存在服务器环境中。Key 可以编辑、禁用/启用以及删除。如果 Secret 丢失或泄露，请更换 Key。

<a id="apakah-passkey-dan-2fa-tersedia"></a>

<a id="有通行密钥和2fa吗"></a>

### 是否支持密钥和双因素认证（2FA）？

是的。**设置 → 安全** 通过 Keycloak 提供 WebAuthn 密钥、TOTP 验证器和恢复码。

## 余额和付款

<a id="apa-arti-kredit"></a>

<a id="信用额度是什么"></a>

### “信用”是什么意思？

**1 积分 = 1 美元**，作为预付费服务的计量单位。组织余额由相关密钥使用，并非可自由使用的法定货币。退款遵循 [退款政策](/zh/legals/refund-policy)。

<a id="bagaimana-top-up"></a>

### 如何充值？

打开**Billing**，选择金额和支付方式。新的QRIS/VA使用**iPaymu Direct**，加密货币使用**Heleket hosted**。金额、奖励、汇率、费用和截止日期会在支付前显示。验证通过后，款项将自动到账。 查看 [账单与余额](/zh/billing)。

<a id="di-mana-biaya-dan-invoice"></a>

### 费用和发票在哪里？

**日志**显示请求费用，**分析**显示使用情况摘要，**计费**显示交易和发票。非流式聊天包含 `hostlinku.cost`；对于 SSE，请在完成后查看最终费用。缺失的使用量可以进行估算。

发票可通过浏览器打印或导出为 PDF。计费配置文件保存在 Console 浏览器的本地，因此 Console 的打印件可能与 Pay 或其他设备的发票有所不同。

<a id="apakah-ada-auto-recharge-atau-email-saldo-rendah"></a>

<a id="有自动充值或低余额邮件吗"></a>

### 是否有自动充值或余额不足提醒邮件？

当前尚不支持活跃计费。在投入生产环境前请监控余额并充值。充值不会提高密钥限额。

<a id="错误与隐私"></a>

## 错误和隐私

<a id="apa-tindakan-untuk-429-atau-402"></a>

<a id="如何处理429和402"></a>

### 遇到 429 或 402 错误时应采取什么措施？

对于 429 状态码，请按照 `Retry-After` 设置的间隔等待并采用退避策略；参见 [使用与限制](/zh/usage-and-limits)。对于 402 状态码，请检查可用余额和密钥信用额度；参见 [计费与余额](/zh/billing)。

<a id="apakah-semua-request-gagal-bebas-biaya"></a>

<a id="所有失败请求都免费吗"></a>

### 所有请求失败是否均不收费？

若未产生可计费的使用量，则会释放预留资源。对于流中断或部分使用的情况，请在日志中查看最终费用。

<a id="apakah-prompt-dan-respons-disimpan"></a>

<a id="提示词和回答会保存吗"></a>

### 提示和响应是否会被保存？

请求正文日志记录**默认处于禁用状态**；费用元数据、令牌、状态和延迟仍会被记录。若由管理员启用，请求正文将受大小限制，凭据字段会被过滤，默认保留期为 14 天。提示文本中的机密信息不会被自动过滤。 请参阅 [隐私政策](/zh/legals/privacy-policy)。
