服务配额为 **每分钟 600 次请求、6,500,000 输入 token 和 200,000 输出 token**，由同一组织共享。达到配额时，该组织所有 API 密钥和成员都会受到影响。

配额及 429 处理见[用量与限额](/zh/usage-and-limits)。

## 建议的后退距离

1. 读取`Retry-After`；如果存在，则等待该值所对应的时间。
2. 如果没有，则从1秒开始，每次试验将时间翻倍（1、2、4、8秒），并加入抖动。
3. 限制尝试次数，例如5次。
4. 对于高负载情况，应让请求在应用程序端排队，而不是发送突发请求。
