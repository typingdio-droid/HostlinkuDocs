服务配额为**每分钟 600 次请求、6,500,000 个输入令牌和 200,000 个输出令牌**，在同一组织内共享。当配额用尽时，所有 API 密钥和组织成员都会受到影响。

配额详情及如何处理 429 错误请参见 [使用与限制](/zh/usage-and-limits)。

## 建议的回退策略

1. 读取 `Retry-After`；如果存在，则等待该值所指定的时间。
2. 如果不存在，则从 1 秒开始，每次尝试将时间翻倍（1、2、4、8 秒），并加入抖动。
3. 限制尝试次数，例如 5 次。
4. 对于高负载情况，应在应用程序端对请求进行排队，而非发送突发流量。
