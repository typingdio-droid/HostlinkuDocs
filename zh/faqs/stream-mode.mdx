流模式通过 SSE（`text/event-stream`）以单个令牌为单位发送响应。令牌可在模型开始响应时显示，无需等待整个响应完成；第一个令牌出现的时间取决于模型和提供商。通过 `"stream": true` 启用该模式。

<a id="ringkas-curl"></a>

<a id="简述curl"></a>

## 简写：curl

```bash
curl -N https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Hitung 1 sampai 5." }],
    "stream": true
  }'
```

`-N` 标志很重要：如果没有它，curl 会暂停输出，直到缓冲区已满或流结束。

分段格式：

```text
data: {"id":"cmpl_…","model":"gpt-5-5","choices":[{"index":0,"delta":{"content":"1"}}]}

data: [DONE]
```

<a id="python---sdk-openai"></a>

## Python - OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key="sk-your-api-key",
)

stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
```

## Python - requests

在请求中使用 `stream=True`，并调用 `iter_lines()`。收到 `data: [DONE]` 时停止。

```python
import json
import requests

response = requests.post(
    "https://api.hostlinku.com/v1/chat/completions",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json",
    },
    json={
        "model": "gpt-5-5",
        "messages": [{"role": "user", "content": "Halo!"}],
        "stream": True,
    },
    stream=True,
)

for line in response.iter_lines():
    if not line:
        continue
    text = line.decode("utf-8")
    if not text.startswith("data: "):
        continue
    payload = text[6:]
    if payload == "[DONE]":
        break
    chunk = json.loads(payload)
    if "error" in chunk:
        raise RuntimeError(chunk["error"])
    delta = chunk["choices"][0].get("delta", {}).get("content")
    if delta:
        print(delta, end="", flush=True)
```

<a id="nodejs---sdk-openai"></a>

## Node.js - OpenAI SDK

```js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.hostlinku.com/v1",
  apiKey: process.env.HOSTLINKU_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "gpt-5-5",
  messages: [{ role: "user", content: "Halo!" }],
  stream: true,
});

for await (const chunk of stream) {
  const delta = chunk.choices[0]?.delta?.content;
  if (delta) process.stdout.write(delta);
}
```

<a id="备注-hostlinku"></a>

## Hostlinku 注释

- 在流式响应中仍需发送 `x-request-id` 标头。
- 如果流在中间失败，网关会发送事件 `data: {"error": {...}}`，而**不会**发送虚假的 `[DONE]`。
- 费用根据流结束后的实际使用量计算；如果无法获取实际使用量，则按预留量估算进行计费。
- 请勿在反向代理或 CDN 中缓存响应。请原样转发 `text/event-stream`。

<Callout type="tip" title="何时适合进行流媒体传输？">
  对于需要快速响应的聊天或客服应用，请使用 `stream: true`。对于不显示进度条的批处理/任务，非流式处理更为简单。
</Callout>
