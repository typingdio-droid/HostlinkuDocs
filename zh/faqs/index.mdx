## 什么是Hostlinku Playground？

Playground是[Console](https://console.hostlinku.com/playground)中用于试用可用模型并选择Service Mode的界面。它使用登录会话以及与API共享的组织余额，无需输入API密钥。

## 集成如何工作？

将SDK或应用连接到Hostlinku，使用API密钥并指定模型slug。OpenAI Chat Completions与Responses的base URL为`https://api.hostlinku.com/v1`，Anthropic Messages为`https://api.hostlinku.com`。功能取决于模型和协议。参见[集成指南](/zh/integrations/index)。

## 如何计费？

为组织余额充值，按模型和Service Mode的价格支付用量费用。输入、输出和缓存分别计价。QRIS/VA通过iPaymu Direct支付，加密货币通过Heleket支付。参见[计费与余额](/zh/billing)。

## 我的提示词会被保存吗？

请求和响应body默认不保存。token数、费用、状态和延迟元数据会被记录。若管理员开启body logging，body默认保留14天；提示词正文中的秘密不会自动被隐藏。参见[隐私政策](/zh/legals/privacy-policy)。

## 模型发生故障时会怎样？

网关可以按可用的路由配置尝试其他路径。若仍失败，应用会收到`503`等错误；请使用退避并查看[Status](https://status.hostlinku.com)。不保证自动切换到同系列的其他模型。

## Hostlinku可以免费试用吗？

注册免费，无需信用卡。不提供试用额度；在Playground或API发起付费请求前，请先充值。

## OpenAI的官方SDK可以使用吗？

可以，无需修改代码。将 `base_url`/`baseURL` 指向 `https://api.hostlinku.com/v1`，并将 API 密钥 `sk-…` Hostlinku 作为 `api_key` 使用。 完整示例请参见 [Chat Completions](/zh/chat-completions#contoh-python-sdk-resmi-openai)。

## 有哪些可用端点？

网关端点使用API密钥：

- `POST /v1/chat/completions`：[Chat Completions](/zh/chat-completions)。
- `POST /v1/messages`：[Anthropic Messages](/zh/anthropic-messages)。
- `POST /v1/messages/count_tokens`：Anthropic格式的token计数。
- `POST /v1/responses`：无状态的[Responses API](/zh/responses)。
- `GET /v1/models`：[密钥对应Service Mode的目录](/zh/models)。

网站目录使用`GET /api/public/models-v2`。Console账户端点`/api/*`使用登录会话。公开网关暂不提供embeddings。

## 我可以使用哪些模型？

请查看[模型目录](/zh/models)或Console中的**Models**。`GET /v1/models`返回当前API密钥对应Service Mode可用的模型与价格。

## 为什么我的请求被401拒绝了？

最常见的原因：`Authorization` 标头不存在或格式不正确（`Bearer`），API 密钥复制有误、已被撤销或已过期。 请在 [console.hostlinku.com](https://console.hostlinku.com) 上创建/检查 API 密钥。详细信息：[身份验证](/zh/authentication)。

## 明明我有余额，为什么会显示402？

请检查错误信息。402 错误有两种原因：**账户余额**不足（`available` 低于请求的预估费用），或者**API 密钥的额度**已用尽。 如果错误信息中提到“API密钥额度”，请等待重置周期（每日/每周/每月）结束，或在控制台中调整额度。详情请参阅 [计费与余额](/zh/billing)。

## 一个请求需要多少钱？

价格取决于模型、Service Mode以及输入、输出和缓存用量。非流式chat响应包含`hostlinku.cost`；流式费用可在结束后查看Logs/Billing，上游usage缺失时可能采用估算。参见[计费与余额](/zh/billing)。

## 是否有请求频率限制？

服务配额为 **每分钟 600 次请求、6,500,000 输入 token 和 200,000 输出 token**，由同一组织共享。达到配额时，该组织所有 API 密钥和成员都会受到影响。 配额及 429 处理见[用量与限额](/zh/usage-and-limits)。

## 如何发送图片/多媒体消息？

将`messages[].content`填充为OpenAI格式的内容数组 （例如：一个 `image_url` 类型的对象和一个 `text` 类型的对象），并在目录中选择具备 `vision`/`image-input` 功能的支持模型。具体支持程度取决于模型提供商。

## 如何停止使用已泄露的API密钥？

在Console → **API Keys**中禁用密钥，即可拒绝后续请求。创建替代密钥并更新应用，不再需要旧密钥时将其删除。用量历史仍会保留。

## 请求日志会保存我的对话内容吗？

token数、费用、状态和延迟元数据会被记录。body存储参见上方提示词存储说明与[隐私政策](/zh/legals/privacy-policy)。

## 如何理解延迟、TTFT和TPS？

延迟是网关收到请求到响应完成的时间。TTFT是观察到第一个流式token所需的时间。TPS是首个token之后生成阶段的每秒输出token数，使用符合条件的流式样本计算。参见[API Reference](/zh/api-reference#指标与示例数值)。

## 动画和模型图表是直接测量结果吗？

landing速度动画使用固定示例数值。模型详情中的60根柱由平均/P95延迟和失败次数汇总生成，柱的位置不代表最近60个请求的顺序。汇总数值和Console用量图表来自请求数据。比较性能前请查看时间范围和样本。

## 页脚绿色徽章显示实时状态吗？

landing页脚徽章目前使用固定状态值。监控结果和故障请查看[Status页面](https://status.hostlinku.com)。

## “reachable”是什么意思？

端点返回低于500的HTTP响应，包括`401`、`403`或`404`。它表示服务器可访问；登录或推理是否成功，需要检查相应功能的结果。

## 为什么历史费用明细可能不同？

已计费总额保存在交易日志中。analytics中的部分输入、输出和缓存明细按当前价格重新计算，因此可能与历史总额不同。这不会对旧请求再次计费。参见[计费与余额](/zh/billing)。

## probe数据保留多久？

原始健康probe记录默认保留30天，并定期清理。它与body的14天保留期以及用量/交易元数据分开处理。参见[用量与限额](/zh/usage-and-limits)。
