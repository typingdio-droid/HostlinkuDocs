<a id="什么是hostlinku-playground"></a>

## 什么是 Hostlinku Playground？

Playground 是 [Console](https://console.hostlinku.com/playground) 中的一个界面，用于试用可用模型并选择服务模式。Playground 使用与 API 相同的登录会话和组织余额；您无需输入 API 密钥。

<a id="bagaimana-cara-kerja-integrasinya"></a>

<a id="集成如何工作"></a>

## 该集成是如何工作的？

将 SDK 或应用程序指向 Hostlinku，使用 API 密钥，然后选择模型 slug。 OpenAI 的 Chat Completions 和 Responses 使用基础 URL `https://api.hostlinku.com/v1`；Anthropic Messages 使用 `https://api.hostlinku.com`。功能支持取决于模型和协议。请参阅 [集成](/zh/integrations/index)。

<a id="bagaimana-sistem-billing-nya"></a>

<a id="如何计费"></a>

## 计费系统是怎样的？

先充值组织余额，然后根据定价模型和服务模式支付使用费用。输入、输出和缓存各有相应的费率。可通过 iPaymu Direct 支付 QRIS/VA 费用，通过 Heleket 支付加密货币费用。请参阅 [计费与余额](/zh/billing)。

<a id="apakah-prompt-saya-disimpan"></a>

<a id="我的提示词会被保存吗"></a>

## 我的提示语会被保存吗？

请求正文和响应正文默认不会被保存。令牌元数据、费用、状态和延迟仍会被记录。如果管理员启用了正文日志记录，正文的默认保留期为 14 天；提示文本中的机密信息不会被自动过滤。请参阅 [隐私政策](/zh/legals/privacy-policy)。

<a id="apa-yang-terjadi-jika-sebuah-model-mengalami-gangguan"></a>

<a id="模型发生故障时会怎样"></a>

## 如果某个模型出现故障会怎样？

网关可根据可用的路由配置尝试其他路径。如果请求仍然失败，应用程序将收到诸如 `503` 之类的错误；请使用回退机制并检查 [状态](https://status.hostlinku.com)。无法保证会自动切换到同一产品系列中的其他模型。

<a id="apakah-hostlinku-gratis-dicoba"></a>

<a id="hostlinku可以免费试用吗"></a>

## Hostlinku 提供免费试用吗？

注册免费，无需信用卡。不提供试用额度；在 Playground 或 API 中执行付费请求前，请先充值。

<a id="apakah-sdk-resmi-openai-bisa-dipakai"></a>

<a id="openai的官方sdk可以使用吗"></a>

## 能否使用 OpenAI 的官方 SDK？

可以。将 `base_url`/`baseURL` 指向 `https://api.hostlinku.com/v1`，并
使用 Hostlinku 的 API 密钥 `sk-…` 作为 `api_key`。完整示例请参见
[聊天补全](/zh/chat-completions#contoh-python-sdk-resmi-openai)。

<a id="endpoint-apa-saja-yang-tersedia"></a>

## 有哪些可用端点？

网关端点接受 API 密钥：

- `POST /v1/chat/completions`：[聊天补全](/zh/chat-completions)。
- `POST /v1/messages`：[Anthropic Messages](/zh/anthropic-messages)。
- `POST /v1/messages/count_tokens`：计算 Anthropic 格式的令牌数量。
- `POST /v1/responses`：[Responses API](/zh/responses)，无状态。
- `GET /v1/models`：[按服务模式键分类的目录](/zh/models)。

网站目录使用 `GET /api/public/models-v2`。位于 `/api/*` 的 Console 账户端点使用登录会话。嵌入功能在公共网关上尚不可用。

<a id="model-apa-saja-yang-bisa-saya-pakai"></a>

## 我可以使用哪些模型？

请参阅 [模型目录](/zh/models) 或 Console 中的 **Models** 菜单。`GET /v1/models` 将显示您所用服务模式 API 密钥可用的模型及其价格。

<a id="kenapa-request-saya-ditolak-401"></a>

## 为什么我的请求被401拒绝了？

请检查 API 密钥和身份验证头。网关接受 `Authorization: Bearer sk-...` 或 `x-api-key`；密钥必须正确、有效且未过期。请参阅 [身份验证](/zh/authentication)。

<a id="kenapa-muncul-402-padahal-saya-punya-saldo"></a>

<a id="明明我有余额为什么会显示402"></a>

## 明明我有余额，为什么会出现 402 错误？

请检查错误信息。402 错误有两种原因：**组织余额**不足（`available` 少于
请求的预估费用），或者 **API 密钥信用额度**已用尽。 如果错误信息中提到“API 密钥
信用额度限制”，请等待重置周期（每日/每周/每月）结束，或在控制台中调整限制。
更多详情请参阅 [计费与余额](/zh/billing)。

<a id="berapa-biaya-satu-request"></a>

<a id="一个请求需要多少钱"></a>

## 一次请求的费用是多少？

价格取决于所使用的模型、服务模式以及令牌/缓存的维度。非流式聊天响应中包含 `hostlinku.cost`；流式传输的费用可在任务完成后在“日志/计费”中查看，若上游使用量不可用，可使用预估值。请参阅 [计费与余额](/zh/billing)。

<a id="apakah-ada-rate-limit"></a>

<a id="是否有请求频率限制"></a>

## 是否有速率限制？

每种服务模式的配额为**每分钟 600 次请求、6,500,000 个输入令牌和 200,000 个输出令牌**，在同一组织内共享。当配额用尽时，所有 API 密钥和组织成员都会受到影响。 配额详情及 429 错误的处理方法请参阅 [使用与限制](/zh/usage-and-limits)。

<a id="bagaimana-cara-mengirim-pesan-gambar--multimodal"></a>

<a id="如何发送图片多媒体消息"></a>

## 如何发送图片/多模态消息？

将 `messages[].content` 填充为 OpenAI 格式的内容数组（例如：一个 `image_url` 类型的对象
 followed by 一个 `text` 类型的对象），并在
目录中选择具备 `vision`/`image-input` 能力的模型。支持程度取决于模型提供商。

<a id="bagaimana-cara-menghentikan-pemakaian-api-key-yang-bocor"></a>

<a id="如何停止使用已泄露的api密钥"></a>

## 如何停止使用已泄露的 API 密钥？

在 Console → **API Keys** 中停用密钥，以便后续请求被拒绝。创建替代密钥，更新应用程序，然后在不再需要时删除旧密钥。使用历史记录仍会保留。

<a id="bagaimana-membaca-latensi-ttft-dan-tps"></a>

<a id="如何理解延迟ttft和tps"></a>

## 如何解读延迟、TTFT 和 TPS？

延迟是指网关收到请求到响应完成之间的时间。TTFT是指在流中观察到第一个令牌所需的时间。TPS是指在第一个令牌之后，从符合条件的流样本中，令牌生成阶段的令牌输出速率。 这三者含义不同；请参阅 [API 参考](/zh/api-reference#arti-metrik-dan-contoh-angka)。

<a id="apakah-animasi-dan-grafik-model-adalah-hasil-pengukuran-langsung"></a>

<a id="动画和模型图表是直接测量结果吗"></a>

## 动画和模型图表是直接测量的结果吗？

着陆速度动画使用固定的示例数值。 模型详情中的 60 根柱状图由平均延迟、P95 和故障次数的汇总数据构成；每根柱状图的位置并不代表最近 60 个请求的顺序。Console 的汇总数据和使用情况图表源自请求数据。在比较性能之前，请核对时间段和样本。

<a id="apakah-indikator-hijau-di-footer-menunjukkan-status-live"></a>

<a id="页脚绿色徽章显示实时状态吗"></a>

## 页脚处的绿色指示灯是否表示系统处于运行状态？

当前着陆页页脚徽章使用固定状态值。请访问 [状态页面](https://status.hostlinku.com) 以查看服务监控和事件信息。

<a id="apa-arti-status-reachable"></a>

<a id="reachable是什么意思"></a>

## “reachable”状态是什么意思？

端点返回的 HTTP 响应代码小于 500，包括 `401`、`403` 或 `404`。这表明服务器可访问；登录成功或相关推断需根据相关函数的检查结果来判断。

<a id="mengapa-rincian-biaya-historis-dapat-berbeda"></a>

<a id="为什么历史费用明细可能不同"></a>

## 为什么历史费用明细可能会有所不同？

已开具的总费用记录在交易日志中。分析中的部分输入/输出/缓存明细会根据当前费率重新计算，因此明细金额可能与历史总计存在差异。这不会对旧请求进行重复计费。请参阅 [计费与余额](/zh/billing)。

<a id="berapa-lama-data-probe-disimpan"></a>

<a id="probe数据保留多久"></a>

## 探针数据会保存多长时间？

健康检查的原始数据默认保存 30 天，之后会定期清理。请求内容有独立的 14 天保留期。使用和交易元数据将持续保存。请参阅 [使用情况与限制](/zh/usage-and-limits)。
