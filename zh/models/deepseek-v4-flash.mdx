## 摘要

DeepSeek V4 Flash 是一款注重效率的 V4 变体，支持 1M 的上下文窗口，适用于日常聊天、摘要生成、代码生成、结构化处理以及高吞吐量的生产级调用。

| 属性 | 值 |
|---|---|
| 提供商 | DeepSeek |
| Slug | `deepseek-v4-flash` |
| 上下文 | 1,000,000 个Token |
| 最大输出 | 未发布 |
| 输入 | 文本 |
| 输出 | 文本 |
| 发布日期 | 2026-07-30 |

## 支持的端点

| 端点 | 格式 | 支持 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 可用 |
| `POST /v1/messages` | Anthropic Messages | 适配（桥接） |
| `POST /v1/responses` | OpenAI Responses | 适配（桥接） |

端点和模型的可用性遵循目录以及所使用的Service Mode API key。如果该模式下没有可用模型，则可能以`400 MODEL_NOT_IN_SERVICE_MODE`为由拒绝该请求。

## 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
