## 摘要

Kimi K3 是 Kimi 的旗舰模型，专为长距离编程和端到端知识工作而设计；它具备 100 万Token的上下文窗口，并提供领先的综合智能。该模型针对短上下文聊天应用进行了优化，而非编码代理。

| 属性 | 值 |
|---|---|
| 提供商 | Moonshot |
| Slug | `kimi-k3-hyper-chat` |
| 上下文 | 1,000,000 个Token |
| 最大输出 | 64,000 个Token |
| 输入 | 文本、图片 |
| 输出 | 文本 |
| 发布日期 | 2026-07-16 |
| 标签 | 旗舰、专用 |

## 支持的端点

| 端点 | 格式 | 支持 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 可用 |
| `POST /v1/messages` | Anthropic Messages | 适配（桥接） |
| `POST /v1/responses` | OpenAI Responses | 适配（桥接） |

端点和模型的可用性遵循目录以及所使用的Service Mode API key规范。如果该模式下没有可用模型，则可能以`400 MODEL_NOT_IN_SERVICE_MODE`为由拒绝该请求。

## 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3-hyper-chat",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
