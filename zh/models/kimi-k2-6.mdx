## 摘要

Kimi K2.6 是 Kimi 最新且最智能的机型，具备增强且更稳定的长距离编码能力，以及显著提升的执行指令和自我纠正能力；它同时支持“思考”模式和非思考模式，并可进行对话交互及执行代理任务。

## 支持的端点

| 端点 | 格式 | 支持 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 可用 |
| `POST /v1/messages` | Anthropic Messages | 适配（桥接） |
| `POST /v1/responses` | OpenAI Responses | 适配（桥接） |

端点和模型的可用性取决于所使用的目录及Service Mode API key。如果该模式下没有可用模型，则可能以`400 MODEL_NOT_IN_SERVICE_MODE`为由拒绝该请求。

## 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2-6",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
