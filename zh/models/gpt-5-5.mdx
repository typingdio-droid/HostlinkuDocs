## 摘要

GPT-5.5 是 OpenAI 专为复杂专业工作设计的旗舰模型，支持文本/图像输入、文本输出，拥有 1.05M 的上下文容量、128K 的最大输出量，并支持 Responses 工具。

| 属性 | 值 |
|---|---|
| 提供商 | OpenAI |
| Slug | `gpt-5-5` |
| 上下文 | 1,000,000 个Token |
| 最大输出 | 128,000 个Token |
| 输入 | 文本、图片 |
| 输出 | 文本 |
| 发布日期 | 2026-04-27 |
| 标签 | 生产 |

## 支持的端点

| 端点 | 格式 | 支持 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 可用 |
| `POST /v1/messages` | Anthropic Messages | 适配（桥接） |
| `POST /v1/responses` | OpenAI Responses | 原生 |

端点和模型的可用性取决于所使用的目录及Service Mode API key。如果该模式下没有可用模型，则可能以`400 MODEL_NOT_IN_SERVICE_MODE`为由拒绝该请求。

## 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
