## 摘要

GLM-5.3 是 Zhipu AI 针对复杂软件工程和长周期智能体任务推出的最新旗舰文本模型。与 GLM-5.2 相比，它在编码、终端操作和长期任务性能方面均有提升，且始终启用推理功能。

| 属性 | 值 |
|---|---|
| 提供商 | Zhipu |
| Slug | `glm-5-3` |
| 上下文 | 1,000,000 个Token |
| 最大输出 | 64,000 个Token |
| 输入 | 文本 |
| 输出 | 文本 |
| 发布日期 | 2026-08-17 |
| 标签 | 旗舰，推理 |

## 支持的端点

| 端点 | 格式 | 支持 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 可用 |
| `POST /v1/messages` | Anthropic Messages | 适配（桥接） |
| `POST /v1/responses` | OpenAI Responses | 适配（桥接） |

端点和模型的可用性遵循目录以及所使用的Service Mode API key规范。如果该模式下没有可用模型，则可能以`400 MODEL_NOT_IN_SERVICE_MODE`为由拒绝该请求。

## 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5-3",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
