## 摘要

GLM-5.1 是 Zhipu 的旗舰文本模型，具备 20 万词的上下文容量和 12.8 万词的最大输出长度，在长时规划、代理编码、工具使用、结构化输出、上下文缓存以及 MCP 方面得到了强化。

| 属性 | 值 |
|---|---|
| 提供商 | Zhipu |
| Slug | `glm-5-1` |
| 上下文 | 200,000 个Token |
| 最大输出 | 128,000 个Token |
| 输入 | 文本 |
| 输出 | 文本 |
| 发布日期 | 2026-06-14 |

## 支持的端点

| 端点 | 格式 | 支持 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 可用 |
| `POST /v1/messages` | Anthropic Messages | 适配（桥接） |
| `POST /v1/responses` | OpenAI Responses | 适配（桥接） |

端点和模型的可用性遵循目录以及所使用的Service Mode API key规范。如果该模式下没有可用模型，则可能以`400 MODEL_NOT_IN_SERVICE_MODE`为由拒绝该请求。

## 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5-1",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
