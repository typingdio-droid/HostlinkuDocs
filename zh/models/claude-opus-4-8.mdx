## 摘要

Claude Opus 4.8 是 Anthropic 的高性能 Opus 模型，专用于复杂推理和代理编码，支持文本/图像输入、文本输出，具有 1M 的上下文窗口，最大输出为 128K。

| 属性 | 值 |
|---|---|
| 提供商 | Anthropic |
| Slug | `claude-opus-4-8` |
| 上下文 | 1,000,000 个Token |
| 最大输出 | 128,000 个Token |
| 输入 | 文本、图片 |
| 输出 | 文本 |
| 发布日期 | 2026-05-28 |
| 标签 | 推理 |

## 支持的端点

| 端点 | 格式 | 支持 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | 可用 |
| `POST /v1/messages` | Anthropic Messages | 原生 |
| `POST /v1/responses` | OpenAI Responses | 适配（桥接） |

端点和模型的可用性取决于所使用的目录及Service Mode API key。如果该模式下没有可用模型，则可能以`400 MODEL_NOT_IN_SERVICE_MODE`为由拒绝该请求。

## 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
