## 摘要

DeepSeek-V4.1-Flash 是一种基于非对称因果编码器-解码器架构的多模态专家混合模型，具备原生视觉理解能力。 它支持 100 万Token的上下文窗口、最多 38.4 万个输出Token、思考模式和非思考模式、工具调用以及结构化 JSON 输出。可在 Hostlinku 专用通道上使用，该通道具有更高的吞吐量。

| 属性 | 值 |
|---|---|
| 提供商 | DeepSeek |
| Slug | `deepseek-v4-1-flash-hyper` |
| 上下文 | 1,000,000 个Token |
| 最大输出 | 384,000 个Token |
| 输入 | 文本、图片 |
| 输出 | 文本 |
| 发布日期 | 2026-09-13 |
| 标签 | 快速、经济、专属 |
