## 1. 加密与机密存储

- 所有访问网站、控制台和API的流量均通过HTTPS（TLS）进行传输。
- Keycloak管理账户登录，不以明文保存密码。
- 客户的API密钥以SHA-256哈希值的形式存储。
- 集成凭据（如上游提供商的密钥和SSO密钥）在应用程序层级使用AES-256-GCM进行加密，所用的密钥与数据库分开存储。

<a id="autentikasi"></a>

## 2. 账户认证

- Keycloak管理邮箱验证和账户登录。
- 如果启用了通过SSO（例如Google、GitHub、Discord）登录的选项。
- Console服务器会话使用 `hl_sid`；部分流程的JWT Cookie为 `hl_session`。会话Cookie使用 `HttpOnly`、`SameSite=Lax`，生产环境设置 `Secure`。
- 组织共享配额和按IP的请求限制见[用量与限额](/zh/usage-and-limits)。
- 被暂停的账户无法登录，也无法使用API。

Console → **Settings → Security** 提供Keycloak的WebAuthn通行密钥、TOTP验证器和恢复码。

<a id="api-key"></a>

## 3. API密钥的管理

- 密钥在生成时会完整显示一次，此后无法再次查看。
- 密钥具有Service Mode、有效期、额度上限，可在Console停用。当前表单没有端点作用域选择。
- 开启Body logging时，保存前遮蔽凭据字段；提示词文本中的秘密不自动遮蔽。
- 上游提供商的身份信息和凭据绝不会发送给客户。

<a id="akses"></a>

## 4. 隔离与访问控制

- 根据获授权用户、组织和角色检查请求、日志、余额和API密钥访问。
- 管理员功能仅限于管理员角色，且任何敏感设置的更改（包括启用正文日志记录和调整余额）都会记录在审计日志中。
- 请求和响应的内容默认不会被保存；如果启用了正文日志记录，内容将根据保留期限自动删除。请参阅[隐私政策](/zh/legals/privacy-policy)。

<a id="perlindungan"></a>

## 5. 服务保障

- 公共流量会经过Cloudflare，以缓解机器人攻击和流量型攻击。
- 组织共享配额和按IP的请求限制见[用量与限额](/zh/usage-and-limits)。
- 在请求转发前预留余额，可防止使用量过度超出可用余额。
- 模型和上游的健康监测结果已发布在[状态](https://status.hostlinku.com)页面上。

<a id="audit"></a>

## 6. 审计日志

我们会记录登录、注销、注册、API密钥的创建和撤销以及设置更改等安全事件，并记录相关的时间、IP地址和用户代理信息。机密信息绝不会被记录下来。

<a id="tanggung-jawab"></a>

## 7. 共同责任

<Callout type="note">

账户安全也取决于你：

- 使用强密码且密码要独特；
- 将 API 密钥保存在服务器端，不要保存在前端代码或代码库中；
- 为每个应用程序或环境使用独立的密钥，设置信用额度，并撤销未使用的密钥；
- 在控制台中监控日志和交易记录，以检测异常使用情况。

</Callout>

<a id="insiden"></a>

## 8. 事件响应

当发生安全事件时，我们会进行识别、遏制、恢复和评估。如果事件导致个人数据保护出现漏洞，我们将根据《个人数据保护法》的规定，通知受影响的用户和相关主管部门。如果我们检测到API密钥泄露，我们会停用该密钥，并通知其所有者。

<a id="laporan"></a>

## 9. 报告漏洞

请将报告发送至 [halo@hostlinku.com](mailto:halo@hostlinku.com)，其中应包含问题描述、重现步骤以及您发现的影响。我们将在5个工作日内确认收到。

为确保测试安全：

- 请仅使用您自己的账户和数据进行测试；
- 请勿访问、修改或删除其他用户的数据；
- 请勿对工作人员或用户实施拒绝服务攻击、发送垃圾信息或进行社会工程学攻击；
- 在公布调查结果之前，请给予我们合理的时间进行整改。

对于本着善意并遵循本指南进行举报的研究人员，我们不会对其采取法律行动。
