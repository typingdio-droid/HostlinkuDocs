## 1. 范围

本政策适用于所有账户、API密钥以及向Hostlinku发出的请求，包括您的应用程序代表最终用户发出的请求。 本政策是[服务条款](/zh/legals/terms-of-service)的一部分。您需对通过您的账户进行的使用行为负责，包括您应用程序的最终用户所进行的使用。

<a id="2-penggunaan-yang-diizinkan"></a>

## 2. 允许的使用方式

- 对话应用、助手、摘要、翻译和文本生成；
- 搜索、推荐和分类应根据模型能力进行处理；嵌入式端点在公共网关上尚不可用；
- 代码生成、代理和工作流自动化；
- 研究、评估、实验和原型；
- 基于 API 构建的商业产品，只要符合本政策即可。

<a id="dilarang"></a>

<a id="3-konten-dan-aktivitas-terlarang"></a>

## 3. 禁止的内容和活动

- **儿童色情**：以任何形式涉及儿童的色情或剥削性内容。违规行为将上报给相关主管部门。
- **暴力与武器**：煽动暴力、恐怖主义，或制造武器、爆炸物以及化学、生物、放射性或核武器的说明。
- **欺诈与社会工程学**：网络钓鱼、诈骗、虚假投资、伪造文件或利用深度伪造技术进行欺骗。
- **恶意软件和入侵**：制作恶意软件、勒索软件，或编写代码以入侵不属于你或未经所有者许可的系统。
- **垃圾信息和操纵行为**：未经许可的群发消息、机器人网络、虚假评论，或对指标及第三方平台的操纵。
- **隐私侵犯**：在缺乏法律依据的情况下处理个人数据，未经同意对个人进行监控或追踪，以及未经许可对个人进行生物特征识别。
- **歧视**：基于种族、宗教、性别、残疾或受法律保护的其他特征，对个人造成不利影响的自动决策。
- **侵犯版权**：大规模复制受版权保护的材料，或删除水印和所有权标记。
- **冒充**：未经许可，误导性地声称内容来自特定个人或组织的虚假内容。
- **其他违法行为**：违反《信息技术与电子交易法》（ITE）、《个人数据保护法》（PDP）或适用行业法规的活动。

<a id="4-技术限制"></a>

## 4. 技术禁令

- 避免使用“速率限制”、“验证码”、“验证”或“余额限制”等表述，包括涉及多个账户或 API 密钥轮换的情况；
- 未经书面许可，对端点进行洪水攻击、执行负载测试或进行漏洞扫描；
- 切勿试图揭露我们未公开的上游身份、系统提示或内部配置；
- 旨在绕过模型安全策略的越狱或提示符注入；
- 若上游模型提供商的条款禁止，则不得使用该输出结果来训练或提炼竞争对手的模型；
- 转售、分享或公开 API 密钥。

<a id="aplikasi"></a>

<a id="5-kewajiban-untuk-aplikasi-kamu"></a>

## 5. 针对您应用程序的义务

- 如果上下文中不明确，请告知最终用户他们正在与 AI 进行交互。
- 对于医疗、法律、金融和招聘等高风险领域，应实施充分的人工审核和监督。
- 请将 API 密钥保存在服务器端，并通过您自己的后端限制最终用户的访问权限。
- 为最终用户提供渠道，以便其报告有害的输出内容。

<a id="6-上游服务提供商的政策"></a>

## 6. 上游提供商政策

每个模型均由上游提供商运行，该提供商拥有自己的使用政策。除本政策外，您还必须遵守该政策。请求可能会被上游提供商拒绝或过滤，且若提供商提出要求，我们可能会限制对特定模型的访问。

<a id="rate-limit"></a>

<a id="7-rate-limit"></a>

## 7. 速率限制

每个服务模式都有组织共享的配额。Console、public、checkout 和身份验证后端端点也设有每 IP 的限制。具体数值和端点范围详见 [使用与限制](/zh/usage-and-limits)；Keycloak 中的登录保护遵循 realm 设置。

被限流器拒绝的请求将返回状态码 `429`，且不产生费用；如有提供，请查阅 `Retry-After` 字段。限额可能随容量变化而调整，并可针对特定账户提高；请联系 [halo@hostlinku.com](mailto:halo@hostlinku.com)。

## 8. 执行

<Callout title="注释" type="note">

根据违规程度，我们可能会：

- 拒绝或过滤特定请求；
- 发出警告并要求在规定时间内进行修正；
- 限制速率限制或访问模型；
- 撤销 API 密钥、暂停或关闭账户；
- 在法律要求或涉及人身安全时，应向主管部门报告。

因违规而被关闭的账户中的余额，其处理规定详见[退款政策](/zh/legals/refund-policy)。

</Callout>
