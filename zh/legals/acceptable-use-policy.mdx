## 1. 适用范围

本政策适用于所有账户、API密钥以及发往Hostlinku的请求，包括您的应用程序代表最终用户发出的请求。 本政策是[《条款与条件》](/zh/legals/terms-of-service)的一部分。您需对通过您的账户进行的使用行为负责，包括由您应用程序的最终用户所进行的使用。

<a id="diizinkan"></a>

## 2. 允许的使用方式

- 聊天应用、语音助手、摘要、翻译和文本生成；
- 用于搜索、推荐和分类的嵌入；
- 代码生成、代理和工作流自动化；
- 研究、评估、实验和原型；
- 基于API构建的商业产品，只要符合本政策即可。

<a id="dilarang"></a>

## 3. 禁止的内容和活动

- **儿童色情**：以任何形式涉及儿童的色情或剥削性内容。此类违规行为将上报给相关主管部门。
- **暴力与武器**：煽动暴力、恐怖主义，或提供制造武器、爆炸物以及化学、生物、放射性或核武器的指导。
- **诈骗与社会工程学**：网络钓鱼、诈骗、虚假投资、伪造文件或利用深度伪造技术实施欺诈。
- **恶意软件和入侵**：制作恶意软件、勒索软件，或编写代码以入侵不属于你或未经所有者许可的系统。
- **垃圾信息和操纵行为**：未经许可的群发消息、机器人网络、虚假评论，或对指标及第三方平台的操纵。
- **侵犯隐私**：在缺乏法律依据的情况下处理个人数据；未经同意对个人进行监控或追踪；以及未经许可对个人进行生物特征识别。
- **歧视**：基于种族、宗教、性别、残疾或受法律保护的其他特征，对个人造成不利影响的自动化决策。
- **侵犯版权**：大规模复制受版权保护的内容，或删除水印和所有权标记。
- **冒用身份**：未经许可，冒充特定个人或组织发布的误导性内容。
- **其他违法行为**：违反《信息与电子交易法》（ITE）、《个人数据保护法》（PDP）或相关行业法规的行为。

## 4. 技术限制

- 规避速率限制、验证码、身份验证或余额限制，包括使用多个账户或轮换API密钥；
- 未经书面许可，对终端进行洪水攻击、执行负载测试或进行漏洞扫描；
- 试图揭示我们未显示的上游身份、系统提示或内部配置；
- 旨在绕过模型安全策略的越狱或提示符注入；
- 在该模型的上游提供商条款禁止的情况下，利用该模型的输出结果来训练或蒸馏竞争对手的模型；
- 转售、分享或公开API密钥。

<a id="aplikasi"></a>

## 5. 针对您应用程序的义务

- 如果从上下文中无法明确判断，请告知最终用户他们正在与人工智能进行交互。
- 对于医疗、法律、金融和招聘等高风险领域，应实施适当的人工审核和监督。
- 将 API 密钥保存在服务器端，并通过您自己的后端限制最终用户的访问权限。
- 为最终用户提供报告有害输出的渠道。

<a id="upstream"></a>

## 6. 上游服务提供商的政策

每个模型均由上游提供商运行，这些提供商拥有各自的使用政策。除本政策外，您还必须遵守这些政策。请求可能会被上游提供商拒绝或过滤，且若提供商提出要求，我们可能会限制对特定模型的访问。

<a id="rate-limit"></a>

## 7. 速率限制

当前默认限制：

- 推理 API：每个 API 密钥每分钟 600 次请求；
- API 控制台和公共 API：每个 IP 地址每分钟 120 次请求；
- 身份验证端点（登录、注册、一次性密码）：每15分钟限30次尝试。

超出限额的请求将被拒绝，状态码为`429`，且不收取费用。 剩余配额将通过 `RateLimit-*` 标头发送。限额可能根据容量而变化，并可针对特定账户进行提高；请联系 [halo@hostlinku.com](mailto:halo@hostlinku.com)。

<a id="penegakan"></a>

## 8. 执法

<Callout type="note">

根据违规程度，我们可以：

- 拒绝或过滤特定请求；
- 发出警告，并要求在规定期限内进行整改；
- 限制速率限制或模型访问；
- 撤销 API 密钥、暂停或关闭账户；
- 在法律要求或涉及人身安全时，向主管部门报告。

因违规而被关闭的账户中的余额，其处理规定详见[退款政策](/zh/legals/refund-policy)。

</Callout>
