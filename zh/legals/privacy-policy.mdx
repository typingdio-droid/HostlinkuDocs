## 1. 数据范围与控制

本政策适用于 hostlinku.com 网站、控制台及 Hostlinku API。个人数据控制者为 Hostlinku；企业身份信息详见 [隐私联系信息](#kontak)。 本政策依据《2022年第27号个人数据保护法》（PDP法）制定，是[条款与条件](/zh/legals/terms-of-service)的一部分。

如果您使用 API 处理最终用户的个人数据，则您作为该数据的控制者，而我们（作为处理者）将根据您的指示，在运行服务所必需的范围内处理该数据。

## 2. 我们收集的数据

<a id="data-akun-dan-autentikasi"></a>

<a id="账户数据与身份验证"></a>

### 账户数据和身份验证

- 姓名、电子邮件地址、公司名称（可选）以及个人资料照片（如由 SSO 提供商提供）；
- 由 Keycloak 管理的身份验证数据，包括密码哈希值和密钥/身份验证器凭据（而非原始密码）；
- 通过 SSO（例如 Google、GitHub、Discord）登录时，来自 SSO 提供商的账户身份；
- 电子邮件验证状态、临时 OTP 码、账户角色和账户状态；
- 登录会话数据和安全审计记录，例如登录、注销、注册、设置更改、管理员调整余额以及 API 密钥活动，以及相关的 IP 地址和用户代理。

<a id="api-key"></a>

### API密钥

API密钥的值仅以SHA-256哈希形式存储，我们无法重新显示其原始值。我们存储密钥名称、用于标识的密钥前缀、服务模式、有效期、信用额度、最后使用时间以及撤销状态。

<a id="metadata-request"></a>

<a id="元数据请求"></a>

### 请求元数据

对于通过身份验证和余额检查的请求，我们记录如下：

- 请求时间、请求的模型以及使用的 API 密钥；
- 输入、输出和缓存的令牌数量，以及计费金额；
- 延迟、首次令牌获取时间、流式传输模式、完成原因、状态码和错误消息；
- 请求的源IP地址；
- 仅 Hostlinku 管理员可见的内部上游路由信息。

在该阶段之前被拒绝的请求（例如因身份验证失败、速率限制或余额不足），不会作为请求日志条目记录在控制台中，也不会产生费用。

<a id="saldo-dan-pembayaran"></a>

<a id="余额与付款"></a>

### 余额和付款

我们保存充值、使用、退款和余额调整的历史记录，包括金额、方式、状态和交易参考号。 支付由 iPaymu Direct（QRIS 和虚拟账户）以及 Heleket（托管加密货币）处理。我们既不接收也不存储您的完整卡号、CVV 或银行凭证。对于加密货币支付，可能会记录钱包地址和交易哈希值。

<a id="data-teknis-dan-komunikasi"></a>

<a id="技术与通信数据"></a>

### 技术数据与通信

- 记录在服务器日志和 Cloudflare 防护服务中的 IP 地址、浏览器类型、设备和引荐页面；
- 在联系客服、报告错误或申请退款时，请保留通信内容。

## 3. 请求内容和正文日志

请求内容（提示、消息、附件）和响应内容模型经过处理后，将转发给上游提供商并返回给您。默认情况下，这些内容**不会**存储在我们的数据库中；仅存储第2部分中的元数据。

Hostlinku 管理员可以为整个平台启用 **body logging**，用于调试和故障排查。当此功能处于启用状态时：

- 请求和响应的内容应与相关的请求日志一同保存；
- 包含凭据（如 `authorization`、`api_key`、`password`、`token`）以及上游标识的字段在保存前将被替换为 `[redacted]`。此过滤基于字段名称，因此您在提示文本中写入的机密信息不会被过滤；
- 超出大小限制的内容将不予保存；
- 该内容将在设定的保留期结束后自动删除（默认保留期为14天），而请求元数据将予以保留；
- 账户所有者可通过控制台查看内容，Hostlinku 的授权管理员也可查看。

<Callout title="注释" type="note">

我们不会使用您的请求或响应内容来训练模型。上游提供商会根据各自的隐私政策处理请求内容。请避免发送不必要的敏感个人数据。

</Callout>

## 4. 处理的目的和依据

- **运行服务**：身份验证、请求路由和响应发送（协议执行）。
- **计费**：余额预留和扣款、交易记录、充值和退款处理（协议履行和法律义务）。
- **安全性**：速率限制、滥用和欺诈检测、验证码、审计日志（合法利益）。
- **支持与通知**：账户验证、密码重置以及服务变更通知（协议执行）。
- **服务升级**：关于容量和质量的汇总使用统计数据（合法利益）。
- **法律合规**：响应合法机构的请求，并履行税务或会计义务。

我们不会出售您的个人数据。

## 5. 数据接收方

数据仅在必要范围内与以下对象共享：

- **上游提供商模型**：接收您发送的请求内容以生成响应。我们不会将您的电子邮件或账户身份信息转发给他们。
- **支付服务商**：iPaymu Direct 和 Heleket，用于处理充值和退款。
- **电子邮件服务提供商**：Brevo 或 Amazon SES，用于发送一次性密码（OTP）、通知和交易邮件。
- **SSO 身份提供商**：Google、GitHub、Discord 或您选择的其他登录提供商。
- **基础设施**：Cloudflare（网络、防护、Turnstile 和 R2 对象存储）以及服务器和数据库提供商。
- **授权**：当法律或合法命令要求时，或为了保护我们及其他用户的权利、安全和财产时。
- **业务继受人**：在业务合并、收购或转让的情况下，仍须遵守本政策。

## 6. 跨境传输

上述部分接收方（包括上游提供商和支付服务商）会在印度尼西亚境外处理数据。我们选择的提供商均实施了充分的数据保护措施，并按照《个人数据保护法》（UU PDP）的规定进行数据传输。使用本服务即表示您理解，请求内容将在上游提供商运营的地区进行处理。

## 7. 数据保留

- **账户数据和 API 密钥**：在账户有效期间予以保留，账户关闭后予以删除或匿名化处理，但法律要求必须保留的数据除外。
- **请求和响应内容**：当正文日志记录处于关闭状态时不会被保存；若处于开启状态，则会在保留期结束后自动删除（默认14天）。
- **请求元数据和交易记录**：在账户有效期间以及此后为计费、会计核算、税务、争议解决和防范欺诈所需的时间内予以保存。
- **安全审计日志**：在调查和取证所需期间予以保留。
- **验证码和会话**：根据身份验证流程自动过期或被撤销。

在数据从主系统中删除后，备份副本可在有限时间内保留，且仅用于恢复目的，不得用于其他用途。

## 8. 安全性

我们采取了合理的技术和组织措施，包括 HTTPS 连接、密码和 API 密钥的哈希处理、`HttpOnly` 会话 Cookie、速率限制、公共表单中的验证码、管理员访问限制以及审计日志。 更多详情请参见 [安全](/zh/legals/security) 页面。没有任何系统是完全安全的；若发生个人数据保护失败的情况，我们将根据《个人数据保护法》的规定通知您及相关主管部门。

## 9. 您的权利

根据《个人数据保护法》（PDP），您有权：

- 获取有关您个人数据处理的信息；
- 访问并获取您的个人数据副本；
- 修正不准确的数据，部分内容可直接在控制台个人资料页面中进行；
- 请求删除数据并关闭账户；
- 撤回同意或对特定处理提出异议；
- 限制或延迟处理；
- 向负责个人数据保护的主管部门提出投诉。

请通过注册邮箱向 [privacy@hostlinku.com](mailto:privacy@hostlinku.com) 提交请求。我们可能会要求您进行身份验证，并将在法规规定的时限内予以回复。若法律有要求，我们可能会保留部分数据，例如交易记录。 在申请注销账户前，请先申请退还剩余余额。

## 10. Cookie 和本地存储

- `hl_sid`：用于 Console 身份验证的服务器会话；`hl_session`：部分流程中使用的 JWT Cookie。会话 Cookie 具有有效期，且可能被撤销；
- SSO cookie状态：有效期较短，用于保障通过身份提供商进行的登录流程的安全性；
- 显示偏好设置cookie，例如控制台侧边栏的状态；
- Cloudflare 和 Turnstile 的 Cookie，用于防范机器人和攻击；
- 浏览器本地存储用于保存 Playground 历史记录、配置文件快照、偏好设置和计费配置文件。计费配置文件会影响 Console 的显示内容，且尚未与服务器或其他设备的发票同步。

我们不设置第三方广告或分析cookie。在浏览器中禁用cookie可能会导致登录和控制台无法正常工作。
