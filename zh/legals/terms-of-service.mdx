## 3. API密钥与访问安全

API密钥是用于验证API请求的凭证，也是计费的基础。任何包含您账户API密钥的请求均被视为您发起的请求；根据第7节的规定，仅对已处理的请求收取费用。

- API密钥在创建时会完整显示**一次**。我们仅保存其哈希值，因此丢失的密钥无法恢复；请创建新密钥并撤销旧密钥。
- 您可以通过[API密钥页面](https://console.hostlinku.com/api-keys)根据作用域（例如 `chat`、`embeddings`、`completions`）、有效期以及每个密钥的信用额度来限制密钥。 这些限制是用于控制成本的辅助工具，并不保证在流式传输或并行请求的情况下，使用量不会超过特定数值。
- 请将 API 密钥保存在服务器端。切勿将其放在前端代码、移动应用、公共代码库或他人可访问的日志中。
- 如果您怀疑 API 密钥泄露或账户遭到未经授权的访问，请立即撤销该密钥并联系 [halo@hostlinku.com](mailto:halo@hostlinku.com)。在密钥撤销之前产生的费用仍由您承担，除非能证明泄露是由于我们的疏忽造成的。
- 为了保护您的余额，我们可能会停用疑似泄露的密钥（例如在公共代码库中被发现的密钥）。

## 6. 预付余额

该服务采用基于美元（USD）预付余额的**按需付费**模式。无需订阅，也不会产生定期账单。新账户初始余额为零。

- 可通过[充值](https://console.hostlinku.com/add-balance)使用现有方式为账户充值，目前支持QRIS、虚拟账户（通过iPaymu）以及加密货币（通过BlockBee）。可用支付方式、最低充值金额和最高充值金额会在充值页面显示，且可能会有所变动。
- 以印尼盾或加密货币进行的支付将按结账时显示的汇率转换为美元。已入账的余额不会因汇率波动而发生变化。
- 余额是用于购买服务的预付金额。余额不属于存款，也不是支付工具，不计息，且不得转入其他账户或兑换为现金，但[退款政策](/zh/legals/refund-policy)中另有规定的情况除外。

- 当可用余额低于账户低余额阈值（默认值为25美元）时，我们会发送提醒邮件。此提醒仅供参考，可能会有延迟或无法送达的情况；监控余额仍是您的责任。

## 7. 价格与计费

费用按**每次请求**计算，依据的是请求处理时[模型](/zh/models)和[价格](https://hostlinku.com/pricing)页面上所列的模型价格，通常按每百万个输入和输出令牌计费（如适用，包括缓存令牌）。

1. **预留。** 在将请求转发至上游之前，我们会从可用余额中预留（预估）最大费用。如果可用余额不足，请求将被拒绝，返回状态码为 HTTP `402`，且不会产生费用。
2. **结算。** 请求完成后，系统将根据上游报告的Token数量，从余额中扣除实际费用，并将剩余的预留额度释放回可用余额。
3. **释放。** 如果请求在生成可计费输出之前失败，则该预留将免费释放。因系统故障而被挂起的预留将由定期处理程序自动释放。

客户在流媒体播放过程中取消的请求，仍将根据上游已处理的Token数量进行计费。在某些情况下，实际费用可能超过预留金额，导致余额变为负值；该差额由您承担，并将从下次充值中扣除。

价格变更仅适用于变更公布后处理的请求，且不具有追溯效力。交易记录和每项请求的费用可在控制台中查看。价格不包含相关主管部门或支付服务商可能征收的税费；除非在结账时另有说明，否则该税费由您承担。

## 8. 速率限制与服务限制

为确保系统稳定性，我们针对每个API密钥和每个IP地址实施了请求速率限制。当前的限制值将通过每个响应中的`RateLimit-*`标头发送，超过限制的请求将被拒绝，并返回状态码`429`，且不收取任何费用。 默认限额可能会根据系统容量随时调整，并可根据请求为特定账户提高限额。

我们还可以限制请求大小、输出长度、并行请求数量或对特定模型的访问，并过滤或拦截那些疑似违反《使用政策》或上游政策的请求。
