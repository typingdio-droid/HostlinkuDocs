## 3. API密钥与访问安全

API密钥是用于验证API请求的凭据，也是计费的基础。任何携带您账户API密钥的请求均被视为您发起的请求；根据第7节规定，仅对已处理的请求收取费用。

- API密钥在创建时会完整显示**一次**。我们仅存储其哈希值，因此丢失的密钥无法恢复；请创建新密钥并撤销旧密钥。
- 通过 [API 密钥](https://console.hostlinku.com/api-keys) 设置 **服务模式**、有效期和信用额度。信用额度有助于控制费用；请参阅 [身份验证](/zh/authentication)。
- 请将 API 密钥保存在服务器端。切勿将其放置在前端代码、移动应用、公共代码库或他人可访问的日志中。
- 如果您怀疑 API 密钥泄露或账户遭到未经授权的访问，请立即撤销该密钥并联系 [halo@hostlinku.com](mailto:halo@hostlinku.com)。 在密钥被撤销之前产生的费用仍由您承担，除非能证明泄露是由于我们的疏忽造成的。
- 为了保护您的余额，我们可能会停用疑似泄露的密钥（例如在公共代码库中被发现的密钥）。

## 6. 预付余额

该服务采用基于美元（USD）预付余额的**按量付费**模式。无订阅，无定期账单。新账户初始余额为零。

- 可通过 [充值](https://console.hostlinku.com/billing) 使用可用方式为账户充值，目前支持 QRIS 和虚拟账户（通过 iPaymu）以及加密货币（通过 Heleket）。 可用支付方式、最低充值金额和最高充值金额显示在充值页面上，并可能随时变更。
- 以印尼盾或加密货币进行的支付将按结账时显示的汇率转换为美元。已入账的余额不会因汇率波动而变化。
- 余额是用于购买服务的预付金额。余额不属于存款，不是支付工具，不计息，且不得转入其他账户或兑换为现金，除非[退款政策](/zh/legals/refund-policy)中另有规定。
- 充值奖励、促销积分或补偿积分不具有现金价值，不可退还，且其有效期或使用范围可能受各自促销条款的限制。
- 通过 Console 监控余额。自动充值和余额不足邮件提醒功能在当前的计费流程中尚不可用。

## 7. 价格与计费

费用按**每次请求**计算，依据请求处理时[模型](/zh/models)和[定价](https://hostlinku.com/pricing)页面上列出的模型价格，通常按每百万个输入和输出令牌计费（包括适用的缓存令牌）。

1. **预留。**在请求转发至上游之前，我们会从可用余额中预留（保留）预计的最高费用。如果可用余额不足，请求将被拒绝并返回 HTTP 状态码 `402`，且不会产生费用。
2. **结算。**请求完成后，系统将根据上游报告的令牌数量，从余额中扣除实际费用，并将剩余预留额释放回可用余额。
3. **释放。** 如果请求在生成可计费输出之前失败，则预留资源将被无偿释放。因系统故障而被挂起的预留资源将由定期处理流程自动释放。

客户端在流式传输过程中取消的请求，仍将根据上游已处理的令牌进行计费。在某些情况下，实际费用可能超过预留额度，导致余额变为负值；该差额由您承担，并将从下次充值中扣除。

价格变更适用于变更发布后处理的请求，不具有追溯效力。交易记录和每条请求的费用可在控制台中查看。价格不包含相关机构或支付服务商可能征收的税费；除非在结账时另有说明，否则这些税费由您承担。
