本页面将引导你从零开始，成功通过 Hostlinku 发送一条聊天补全请求。

## 先决条件

- **Hostlinku 账户**：从 [后端注册](https://api.hostlinku.com/api/auth2/register) 开始，浏览器会跳转至Keycloak。
- **余额**：网关会按每个Token扣除余额。在提交生产请求前，请在控制台中充值。测试请求的费用通常低于一分钱，但余额仍不得为零。请参阅 [计费与余额](/zh/billing)。
- **测试工具**：仅需 curl 即可。对于高级示例，可直接使用官方 SDK OpenAI（`pip install openai`）或 Node（`npm install openai`），无需修改代码。

## 步骤

<Steps>

### 注册或登录

打开 [注册](https://api.hostlinku.com/api/auth2/register) 或 [登录](https://api.hostlinku.com/api/auth2/login)。后端启动 `auth2.hostlinku.com` 的Keycloak流程，处理回调后打开Console。通行密钥和SSO选项取决于账户、设备及可用提供商。

### 创建 API 密钥

进入 [console.hostlinku.com](https://console.hostlinku.com) → **API 密钥** 菜单 → **创建 API 密钥**。在创建 API 密钥的对话框中，您可以设置：

- **名称**：用于识别，例如 `your-production-app`。
- **Service Mode**：选择 **Performance**（默认）、**Low-Cost** 或 **Dedicated**。模式决定模型和价格。
- **有效期**：30天（默认）、60天、90天或永不过期。
- **Monthly Spending Limit**：可选的每月支出限额。Console表单没有作用域或每日/每周重置选项；API合约请参阅 [身份验证](/zh/authentication)。

<Callout type="warning" title="密钥只显示过一次">
API密钥创建后，格式为`sk-…`的密钥密文**仅在控制台中显示一次**。请将其复制并保存在安全的地方：服务器会将其以SHA-256哈希值的形式存储，且无法再次显示。如果密钥密文丢失，请撤销该API密钥，然后创建一个新的。
</Callout>

### 发送第一个请求

所有网关端点均位于 `https://api.hostlinku.com`，采用 `Authorization: Bearer sk-…` 进行身份验证。非流式请求示例：

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [
      { "role": "user", "content": "Halo! Perkenalkan dirimu singkat saja." }
    ]
  }'
```

如果一切正常，你将收到类似 OpenAI 格式的 JSON 响应，以及包含请求费用和延迟的 `hostlinku` 数据块：

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "你好! 我是 …" },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60 },
  "hostlinku": {
    "cost": 0.000123,
    "latencyMs": 812
  }
}
```

上述模型 slug仅供示例。您可以在控制台（**模型**菜单）或通过 [端点 `GET /v1/models`](/zh/models) 查看您账户的有效别名列表。

### 建议：使用流式传输

聊天应用可发送 `"stream": true`，在生成过程中显示回答。首个Token时间取决于模型和提供商状态，不保证特定延迟。

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.hostlinku.com/v1",
    api_key=os.environ["HOSTLINKU_API_KEY"],
)

stream = client.chat.completions.create(
    model="gpt-5-5",
    messages=[{"role": "user", "content": "Halo!"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

使用 curl 时，添加 `-N` 以防止输出被缓冲：

```bash
curl -N https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{ "model": "gpt-5-5", "stream": true, "messages": [{ "role": "user", "content": "Halo!" }] }'
```

### 查询余额和交易记录

在Console的 **Billing** 查看组织余额，在 **Logs** 查看Token、费用和延迟。Console会话对应端点为 [`GET /api/wallet/account`](/zh/billing)，公开API（`sk-…`）使用 `/v1/*`。

## 通行密钥登录与2FA

Hostlinku账户使用Keycloak。通行密钥（WebAuthn）、TOTP验证器和恢复码可通过 **Settings → Security** 使用。登录前请注册适合的选项。Keycloak处理注册和认证挑战，SSO取决于启用的提供商。

流式费用请在结束后查看 **Logs / Analytics / Billing**。每个SSE分块不保证包含 `hostlinku.cost`；上游未返回usage时，计费可能使用估算值。
