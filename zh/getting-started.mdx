准备好curl和余额，然后按照以下步骤操作。

<Steps>

### 登录并充值

打开 [注册](https://api.hostlinku.com/api/auth2/register) 或 [登录](https://api.hostlinku.com/api/auth2/login)。登录由Keycloak处理。在 [Console](https://console.hostlinku.com) 的 **Billing** 中充值后再发送请求。支付方式请参阅 [Billing](/zh/billing)。

### 创建API密钥

打开 **API Keys → 创建API密钥**，输入名称并选择 **Performance**（默认）、**Low-Cost** 或 **Dedicated**。Service Mode决定模型及价格。复制仅显示一次的 `sk-…` 密钥并保存在服务器环境变量中。有效期、支出限额及通行密钥／2FA设置请参阅 [身份验证](/zh/authentication)。

### 发送第一个请求

使用密钥Service Mode支持的模型。本例使用 `gpt-5-5`；Dedicated密钥或其他模型请从 [`GET /v1/models`](/zh/models) 获取slug。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{"role": "user", "content": "你好！请简短介绍自己。"}]
  }'
```

非流式响应为JSON。以下为节选示例，Token数、费用和延迟仅作说明：

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "你好！我是 …"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60},
  "hostlinku": {
    "cost": 0.000123,
    "currency": "🪙",
    "serviceMode": "performance",
    "latencyMs": 812
  }
}
```

### 检查结果

在 **Logs** 查看请求Token数、费用和延迟，在 **Billing** 查看组织余额。请求失败时请查看 [错误代码](/zh/errors)。API密钥用于 `/v1/*`；Console账户端点使用登录会话。

</Steps>
