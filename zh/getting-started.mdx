准备好 curl 和信用余额，然后按照以下步骤操作。

<Steps>

<a id="masuk-dan-isi-saldo"></a>

### 登录并充值

打开 [列表](https://api.hostlinku.com/api/auth2/register) 或 [登录](https://api.hostlinku.com/api/auth2/login)。 登录由 Keycloak 提供支持。在 [控制台](https://console.hostlinku.com) 中，打开 **计费** 并充值后，再发送请求。请参阅 [计费](/zh/billing) 了解支付方式。

<a id="buat-api-key"></a>

<a id="创建api密钥"></a>

### 创建 API 密钥

打开 **API Keys → 创建 API 密钥**，命名后，选择 **Performance**（默认）、**Low-Cost** 或 **Dedicated**。服务模式决定模型和价格。 复制仅显示一次的密钥 `sk-…`，并将其保存在服务器环境中。过期设置、信用额度限制以及密钥/双因素认证（2FA）的说明请参见 [身份验证](/zh/authentication)。

<a id="kirim-request-pertama"></a>

### 发送第一个请求

请使用“服务模式”密钥的可用模型。以下示例使用 `gpt-5-5`；若使用 Dedicated 密钥或其他选项，请从 [`GET /v1/models`](/zh/models) 获取 slug。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{"role": "user", "content": "Halo! Perkenalkan dirimu singkat saja."}]
  }'
```

非流式响应采用 JSON 格式。以下示例经过截取；token、费用和延迟仅用于说明：

```json
{
  "id": "cmpl_…",
  "object": "chat.completion",
  "model": "gpt-5-5",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Halo! Saya adalah …"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60},
  "hostlinku": {
    "cost": 0.000123,
    "currency": "🪙",
    "serviceMode": "performance",
    "latencyMs": 812
  }
}
```

<a id="periksa-hasil"></a>

### 检查结果

打开 **日志** 可查看令牌、费用和请求延迟；**计费** 显示组织余额。如果请求失败，请检查 [错误代码](/zh/errors)。API 密钥用于 `/v1/*`；Console 账户的端点使用登录会话。

</Steps>
