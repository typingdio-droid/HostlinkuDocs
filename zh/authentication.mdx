Hostlinku网关使用格式为 `sk-…` 的 API 密钥，对应端点 `/v1/*`：

```http
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

`x-api-key: sk-…` 头部也有效。请在 [Console](https://console.hostlinku.com) → **API Keys** 中创建和管理密钥。

<Callout type="important" title="API密钥和Console会话">

API密钥用于`/v1/chat/completions`、`/v1/messages`、`/v1/responses`和`/v1/models`。位于`/api/*`下的受保护账户端点使用Console登录会话，并会以`403 API_KEY_NOT_ALLOWED`状态码拒绝API密钥的身份验证。 登录 Cookie 不能替代 `/v1/*` 中的 API 密钥。

</Callout>

<a id="console-登录"></a>

## 登录控制台

[登录](https://api.hostlinku.com/api/auth2/login) 或 [注册](https://api.hostlinku.com/api/auth2/register) 以打开 Keycloak 登录页面，然后返回 Console。

Console 使用服务器会话 `hl_sid`；`hl_session` 是部分流程中使用的 JWT cookie。浏览器会自动管理它。Passkey、TOTP 和恢复码可在 **设置 → 安全** 中找到。

<a id="membuat-dan-mengelola-api-key"></a>

## 创建和管理 API 密钥

1. 打开 **API 密钥 → 创建 API 密钥**。
2. 填写名称（最多 64 个字符）并选择 **服务模式**：**性能**、**低成本** 或 **专用**。默认选项为“性能”。模式决定了该密钥适用的目录、路由和定价。
3. 选择有效期：**30 天**（默认）、**60 天**、**90 天** 或 **永不过期**。
4. 如有必要，请启用**Monthly Spending Limit**并填写每月信用额度。
5. 复制仅显示一次的密钥，并将其保存到服务器环境变量中。

当前 API 密钥表单中没有端点范围选项。密钥仍受服务模式、余额、有效期、信用限额和速率限制的约束。您可通过 [`GET /v1/models`](/zh/models) 获取适用于您密钥的正确模型列表。

Secret 以 SHA-256 哈希值形式存储，因此无法还原。Console 支持编辑、启用/禁用以及删除密钥。如果 Secret 丢失或泄露，请创建替代密钥，验证请求，然后禁用旧密钥。

## 每个 API 密钥的信用额度

Console 提供 **月度支出限额**。密钥管理 API 支持以下时间段（UTC 日历）：

| 时间段 | 根据UTC日历计算的费用窗口 |
|---|---|
| `daily` | 自当天 00:00 UTC 起 |
| `weekly` | 自本周一 00:00 UTC 起 |
| `monthly` | 自本月1日00:00（UTC）起 |
| `lifetime` / 不重置 | 密钥有效期内的总计 |

费用是根据密钥记录的请求次数累积计算的。达到限额后，后续请求将被`402 PAYMENT_REQUIRED`状态码拒绝。每个密钥的限额与组织的信用余额不同：充值会增加信用余额，但不会提高密钥的限额。请参阅 [计费与余额](/zh/billing)。

<a id="rate-limit-dan-error"></a>

## 速率限制和错误

配额由所有 API 密钥和组织成员 **针对每种服务模式** 共享。添加密钥或成员账户不会增加配额。限额数值及 429 错误的处理方式详见 [使用与限额](/zh/usage-and-limits)。

| 条件 | HTTP | 代码 |
|---|---|---|
| 密钥不存在、无效、已停用或已过期 | 401 | `UNAUTHORIZED` |
| API密钥用于对Console账户端点进行身份验证 | 403 | `API_KEY_NOT_ALLOWED` |
| 可用余额不足或密钥信用额度已达上限 | 402 | `PAYMENT_REQUIRED` |
| 超出速率限制 | 429 | `RATE_LIMITED` |

<Callout type="tip" title="将密钥保存在服务器上">

在服务器环境中使用 `HOSTLINKU_API_KEY`。为每个应用程序或环境创建独立的密钥，设置适当的有效期和限制，切勿将密钥存储在浏览器或公共代码库中。

</Callout>
