Hostlinku 网关的 `/v1/*` 端点使用 `sk-…` 格式的 API 密钥：

```http
Authorization: Bearer sk-your-api-key
Content-Type: application/json
```

也接受 `x-api-key: sk-…` 标头。在 [Console](https://console.hostlinku.com) → **API Keys** 中创建和管理密钥。

<Callout type="important" title="API 密钥与 Console 会话">

`/v1/chat/completions`、`/v1/messages`、`/v1/responses` 和 `/v1/models` 使用 API 密钥。`/api/*` 下受保护的账户端点使用 Console 登录会话，拒绝 API 密钥认证并返回 `403 API_KEY_NOT_ALLOWED`。登录 Cookie 不能替代 `/v1/*` 的 API 密钥。

</Callout>

## Console 登录

从 [登录](https://api.hostlinku.com/api/auth2/login) 或 [注册](https://api.hostlinku.com/api/auth2/register) 进入Keycloak并返回Console。

Console使用 `hl_sid` 服务器会话，`hl_session` 是部分流程的JWT Cookie。浏览器自动管理。在 **Settings → Security** 使用通行密钥、TOTP和恢复码。

## 创建和管理 API 密钥

1. 打开 **API Keys → Create API key**。
2. 输入名称（最多64个字符），选择 **Service Mode**：**Performance**、**Low-Cost** 或 **Dedicated**。表单默认选择 Performance。模式决定该密钥的模型列表、路由和价格。
3. 选择 **30天**（默认）、**60天**、**90天** 或 **永不过期（Never）**。
4. 如需限制支出，启用 **Monthly Spending Limit** 并输入每月额度。
5. 复制仅显示一次的密钥，将其存入服务器环境变量。

当前 API 密钥表单没有端点作用域选择器。Service Mode、余额、有效期、用量限额和速率限制仍会约束密钥。通过 [`GET /v1/models`](/zh/models) 获取该密钥可用的模型列表。

服务器仅保存密钥的 SHA-256 哈希，无法再次显示原始密钥。Console 支持编辑、停用/启用和删除密钥。密钥丢失或泄露时，创建替代密钥并验证请求，然后停用旧密钥。

## 每个 API 密钥的用量限额

Console提供 **Monthly Spending Limit**，密钥管理API支持以下UTC日历周期：

| 周期 | 按 UTC 日历计算的费用窗口 |
|---|---|
| `daily` | 从当日00:00 UTC开始 |
| `weekly` | 从本周一00:00 UTC开始 |
| `monthly` | 从本月1日00:00 UTC开始 |
| `lifetime` / 不重置 | 密钥有效期间的累计费用 |

按该密钥记录的请求费用累计用量。达到限额后，后续请求返回 `402 PAYMENT_REQUIRED`。密钥限额与组织信用余额不同：充值增加余额，但不会提高密钥限额。参阅 [计费与余额](/zh/billing)。

## 速率限制和错误

所有API密钥和组织成员 **按每个Service Mode** 共享配额。增加密钥或成员账户不会增加配额。具体上限及429处理请参阅 [用量与限额](/zh/usage-and-limits)。

| 情况 | HTTP | 代码 |
|---|---|---|
| 密钥未提供、无效、已停用或过期 | 401 | `UNAUTHORIZED` |
| 使用 API 密钥认证 Console 账户端点 | 403 | `API_KEY_NOT_ALLOWED` |
| 可用余额不足或密钥达到额度上限 | 402 | `PAYMENT_REQUIRED` |
| 超出速率限制 | 429 | `RATE_LIMITED` |

<Callout type="tip" title="在服务器保存密钥">

使用服务器环境变量 `HOSTLINKU_API_KEY`。为每个应用或环境创建独立密钥，设置适当的有效期和限额，不要把密钥放在浏览器或公共代码库中。

</Callout>
