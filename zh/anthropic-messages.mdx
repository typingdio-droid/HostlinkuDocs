除了 OpenAI 格式外，Hostlinku 还提供与
[Anthropic Messages API](https://docs.anthropic.com/en/api/messages) 兼容的端点。官方 Anthropic SDK、
**Claude Code**、Cursor、Cline 以及其他支持 Anthropic 协议的工具，只需
更换基础 URL 即可使用——一个 API 密钥和一个 Hostlinku 余额即可同时支持这两种格式。

```http
POST https://api.hostlinku.com/v1/messages
x-api-key: sk-your-api-key
anthropic-version: 2023-06-01
Content-Type: application/json
```

身份验证接受 `x-api-key` 标头（Anthropic 风格）**或** `Authorization: Bearer sk-…`。
成功响应包含 `request-id` / `x-request-id` 标头（Hostlinku 请求 ID，格式为 `msg_…`）；非流式传输的成功响应还包含 `x-model`。处理程序之前的错误可能不包含此 ID。

<Callout type="note" title="任何模型，不仅限于Claude">
  `model` 使用与 [模型目录](/zh/models) 相同的 Hostlinku 公共 slug -
  例如：`claude-sonnet-4-6`、`gpt-5-5`、`deepseek-v4-flash`。非 Claude 模型仍可通过
  ；由网关负责转换。
</Callout>

## 快速配置

各工具（Claude Code、Cline 等）的分步指南位于
[IDE 与代理集成](/integrations)。

**Claude Code**

```bash
export ANTHROPIC_BASE_URL=https://api.hostlinku.com
export ANTHROPIC_API_KEY=sk-your-api-key
export ANTHROPIC_MODEL=claude-sonnet-4-6
claude
```

**Python（Anthropic 官方 SDK）**

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-your-api-key",
    base_url="https://api.hostlinku.com",
)

message = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Jelaskan apa itu API gateway dalam dua kalimat."}],
)
print(message.content[0].text)
print(message.usage.input_tokens, message.usage.output_tokens)
```

**Node.js**

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({ apiKey: "sk-your-api-key", baseURL: "https://api.hostlinku.com" });
const msg = await client.messages.create({
  model: "claude-haiku-4-5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Halo!" }],
});
```

<a id="parameter-body"></a>

<a id="body-参数"></a>

## 请求体参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `model` | `string` | **必填。** Hostlinku 模型的 Slug。 |
| `messages` | `array` | **必填。** `{ role: "user" \| "assistant", content }`; `content` 为字符串或块数组（`text`、`image`、`tool_use`、`tool_result` 等）。 |
| `max_tokens` | `integer` | **必填**（根据 Anthropic 规范）。若超过模型输出限制，将返回 `400` 错误。 |
| `system` | `string` \| `array` | 系统提示；块数组支持 `cache_control`。 |
| `stream` | `boolean` | SSE 情况请使用 `true`（见下文）。 |
| `temperature` | `number` | `0`–`1`。 |
| `top_p`、`top_k` | `number`、`integer` | 替代译文示例。 |
| `stop_sequences` | `string[]` | 最多 16 个。 |
| `tools`, `tool_choice` | `array`、`any` | 工具采用 Anthropic 格式（包括 `input_schema`）。 |
| `thinking` | `object` | 扩展思考，例如：`{ "type": "enabled", "budget_tokens": 1024 }`。 |
| `metadata` | `object` | 例如：`{ "user_id": "…" }`。 |
| `mcp_servers`、`context_management`、`output_format` | - | 原样保留（取决于模型支持情况）。 |

列表外的字段将被删除。无效的请求正文将被拒绝，返回 `400 invalid_request_error`，
具体错误详情按字段列于 `error.details.issues` 中。

<a id="respons-non-streaming"></a>

## 非流式响应

```json
{
  "id": "msg_…",
  "type": "message",
  "role": "assistant",
  "model": "claude-haiku-4-5",
  "content": [{ "type": "text", "text": "API gateway adalah …" }],
  "stop_reason": "end_turn",
  "stop_sequence": null,
  "usage": {
    "input_tokens": 30,
    "output_tokens": 55,
    "cache_creation_input_tokens": 0,
    "cache_read_input_tokens": 0,
    "cache_creation": { "ephemeral_5m_input_tokens": 0, "ephemeral_1h_input_tokens": 0 }
  },
  "hostlinku": { "cost": 0.00021, "currency": "🪙", "serviceMode": "performance", "latencyMs": 940 }
}
```

`id` 和 `model` 始终是 Hostlinku 的公共标识符。`hostlinku` 块是扩展部分（Anthropic SDK
会忽略它），其中包含费用 <CreditIcon />、服务模式 API 密钥和延迟。

<Callout type="note" title="Anthropic 用法规范">
  根据 Anthropic 的规范，`input_tokens` **不**包含缓存令牌；缓存令牌在
  `cache_read_input_tokens` / `cache_creation_input_tokens` 中单独报告。Hostlinku 的账单会计算
  这三项的费用，其定价方式与 `/v1/chat/completions` 路径
  完全一致（参见 [计费](/zh/billing)）。
</Callout>

<a id="streaming-stream-true"></a>

<a id="流式传输-stream-true"></a>

## 流式传输（`stream: true`）

网关以 Anthropic 格式（`event:` + `data:`）传输 SSE 事件：

```text
event: message_start
data: {"type":"message_start","message":{"id":"msg_…","type":"message","role":"assistant","model":"claude-haiku-4-5","content":[],"usage":{"input_tokens":22,"output_tokens":1,…}}}

event: content_block_start
data: {"type":"content_block_start","index":0,"content_block":{"type":"text","text":""}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"Apel"}}

event: content_block_stop
data: {"type":"content_block_stop","index":0}

event: message_delta
data: {"type":"message_delta","delta":{"stop_reason":"end_turn","stop_sequence":null},"usage":{"input_tokens":22,"output_tokens":7,…}}

event: message_stop
data: {"type":"message_stop"}
```

注：

- 最终使用量记录在 `message_delta` 中；费用根据 `message_stop` 后的实际使用量计算。
- 如果流在中间失败，网关会发送 `event: error`，格式为
  `{"type":"error","error":{"type":…,"message":…}}`，并且**不会**发送虚假的 `message_stop`。
- 在返回第一个字节之前出现的错误（余额不足、模型不存在、速率限制）应作为
  带有正确 HTTP 状态码的常规 JSON 响应返回——Anthropic SDK 会将其映射为异常
  （`AuthenticationError`、`NotFoundError`、`RateLimitError` 等）。

<a id="hitung-token"></a>

<a id="计算token"></a>

## 计算令牌

```http
POST https://api.hostlinku.com/v1/messages/count_tokens
```

正文：`model`、`messages`，可选的 `system`、`tools`、`tool_choice`、`thinking`。响应
`{ "input_tokens": 15 }`。不收取费用。

<a id="format-error"></a>

<a id="格式错误"></a>

## 错误格式

```json
{ "type": "error", "error": { "type": "authentication_error", "message": "The API key is invalid or has been revoked." } }
```

| HTTP | `error.type` | 常见原因 |
|---|---|---|
| 400 | `invalid_request_error` | Body 无效，`max_tokens` 超出了模型限制，该模型在 Service Mode 键中不可用。 |
| 401 | `authentication_error` | API密钥错误/已被撤销/已过期。 |
| 402 | `billing_error` | 余额不足或API密钥的信用额度已用尽。 |
| 403 | `permission_error` | 账户已被暂停/访问被拒绝。 |
| 404 | `not_found_error` | 模型的 Slug 未在目录中出现。 |
| 429 | `rate_limit_error` | 请求限制已达到。 |
| 503 | `overloaded_error` | 模型/上游不可用。请检查目录和替代模型；若为临时故障，请间隔一段时间后重试。 |

表格列出了协议处理的错误。在处理程序之前对请求或请求正文进行限制或解析时，可采用 Hostlinku 的通用格式；请参阅 [错误](/zh/errors)。

错误消息已进行处理以隐藏内部标识；部分上游拒绝原因仍可能显示。[错误](/zh/errors)。
