Hostlinku 提供了一个集中式的模型目录。 每个模型都有一个唯一的**slug**，该**slug**用于 [Chat Completions](/zh/chat-completions) 中的 `model` 参数，并附有上下文大小、功能和每Token价格等信息。

## `GET /v1/models`

返回所有状态为 `available`、尚未被废弃且可用于所选 **Service Mode API key**（性能型或低成本型）的模型，以及该模式下 <CreditIcon /> 每 100 万Token的价格。

```http
GET https://api.hostlinku.com/v1/models
Authorization: Bearer sk-isi-api-key-kamu
```

示例：

```bash
curl https://api.hostlinku.com/v1/models \
  -H "Authorization: Bearer sk-isi-api-key-kamu"
```

响应（示例已截取；您账户的具体数值可从该端点获取）：

```json
{
  "object": "list",
  "service_mode": "performance",
  "data": [
    {
      "id": "claude-haiku-4-5",
      "object": "model",
      "created": 1791380432,
      "owned_by": "hostlinku",
      "context_window": 200000,
      "capabilities": ["text", "tool-calling", "function-calling", "structured-outputs", "json-mode", "streaming", "code-generation", "long-context", "multilingual"],
      "service_mode": "performance",
      "pricing": {
        "input": 0.8,
        "output": 4,
        "cache_read": 0.08,
        "cache_write": 1,
        "unit": "1M_tokens",
        "currency": "🪙"
      }
    }
  ]
}
```

| Field | 含义 |
|---|---|
| `service_mode`（级别列表及项目） | 所使用的Service Mode API key模型：`performance`或`low_cost`。不同模式下的模型列表各不相同。 |
| `id` | 模型标识符，即在字段`model`中使用的值，该字段出现在字段`/v1/chat/completions`、`/v1/messages`和`/v1/responses`中。 |
| `created` | 模型添加到目录的时间（Unix 纪元，秒）。 |
| `owned_by` | 始终为 `"hostlinku"` — 这表示该模型由目录 Hostlinku 管理。 |
| `context_window` | Token（输入+输出）中的最大上下文长度。 |
| `capabilities` | 能力列表，例如：`vision`、`tool-calling`、`json-mode`、`reasoning`、`long-context`。 |
| `pricing` | Service Mode中的价格对象；若该模型在该模式下尚未设定价格，则为`null`。 `pricing.unit`始终为`"1M_tokens"`，而`pricing.currency`包含信用符号（1 <CreditIcon /> = $1）。 |
| `pricing.input` / `pricing.output` | 提示Token/回答Token的价格按**100万个Token**为单位计算（而非按1个Token或1000个Token为单位）。 |
| `pricing.cache_read` / `pricing.cache_write` | 每1MToken对应的5分钟缓存读取/缓存写入费用（参见[提示缓存](/zh/prompt-caching)）；若模型不支持，则参见`null`。 |

<Callout type="note" title="响应中的定价即客户价格">
`pricing` 这一数值即为你在 Service Mode API key 中支付的价格；其中已包含平台手续费。每次请求的实际费用始终会显示在响应中的 `hostlinku.cost` 区块以及控制台日志中。
</Callout>

## 公共目录（无需认证）

对于无需 API 密钥的营销或探索类网站，可使用公共目录：

```http
GET https://api.hostlinku.com/api/public/models
```

公共目录仅显示模型为 Hostlinku 的产品，以及其别名、名称、上下文、功能和公开价格。 支持的查询：`q`（名称/描述搜索）、`capability`、`family`、`sort`（`popular`、 `newest`、`price-asc`、`price-desc`、`context-desc`、`name-asc`）、`page` 和 `pageSize`（最多 100 条）。 `data`的响应包含`items`、`total`、`page`、`pageSize`和`totalPages`。

## 如何选择模型

1. **确定需求**：普通聊天、推理（_reasoning_）、视觉/多模态、工具调用，还是结构化JSON输出。请查看字段`capabilities`。
2. **请注意上下文长度**：请确保 `context_window` 足以容纳您的提示词和输出内容。
3. **价格对比**：`pricing.input` 用于提示Token，`pricing.output` 用于回答Token；推理模型的输出通常价格更高。
4. **从低端模型开始**：在开发阶段，低端模型（例如 `gpt-6-luna`、`deepseek-v4-1-flash`、`qwen3-6-plus`）价格要便宜得多；只有在质量不达标时，才应升级模型。
5. **查看控制台**：[console.hostlinku.com](https://console.hostlinku.com) 上的 **模型** 菜单显示了包含相同价格和功能的目录，以及各模型的详细信息页面。

<Callout type="tip" title="别名（slug）">
请使用与 `GET /v1/models` 返回结果完全一致的 slug。在显示端，slug 不区分大小写，但请务必按目录中的原样复制，以避免输入错误。 目录中不存在的 slug 将返回 `404 MODEL_NOT_FOUND`；已弃用或当前不可用的模型将返回 `503 MODEL_UNAVAILABLE`，并附带替代 slug 的建议（如有）。
</Callout>

## 路由与故障转移

Hostlinku 会自行管理为每个模型服务的内部路径。如果当前使用的路径出现故障（5xx/超时），系统会在放弃之前自动尝试通过其他路径重试请求。您仍可使用相同的模型 slug，无需进行任何更改；这些内部细节不会在响应中显示。
