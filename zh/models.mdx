Hostlinku 提供了一个集中式的模型目录。每个模型都有一个唯一的 **slug**，用于
[Chat Completions](/zh/chat-completions) 中的 `model` 参数，并附有
上下文大小、功能和每令牌价格。

## `GET /v1/models`

返回所有状态为 `available`、尚未弃用且可用于
所用 **服务模式 API 密钥**（性能型、低成本型或专用型）的模型，并附上该模式下每 1M 令牌的 <CreditIcon /> 价格
。

```http
GET https://api.hostlinku.com/v1/models
Authorization: Bearer sk-your-api-key
```

示例：

```bash
curl https://api.hostlinku.com/v1/models \
  -H "Authorization: Bearer sk-your-api-key"
```

响应（示例已截取；您账户的具体值可从该端点获取）：

```json
{
  "object": "list",
  "service_mode": "performance",
  "data": [
    {
      "id": "claude-haiku-4-5",
      "object": "model",
      "created": 1791380432,
      "owned_by": "hostlinku",
      "context_window": 200000,
      "capabilities": [
        "text",
        "tool-calling",
        "function-calling",
        "structured-outputs",
        "json-mode",
        "streaming",
        "code-generation",
        "long-context",
        "multilingual"
      ],
      "service_mode": "performance",
      "pricing": {
        "input": 0.84,
        "output": 4.2,
        "cache_read": 0.084,
        "cache_write": 1.05,
        "unit": "1M_tokens",
        "currency": "🪙"
      },
      "health": "operational"
    }
  ]
}
```

| 字段 | 含义 |
|---|---|
| `service_mode`（列表级和项目级） | 所使用的服务模式 API 密钥：`performance`、`low_cost` 或 `dedicated`。不同模式对应的模型列表各不相同。 |
| `id` | 模型别名（Slug），即在 `/v1/chat/completions`、`/v1/messages` 和 `/v1/responses` 的 `model` 字段中使用的值。 |
| `created` | 模型添加到目录的时间（Unix 纪元，秒）。 |
| `owned_by` | 始终使用 `"hostlinku"`——这表示该模型由 Hostlinku 目录管理。 |
| `context_window` | 令牌中的最大上下文长度（输入 + 输出）。 |
| `capabilities` | 功能列表，例如 `vision`、`tool-calling`、`json-mode`、`reasoning`、`long-context`。 |
| `pricing` | 该服务模式下的定价对象；如果模型在该模式下尚未设定价格，则为 `null`。`pricing.unit` 始终为 `"1M_tokens"`，而 `pricing.currency` 包含信用符号（1 <CreditIcon /> = \$1）。 |
| `pricing.input` / `pricing.output` | 提示令牌/回答令牌的价格按**1M令牌**计（而非按1个令牌或1K令牌计）。 |
| `pricing.cache_read` / `pricing.cache_write` | 每 1M 令牌的缓存读取/缓存写入 5 分钟价格。未提供的费率可不列出；请参阅 [提示缓存](/zh/prompt-caching)。 |

<Callout type="note" title="Pricing 指客户价格">
`pricing` 指客户针对“服务模式”密钥的定价，包含利润。在非流式响应中，费用可在 `hostlinku.cost` 中查看；使用情况和费用也可在 Console 日志中查看。
</Callout>

## 公共目录（无需身份验证）

如果没有 API 密钥，请使用以下端点来比较模型和服务模式：

```http
GET https://api.hostlinku.com/api/public/models-v2
GET https://api.hostlinku.com/api/public/service-modes
```

`models-v2` 返回 `{status, currency, models}`。 每个模型包含 `slug`、`displayName`、`contextTokens`、`maxOutputTokens`（如有）、`capabilities`、`serviceModes`，以及 `modes` 中各模式的价格。`service-modes` 返回 `{status, data}`，其中包含模式及其模型的摘要。

要查看特定 API 密钥适用的列表和价格，请使用 `GET /v1/models`。

## 如何选择模型

1. **确定需求**：普通聊天、推理（_reasoning_）、视觉/多模态、工具调用，
   或结构化 JSON 输出。请检查 `capabilities` 字段。
2. **注意上下文范围**：请确保 `context_window` 足以容纳您的提示词和输出内容。
3. **比较价格**：`pricing.input` 用于提示令牌，`pricing.output` 用于
   回答令牌；推理模型的输出通常价格更高。
4. **从小模型开始**：在开发阶段，轻量级模型（例如 `gpt-6-luna`、
   `deepseek-v4-1-flash`、`qwen3-6-plus`）成本要低得多；仅当
   质量不足时才升级模型。
5. **查看控制台**：[console.hostlinku.com](https://console.hostlinku.com) 中的 **模型** 菜单
   显示了具有相同价格和功能的目录，以及每个模型的详细信息页面。

<Callout type="tip" title="模型 ID">
将 `GET /v1/models` 中的 slug 原样复制到 `model` 字段中。未知 slug 可能会导致 `MODEL_NOT_FOUND` 错误；若该键下不存在模型，可能会导致 `MODEL_NOT_IN_SERVICE_MODE` 或 `MODEL_UNAVAILABLE` 错误。
</Callout>

## 路由和故障转移

网关根据模型和服务模式键选择服务路径。重试或故障转移取决于可用路径和故障类型；并非所有模型都有备用路径。请求中的模型 ID 保持不变。
