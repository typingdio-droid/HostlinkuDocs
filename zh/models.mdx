Hostlinku 提供了一个集中式的模型目录。 每个模型都有一个唯一的**slug**，该**slug**用于 [Chat Completions](/zh/chat-completions) 中的 `model` 参数，并附有上下文大小、功能和每Token价格等信息。

## `GET /v1/models`

返回所有状态为 `available`、尚未被废弃且可用于所选 **Service Mode API key**（Performance、Low-Cost或Dedicated）的模型，以及该模式下 <CreditIcon /> 每 100 万Token的价格。

```http
GET https://api.hostlinku.com/v1/models
Authorization: Bearer sk-your-api-key
```

示例：

```bash
curl https://api.hostlinku.com/v1/models \
  -H "Authorization: Bearer sk-your-api-key"
```

响应（示例已截取；您账户的具体数值可从该端点获取）：

```json
{
  "object": "list",
  "service_mode": "performance",
  "data": [
    {
      "id": "claude-haiku-4-5",
      "object": "model",
      "created": 1791380432,
      "owned_by": "hostlinku",
      "context_window": 200000,
      "capabilities": [
        "text",
        "tool-calling",
        "function-calling",
        "structured-outputs",
        "json-mode",
        "streaming",
        "code-generation",
        "long-context",
        "multilingual"
      ],
      "service_mode": "performance",
      "pricing": {
        "input": 0.84,
        "output": 4.2,
        "cache_read": 0.084,
        "cache_write": 1.05,
        "unit": "1M_tokens",
        "currency": "🪙"
      },
      "health": "operational"
    }
  ]
}
```

| Field | 含义 |
|---|---|
| `service_mode`（级别列表及项目） | 所使用的Service Mode API key模型：`performance`、`low_cost` 或 `dedicated`。不同模式下的模型列表各不相同。 |
| `id` | 模型标识符，即在字段`model`中使用的值，该字段出现在字段`/v1/chat/completions`、`/v1/messages`和`/v1/responses`中。 |
| `created` | 模型添加到目录的时间（Unix 纪元，秒）。 |
| `owned_by` | 始终为 `"hostlinku"` - 这表示该模型由目录 Hostlinku 管理。 |
| `context_window` | Token（输入+输出）中的最大上下文长度。 |
| `capabilities` | 能力列表，例如：`vision`、`tool-calling`、`json-mode`、`reasoning`、`long-context`。 |
| `pricing` | Service Mode中的价格对象；若该模型在该模式下尚未设定价格，则为`null`。 `pricing.unit`始终为`"1M_tokens"`，而`pricing.currency`包含信用符号（1 <CreditIcon /> = \$1）。 |
| `pricing.input` / `pricing.output` | 提示Token/回答Token的价格按**100万个Token**为单位计算（而非按1个Token或1000个Token为单位）。 |
| `pricing.cache_read` / `pricing.cache_write` | 缓存读取／5分钟缓存写入的每100万个Token价格。未设置的费率可能省略；请参见[提示词缓存](/zh/prompt-caching)。 |

<Callout type="note" title="Pricing为客户价格">
`pricing` 是密钥所属Service Mode的客户价格，已包含平台利润。非流式响应包含 `hostlinku.cost`；使用量和费用也可在控制台日志中查看。
</Callout>

## 公共目录（无需认证）

无需API密钥即可通过以下端点比较模型和Service Mode：

```http
GET https://api.hostlinku.com/api/public/models-v2
GET https://api.hostlinku.com/api/public/service-modes
```

`models-v2` 返回 `{status, currency, models}`。每个模型包含 `slug`、`displayName`、`contextTokens`、已列出的 `maxOutputTokens`、`capabilities`、`serviceModes`，以及 `modes` 中的各模式价格。`service-modes` 返回 `{status, data}`，包含模式概要及其模型列表。

要查看特定API密钥可用的模型和价格，请调用 `GET /v1/models`。

## 如何选择模型

1. **确定需求**：普通聊天、推理（_reasoning_）、视觉/多模态、工具调用，还是结构化JSON输出。请查看字段`capabilities`。
2. **请注意上下文长度**：请确保 `context_window` 足以容纳您的提示词和输出内容。
3. **价格对比**：`pricing.input` 用于提示Token，`pricing.output` 用于回答Token；推理模型的输出通常价格更高。
4. **从低端模型开始**：在开发阶段，低端模型（例如 `gpt-6-luna`、`deepseek-v4-1-flash`、`qwen3-6-plus`）价格要便宜得多；只有在质量不达标时，才应升级模型。
5. **查看控制台**：[console.hostlinku.com](https://console.hostlinku.com) 上的 **模型** 菜单显示了包含相同价格和功能的目录，以及各模型的详细信息页面。

<Callout type="tip" title="模型ID">
请将 `GET /v1/models` 返回的完整slug复制到 `model` 字段。未知slug可能返回 `MODEL_NOT_FOUND`；密钥无法使用的模型可能返回 `MODEL_NOT_IN_SERVICE_MODE` 或 `MODEL_UNAVAILABLE`。
</Callout>

## 路由与故障转移

网关根据模型和密钥所属Service Mode选择服务路径。重试或故障转移取决于可用路径及故障类型，并非所有模型都有备用路径。请求中的模型ID保持不变。
