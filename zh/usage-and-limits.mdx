Hostlinku 通过三个相互补充的层级对使用进行限制：**速率限制**（单位时间内的请求数量）、**每个 API 密钥的额度**（每个重置窗口内的费用）以及 **账户余额**（资金来源）。 在请求转发至提供商之前，这三项会在服务器端进行验证。

## 速率限制

| 覆盖范围 | 边界 | 边界确定者 |
|---|---|---|
| `POST /v1/chat/completions` | **600 次请求/分钟** | 每个API密钥（`sk-…`） |
| 控制台和公共端点 (`/api/*`) | **每分钟120次请求** | 按IP地址 |
| 身份验证端点（登录、注册、一次性密码、重置） | **30次试验 / 15分钟** | 按IP地址 |

每个经过限幅器的响应都包含标准标头（IETF `RateLimit-*` 格式）：`RateLimit-Limit`、`RateLimit-Remaining` 和 `RateLimit-Reset`。 请读取 `Reset` 的值，以了解下一个窗口何时开始。

当超过限制时，其响应为：

```http
HTTP/1.1 429 Too Many Requests
```

```json
{
  "status": "error",
  "error": {
    "code": "RATE_LIMITED",
    "message": "Rate limit exceeded. Upgrade your plan for a higher limit."
  }
}
```

<Callout type="tip" title="正确的后退策略">
对于 429，请按照 `RateLimit-Reset` 的要求等待（或采用 1s → 2s → 4s… 的指数退避，并带抖动），然后重试。请勿不间断地重复发送；这只会延长在运行窗口中的阻塞时间。
</Callout>

## 每个 API 密钥的额度

除了速率限制外，每个 API 密钥均可设置**费用限额**（美元），重置周期可选每日、每周、每月（UTC 日历）或无重置的总限额。使用量根据每个 API 密钥的实际请求费用计算。 达到限额的 API 密钥将被拒绝，返回 **402 PAYMENT_REQUIRED** 状态码，直至下一个计费周期开始。设置详情请参见 [身份验证](/zh/authentication)。

## 请求时的余额预留

对于每个请求，网关：

1. **预留**预估费用（根据提示词长度及`max_tokens`）从账户余额中扣除。
2. 将请求转发给服务提供商。
3. **Commit** 根据已使用的Token计算实际费用，并释放剩余的预留额度。

这意味着：控制台中的余额分为 `balance`（总余额）和 `reserved`（正在处理的待处理请求）。可用于新请求的是 `balance − reserved`（`available`）。 失败的请求**不收取费用**；其预留资源将自动释放。

## 在控制台中监控使用情况

访问 [console.hostlinku.com](https://console.hostlinku.com)：

| 菜单 | 内容 |
|---|---|
| **仪表盘 / 使用** | 请求摘要、Token进出情况、缓存以及各时间段（24小时、7天/30天/90天）的费用。 |
| **请求日志** | 完整的请求列表：模型、状态、Token、费用、延迟（包括流式传输的TTFT）以及每个请求的详细信息。 |
| **审计日志** | 账户操作记录：API密钥的创建/撤销、充值、设置更改等。 |
| **API密钥** | 每个API密钥的使用情况：请求、Token、费用、`lastUsed`、过期时间和限制。 |

所有数据均来自与计费所用相同的后端遥测表，界面端未进行任何估算。

<Callout type="note" title="每次API调用的费用">
对于您自己的应用程序，每个聊天补全响应中的 `hostlinku.cost` 块包含该请求的费用，而 `x-request-id` 标头将其与控制台中的日志行关联起来。
</Callout>

## 行为摘要 429 和 402

| 代码 | 含义 | 需要做的事情 |
|---|---|---|
| `429 RATE_LIMITED` | 该时间段内的请求过多 | 等待 `RateLimit-Reset`，进行退避，或降低并发度 |
| `402 PAYMENT_REQUIRED` | 信用问题：余额不足 **或** API 密钥额度已用尽 | 请查看错误信息。如果提示“API密钥额度已达上限”，请等待重置或提高额度；如果提示“额度不足”，请进行充值（[计费与余额](/zh/billing)） |
