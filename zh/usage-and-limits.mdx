## 组织共享配额

以下配额由同一组织内的所有 API 密钥和成员共享。添加密钥或使用其他成员的账户不会增加配额。

| Service Mode | 每分钟请求数 | 每分钟的 `input` 令牌 | 每分钟的 `output` 令牌 |
|---|---|---|---|
| Performance | 600 | 6,500,000 | 200,000 |
| Low-Cost | 600 | 6,500,000 | 200,000 |
| Dedicated | 600 | 6,500,000 | 200,000 |

<a id="batas-endpoint-lain"></a>

## 其他端点限制

Console、登录和结账的端点限制按 IP 地址计算，并与模型使用配额分开计算。

| 范围 | 限制 | 分组 |
|---|---|---|
| 带通用限流器的 Console/公共端点 | **120 次请求 / 60 秒** | 按 IP |
| 带身份验证限制器的端点 | **30 次尝试 / 15 分钟** | 按 IP |
| GET 带令牌的结账 | **90 次请求 / 60 秒** | 按 IP |
| 带令牌的结账变更 | **15 次请求 / 60 秒** | 按 IP |

<Callout type="tip" title="遇到 429 状态码被拒绝的请求时，请等待一段时间后再重试">

如有，请读取重置标头或 `Retry-After`。减少并发次数，并使用带抖动的指数退避算法。不间断地重复请求无法解决限制问题。

限流端点返回 `RateLimit-Limit`、`RateLimit-Remaining` 和 `RateLimit-Reset`（秒）。当出现 429 状态码时，`Retry-After` 或 `retry-after-ms` 也可能出现。
</Callout>

## API密钥信用额度

Console 表单提供 **Monthly Spending Limit**。密钥管理 API 接受 `daily`、`weekly`、`monthly` 或使用 `null` 表示不重置。 每日计费周期从 UTC 00:00 开始，每周计费周期从周一 UTC 00:00 开始，每月计费周期从每月 1 日 UTC 00:00 开始。请参阅 [身份验证](/zh/authentication)。

限额基于密钥的累计费用，而非令牌数量。达到限额后，后续请求将被拒绝并返回 `402 PAYMENT_REQUIRED` 状态码。追加余额不会改变密钥的限额。

<a id="reservasi-saldo"></a>

## 余额预留

网关从组织余额中预留费用估算额，转发请求，然后根据上游使用情况结算费用。剩余预留额将被释放。若无可用使用量，计费可采用估算值。若发生无法产生可计费使用量的故障，预留额将被释放。

新请求的余额为 `available = balance − reserved`。余额和密钥限额需充足；请参阅 [计费与余额](/zh/billing)。

<a id="console-监控"></a>

## 在 Console 中进行监控

| 菜单 | 数据 |
|---|---|
| **概述 / 分析** | 按时间范围汇总请求、令牌、缓存和费用 |
| **日志** | 模型、状态、令牌、费用、延迟、TTFT 以及请求详情 |
| **API Keys** | 状态、服务模式、过期、限制以及密钥使用情况 |
| **计费** | 组织余额、充值、交易、发票 |

非流式聊天补全包含 `hostlinku.cost`。流式 SSE 无法保证按数据块计费；请通过“日志/分析/计费”查看最终费用。`x-request-id` 有助于将请求与日志关联起来。

<a id="isi-log-dan-retensi"></a>

## 日志内容与保留期限

正文日志记录**默认处于禁用状态**。若由管理员启用，内容将受大小限制且凭据字段会被过滤；正文默认保留期为 14 天。使用/交易元数据仍会被保存。请参阅 [隐私政策](/zh/legals/privacy-policy)。

健康检查的原始数据默认保存 **30 天**，之后会定期清理。请求内容有单独的 **14 天** 保留期。使用和交易元数据将持续保存。

<a id="biaya-historis"></a>

## 历史费用

计费总额仍采用日志中存储的数值。部分分析明细将根据当前令牌和费率重新计算；这些明细可能与历史总额存在差异，但不会重新计费。

<a id="arti-429-dan-402"></a>

<a id="429和402含义"></a>

## 429 和 402 的含义

| 代码 | 含义 | 操作 |
|---|---|---|
| `429 RATE_LIMITED` | 请求数量超限 | 等待重置、回退、降低并发度 |
| `402 PAYMENT_REQUIRED` | 可用余额不足或已达到密钥限额 | 阅读提示：充值余额、等待重置或调整相应限额 |
