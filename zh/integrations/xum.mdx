[Xum](https://xum.cdr.dev/config/providers)（原名 **Mux**）可在桌面或浏览器上并行运行多个编码代理
，每个代理均拥有隔离的工作区。Xum支持
**自定义提供商**，并支持自选的API格式——这是在不
更改内置的OpenAI/Anthropic提供商的情况下，添加Hostlinku的最简洁方式。

<Steps>

<a id="simpan-api-key-di-file"></a>

<a id="将-api-密钥保存到文件中"></a>

### 将 API 密钥保存在文件中

```bash
mkdir -p ~/.config/hostlinku
printf '%s' 'sk-your-api-key' > ~/.config/hostlinku/api-key
chmod 600 ~/.config/hostlinku/api-key
```

<a id="tambahkan-provider-hostlinku"></a>

<a id="添加提供商-hostlinku"></a>

### 添加 Hostlinku 提供商

编辑 `~/.xum/providers.jsonc` 并添加新的提供商：

```jsonc
{
  // Semua model katalog lewat Chat Completions
  "hostlinku": {
    "providerType": "openai-compatible",
    "displayName": "Hostlinku",
    "baseUrl": "https://api.hostlinku.com/v1",
    "apiKeyFile": "~/.config/hostlinku/api-key",
    "models": ["claude-sonnet-4-6", "gpt-5-5", "deepseek-v4-flash"],
  },
  // Opsional: model Claude lewat Anthropic Messages (prompt caching penuh)
  "hostlinku-claude": {
    "providerType": "anthropic-messages",
    "displayName": "Hostlinku (Anthropic)",
    "baseUrl": "https://api.hostlinku.com",
    "apiKeyFile": "~/.config/hostlinku/api-key",
    "models": ["claude-sonnet-4-6", "claude-haiku-4-5"],
  },
}
```

对于 `anthropic-messages`，Xum 会自行添加 `/v1`，因此基础 URL 应**不包含** `/v1`。
提供商 ID（`hostlinku`、`hostlinku-claude`）必须为小写，且不得与
内置提供商的名称相同。

<a id="pilih-model"></a>

### 选择模型

打开模型选择器（或 `/model`）并从 **Hostlinku** 组中选择模型。`models` 仅为建议列表
——[目录](/zh/models) 中的其他 slug 仍可直接输入。请求显示在
控制台 → **请求日志** 中。

</Steps>

<a id="alternatif-provider-openai-bawaan"></a>

<a id="备选方案内置提供商-openai"></a>

## 备选方案：内置的 OpenAI 提供商

若仅希望使用一个提供商，请通过 wire
格式将内置的 **OpenAI** 提供商指向 Hostlinku，采用 Chat Completions 格式（**设置 → 提供商 → OpenAI**，或在 `providers.jsonc` 中）：

```jsonc
{
  "openai": {
    "apiKey": "sk-your-api-key",
    "baseUrl": "https://api.hostlinku.com/v1",
    "wireFormat": "chatCompletions",
  },
}
```

<Callout type="note" title="为什么是 chatCompletions？">
  OpenAI 提供商的默认数据格式是 Responses API，而 Hostlinku 中的 Responses 属于
  *无状态* ([详情](/zh/responses))。Chat Completions 支持目录中的所有模型——包括
  Claude——且不受此限制。
</Callout>

<a id="troubleshooting"></a>

## 故障排除

| 症状 | 解决方案 |
|---|---|
| `401` | `apiKeyFile` 文件内容有误（包含换行符/空格）或密钥已被撤销。 |
| `404` | `anthropic-messages` 带有双重 `/v1` — 请写成基础 URL `https://api.hostlinku.com`。 |
| “Provider”未出现 | ID provider 需使用大写字母/句点，否则将与内置提供商名称冲突。 |
| `404 model_not_found` | Slug 拼写有误——复制自 `GET /v1/models`。 |
