## 兼容性限制

- **不同工具的 URL 格式各异。** Anthropic SDK 通常使用 `https://api.hostlinku.com`；OpenAI 工具使用 `https://api.hostlinku.com/v1`。VS Code 和 Junie 可能需要完整的端点 URL。请遵循表格中各工具的指南。
- **Codex CLI 需要原生 Responses 工具的支持**，包括 shell 和 `apply_patch`。仅靠文本/函数调用桥接还不够；请参阅 [Codex](/zh/integrations/codex-cli)。
- **功能遵循模型和协议。**请在模型页面以及[API参考](/zh/api-reference)中查看对视觉、推理、JSON模式和工具调用的支持情况。
- **FIM/内联自动补全和嵌入功能尚未支持。** 此集成通过“聊天补全”、“响应”和“消息”功能使用聊天、代理或编辑功能。

## API密钥和帮助

为每个工具创建独立的 API 密钥并设置信用额度，以便于撤销。将密钥存储在环境变量或密钥存储工具中；切勿提交代码或打印其值。密钥配置详见 [身份验证](/zh/authentication)。

关于请求失败，请参阅 [错误代码列表](/zh/faqs/errors)。各工具的具体配置和限制详情请参见表格中的指南。
