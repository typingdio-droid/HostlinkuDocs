[Zed](https://zed.dev/docs/ai/use-api-access) 支持通过 `settings.json` 配置自定义的 **OpenAI-compatible** 提供商
。必须显式声明模型（Zed 不进行自动发现），然后
通过代理面板或环境变量一次性输入 API 密钥。

<Steps>

<a id="deklarasikan-provider-dan-model"></a>

<a id="声明提供者和模型"></a>

### 声明提供商和模型

打开 `zed: open settings`（⌘/Ctrl + ,）并添加：

```json
{
  "language_models": {
    "openai_compatible": {
      "hostlinku": {
        "api_url": "https://api.hostlinku.com/v1",
        "available_models": [
          {
            "name": "claude-sonnet-4-6",
            "display_name": "Claude Sonnet 4.6 (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": true, "parallel_tool_calls": true }
          },
          {
            "name": "gpt-5-5",
            "display_name": "GPT-5.5 (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": true, "parallel_tool_calls": true }
          },
          {
            "name": "deepseek-v4-flash",
            "display_name": "DeepSeek V4 Flash (Hostlinku)",
            "max_tokens": 1000000,
            "capabilities": { "tools": true, "images": false }
          }
        ]
      }
    }
  },
  "agent": {
    "default_model": { "provider": "hostlinku", "model": "claude-sonnet-4-6" }
  }
}
```

`api_url` 必须以 `/v1` 结尾，且不带尾斜杠。`max_tokens` 是模型的上下文大小
（参见 [目录](/zh/models) 中的 `context_window`）；`name` 必须与原始名称完全一致。

<a id="masukkan-api-key"></a>

### 输入 API 密钥

请选择其中一种：

- **Agent Panel** → 设置图标（`agent: open settings`）→ 查找提供商 **hostlinku** → 粘贴
  API密钥 `sk-…`。Zed将其保存在系统钥匙串中，而非 `settings.json` 文件中。
- **环境变量**，名称为大写字母的提供商 ID + `_API_KEY`：

```bash
export HOSTLINKU_API_KEY=sk-your-api-key
```

请在已导出该变量的 shell 中运行 Zed（或将其添加到 shell 配置文件中
，然后重新登录）。

<a id="pilih-model-di-agent-panel"></a>

### 在代理面板中选择模型

打开代理面板（⌘/Ctrl + ?）→ 模型选择器 → **hostlinku** 组。发送一条消息，并在控制台的
**请求日志**中查看该请求。

</Steps>

<a id="opsi-model-lanjutan"></a>

## 高级模型选项

| 字段 | 何时使用 |
|---|---|
| `reasoning_effort`（`"low"`/`"medium"`/`"high"`） | 推理模型（GPT-5.x、Claude 4.6、DeepSeek V4）。 |
| `capabilities.max_tokens_parameter: true` | 仅当模型不支持 `max_completion_tokens` 时；Hostlinku 同时支持这两种情况，请保留默认设置。 |
| `capabilities.chat_completions: false` | 将模型切换至 Responses API（`/v1/responses`）——Hostlinku 也支持该接口，但 Zed 中的默认聊天补全功能经过了更充分的测试。 |

<Callout type="note" title="“编辑预测”不包含在内">
  Zed 的 *edit predictions*（内联自动完成）功能在 `edit_predictions` 中单独配置，
  并使用 Hostlinku 未提供的 `/v1/completions`（FIM）端点。请使用 Hostlinku
  用于代理面板、内联助手和线程；将编辑预测功能保留在默认提供商中。
</Callout>

<a id="troubleshooting"></a>

## 故障排除

- **提供商未显示** - `settings.json` 无效（逗号/括号）。请检查 `zed: open log`。
- **`401`** - 提供商 `hostlinku` 尚未输入密钥，或者环境变量是在 Zed
  启动后导出的；请重启 Zed。
- **忽略工具调用** - 请确保该模型中 `capabilities.tools: true`。
- **完整上下文处理过快** - `max_tokens` 相对于模型的 `context_window` 而言过小；
  请根据目录进行调整。
