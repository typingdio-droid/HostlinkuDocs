[Claude Code](https://code.claude.com/docs) 采用 Anthropic Messages 协议。Hostlinku
在 [`POST /v1/messages`](/zh/anthropic-messages) （包括
`/v1/messages/count_tokens`），因此只需通过
环境变量即可将 Claude Code 定向至 Hostlinku——无需额外代理。

<Steps>

<a id="instal-claude-code"></a>

### 安装 Claude Code

请根据您的操作系统选择安装方法：

**macOS / Linux / WSL：**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell：**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**npm（需要 Node.js 18+）：**

```bash
npm install -g @anthropic-ai/claude-code
```

如果你之前曾使用 Anthropic/Claude 账户登录过，请运行 `claude` 并输入
`/logout`，以确保已保存的 OAuth 凭据不会影响网关配置。

<a id="arahkan-ke-hostlinku"></a>

<a id="请转至-hostlinku"></a>

### 跳转至 Hostlinku

最快的方法——在 shell 中导出（`~/.zshrc` / `~/.bashrc`）：

```bash
export ANTHROPIC_BASE_URL=https://api.hostlinku.com
export ANTHROPIC_AUTH_TOKEN=sk-your-api-key

# Pin model untuk alias yang dipakai Claude Code
export ANTHROPIC_DEFAULT_SONNET_MODEL=claude-sonnet-4-6
export ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-4-6
export ANTHROPIC_DEFAULT_HAIKU_MODEL=claude-haiku-4-5

claude
```

持久化方式——`~/.claude/settings.json` 中的 `env` 块（适用于所有项目）或
项目根目录下的 `.claude/settings.local.json`（仅限该项目；该文件通常被添加到 `.gitignore` 中）：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.hostlinku.com",
    "ANTHROPIC_AUTH_TOKEN": "sk-your-api-key",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-6",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-6",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5"
  }
}
```

`settings.json` 中的值 **优先于** shell 导出的值。

<Callout type="tip" title="想通过GUI管理而不编辑JSON吗？">
  使用桌面应用程序 [CC Switch](/zh/integrations/cc-switch) 从 `/v1/models` 自动获取模型列表，
并一键切换 Claude Code 的配置文件/模型。
</Callout>

<a id="verifikasi"></a>

### 验证

在 Claude Code 会话中输入 `/status`：*API* 部分应显示基础 URL
`https://api.hostlinku.com` 以及 *auth token* 认证方法。发送一个简单的提示，然后
检查该请求是否出现在控制台 → **请求日志** 中，并确认使用的是您自己的 API 密钥。

<a id="opsional-ganti-model-dari-dalam-sesi"></a>

<a id="可选在会话中切换模型"></a>

### （可选）在会话内切换模型

`/model` 显示了你上面已固定的别名 `sonnet` / `opus` / `haiku`。若要一次性使用
其他 slug：

```bash
claude --model deepseek-v4-flash
# atau pin default lewat env: export ANTHROPIC_MODEL=gpt-5-5
```

</Steps>

<a id="autentikasi-auth_token-atau-api_key"></a>

<a id="认证auth_token-还是-api_key"></a>

## 身份验证：`AUTH_TOKEN` 还是 `API_KEY`？

| 变量 | 发送的标头 | 由 Hostlinku 提供支持 |
|---|---|---|
| `ANTHROPIC_AUTH_TOKEN` | `Authorization: Bearer sk-…` | 是（建议） |
| `ANTHROPIC_API_KEY` | `x-api-key: sk-…` | 是 |

两者均被网关接受；请选择其中之一，不要同时填写两个不同的值。

<a id="ekstensi-vs-code--jetbrains"></a>

## VS Code 和 JetBrains 扩展

Claude Code 扩展会自行检查登录信息，因此必须在扩展设置中填写相同的变量
- VS Code：在 `settings.json` 中的 `claudeCode.environmentVariables`：

```json
{
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.hostlinku.com" },
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "sk-your-api-key" },
    { "name": "ANTHROPIC_DEFAULT_SONNET_MODEL", "value": "claude-sonnet-4-6" },
    { "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL", "value": "claude-haiku-4-5" }
  ]
}
```

在 JetBrains 中，请在 *设置 → 工具 → Claude Code → 环境变量* 中填写相同的变量值
（或确保 IDE 从已导出该变量的 shell 中运行）。

<a id="pakai-model-non-claude"></a>

## 使用非Claude模型

在“服务模式”的“高性能”和“低成本”模式下，Claude Code 支持 Claude 模型以及 DeepSeek、Qwen、GLM、Kimi、MiniMax 和 MiMo 等本土模型。 在上述模式下，Claude Code 不支持 GPT 模型；如需使用 GPT 模型，请使用 Codex CLI、Chat 或 Responses API。由于网关会转换协议，因此 `sonnet`/`haiku` 中的别名可以填入来自 [目录](/zh/models) 的本土模型 slug：

```bash
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
```

依赖于模型能力的功能（工具使用、*扩展思维*、视觉）应遵循
目标模型的能力——请查阅目录中的 `capabilities` 字段。

<Callout type="note" title="Claude Code 不识别非 Claude 的模型名称">
  当使用类似 `deepseek-v4-pro` 或 `deepseek-v4-flash` 的 slug 时，Claude Code 会显示 `unrecognized_model` 的警告，并默认采用 200k 令牌的上下文。如果目标模型的上下文窗口更大，请在客户端调整上下文。
</Callout>

<Callout type="tip" title="为子代理节省余额">
  Claude Code 使用别名 *haiku* 处理轻量级任务（摘要、会话标题、快速子代理）。
  使用 `claude-haiku-4-5` 或 `deepseek-v4-flash` 作为参数，可显著降低长会话的成本，
  同时不影响主模型的质量。
</Callout>

<Callout type="note" title="大上下文与缓存">
  Hostlinku 会传递 `cache_control`（提示缓存），并在 `usage` 中报告 `cache_read_input_tokens` /
  `cache_creation_input_tokens`——Claude Code 会自动利用这些信息。 计费遵循
  相关缓存模型的定价（参见 [计费](/zh/billing)）。
</Callout>

<a id="troubleshooting"></a>

## 故障排除

- **`401 authentication_error` 尽管密钥正确** - 仍在使用旧的 OAuth 凭据。执行
  `/logout`，关闭会话，确保 `ANTHROPIC_BASE_URL` 可读取（`/status`）。
- **未找到模型（`404`）** - 别名尚未被固定，因此 Claude Code 发送了其
  默认模型名称。请将 `ANTHROPIC_DEFAULT_*_MODEL` 替换为目录中的 slug。
- **`400 max_tokens melebihi batas`** - 若目标模型的输出限制较小，请通过 `CLAUDE_CODE_MAX_OUTPUT_TOKENS`
  （例如 `32000`）降低 `max_tokens` 的值。
- **速率限制（`429`）** - Claude Code 可以并行运行多个子代理。请参阅
  [使用与限制](/zh/usage-and-limits) 中的限制说明。
