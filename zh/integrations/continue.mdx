[继续](https://docs.continue.dev) 通过 `config.yaml` 进行配置。每个模型
都有 `provider`、`apiBase`、`apiKey` 以及 `roles` 列表（chat、edit、apply 等）。对于
Hostlinku 使用 `openai` 提供商，其 `apiBase` 为 gateway。

<Steps>

<a id="buka-konfigurasi"></a>

### 打开配置

在“Continue”面板中，点击齿轮图标 → **打开配置文件**，或直接编辑
`~/.continue/config.yaml`（全局） / `.continue/config.yaml`（按项目）。

<a id="tambahkan-model-hostlinku"></a>

<a id="添加模型-hostlinku"></a>

### 添加 Hostlinku 模型

```yaml
name: Hostlinku
version: 0.0.1
schema: v1

models:
  - name: Claude Sonnet 4.6 (Hostlinku)
    provider: openai
    model: claude-sonnet-4-6
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply]
    defaultCompletionOptions:
      contextLength: 1000000
      maxTokens: 32000

  - name: GPT-5.5 (Hostlinku)
    provider: openai
    model: gpt-5-5
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply]

  - name: DeepSeek V4 Flash (Hostlinku)
    provider: openai
    model: deepseek-v4-flash
    apiBase: https://api.hostlinku.com/v1
    apiKey: ${{ secrets.HOSTLINKU_API_KEY }}
    roles: [chat, edit, apply, summarize]
```

<a id="simpan-api-key-sebagai-secret"></a>

<a id="将-api-密钥保存为密钥"></a>

### 将 API 密钥作为机密保存

创建文件 `~/.continue/.env`（不提交到代码库），内容如下：

```bash
HOSTLINKU_API_KEY=sk-your-api-key
```

或者，如果您的配置文件
确实是私有的，请将 `${{ secrets.HOSTLINKU_API_KEY }}` 替换为密钥的直接值。

<a id="muat-ulang-dan-uji"></a>

### 重新加载并测试

在“Continue”面板中点击**Reload config**（或保存文件——“Continue”会自动检测更改）。在下拉菜单中选择
模型 *Claude Sonnet 4.6 (Hostlinku)*，发送消息，然后查看控制台 → **请求日志**
。

</Steps>

<a id="peran-roles-yang-didukung"></a>

<a id="支持的角色"></a>

## 支持的角色（roles）

| Role | 通过 Hostlinku 提供支持 | 注释 |
|---|---|---|
| `chat` | 是 | 所有目录模型。 |
| `edit`、`apply` | 是 | 使用工具调用模型；`claude-sonnet-4-6` 非常适合 *apply*。 |
| `summarize` | 是 | 经济型模型如 `deepseek-v4-flash` / `claude-haiku-4-5`。 |
| `autocomplete` | 不 | 需要通过 `/v1/completions` 获取 FIM 模型。将此角色留给其他提供商（例如本地模型）。 |
| `embed`、`rerank` | 不 | Hostlinku 尚未提供 embeddings/rerank 端点。 |

如果 `edit`/`apply` 未指定特定模型，则继续使用当前活动的 `chat` 模型。

<Callout type="tip" title="YAML 锚点，用于减少重复">
  将 `apiBase` 和 `apiKey` 定义一次作为锚点（`&hostlinku`），然后在每个模型中使用
  `<<: *hostlinku`。请参阅 `config.yaml` 参考文档。继续。
</Callout>

<a id="troubleshooting"></a>

## 故障排除

- **模型未出现在下拉菜单中** - YAML 缩进错误，或者 `roles` 中未包含 `chat`。
  请参阅 VS Code 中的 *输出 → 继续*。
- **`401`** - 尚未读取 `~/.continue/.env`；请重新加载配置或重启 IDE。
- **`404 model_not_found`** - `model:` 必须与 `GET /v1/models` 中的 slug 完全一致。
- **流媒体卡顿** - 请确保没有企业代理对 `text/event-stream` 进行缓冲。
