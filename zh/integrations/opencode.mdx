[OpenCode](https://opencode.ai/docs/providers/) 使用 AI SDK，因此任何
与 OpenAI 兼容的提供商均可通过 `opencode.json` 添加。凭据由命令
`/connect` 单独存储。

<Steps>

<a id="simpan-kredensial"></a>

### 保存凭据

在 OpenCode 中运行 `/connect`，滚动至 **Other**，填写提供商 ID `hostlinku`，然后粘贴
API 密钥 `sk-…`。密钥存储在 `~/.local/share/opencode/auth.json` 中。

```text
/connect  →  Other  →  provider id: hostlinku  →  API key: sk-…
```

<a id="definisikan-provider"></a>

### 定义提供商

在项目根目录下创建/修改 `opencode.json`（或全局路径 `~/.config/opencode/opencode.json`）：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "hostlinku": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Hostlinku",
      "options": {
        "baseURL": "https://api.hostlinku.com/v1"
      },
      "models": {
        "claude-sonnet-4-6": {
          "name": "Claude Sonnet 4.6",
          "limit": { "context": 1000000, "output": 64000 }
        },
        "gpt-5-5": {
          "name": "GPT-5.5",
          "limit": { "context": 1000000, "output": 64000 }
        },
        "deepseek-v4-flash": {
          "name": "DeepSeek V4 Flash",
          "limit": { "context": 1000000, "output": 32000 }
        }
      }
    }
  },
  "model": "hostlinku/claude-sonnet-4-6",
  "small_model": "hostlinku/deepseek-v4-flash"
}
```

`opencode.json` 中的提供商 ID **必须与**在 `/connect` 时输入的完全一致。
`models` 中的密钥是 Hostlinku 的 slug；`limit` 有助于 OpenCode 计算剩余配额。

<a id="pilih-model"></a>

### 选择模型

运行 `/models` — 包含你注册的模型的 **Hostlinku** 组将显示出来。`small_model`
用于轻量级任务（会话标题、摘要），从而使长时间会话更节省资源。

</Steps>

<a id="variasi-konfigurasi"></a>

<a id="配置选项"></a>

## 配置变体

**环境变量中的 API 密钥**（不含 `/connect`）：

```json
{
  "provider": {
    "hostlinku": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Hostlinku",
      "options": {
        "baseURL": "https://api.hostlinku.com/v1",
        "apiKey": "{env:HOSTLINKU_API_KEY}"
      }
    }
  }
}
```

**通过 Responses API** - 将 `npm` 替换为 `@ai-sdk/openai`；OpenCode 将使用
[`/v1/responses`](/zh/responses)。若需获取 GPT-5.x 模型的 *推理摘要*，此接口非常有用。
对于大多数用户而言，`@ai-sdk/openai-compatible`（Chat Completions）已足够。

<Callout type="note" title="采用交织推理的模型">
  返回 `reasoning_content` 的模型（例如 DeepSeek V4、GLM 5）可在其模型定义中添加选项
  `"reasoning": true` 和 `"interleaved": { "field": "reasoning_content" }`
  ，以便 OpenCode 显示其推理路径。
</Callout>

<a id="troubleshooting"></a>

## 故障排除

- **提供商未出现在 `/models` 中** - `/connect` 和 `opencode.json` 中的 ID 不一致，或者 JSON
  无效。请检查 `opencode auth list`。
- **`401`** - 该 ID 尚未保存密钥；请重试 `/connect`。
- **`404 model_not_found`** - `models` 键必须与 `GET /v1/models` 中的 slug 完全一致。
