[Droid](https://docs.factory.ai/cli/byok/overview) —— Factory 的代理编码工具 —— 支持 **BYOK
自定义模型**。自定义模型从 `~/.factory/settings.json` 读取，并在 Droid CLI 以及
Factory 桌面应用程序中可用（不适用于 Factory 网页/移动平台）。API 密钥保存在本地，不会发送
至 Factory 服务器。

<Steps>

<a id="simpan-api-key-di-environment"></a>

<a id="将-api-密钥保存到环境变量中"></a>

### 将 API 密钥保存在环境中

```bash
export HOSTLINKU_API_KEY=sk-your-api-key
```

将其添加到 `~/.zshrc` / `~/.bashrc` 中以永久生效。Droid 从 `settings.json` 中读取 `${HOSTLINKU_API_KEY}`
的引用。

<a id="daftarkan-model-di-settingsjson"></a>

### 在 settings.json 中注册模型

打开（或创建）`~/.factory/settings.json`，然后添加 `customModels`：

```json
{
  "customModels": [
    {
      "model": "claude-sonnet-4-6",
      "displayName": "Claude Sonnet 4.6 (Hostlinku)",
      "baseUrl": "https://api.hostlinku.com",
      "apiKey": "${HOSTLINKU_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 64000
    },
    {
      "model": "gpt-5-5",
      "displayName": "GPT-5.5 (Hostlinku)",
      "baseUrl": "https://api.hostlinku.com/v1",
      "apiKey": "${HOSTLINKU_API_KEY}",
      "provider": "generic-chat-completion-api",
      "maxOutputTokens": 64000
    },
    {
      "model": "deepseek-v4-flash",
      "displayName": "DeepSeek V4 Flash (Hostlinku)",
      "baseUrl": "https://api.hostlinku.com/v1",
      "apiKey": "${HOSTLINKU_API_KEY}",
      "provider": "generic-chat-completion-api",
      "maxOutputTokens": 32000
    }
  ]
}
```

| `provider` | API 格式 | Base URL Hostlinku |
|---|---|---|
| `anthropic` | Anthropic 消息 | `https://api.hostlinku.com`（不带 `/v1`） |
| `generic-chat-completion-api` | OpenAI 聊天补全 | `https://api.hostlinku.com/v1` |

<a id="pilih-model-di-droid"></a>

<a id="在droid上选择机型"></a>

### 在 Droid 中选择机型

运行 `droid`，输入 `/model`，然后在 **自定义模型** 部分选择模型（名称与
`displayName` 一致）。首次请求将显示在控制台 → **请求日志** 中。

</Steps>

<a id="yang-perlu-diketahui"></a>

<a id="需知事项"></a>

## 注意事项

<Callout type="tip" title="通过 Anthropic 提供商提供的 Claude 模型">
  提供商 `anthropic` 使用 Messages API，因此 `cache_control` 会被传递，且提示缓存
  功能完全有效。您可以在 Droid 中通过 `/cost` 或请求日志中的 *cache* 列查看节省情况。
</Callout>

- **GPT 及其他模型**（DeepSeek、GLM、Qwen、Kimi）通过
  `generic-chat-completion-api` 实现。Droid 中的 `openai` 提供商使用 Responses API；Hostlinku
  以 *无状态* 方式提供 Responses 服务（[详情](/zh/responses)），因此如有疑问，请选择 Chat Completions。
- **`maxOutputTokens`** 请勿超过 [目录](/zh/models) 中模型的输出限制。
- **通用提供商的提示缓存**取决于目标模型。

<a id="troubleshooting"></a>

## 故障排除

| 症状 | 解决方案 |
|---|---|
| “Model”未出现在 `/model` 中 | JSON 无效或 `provider` 拼写错误——请使用 `jq . ~/.factory/settings.json` 进行检查。 |
| 未找到 Error 变量 | `HOSTLINKU_API_KEY` 尚未在运行 `droid` 的 shell 中导出。 |
| 所有请求中的 `404` | Base URL 混淆：`anthropic` 缺少 `/v1`，`generic-chat-completion-api` 包含 `/v1`。 |
| `404 model_not_found` | `model` 必须与 `GET /v1/models` 中的 slug 完全一致。 |
