[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) 是 DeepSeek 推出的开源 AI
编程代理。在您选择的本地工作区目录中，`dsh` 可以通过 Web 界面、无头模式（headless）、SDK 或 ACP 读取文件、
修改代码、运行命令并完成多步骤任务。

`dsh` 使用 **Anthropic Messages** 协议。Hostlinku 在
[`POST /v1/messages`](/zh/anthropic-messages) 原生提供该端点，因此只需设置两个环境变量即可将 `dsh` 指向
Hostlinku - 无需额外代理或插件。

<Callout type="note" title="已验证版本">
  本指南已使用 `@deepseek-ai/dsh` **0.2.1-rc.5** 完成端到端验证（无头模式下代理通过工具调用读取文件并返回最终答案）。
  DeepSeek Harness 目前处于 *development preview* 阶段，后续版本可能会调整配置文件路径或参数行为。
</Callout>

## 开始之前

- **最新的 Node.js LTS 版本** (`node --version`)。`dsh` 包含数百个依赖项，首次安装可能需要 1-3 分钟。
- **Hostlinku API 密钥** (`sk-…`)，在 [console.hostlinku.com](https://console.hostlinku.com) → **API Keys** 创建。
- **充足的账户余额**或该密钥的可用额度。
- **安全的测试文件夹。** 启动 `dsh` 时所在的目录会成为其默认工作区。请勿直接在主目录（home）或包含敏感数据的文件夹中启动。

<Steps>

### 安装 DeepSeek Harness

```bash
npm install -g @deepseek-ai/dsh
dsh --version
```

或者不全局安装直接运行：`npx @deepseek-ai/dsh web`。

### 指向 Hostlinku

`dsh` 从 `DEEPSEEK_BASE_URL` 读取端点地址，从 `DEEPSEEK_API_KEY` 读取 API 密钥。

**macOS / Linux / WSL**（可保存在 `~/.zshrc` 或 `~/.bashrc`）：

```bash
export DEEPSEEK_BASE_URL=https://api.hostlinku.com
export DEEPSEEK_API_KEY=sk-your-api-key
```

**Windows PowerShell：**

```powershell
$env:DEEPSEEK_BASE_URL = "https://api.hostlinku.com"
$env:DEEPSEEK_API_KEY  = "sk-your-api-key"
```

`dsh` 会自动拼接 `/v1/messages`。基础 URL 填写 `https://api.hostlinku.com/v1` 同样有效（末尾的 `/v1` 会被复用，不会重复拼接）。

### 配置模型与最大输出上限

`dsh` 默认内置的模型名（`deepseek-flash`）不是 Hostlinku 目录中的模型标识符，且 `dsh` 默认发送
`max_tokens: 256000` - 超过了大多数模型的输出上限。请在主目录补丁文件 `~/.dsh/cordis.patch.yml`（如果设置了
`DSH_HOME`，则为 `$DSH_HOME/cordis.patch.yml`）中同时配置这两项：

```yaml
- id: agent-default-model
  config:
    provider: deepseek-official
    model: deepseek-v4-flash
- id: llm-deepseek
  config:
    apiKeyEnv: DEEPSEEK_API_KEY
    maxTokens: 32000
```

<Callout type="important" title="补丁会替换整个 config 块">
  Cordis 补丁不会逐字段合并 - 补丁中的 `config` 块会**完整替换**默认配置块。因此必须同时保留
  `provider: deepseek-official` 和 `apiKeyEnv`，否则 `dsh` 启动时会报错 `$.provider missing required value`。
</Callout>

### 运行

使用无头模式快速测试（执行单个任务、打印最终答案并退出）：

```bash
mkdir dsh-test && cd dsh-test
echo "the secret word is PINEAPPLE" > hello.txt
dsh --profile headless "Read hello.txt and reply with only the secret word."
```

预期输出：`PINEAPPLE`。这表明代理已成功通过 Hostlinku 调用文件读取工具并返回答案。如需在浏览器中使用完整 Web 界面：

```bash
dsh web
```

### 验证

打开控制台 → **请求日志**。来自 `dsh` 的请求会显示您选择的模型、Token 用量、费用以及所使用的 API 密钥。

</Steps>

## 推荐模型

`model` 字段可以填写[模型目录](/zh/models)中支持工具调用的任意模型标识符（slug）。您可以通过 `GET /v1/models`
查看当前密钥可用的模型列表。

| 使用场景 | 模型标识符 (Slug) | 说明 |
|---|---|---|
| 日常默认，快速且高性价比 | `deepseek-v4-flash` | 1M 上下文，支持推理与工具调用。 |
| 需要图片输入（截图、架构图） | `deepseek-v4-1-flash` | 支持视觉（Vision）。 |
| 复杂任务 / 大规模重构 | `deepseek-v4-pro` | 1M 上下文，深度推理能力更强。 |
| 开源权重替代方案 | `kimi-k2-7-code`, `glm-5-3` | 支持工具调用与推理。 |

<Callout type="tip" title="根据模型调整 maxTokens">
  `maxTokens` 是单次请求的最大输出上限，而非上下文窗口大小。`32000` 对绝大多数模型都是安全值。各模型的最大输出上限
  （例如 `deepseek-v4-flash` 为 `131072`）可在对应模型的目录详情页查看。
</Callout>

## 安全建议

- 任务运行期间，用户提示词、代码片段、文件内容及工具执行结果会发送至 Hostlinku 进行推理。未经授权，请勿在包含商业机密或个人隐私数据的项目上运行 `dsh`。
- 建议为 `dsh` 创建带额度上限的**独立 API 密钥**，一旦泄露可随时单独撤销。参见[认证](/zh/authentication)。
- 请勿将明文 API 密钥直接写入 `cordis.patch.yml`。`apiKeyEnv` 仅保存环境变量的**名称**，真实密钥仍从终端环境中读取。

## 故障排除

| 现象 | 原因与解决方法 |
|---|---|
| `INVALID_REQUEST: max_tokens (256000) exceeds the output limit of model …` | 未设置 `maxTokens`。请在 `llm-deepseek` 块中添加 `maxTokens: 32000`。 |
| `startup failed … $.provider missing required value` | 补丁中的 `agent-default-model` 块缺少 `provider` 字段。请按上方示例完整填写。 |
| `MISSING_CREDENTIAL` | 运行 `dsh` 的终端中未导出 `DEEPSEEK_API_KEY`。 |
| `401` / *invalid API key* | 密钥错误、已撤销或已过期。请在控制台创建新密钥。 |
| `404 model not found` | 模型标识符拼写错误或仍为默认的 `deepseek-flash`。请从 `GET /v1/models` 复制准确的模型标识符。 |
| 图片附件上传失败 | `dsh` 会先尝试通过 `/v1/files` 上传文件，随后自动回退为内联 base64 图片发送。请确保所选模型支持视觉功能（如 `deepseek-v4-1-flash`）。 |
