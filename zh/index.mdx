Hostlinku通过一个网关提供OpenAI Chat Completions、Anthropic Messages和Responses API。每个API密钥绑定**Performance**、**Low-Cost**或**Dedicated** Service Mode，模型和价格随该模式而定。

## 第一个请求

在[Console](https://console.hostlinku.com)注册、为组织充值并创建API密钥。从密钥目录选择模型slug，必要时替换示例。[完整入门指南](/zh/getting-started)。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-5","messages":[{"role":"user","content":"Hello"}]}'
```
