**Hostlinku** 是提供 OpenAI Chat Completions、Anthropic Messages 和 Responses API 格式的 AI 网关。参数与能力支持取决于模型和端点。API 密钥访问创建时选择的 **Service Mode** 目录：**Performance**、**Low-Cost** 或 **Dedicated**。最新模型和价格请查看 [模型目录](/zh/models) 及目标密钥的 `GET /v1/models`。

使用 Hostlinku，您无需为每个提供商分别管理账户、API 密钥和不同的请求格式：

- **一个API密钥**访问所选 Service Mode 的模型（`sk-…`）。
- **兼容 OpenAI**：使用官方 SDK OpenAI（`openai-python`、`openai-node`）时，只需将 `base_url` 替换掉即可。
- **SSE 流式传输**：以 `text/event-stream` 格式（如 OpenAI）返回逐个Token的响应。
- **集中式模型目录**：将别名、每Token价格、上下文和功能集中在一个地方。
- **使用控制**：每个 API 密钥的额度限制、请求历史记录以及控制台中的完整日志。
- **预付充值**：通过 QRIS/Virtual Account（iPaymu Direct）或加密货币（Heleket 托管支付）为组织充值。服务信用记账单位为 **1信用额度 = $1**。

## 简要架构

```text
你的应用程序
    │  Authorization: Bearer sk-…
    ▼
api.hostlinku.com  ──►  Gateway Hostlinku  ──►  Routing & failover
(v1/chat/completions)        │                        │
                             │                        ├─► OpenAI
                             ├─ Reservasi saldo       ├─► Anthropic
                             ├─ Telemetri & log       ├─► Google
                             └─ Commit biaya nyata    └─► …dan lainnya
```

请求经过API密钥认证、限额检查、余额预留和模型服务转发，结束后依据上游usage结算费用；缺少usage时可能使用估算值，并记录遥测数据。

控制台 Hostlinku (`console.hostlinku.com`) 使用相同的后端：API 密钥、余额、请求历史记录和审计日志均来自真实的数据网关。
