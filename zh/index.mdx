Hostlinku 通过一个网关提供 OpenAI 聊天补全、Anthropic 消息和响应 API。API 密钥与 **Performance**、**Low-Cost** 或 **Dedicated** 服务模式绑定；模型和价格随该模式而定。

<a id="request-pertama"></a>

<a id="第一个请求"></a>

## 首次请求

在 [Console](https://console.hostlinku.com) 注册，充值组织余额，然后创建 API 密钥。以下示例使用了密钥目录中的模型；如有必要，请替换 slug。[完整指南](/zh/getting-started)。

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-5","messages":[{"role":"user","content":"Hello"}]}'
```
