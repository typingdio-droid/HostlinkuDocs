请使用 API 密钥访问网关端点。位于 `/api/*` 下的 Console 账户端点使用登录会话。对参数、视觉、推理、缓存和工具调用的支持应遵循其模型及协议路径。

| 端点 | 用途 | 指南 |
|---|---|---|
| `GET /v1/models` | 服务模式关键术语目录 | [Models](/zh/models) |
| `POST /v1/chat/completions` | 聊天和 SSE 流媒体 | [聊天补全](/zh/chat-completions) |
| `POST /v1/messages` | Anthropic 格式消息 | [Anthropic Messages](/zh/anthropic-messages) |
| `POST /v1/messages/count_tokens` | 免费计算 Anthropic 格式的令牌 | [计数令牌](/zh/anthropic-messages) |
| `POST /v1/responses` | 无状态响应 | [API 响应](/zh/responses) |

<a id="base-url-dan-autentikasi"></a>

<a id="base-url与认证"></a>

## 基础 URL 和身份验证

OpenAI SDK 使用 `https://api.hostlinku.com/v1`；Anthropic SDK 使用 `https://api.hostlinku.com`。网关接受 `Authorization: Bearer sk-your-api-key` 或 `x-api-key`。 请参阅 [身份验证](/zh/authentication)。

<a id="kompatibilitas-model-dan-tool"></a>

<a id="模型与工具兼容性"></a>

## 模型和工具的兼容性

密钥目录中出现的 Slug 可在支持的端点上使用。格式兼容性并不保证每个客户端都能支持所有功能。请检查 [响应](/zh/responses) 的限制以及 [所使用的集成](/integrations)。

<a id="kuota-bersama-organisasi"></a>

<a id="rate-limiting"></a>

## 速率限制

以下配额按 **组织 × 服务模式** 计算。同一组织下的所有 API 密钥和成员共享配额；增加密钥或成员不会增加配额。

| 限制类型 | 默认配额 | 说明 |
|---|---:|---|
| RPM（请求/分钟） | 600 | 按组织和服务模式计算，而非按型号计算。 |
| Input TPM（令牌/分钟） | 6,500,000 | 根据组织和服务模式下记录的输入令牌进行计算。 |
| Output TPM（令牌/分钟） | 200,000 | 根据组织和服务模式下记录的输出令牌进行计算。 |

- 请求配额在请求被接收时开始计算。输入和输出令牌在响应完成后记录；正在处理的请求不会被中断。
- 登录、控制台和结账各自采用独立的每 IP 限制；请参阅 [使用情况与限制](/zh/usage-and-limits)。
- 如果超出配额，网关将返回`429 RATE_LIMITED`。如有可用，请使用`Retry-After`或`retry-after-ms`，减少并发请求，并采用带抖动的指数退避策略。
- 需要更高的容量吗？请联系 [支持](/zh/support)。

<a id="error-codes"></a>

## 错误代码

错误格式遵循端点规范；处理程序之前的失败可使用 Hostlinku 的通用封装格式。错误代码列表及处理方法详见 [Error](/zh/errors)。 特定格式请参见 [Anthropic Messages](/zh/anthropic-messages#format-error) 和 [Responses](/zh/responses#format-error)。

<a id="query-available-models"></a>

## 查询可用模型

`GET /v1/models` 返回服务模式密钥对应的模型及其价格。网站目录使用 `GET /api/public/models-v2`。请参阅 [模型](/zh/models) 以了解列表、功能以及如何解读定价。

<a id="biaya-dan-streaming"></a>

<a id="费用与流式传输"></a>

## 费用和流媒体

非流式聊天响应包含 `hostlinku.cost` 和 `hostlinku.latencyMs`。流式传输完成后，请在“日志/分析/计费”中查看费用；不要期望每个数据块都会产生费用。如有，请记录 `x-request-id`。 [计费与余额](/zh/billing)。

<a id="arti-metrik-dan-contoh-angka"></a>

<a id="指标与示例数值"></a>

## 指标的含义和数值示例

| 指标 | 含义 |
|---|---|
| `hostlinku.latencyMs` | 从网关接收请求到响应完成所花费的时间。 |
| TTFT | 在流中观察到第一个令牌所需的时间；在非流式传输中可以为空。 |
| TPS | 从符合条件的样本流中，在第一个令牌之后每秒输出的令牌数。 |

- **着陆页动画**使用固定的示例数字；动画中的数字并非在播放时根据请求推断得出。
- **模型详细信息中的 60 根柱状图** 由延迟的平均值/P95 值和故障次数的聚合数据构成。每根柱状图均为综合可视化结果，并非单个请求或连续探针的数据。Console 的使用情况图表使用请求数据的聚合结果。
- **Badge footer landing** 采用固定状态；请查看 [状态](https://status.hostlinku.com) 以获取监控结果和事件信息。
- **Reachable** 指 HTTP 响应代码小于 500，包括 401/403/404。此检查用于验证端点的可达性；登录成功与推断结果则通过各自的函数进行验证。

请比较同一时间段、同一服务模式和同一样本的指标。动画结果、容量规格、流量汇总和基准测试的数据来源各不相同。
