网关端点使用API密钥，Console账户的`/api/*`端点使用登录会话。参数、vision、reasoning、cache和tool calling支持取决于模型与协议路径。

| 端点 | 用途 | 指南 |
|---|---|---|
| `GET /v1/models` | 密钥Service Mode的模型目录 | [Models](/zh/models) |
| `POST /v1/chat/completions` | 聊天与SSE流式传输 | [Chat Completions](/zh/chat-completions) |
| `POST /v1/messages` | Anthropic格式消息 | [Anthropic Messages](/zh/anthropic-messages) |
| `POST /v1/messages/count_tokens` | 免费计算Anthropic格式token数 | [Count tokens](/zh/anthropic-messages) |
| `POST /v1/responses` | 无状态Responses | [Responses API](/zh/responses) |

## Base URL与认证

OpenAI SDK使用`https://api.hostlinku.com/v1`，Anthropic SDK使用`https://api.hostlinku.com`。网关接受`Authorization: Bearer sk-your-api-key`或`x-api-key`。参见[认证](/zh/authentication)。

## 模型与工具兼容性

请在支持的端点上使用密钥目录中的slug。格式兼容不保证所有客户端功能。查看[Responses限制](/zh/responses)和[集成指南](/zh/integrations)。

## 组织共享配额

每个Service Mode每分钟有**600请求、6,500,000输入token和200,000输出token**的配额，由组织的所有成员和API密钥共享。登录、Console和checkout另有独立的IP限额。参见[用量与限额](/zh/usage-and-limits)。

## 错误代码

错误格式随端点而定；到达端点处理器前的错误可能采用Hostlinku通用格式。代码与处理方式见[Error](/zh/errors)，专用格式见[Anthropic Messages](/zh/anthropic-messages)和[Responses](/zh/responses)。

## 查询可用模型

`GET /v1/models`返回密钥Service Mode的模型和价格。网站目录使用`GET /api/public/models-v2`。能力和价格说明见[模型](/zh/models)。

## 费用与流式传输

非流式chat响应包含`hostlinku.cost`和`hostlinku.latencyMs`。流结束后请在Logs / Analytics / Billing查看费用，不要期待每个chunk都包含费用。响应有`x-request-id`时请记录。参见[计费与余额](/zh/billing)。

## 指标与示例数值

| 指标 | 含义 |
|---|---|
| `hostlinku.latencyMs` | 网关收到请求到响应完成的时间。 |
| TTFT | 观察到第一个流式 token 的时间；非流式请求可能为空。 |
| TPS | 符合条件的流式样本中，第一个 token 之后每秒输出 token 数。 |

- **landing动画**使用固定示例数值，并非动画播放时推理请求的测量结果。
- **模型详情60柱图**由平均/P95延迟和失败汇总生成。每根柱为合成展示，不代表按时间排序的请求或probe。Console用量图表使用请求数据汇总。
- **landing页脚徽章**使用固定状态；监控结果与故障请查看[Status](https://status.hostlinku.com)。
- **Reachable**表示低于500的HTTP响应，包括401/403/404。它说明端点可访问；登录和推理是否成功需分别检查相应功能。

请比较同一时间范围、Service Mode和样本的指标。动画、容量规格、流量汇总和benchmark的数据来源各不相同。
