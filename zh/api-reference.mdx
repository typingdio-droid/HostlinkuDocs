基础 URL：`https://api.hostlinku.com`。所有网关端点均位于 `/v1` 之下，并通过 `Authorization: Bearer` **或** `x-api-key` 请求头接收 API 密钥 Hostlinku（`sk-…`）。

## 模型与工具兼容性

请选择 API 密钥 Service Mode 中可用的模型。vision、reasoning、缓存、JSON schema 和 tool calling 取决于模型。原生 Responses 转发 upstream 功能；Chat Completions 桥接支持消息、模型支持的图片和 `type: "function"` 工具。hosted/custom tools 和加密 reasoning 需要原生支持。

## 组织共享配额

同一组织的所有 API 密钥及成员共享此配额。增加密钥或使用其他成员账户不会增加配额。

| Service Mode | 请求/分钟 | 输入 token/分钟 | 输出 token/分钟 |
|---|---|---|---|
| Performance | 600 | 6,500,000 | 200,000 |
| Low-Cost | 600 | 6,500,000 | 200,000 |
| Dedicated | 600 | 6,500,000 | 200,000 |

配额及 429 处理见[用量与限额](/zh/usage-and-limits)。

Console、登录和 checkout 端点按 IP 限制，与模型使用配额分别计算。

## Anthropic Messages API 格式

`POST /v1/messages`

以原生格式 Anthropic 调用模型。请求头必须包含 `x-api-key: YOUR_API_KEY`（或 `Authorization: Bearer`）。 适用于 Anthropic SDK、Claude Code、Cursor 和 Cline - 只需设置 `ANTHROPIC_BASE_URL=https://api.hostlinku.com` 即可。完整文档：[Anthropic Messages](/zh/anthropic-messages)。

### 请求正文参数

| 参数 | 类型 | 描述 | 必填 |
|---|---|---|---|
| `model` | 字符串 | 模型为Hostlinku的螺纹杆，例如`claude-sonnet-4-6` | true |
| `messages` | 数组 | 对话消息数组（`role`：`user` \| `assistant`） | true |
| `max_tokens` | 整数 | 最大输出Token数量 | true |
| `system` | 字符串 \| 数组 | 系统提示（块数组支持 `cache_control`） | false |
| `stream` | 布尔型 | SSE流式传输，默认`false` | false |
| `tools`, `tool_choice`, `thinking`, `temperature`, `top_p`, `top_k`, `stop_sequences`, `metadata` | - | 符合Anthropic规格 | false |

### 请求示例

```bash
curl --request POST \
  --url https://api.hostlinku.com/v1/messages \
  --header 'content-type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'anthropic-version: 2023-06-01' \
  --data '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "system": "You are a professional coding assistant",
    "messages": [
      { "role": "user", "content": "Write a quicksort in Python" }
    ]
  }'
```

### 响应示例

```json
{
  "id": "msg_mv5ujf05qf6ayfbx",
  "type": "message",
  "role": "assistant",
  "model": "claude-sonnet-4-6",
  "content": [
    { "type": "text", "text": "def quicksort(arr):\n    if len(arr) <= 1:\n        return arr\n    ..." }
  ],
  "stop_reason": "end_turn",
  "stop_sequence": null,
  "usage": {
    "input_tokens": 14,
    "output_tokens": 86,
    "cache_creation_input_tokens": 0,
    "cache_read_input_tokens": 0,
    "cache_creation": { "ephemeral_5m_input_tokens": 0, "ephemeral_1h_input_tokens": 0 }
  },
  "hostlinku": { "cost": 0.0013, "currency": "🪙", "serviceMode": "performance", "latencyMs": 2410 }
}
```

### 流式输出

```bash
curl -N --request POST \
  --url https://api.hostlinku.com/v1/messages \
  --header 'content-type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'accept: text/event-stream' \
  --data '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": [{ "type": "text", "text": "Hello" }] }],
    "stream": true
  }'
```

响应以SSE格式按片段发送：

```text
event: message_start
data: {"type":"message_start","message":{"id":"msg_…","type":"message","role":"assistant","model":"claude-sonnet-4-6","content":[],"stop_reason":null,"usage":{"input_tokens":10,"output_tokens":1}}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"Hello"}}

event: message_delta
data: {"type":"message_delta","delta":{"stop_reason":"end_turn","stop_sequence":null},"usage":{"input_tokens":10,"output_tokens":5}}

event: message_stop
data: {"type":"message_stop"}
```

## OpenAI 协议（Chat Completions API）

`POST /v1/chat/completions`

以 OpenAI Chat Completions 格式调用任意模型。请求头中必须包含 `Authorization: Bearer YOUR_API_KEY`。 OpenAI SDK 只需指向 `base_url="https://api.hostlinku.com/v1"` 即可。完整文档：[Chat Completions](/zh/chat-completions)。

### 请求正文参数

| 参数 | 类型 | 描述 | 必填 |
|---|---|---|---|
| `model` | 字符串 | 模型为Hostlinku的螺杆，例如`gpt-5-5` | true |
| `messages` | 数组 | 对话消息数组（`system` \| `user` \| `assistant` \| `tool`） | true |
| `max_tokens` | 整数 | 最大输出Token数量 | false |
| `stream` | 布尔型 | SSE 流式传输，默认 `false` | false |
| `temperature`, `top_p`, `tools`, `tool_choice`, `response_format`, `reasoning_effort`, `thinking` | - | 符合 OpenAI 规格（+ thinking 扩展） | false |

### 请求示例

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-YOUR_API_KEY" \
  -d '{
    "model": "gpt-5-5",
    "messages": [
      { "role": "user", "content": "Write a quicksort in Python" }
    ],
    "stream": false
  }'
```

### 示例回复

## OpenAI Responses API 格式

`POST /v1/responses`

**Codex CLI**、**OpenAI Agents SDK** 和 `client.responses.create()` 采用的格式。请求头包含 `Authorization: Bearer YOUR_API_KEY`；基础 URL 为 `https://api.hostlinku.com/v1`。 无状态：`store` 始终为 `false`，`previous_response_id` 被 `400` 拒绝 - 请在 `input` 中发送完整历史记录。 完整文档：[Responses API](/zh/responses)。

### 请求正文参数

| 参数 | 类型 | 描述 | 必填 |
|---|---|---|---|
| `model` | 字符串 | 模型为Hostlinku的螺杆，例如`gpt-5-5` | true |
| `input` | 字符串 \| 数组 | 文本，或数组项 `message` / `function_call` / `function_call_output` / `reasoning` | true |
| `instructions` | 字符串 | 系统提示 | false |
| `max_output_tokens` | 整数 | 最大输出Token数量 | false |
| `stream` | 布尔型 | SSE（`event: response.*`）直播，默认 `false` | false |
| `tools`, `tool_choice`, `reasoning`, `include`, `text`, `temperature`, `top_p`, `metadata` | - | 符合OpenAI Responses规格 | false |

### 请求示例

```bash
curl https://api.hostlinku.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-YOUR_API_KEY" \
  -d '{
    "model": "gpt-5-5",
    "instructions": "Be concise.",
    "input": "Write a quicksort in Python",
    "max_output_tokens": 512
  }'
```

### 示例回复

```json
{
  "id": "resp_mv5xpsggbnpc4x7g",
  "object": "response",
  "created_at": 1791850828,
  "status": "completed",
  "model": "gpt-5-5",
  "output": [
    { "id": "rs_…", "type": "reasoning", "summary": [], "encrypted_content": "…" },
    { "id": "msg_…", "type": "message", "status": "completed", "role": "assistant",
      "content": [{ "type": "output_text", "text": "def quicksort(arr): …", "annotations": [] }] }
  ],
  "usage": { "input_tokens": 20, "output_tokens": 95, "total_tokens": 115,
             "input_tokens_details": { "cached_tokens": 0 }, "output_tokens_details": { "reasoning_tokens": 12 } },
  "previous_response_id": null,
  "store": false,
  "hostlinku": { "cost": 0.0011, "currency": "🪙", "serviceMode": "performance", "latencyMs": 1420 }
}
```

### 流式输出

```text

```

## 错误代码

封装错误遵循所调用的端点协议：`/v1/chat/completions` → `{ "status": "error", "error": { "code", "message" } }`；`/v1/messages` → `{ "type": "error", "error": { "type", "message" } }`；`/v1/responses` → `{ "error": { "message", "type", "param", "code" } }`。

| HTTP 状态码 | 描述 | 错误消息示例 |
|---|---|---|
| 400 | 正文无效，`max_tokens` 超出了模型的输出限制，或者 Service Mode API key 中未提供该模型。 | `max_tokens (20000) exceeds the output limit of model 'claude-haiku-4-5' (16000).` |
| 401 | API密钥未发送、无效、已被撤销或已过期。 | `The API key is invalid or has been revoked.` |
| 402 | 余额不足以支付请求的预估费用，或者API密钥的额度已用尽。 | `余额不足。` |
| 403 | 账户已被暂停/访问被拒绝。 | `You do not have access to this resource.` |
| 404 | 该模型的Slug未收录在产品目录中。 | `Model 'xxx' was not found.` |
| 413 | 请求正文超过最大长度。 | `The payload is too large.` |
| 422 | 正文验证失败（仅 `/v1/chat/completions`；`/v1/messages` 和 `/v1/responses` 使用 400）。 | `The request body is invalid.` |
| 429 | 超出速率限制。 | `Rate limit exceeded. Upgrade your plan for a higher limit.` |
| 503 | 模型/上游当前不可用-可以安全地采用退避策略重试。 | `The model is currently unavailable. Please try again later.` |

错误会处理以隐藏内部标识；部分 upstream 拒绝原因仍可能显示。 [Error](/zh/errors).

### 429 响应头

| 响应头 | 描述 |
|---|---|
| `Retry-After` | 建议在再次尝试前等待的时间（秒） |
| `RateLimit-Limit` | 转速限制 |
| `RateLimit-Remaining` | 当前窗口中剩余的请求 |
| `RateLimit-Reset` | 距离下一个窗口开始还有X秒 |

## 重试建议

- `400`、`401`、`402`、`403` 和 `404` 需要修改请求参数或账户余额/状态，不应自动重试。
- `429`、`500`、`502` 和 `503` 可以使用指数退避（exponential backoff）加随机抖动（jitter）进行重试（遇到 `429` 时请遵循 `Retry-After` 响应头）。
- 联系技术支持时请附上响应中的请求 ID（`cmpl_…`、`msg_…` 或 `resp_…`），以便在请求日志中快速排查。

## 安全建议

API 密钥按 Service Mode 和额度授权付费网关访问；账户管理使用 Console 会话。

- 请将 API 密钥保存在服务器端或受保护的本地环境中，通过环境变量（`HOSTLINKU_API_KEY`、`ANTHROPIC_API_KEY`、`OPENAI_API_KEY`）注入，切勿提交到代码仓库。
- 为开发、测试和生产环境分别创建具有独立**额度限制**和**有效期**的不同 API 密钥。
- 若密钥泄露，请立即前往 [Console → API Keys](https://console.hostlinku.com/api-keys) 吊销（Revoke），并在日志与工单中仅保留脱敏格式（如 `sk-****`）。

## 指标与示例数值

| 指标 | 含义 |
|---|---|
| `hostlinku.latencyMs` | 网关收到请求到响应完成的时间。 |
| TTFT | 观察到第一个流式 token 的时间；非流式请求可能为空。 |
| TPS | 符合条件的流式样本中，第一个 token 之后每秒输出 token 数。 |

- **landing动画**使用固定示例数值，并非动画播放时推理请求的测量结果。
- **模型详情60柱图**由平均/P95延迟和失败汇总生成。每根柱为合成展示，不代表按时间排序的请求或probe。Console用量图表使用请求数据汇总。
- **landing页脚徽章**使用固定状态；监控结果与故障请查看[Status](https://status.hostlinku.com)。
- **Reachable**表示低于500的HTTP响应，包括401/403/404。它说明端点可访问；登录和推理是否成功需分别检查相应功能。

请比较同一时间范围、Service Mode和样本的指标。动画、容量规格、流量汇总和benchmark的数据来源各不相同。
