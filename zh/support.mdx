## 支持渠道

| Kanal | 用途 |

| [halo@hostlinku.com](mailto:halo@hostlinku.com) | 技术问题、账户和计费 |

<a id="informasi-untuk-laporan"></a>

<a id="报告所需信息"></a>

## 报告信息

1. `x-request-id`（若在 Console 的响应或日志中出现）。
2. 事件时间（含时区）、端点和模型 slug。
3. HTTP 状态码及错误正文；代码/类型根据 [API 格式](/zh/errors) 有所不同。
4. 可重现的最小请求示例，其中已删除 API 密钥和敏感数据。

```text
Waktu: 2026-11-06 14:32 UTC+7
Request ID: <x-request-id>
Endpoint: /v1/chat/completions
Model: gpt-5-5
HTTP: 503
Error: UPSTREAM_TIMEOUT ("The request timed out. Please retry.")
Catatan: Terjadi 3 kali dalam 10 menit terakhir.
```

<a id="masalah-keamanan"></a>

## 安全问题

请将安全发现私下发送至 [halo@hostlinku.com](mailto:halo@hostlinku.com)，邮件主题请注明 `[SECURITY]`。在问题处理完成前，请勿公开相关细节。支持团队不会索要 API 密钥、密码或 OTP 代码；请勿在报告中包含机密信息。
