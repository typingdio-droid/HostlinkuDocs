## 联系渠道

| 渠道 | 用途 |
|---|---|
| [halo@hostlinku.com](mailto:halo@hostlinku.com) | 技术、账户和计费问题 |
| [Console](https://console.hostlinku.com) | 余额、API密钥、请求日志及审计 |
| [Status](https://status.hostlinku.com) | 正在发生的故障和事件 |

小型团队会在工作日尽快回复邮件（尽最大努力）。事件更新会发布在Status页面。

## 报告所需信息

1. 响应或Console日志中可用的 `x-request-id`。
2. 包含时区的时间、端点和模型slug。
3. HTTP状态和错误正文；代码／类型因 [API格式](/zh/errors) 而异。
4. 去除API密钥及敏感数据的最小可复现请求。

```text
时间: 2026-11-06 14:32 UTC+7
Request ID: <x-request-id>
Endpoint: /v1/chat/completions
Model: gpt-5-5
HTTP: 503
Error: UPSTREAM_TIMEOUT ("The request timed out. Please retry.")
备注: 最近10分钟出现3次。
```

## 安全问题

请将安全发现私下发送至 [halo@hostlinku.com](mailto:halo@hostlinku.com)，主题为 `[SECURITY]`。处理前请勿公开细节。支持团队不会索要API密钥、密码或OTP验证码；报告中请勿包含密钥。
