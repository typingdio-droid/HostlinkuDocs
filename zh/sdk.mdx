一个 API 密钥在三种方言中均有效。唯一的区别仅在于 **基础 URL** 和 **身份验证头**：

| 方言 | 基础 URL | 标题 |
|---|---|---|
| Anthropic 消息 | `https://api.hostlinku.com`（不带 `/v1`） | `x-api-key: <API_KEY>` |
| OpenAI 聊天补全 | `https://api.hostlinku.com/v1` | `Authorization: Bearer <API_KEY>` |
| OpenAI 响应 | `https://api.hostlinku.com/v1` | `Authorization: Bearer <API_KEY>` |

请使用 [目录](/zh/models) 中的 slug 替换模型名称——下文示例中使用的模型
可在“服务模式性能”中找到。

<Callout type="note" title="模型和工具的兼容性">
  选择适用于服务模式 API 密钥的可用模型。对 Vision、JSON 模式、推理和工具调用的支持均遵循该模型及其协议路径。请参阅 [兼容性限制](/zh/responses)。
</Callout>

## Python

<a id="anthropic-messages"></a>

### Anthropic 消息

```bash
pip install anthropic
```

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-your-api-key",
    base_url="https://api.hostlinku.com",
)

message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Jelaskan API gateway dalam dua kalimat."}],
)
print(message.content[0].text)
print(message.usage.input_tokens, message.usage.output_tokens)
```

流媒体：

```python
with client.messages.stream(
    model="claude-sonnet-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

<a id="openai-chat-completions"></a>

### OpenAI 聊天补全

```bash
pip install openai
```

```python
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.hostlinku.com/v1")

response = client.chat.completions.create(
    model="gpt-6-astra",
    messages=[
        {"role": "system", "content": "Kamu asisten yang ringkas."},
        {"role": "user", "content": "Halo dari SDK OpenAI!"},
    ],
)
print(response.choices[0].message.content)
```

流媒体：

```python
stream = client.chat.completions.create(
    model="gpt-6-astra",
    messages=[{"role": "user", "content": "Tulis satu paragraf pendek."}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
```

<a id="openai-responses"></a>

### OpenAI 响应

```python
response = client.responses.create(
    model="gpt-6-astra",
    instructions="Jawab singkat dalam bahasa Indonesia.",
    input="Apa itu API gateway?",
    max_output_tokens=256,
)
print(response.output_text)
```

流媒体：

```python
with client.responses.stream(
    model="gpt-6-astra",
    input="Tulis satu paragraf pendek.",
) as stream:
    for event in stream:
        if event.type == "response.output_text.delta":
            print(event.delta, end="", flush=True)
```

## Node.js / TypeScript

<a id="anthropic-messages-1"></a>

### Anthropic 消息

```bash
npm install @anthropic-ai/sdk
```

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: "sk-your-api-key",
  baseURL: "https://api.hostlinku.com",
});

const message = await client.messages.create({
  model: "claude-sonnet-5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Halo!" }],
});
console.log(message.content[0].text);
```

流媒体：

```ts
const stream = client.messages.stream({
  model: "claude-sonnet-5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Tulis satu paragraf pendek." }],
});

stream.on("text", (text) => process.stdout.write(text));
await stream.finalMessage();
```

<a id="openai-chat-completions-1"></a>

### OpenAI 聊天补全

```bash
npm install openai
```

```ts
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-your-api-key",
  baseURL: "https://api.hostlinku.com/v1",
});

const response = await client.chat.completions.create({
  model: "gpt-6-astra",
  messages: [{ role: "user", content: "Halo!" }],
});
console.log(response.choices[0].message.content);
```

流媒体：

```ts
const stream = await client.chat.completions.create({
  model: "gpt-6-astra",
  messages: [{ role: "user", content: "Tulis satu paragraf pendek." }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
```

<a id="openai-responses-1"></a>

### OpenAI 响应

```ts
const response = await client.responses.create({
  model: "gpt-6-astra",
  input: "Halo!",
  max_output_tokens: 256,
});
console.log(response.output_text);
```

流媒体：

```ts
const stream = await client.responses.create({
  model: "gpt-6-astra",
  input: "Tulis satu paragraf pendek.",
  stream: true,
});

for await (const event of stream) {
  if (event.type === "response.output_text.delta") {
    process.stdout.write(event.delta);
  }
}
```

## 注释

<Callout type="note" title="其他语言">
  Java、Go 和 PHP 采用相同的模式：将 `base_url` 替换为 Hostlinku，然后使用官方的
  Anthropic（消息）或 OpenAI（聊天/响应）SDK。没有专门针对 Hostlinku 的库。
</Callout>

<Callout type="warning" title="每个客户端的限制">
  **Codex CLI 仅适用于 OpenAI 模型**（`gpt-*`）——Claude 模型及其他非 OpenAI 模型
  因工具类型不同而被上游拒绝。 **Claude Code** 可以使用非 Claude 模型，
  但会显示 `unrecognized_model` 警告，并默认上下文长度为 200k 个令牌。
  详情请参阅 [Codex](/zh/integrations/codex-cli) 页面以及
  [Claude Code](/zh/integrations/claude-code) 页面中。
</Callout>
