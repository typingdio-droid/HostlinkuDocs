**Dedicated** 是 Hostlinku 的一种服务模式，适用于该模式下可用的模型集合。在 [Console](https://console.hostlinku.com) 中创建 API 密钥时，请选择 **Dedicated**。该模式与密钥绑定；请求无需使用额外参数来切换模式。

<Callout type="note" title="一个 API 密钥 = 一种服务模式">
若要同时使用“Performance”或“Low-Cost”模式，请创建独立的 API 密钥。可调用的模型和定价遵循服务模式密钥；请使用该密钥查询 `GET /v1/models`。
</Callout>

关于三种模式的对比以及如何选择密钥，请参阅 [服务模式](/zh/service-modes)。

## 端点和身份验证

基础 URL 保持为 `https://api.hostlinku.com`。提供以下 API 格式；部分模型使用桥接器来调整格式。需单独核查是否支持所有供应商功能或应用程序内置工具。

| 格式 | 端点 | 身份验证头 |
|---|---|---|
| OpenAI Chat | `POST /v1/chat/completions` | `Authorization: Bearer <API_KEY>` |
| OpenAI 响应 | `POST /v1/responses` | `Authorization: Bearer <API_KEY>` |
| Anthropic 消息 | `POST /v1/messages` | `x-api-key: <API_KEY>` |

<a id="harga"></a>

## 价格

根据服务模式 API 密钥的使用情况计费。**1 <CreditIcon /> = \$1**。请查看 [专用版定价](https://hostlinku.com/models?mode=dedicated) 或使用专用版密钥调用 `GET /v1/models`。

## 提示缓存

在支持自动缓存的模型中，重复的前缀可在不使用 `cache_control` 的情况下触发缓存命中。命中情况和缓存时长遵循上游规则。缓存使用情况通过 Chat Completions 中的 `cached_tokens` 或 Messages 中的 `cache_read_input_tokens`（如有）进行报告。 参见 [提示词缓存](/zh/prompt-caching)。

<a id="batasan"></a>

## 限制

- 服务模式必须支持“Model”键；不会自动回退到其他模式。
- 功能和输出限制遵循模型及协议。应用程序内置工具未必受桥接器支持。
