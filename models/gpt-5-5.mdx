## Contoh request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5-5",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
