## Ringkasan

GLM-5.1 is Zhipu's flagship text model, with 200K context and 128K max output, strengthened for long-horizon planning, agentic coding, tool use, structured output, context caching, and MCP.

| Properti | Nilai |
|---|---|
| Provider | Zhipu |
| Slug | `glm-5-1` |
| Input | text |
| Output | text |
| Rilis | 2026-06-14 |
| Konteks katalog | 200,000 token |
| Output maks katalog | 128,000 token |
| Service Mode | Performance |

## Kapabilitas

`text`, `tool-calling`, `function-calling`, `structured-outputs`, `json-mode`, `streaming`, `reasoning`, `code-generation`, `long-context`, `multilingual`.

## Endpoint yang didukung

| Endpoint | Format | Dukungan |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | tersedia |
| `POST /v1/messages` | Anthropic Messages | adapted (bridge) |
| `POST /v1/responses` | OpenAI Responses | adapted (bridge) |

Bridge menyesuaikan format API; fitur vendor dan tool bawaan aplikasi dapat berbeda. Gunakan API key dengan Service Mode yang tercantum di atas.

## Contoh request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5-1",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
