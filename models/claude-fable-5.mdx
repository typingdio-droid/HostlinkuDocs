## Ringkasan

Claude Fable 5 is Anthropic's flagship Mythos-class model optimized for long-horizon reasoning, agentic coding, and autonomous workflows. It supports text and image inputs with text output, featuring a 1M-token context window and 128K maximum output.

| Konteks katalog | 1,000,000 token |

| Service Mode | Performance, Low-Cost |

## Endpoint yang didukung

| Endpoint | Format | Dukungan |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | tersedia |
| `POST /v1/messages` | Anthropic Messages | native |
| `POST /v1/responses` | OpenAI Responses | adapted (bridge) |

Bridge menyesuaikan format API; fitur vendor dan tool bawaan aplikasi dapat berbeda. Gunakan API key dengan Service Mode yang tercantum di atas.

## Contoh request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-fable-5",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
