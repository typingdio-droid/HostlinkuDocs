## Harga

| Item | Harga |
|---|---|
| Input (prompt) | $0.2 |
| Output (completion) | $1.2 |
| Cache read | $0.02 |
| Cache write | $0.25 |

Harga adalah harga customer per **1M token** untuk API key Hostlinku, dengan 1 🪙 = $1. Harga aktual per request tetap mengikuti Service Mode API key dan dapat berubah; cek [Console](https://console.hostlinku.com/models) atau `GET /v1/models` untuk nilai yang berlaku.

## Endpoint yang didukung

| Endpoint | Format | Dukungan |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | tersedia |
| `POST /v1/messages` | Anthropic Messages | adapted (bridge) |
| `POST /v1/responses` | OpenAI Responses | native |

Ketersediaan endpoint dan model mengikuti katalog serta Service Mode API key yang dipakai. Jika model tidak tersedia untuk mode tersebut, request dapat ditolak dengan `400 MODEL_NOT_IN_SERVICE_MODE`.

## Contoh request

```bash
curl https://api.hostlinku.com/v1/chat/completions \
  -H "Authorization: Bearer sk-isi-api-key-kamu" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5-6-luna",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```
