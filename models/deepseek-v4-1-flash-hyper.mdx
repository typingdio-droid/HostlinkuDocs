## Ringkasan

DeepSeek-V4.1-Flash is a multimodal mixture-of-experts model built on an asymmetric Causal Encoder–Decoder architecture, with native visual understanding. It supports a 1M-token context window, up to 384K output tokens, thinking and non-thinking modes, tool calls, and structured JSON output. Available in the Hostlinku Dedicated catalog; performance depends on the model and request.

## Endpoint yang didukung

| Endpoint | Format | Dukungan |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI Chat Completions | tersedia |
| `POST /v1/messages` | Anthropic Messages | adapted (bridge) |

Bridge menyesuaikan format API; fitur vendor dan tool bawaan aplikasi dapat berbeda. Gunakan API key dengan Service Mode yang tercantum di atas.
