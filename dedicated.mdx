**Dedicated** adalah salah satu Service Mode Hostlinku untuk kumpulan model yang tersedia pada mode tersebut. Pilih **Dedicated** saat membuat API key di [Console](https://console.hostlinku.com). Mode melekat pada key; request tidak memakai parameter tambahan untuk mengganti mode.

<Callout type="note" title="Satu API key = satu Service Mode">
Untuk memakai Performance atau Low-Cost secara bersamaan, buat API key terpisah. Model yang dapat dipanggil dan harga mengikuti Service Mode key; periksa `GET /v1/models` memakai key tersebut.
</Callout>

Perbandingan ketiga mode dan cara memilih key tersedia di [Service Mode](/service-modes).

## Endpoint dan autentikasi

Base URL tetap `https://api.hostlinku.com`. Format API berikut tersedia; beberapa model memakai bridge untuk menyesuaikan format. Dukungan semua fitur vendor atau tool bawaan aplikasi perlu diperiksa tersendiri.

| Format | Endpoint | Header autentikasi |
|---|---|---|
| OpenAI Chat | `POST /v1/chat/completions` | `Authorization: Bearer <API_KEY>` |
| OpenAI Responses | `POST /v1/responses` | `Authorization: Bearer <API_KEY>` |
| Anthropic Messages | `POST /v1/messages` | `x-api-key: <API_KEY>` |

## Harga

Ditagih berdasarkan penggunaan pada Service Mode API key. **1 <CreditIcon /> = \$1**. Cek [tarif Dedicated](https://hostlinku.com/models?mode=dedicated) atau `GET /v1/models` dengan key Dedicated.

## Prompt caching

Pada model yang mendukung auto-cache, prefix berulang dapat menghasilkan cache hit tanpa `cache_control`. Hit dan masa cache mengikuti upstream. Penggunaan cache dilaporkan melalui `cached_tokens` pada Chat Completions atau `cache_read_input_tokens` pada Messages bila tersedia. Lihat [Prompt Caching](/prompt-caching).

## Batasan

- Model harus tersedia untuk Service Mode key; tidak ada fallback otomatis ke mode lain.
- Fitur dan batas output mengikuti model serta protokol. Tool bawaan aplikasi belum tentu didukung oleh bridge.
